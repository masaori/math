# インフラ

アプリケーションを動かすインフラ（クラウドリソース、ネットワーク、権限等）の方針。
言語・フレームワークの選定（[言語選択](./language-selection.md)）とは別の軸として定める。

## Infrastructure as Code

- **インフラは Terraform で記述する**。コンソールでの手動構築をやめ、構成をコード化してレビュー・再現を可能にする。
- 選定したリソース（コンピュート / DB / ストレージ / ネットワーク / 権限等）は必ず Terraform に落とし、コンソールでの手動操作を残さない。
- Terraform の定義は monorepo の `infra/` に置く（[アーキテクチャ概要](./architecture-overview.md) のモノレポ構成を参照）。

## クラウドベンダー

- **クラウドベンダーはプロジェクトによる** が、**特に指定がなければ Google Cloud を使用する**。
- ベンダー固有のサービス選定はプロジェクトごとに決める。決めた結果は上記のとおり Terraform に落とす。
