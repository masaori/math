# 行列式と permanent の非対称

計算複雑性の側の事実を整理し、**どこまでが正しい主張か**の境界を引く。

## 二つの母関数

$n\times n$ 行列 $A=(a_{ij})$ に対し、

$$
\det A=\sum_{\pi\in S_n}\mathrm{sgn}(\pi)\prod_i a_{i\pi(i)},
\qquad
\mathrm{per}\,A=\sum_{\pi\in S_n}\prod_i a_{i\pi(i)}.
$$

**違いは $\mathrm{sgn}(\pi)\in\{-1,+1\}$ の有無だけである。**
それだけで計算複雑性が変わる。

| | $\det$ | $\mathrm{per}$ |
|---|---|---|
| 厳密計算 | $O(n^3)$（Gauss 消去） | **#P 完全**（Valiant 1979、$0/1$ 行列でも） |
| 帰属（整数成分） | $\mathbb{Z}$ | $\mathbb{Z}$ |
| 非負成分の近似 | — | **FPRAS あり**（Jerrum–Sinclair–Vigoda 2004） |
| 複素成分の近似 | — | **困難**（Aaronson–Arkhipov 2011 の中身） |

**Gauss 消去が効くのは符号があるからである。** 行の一次結合で消去できるのは
$\det$ が交代形式だからで、$\mathrm{per}$ には対応する操作がない。

## 物理との対応

| | フェルミオン | ボソン |
|---|---|---|
| 多体波動関数 | Slater 行列式 | permanent |
| 統計性 | 反対称（反可換） | 対称（可換） |
| 分配関数（自由な場合） | 行列式 | permanent ／ 無限積 |
| サンプリング問題 | 古典的に効率的 | **古典的に困難**（boson sampling） |

**fermion sampling が古典計算機で効率的にでき、boson sampling ができない**というのが、
量子超越性の実験提案の理論的背景である。
すなわち**この非対称は既に量子計算の分野で中心的な事実として使われている。**

本ノートの内容が新しくない可能性は、ここから見ても高い。

## 正確に言うために要る限定

### ボソン側の限定

「ボソン＝計算困難」は**言い過ぎ**である。

- **非負成分なら近似できる**（JSV の FPRAS）。統計力学の重みは正なので、
  多くの物理的状況では近似可能な側に入る
- 困難なのは**厳密計算**と、**複素成分（干渉がある場合）の近似**である
- 自由ボソン場の分配関数は無限積の閉形式で書ける場合があり、
  「困難」の一言では片付かない

したがって正確には：

> **ボソンの母関数は、厳密には #P 完全であり、複素成分では近似も困難である。**

### フェルミオン側の限定

「フェルミオン＝可算側」も無条件ではない。

- **自由フェルミオン（二次形式）**なら行列式・Pfaffian で閉じる。相互作用があると閉じない
- **Kasteleyn の Pfaffian 法は平面性に依存する。** 非平面格子（3 次元 Ising、
  平面でないグラフ上の Ising）では効かない。実際 3 次元 Ising は #P 困難である ［要確認：正確な主張］
- 「フェルミオンだから簡単」ではなく、**「二次形式だから簡単」**が正しい

したがって正確には：

> **自由（二次形式の）フェルミオン、または平面グラフ上の Ising 型の模型では、
> 分配関数が整係数の行列式・Pfaffian として書け、多項式時間で厳密に計算できる。**

**この限定を落とすと主張が誤りになる。** 3 次元 Ising が困難であることは、
「フェルミオンなら可算側」という素朴な主張の反例そのものである。

## それでも残る非対称

限定を入れたうえで、なお言えることがあるか。

**表現の有限性**は限定なしに成り立つ。

- 有限モードのフェルミオン Fock 空間は**有限次元**（$2^n$）。
  相互作用があっても有限次元のまま
- 有限モードのボソン Fock 空間は**無限次元**。占有数に上限がないため

これは計算複雑性ではなく**次元の問題**であり、限定を要しない。
そして可算性の観点では決定的である。有限次元なら固有値は代数的数で `QQbar` に載るが、
無限次元では最初から作用素論が要る。

> **フェルミオン系は、相互作用があっても有限モードなら有限次元線形代数に留まる。
> ボソン系は自由でも無限次元である。**

これが**限定なしに言える非対称**であり、主張の核になりうる部分だと思われる。
ただし、これも既知である可能性が高い ［要調査］。
