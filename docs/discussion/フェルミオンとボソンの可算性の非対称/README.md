# フェルミオンとボソンの可算性の非対称

**フェルミオンは可算側にネイティブで、ボソンはそうではない**——
この非対称を主張の形にできるか、という研究ノート。

## 出発点

[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の
「統計力学と量子力学は同じものを別の入口から見ている」の節に、フェルミオン側は既に書かれている。

> 反可換性は $\mathbb{Z}$ の中の符号の構造であり、$\mathbb{R}$ を必要としない。

- Jordan–Wigner / Clifford 代数の中身は**置換の符号**
- Kac–Ward・Kasteleyn 経路では Pfaffian と行列式、すなわち**整数係数の組合せ量**
- 有限格子の Grassmann 積分は**有限次元外積代数の係数抽出**であって解析的な積分ではない

**本ノートが付け加えるのは、ボソンとの対比である。**

物理ではフェルミオンとボソンは対等な二種類として並べられる。
しかし可算性の観点では**対等ではない**。

## 非対称の内容

| | フェルミオン | ボソン |
|---|---|---|
| 母関数 | 行列式・Pfaffian | permanent |
| 厳密計算の複雑性 | **多項式時間** | **#P 完全**（Valiant 1979） |
| 1 モードの占有数 | 有限（$0$ または $1$） | **非有界** |
| Fock 空間（有限モード） | **有限次元**（$2^n$） | **無限次元** |
| 母関数を閉じるのに要るもの | 有限和 | **等比級数＝収束＝$\mathbb{R}$** |
| 値の帰属（整数重み） | $\mathbb{Z}$ | $\mathbb{Z}$ だが計算が困難 |

**「非可算が要る／要らない」ではなく、二段階の非対称がある**ことに注意する。

1. **表現の有限性**：フェルミオンの Fock 空間は有限モードなら有限次元、ボソンは無限次元。
   これは $\mathbb{R}$ 以前に**有限性の問題**である
2. **計算複雑性**：行列式は多項式時間、permanent は #P 完全。
   これは帰属の問題ではなく**可解性の問題**である

[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の
「帰属・計算可能性・可解性は独立な軸である」に照らすと、
**この非対称は帰属の軸ではなく、有限性と可解性の軸に現れている。**
ここを混同すると主張が崩れる。

## 慎重に扱うべき点

**「ボソン＝ #P 完全だから可算側で扱えない」は言い過ぎである。**

- Jerrum–Sinclair–Vigoda (2004) により、**非負成分行列の permanent には FPRAS がある**。
  近似は可能である
- 困難なのは（a）厳密計算と、（b）**複素・負成分**の permanent である。
  後者は boson sampling の困難性（Aaronson–Arkhipov 2011）の中身でもある
- したがって正確な主張は「permanent は難しい」ではなく、
  **「厳密には #P 完全、複素成分では近似も困難」**である

同様に、フェルミオン側も無条件ではない。

- 自由フェルミオン（二次形式）は行列式で閉じるが、**相互作用があると行列式では書けない**
- Kasteleyn の Pfaffian 法は**平面性**に依存する。非平面格子では効かない
- したがって「フェルミオンは常に可算側」ではなく、
  **「自由フェルミオン、または平面格子の Ising 型は可算側」**が正確である

**この二つの限定を落とすと、主張が誤りになる。**

## 何を主張するのか（未確定）

現時点で、**述べるべき命題の形が定まっていない。**
言えそうなことは三つの水準に分かれるが、どれも中身が空である。

### 観察水準

「行列式は多項式時間、permanent は #P 完全」「フェルミオン Fock は有限次元、ボソンは無限次元」
——これらは既知の事実の並置に過ぎない。**主張ではない。**

### 命題水準（候補）

「有限格子上の統計力学模型で、分配関数が $\mathbb{Z}$ 係数の**行列式**として書けるための条件は何か」
——Kac–Ward / Kasteleyn の一般化に当たる。既存研究が厚い ［要調査］。

### 構造水準（本命だが未定式化）

「可算な土台の上で、フェルミオンとボソンの区別はどう現れるか」
——反可換性を $\mathbb{Z}$ の符号として定義したとき、
可換側（ボソン）に対応するものが何になるか。**これが定式化できていない。**

**素朴には、ボソンは「符号なしの数え上げ」＝ permanent に対応する。**
すると「フェルミオン／ボソンの区別＝符号を入れるか入れないか」となり、
そのまま「行列式／permanent」「多項式時間／#P 完全」に落ちる。
これが正しいなら、**統計性の区別が計算複雑性の区別と一致している**ことになる。

これは面白いが、**私が思いついたのではなく、既に量子計算の分野で標準的な理解である可能性が高い**
［要調査］。boson sampling と fermion sampling の複雑性の差はまさにこの話である。

## 立場依存性

**個々の事実は立場に依存しない。** permanent の #P 完全性も Fock 空間の次元も、
立場と無関係な事実である。

**立場に依存するのは「これを非対称として主張する動機」のほうである。**
可算性を軸に据えなければ、この並置は自然な問いにならない。

したがって、[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の「前提と成果物を分離する」に従うなら、成果物は**個々の事実についての命題**として書き、
非対称という読みは動機の側に置く。

**四つの標的の中で最も未熟である。** 述べるべき命題の形が定まっておらず、
かつ**既に知られている可能性が最も高い**。

それをせずに手を動かすべきではない。
