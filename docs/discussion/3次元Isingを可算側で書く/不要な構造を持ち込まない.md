# 不要な構造を持ち込まない（$\mathbb{R}$ を避ける理由と同じ話）

**2026-08-14 にユーザーが述べた原則を記録する。**
**この原則は同日、ユーザーの指示で `docs/context/` へ昇格した**
（[物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の
「不要な構造を持ち込まない」、および
[証明の書き方.md](../../context/証明の書き方.md) の「新しい道具を入れるときの判断」の第 5 項）。
**原則の正本はそちらである。** この文書に残すのは、3 次元 Ising の本文に対する点検の記録である。

## 原則

> **議論に不要な構造を「便利だから」という理由で持ち込むと、その構造が持つ性質について
> 余計な議論をしなければならなくなる。**

$\mathbb{R}$ を研究対象にしない理由は、まさにこれである。非可算性・完備性・極限・
連続性は、数え上げの議論には不要なのに、いったん土台に置けば、それらを前提にした操作の
正当化・例外処理・well-defined 性の確認が必要になる。**持ち込んだ構造の分だけ、
本題と無関係な議論が増える。**

## 同じ危険は $\mathbb{Z}$ にもある

**整数を素朴に持ち出して楽をする姿勢は、$\mathbb{R}$ を持ち出すのと同じ種類の危険である。**
$\mathbb{Z}$ は一括で次を持ち込む。加法群の構造、環の構造、全順序、無限性、減法、絶対値。
これらのうち、いま必要なものはどれかを問わずに使うのは、便利さを理由にした持ち込みである。

具体例として、この文書を書いた時点の本文（3 次元 Ising の帰無モデル）を点検する。
箱を $V_L=I_L\times I_L\times I_L$（$I_L=\{0,\dots,L-1\}$、整数の有限集合）として定義し、
辺を始点と方向の組 $(a,i)$（条件は $a_i\le L-2$）、端点写像を $\partial_1(a,i)=a+\varepsilon_i$
と書いている。ここで使っているのは次である。

| 使っているもの | 論証で本当に必要か |
| --- | --- |
| 各方向に沿って「次の点」を与える対応 | **必要**（辺の両端がこれで決まる） |
| 二部性（点を 2 色に塗り分け、辺の両端が違う色になること） | **必要**（回文性の証明の中身） |
| 破れ辺の集合の補集合の元の個数（有限集合の差） | **必要**（補数の式） |
| 整数の加法 $a+\varepsilon_i$ | 「次の点」を書くための手段にすぎない |
| 整数の順序 $a_i\le L-2$ | 辺の集合の条件を書くための手段にすぎない |
| 座標和 $s(a)=a_1+a_2+a_3$ とその偶奇 | 2 色の塗り分けを作るための手段にすぎない |
| 絶対値 | **不要**（隣接の定義を落としたので、もう使っていない） |

すなわち、**論証が要求しているのは「有限集合と、方向ごとの部分単射（次の点を与える写像）と、
その写像で色が変わる 2 色の塗り分け」だけ**であり、整数の加法・順序・座標和は
それを書き下すための便宜である。

## この点検から出る次の作業

**箱を「有限集合＋方向ごとの後続の部分写像」として定義し直せるかを問う。** 具体的には、

- 有限集合 $V$ と、3 つの部分単射 $\mathrm{succ}_i:\ \mathrm{dom}_i\to V$（$\mathrm{dom}_i\subseteq V$）。
- 辺の集合は $E=\{(a,i)\ :\ a\in\mathrm{dom}_i\}$、端点写像は $\partial_0(a,i)=a$、
  $\partial_1(a,i)=\mathrm{succ}_i(a)$。
- 二部性は「写像 $c:V\to\{0,1\}$ が存在して、すべての辺で両端の色が異なる」こと。

この形で回文性の証明が通るなら、**整数の算術は本質的でなかった**ことになる。
通らないなら、どこで整数が要るのかが判明する。**どちらでも収穫がある。**

これは Lean の必要十分版が答える種類の問い（何が本質的か）と同じであり、
[docs/context/証明の書き方.md](../../context/証明の書き方.md) の四層の設計と噛み合っている。
ただし**人手証明の側でも同じ問いを立てる**のがこの原則の要求である
（Lean で気づくのを待たない）。

## 周期族に群構造を持たせる筋（2026-08-15 の検討。採らない）

**論点（ユーザー提起）**: 周期境界の族は、いま端点写像の場合分け
（第 $i$ 成分が端なら $0$ へ巻き戻す）で表しているが、頂点集合そのものを
$\mathbb{Z}/L\mathbb{Z}\times\mathbb{Z}/L\mathbb{Z}\times\mathbb{Z}/L\mathbb{Z}$ とし、
辺の他端を平行移動 $a\mapsto a+\varepsilon_i$ で与える流儀もあるのではないか。

**確認したこと。** 周期族で証明済みの三つ（定数配位は周期辺を破らない／奇数周期では
すべての周期辺を破る配位は無い／ゆえに多重度は回文でない）が使っているのは、
**方向 $i$ の後続を $L$ 回たどると出発点へ戻ること**と、**$L$ が奇数であること**だけである。
剰余環の乗法、商集合の構成、平行移動の群全体は使っていない。
一方、いまの端点写像の場合分けが使うのは整数の $+$ と $\le$ だけで、2 行で済んでいる。

**判断**: 採らない。$\mathbb{Z}/L\mathbb{Z}$ を土台に置くと、使わない構造
（乗法・商の構成・群作用）を一括で持ち込むことになり、この文書の原則に反する。
**一般化するなら群ではなく置換**である。すなわち
[有限二部後続系](../../../countable-core-of-3d-ising/structured-latex/content/structural-core.ts)
の部分単射を「軌道の長さが $L$ の置換」に強め、定理を

> ある方向の軌道の長さが奇数なら、多重度は回文でない

の形にする。これは使っている性質そのものを仮定にした形であり、抽象層の場合分けも消える
（具体版では「巻き戻しが軌道長 $L$ の置換である」という補題に姿を変えて残る。これは消えない）。

**採るべき条件（将来これが満たされたら群構造を入れる）**:
平行移動そのものを主張に使うとき。具体的には、周期族の分配多項式の平行移動不変性、
軌道の数え上げ、周期方向に沿った転送の指標による対角化
（$1$ の $L$ 乗根なので $\bar{\mathbb{Q}}$ に留まり可算側から出ない）。
そのときは群作用が便宜ではなく論証の中身になるので、印を付けて採る。

**記録しておく非対称**: 証明は置換の言葉で足りるが、**なぜ奇数周期で壊れるかの説明**は
群の言葉のほうが短い。二部性が偶数 $L$ でだけ成り立つのは、
$\mathbb{Z}/L\mathbb{Z}\to\mathbb{Z}/2\mathbb{Z}$ の準同型が $L$ 偶数のときしか無いからである。
**説明に効く道具と、証明に要る道具は別**であり、前者を理由に後者を重くしない。

## 判断基準（妥協の両側を避ける）

- **持ち込んでよいのは、その構造の性質を論証で実際に使う場合だけである。**
  使わない性質を連れてくる集合を土台に置かない。
- 逆に、**表記が煩雑になるという理由で構造を落とすのをやめるのも同じ過ち**である。
  判断は「論証で使うか」だけで行う。式が長くなる側を選ぶ、というプロジェクトの規則と一致する。
- **落とせるかどうかは点検して初めて分かる。** 定義を書いた時点で「これは便宜だ」と印を付け、
  あとで落とせるかを問う欄を残す（この文書の表がその形式である）。
