# 2 次元から 3 次元で失われる道具

**2 次元 Ising を可算側で書くときに使っていた道具のうち、3 次元で何が残り何が失われるか**を並べる。
方針を立てるための対応表であり、ここに新しい主張はない。

## 対応表

| 道具 | 2 次元 | 3 次元 | 帰属 |
| --- | --- | --- | --- |
| 分配多項式 $Z_L(x)\in\mathbb{Z}[x]$ | 定義できる | **定義できる**（次元に依らない。数え上げだけ） | $\mathbb{Z}[x]$ |
| 有限系の自由エントロピー $\Phi_L=\log Z_L(q)$ | $\Lambda$ に住む | **$\Lambda$ に住む**（$q\in\mathbb{Q}$ なら素因数分解の指数ベクトル） | $\Lambda$ |
| Fisher 零点 | $\overline{\mathbb{Q}}$ の元 | **$\overline{\mathbb{Q}}$ の元**（整係数多項式の根） | $\overline{\mathbb{Q}}$ |
| 転送行列 | $M_{2^L}(\mathbb{Z}[x])$ | $M_{2^{L^2}}(\mathbb{Z}[x])$。$L=3$ で 512 次、$L=4$ で 65536 次 | $\mathbb{Z}[x]$ |
| 自己双対性 | あり。$x_c$ を $x^2+2x-1=0$ の根として決める | **ない**。双対は $\mathbb{Z}_2$ ゲージ理論へ移る（下記） | — |
| 臨界点 | $x_c=\sqrt2-1\in\overline{\mathbb{Q}}$ | **代数的か否か知られていない**。厳密値も未知 | 不明（$\mathbb{R}$ には住む） |
| 自由フェルミオン構造（Pfaffian・行列式） | ある。零点の軌跡が閉じた式で出る | **ない**。非平面なので分配関数の計算は NP 完全 | — |
| 零点の軌跡 | 2 円 $\lvert z\pm1\rvert=\sqrt2$ の上に乗る（閉じた式） | **閉じた式が知られていない**。零点密度の表式も未知 | — |
| 高温・低温展開 | 整係数級数 | **整係数級数**（3 次元は 24 次まで計算されている） | $\mathbb{Z}$ |

読み取れることは一つである。**有限系について述べる限り、可算側の枠組みはそのまま 3 次元で成立する。**
失われるのは「閉じた式を与える構造」（自己双対性と自由フェルミオン）だけであり、
それは可算性の問題ではなく可解性の問題である
（[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の「帰属・計算可能性・可解性は独立な軸である」）。

## 双対性が 3 次元で何を与えるか

2 次元正方格子の Kramers–Wannier 双対は Ising を Ising へ移す。だから不動点が臨界点を決める。
3 次元では Wegner 双対が Ising を $\mathbb{Z}_2$ 格子ゲージ理論へ移す（双対格子の上のゲージ模型）。
**移り先が同じ模型ではないので、不動点による臨界点の決定は成り立たない。**

これは否定的な事実だが、**有限格子の $\mathbb{Z}[x]$ の等式としては厳密に書ける主張である**。
すなわち「3 次元 Ising の分配多項式と、双対格子上の $\mathbb{Z}_2$ ゲージ模型の分配多項式は、
明示的な整数係数の因子と変数変換で結ばれる」。これは

- 数え上げだけで示せる（高温展開の項を閉じた曲面と対応させる組合せ的な全単射）
- 四層検証（記述・SageMath・Lean 具体版・Lean 必要十分版）に載る
- そして**「双対性は 3 次元で臨界点を決めない」ことの正確な内容を与える**

ので、着手する価値がある。**低コストで、可算側で完全に閉じる標的**である。
文献の状況は [文献と確認状況](文献と確認状況.md) に書いた（双対性そのものは Wegner 1971 以来の標準。
一般の有限三角形分割上の明示式について書いた文献があるが要旨のみ確認）。

## 有限格子の厳密データはどこまで取れるか

3 次元の $Z_L(x)\in\mathbb{Z}[x]$ を厳密に構成した仕事は既にある。**規模はごく小さい。**

- 転送行列で有限単純立方格子の厳密な分配関数を計算し、複素温度の零点分布を調べた例がある
  （Valani の学位論文 2011。$3\times3\times3$ 等の小格子。要旨のみ確認）。
- $4\times5\times5$ の分配関数の計算（Bhanot 1990）、$3\times3\times L_z$・$4\times4\times L_z$・
  $5\times5\times L_z$（$L_z\le9$）でのスピングラスの厳密計算という報告がある（要旨のみ確認）。
- 密度状態の厳密な数え上げを $5^3$ に適用した例がある（要旨のみ確認）。

したがって我々が新規性を主張できるのは**計算したこと自体ではない**。
主張できるとすればその扱い方である。

1. **零点を `QQbar` で厳密に扱い、最小多項式・次数・判別式を記録する。**
   既存の仕事は零点を浮動小数点で求めて分布を見ている。
   最小多項式の族としての規則性は、連続体側に対応物がない量である
   （[臨界指数をFisher零点列で書く/何が厳密で何が非厳密か](../臨界指数をFisher零点列で書く/何が厳密で何が非厳密か.md)
   の末尾で「ここに何かある可能性はある」と書いた項目に対応する）。
2. **$\Phi_L=\log Z_L(q)\in\Lambda$ を素因数分解の指数ベクトルとして記録する。**
   3 次元で $\Lambda$ 値の厳密データを取った例は知らない（探していない、の意味である）。
3. **「零点が実軸へ詰め寄る」を $\mathbb{Q}$ 上の量化言明として書く。**
   2 次元と同じ形の述語がそのまま書ける。3 次元では極限の値が未知なので、
   言明は有限 $L$ のデータについてのものに留まる。

規模の制約は正直に書く。$L=4$ で転送行列は 65536 次であり、$\mathbb{Z}[x]$ 上の演算としては重い。
**どこまで届いたかを記録し、届かなかったことを「傾向」と言い換えない。**

## 誤って持ち込みそうな道具

- **共形ブートストラップの数値**（3 次元 Ising の臨界指数）。高精度だが証明ではなく、
  さらに CFT の存在とスケーリング仮説を前提する。**可算側の言明の根拠に使えない。**
  比較対象として引くのは構わないが、そのときは前提を明示する。
- **「厳密解」と称する文献**（Zhang 系列）。係争中であり、前提として引かない。
- **有限サイズスケーリング仮説**。2 次元ですでに「関係式そのものは一般には証明されていない」と
  整理してある。3 次元でも同じであり、指数を読み取る手続きを証明の一部に使わない。
