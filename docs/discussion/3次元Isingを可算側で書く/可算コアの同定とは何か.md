# 可算コアの同定とは何か

**最初のゴール設定を「可算コアの同定」に確定した（2026-08-13、ユーザーの判断）。**
この文書は、それをスローガンで終わらせないために、**何をもって同定と呼ぶか**を定める。

## 素朴な形は空である（先に潰しておく）

「有限系の可算データが全部を決めている」は内容が無い。有限格子の分配多項式は
配位の数え上げそのものであり、有限系について言えることはすべてそこに含まれる。
**この向きは定義から従うので、主張として立てない。**

内容があるのは逆向き、すなわち**潰れる情報の同定**である。

> 有限系の可算データのうち、**極限で効く部分**と**極限で潰れる部分**を分離する。

`docs/context/物理を記述する数学の選び方.md` の問い（連続理論は何を落としたのか、
実際の内容を担っている可算な部分構造はどれか）を、この形に読み替える。
落としたものを言うには、落ちる前の側で「何が残り何が消えるか」を分ける必要がある。

## 同定の定義（この文書での約束）

有限の箱ごとに決まる可算データを $D_L$ と書く（何を $D_L$ に取るかは下記）。
$D_L$ から決定可能な操作だけで得られる量を**粗視化**と呼び、$\pi(D_L)$ と書く。

**粗視化 $\pi$ が、ある極限量に対して十分であるとは**、次が成り立つことをいう。

> 二つの族 $(D_L)$ と $(D'_L)$ について、すべての $L$ で $\pi(D_L)=\pi(D'_L)$ ならば、
> 対応する極限量が一致する。

**必要でないとは**、逆に $\pi$ の値が違っても極限量が一致する例があることをいう。

このとき、

- **可算コア**＝極限量に対して十分な粗視化のうち、これ以上粗くできないもの。
- **潰れる部分**＝必要でない部分。すなわち極限で情報として消える部分。

**極限量を持ち出す箇所が、このプロジェクトで唯一許される脱出（箱の大きさの極限）である。**
それ以外の主張（粗視化どうしの決定関係）は有限の箱ごとの言明であり、脱出を含まない。

## 族は境界条件で添字づける。単変数の多項式だけでは足りない

**（2026-08-13 の 3 回目のレビューで指摘された点を反映した。）**

- **境界条件を族の添字に含める。** 自由境界・周期境界・外側を固定した境界は別の族である。
  同じ記号で書かない。
- **一次データは単変数の分配多項式だけでは足りない。** 相関や秩序変数を復元するには、
  辺ごと（あるいは点ごと）に変数を持つ**多変数の分配多項式**、および
  **箱の包含に伴う写像**（小さい箱のデータを大きい箱から取り出す操作）が要る。
  単変数へ落とすと何が失われるかを問うことが、そのまま「潰れる情報の同定」になる。
- したがって扱う対象は、**境界条件と局所観測量と箱の包含を備えた有向な族**である。

**最初に立つ具体的な問い**：単変数の $Z_L$ が一致していて、二点相関のデータが異なる二つの例を作れるか。
作れれば「単変数化で相関の情報が潰れる」ことの明示的な証拠になる（**反例なので安い**）。

## 強制される構造（先に確定させる。帰無モデル）

測る前に、**格子の構造から強制される部分**を確定させる。これを「発見」と呼ばないためである。

- **二部性からの回文性**：立方格子の点を座標の和の偶奇で二つに分けると、どの辺も異なる側を結ぶ。
  片側だけ値を入れ替える写像は配位の全単射で、各辺の一致・不一致をすべて反転させるので、
  破れ本数 $m$ は $\#E_L-m$ へ移る。したがって
  $$\Omega_L(m)=\Omega_L(\#E_L-m),\qquad x^{\#E_L}Z_L(1/x)=Z_L(x)$$
  が**強制される**（自由境界、および偶数周期の周期境界。**証明は上の 3 行で尽きる**）。
  **数値でも確認した**（$2\times2\times2$、$3\times2\times2$、$3\times3\times2$ の自由境界と
  周期 4 で回文、二部性が崩れる周期 3 では回文でない。2026-08-13 の全数列挙）。
- **回文性の帰結として、Galois 群は一般の対称群になりえない。** 根が $\alpha\mapsto1/\alpha$ で
  対に組まれるので、正規化した多項式の Galois 群は**高々超八面体群**（$C_2$ による輪積）である。
  **ここが帰無モデルであり、「Galois 群を測る」ことに内容があるのは、この上限から
  系統的に外れる構造を見つけて全ての $L$ について証明できたときだけである。**
- ほかに強制されるもの：$Z_L(1)=2^{\#V_L}$、係数の非負性、台の両端の値、
  格子の対称性（平行移動・回転・鏡映）から従う等式。

**帰無モデルを確定させずに測ると、強制された構造を発見と誤認する。** 順序を守る。

## 一次データの候補と、その間の決定関係

$D_L$ の候補と粗視化の候補を並べる。**まず有限の箱ごとに「何が何を決めるか」を確定させる。
これは可算側で閉じ、四層検証に載る。**

| データ・粗視化 | 住処 | 何を決めるか（示すべきこと） |
| --- | --- | --- |
| 多重度の列 $\Omega_L(m)$ | $\mathbb{N}$ | 分配多項式そのもの（係数の並べ替えに過ぎない） |
| 分配多項式 $Z_L$ | $\mathbb{Z}[x]$ | 以下すべて |
| 有理点での値の素因数分解 $\Phi_L(q)\in\Lambda$ | $\Lambda$ | **有限個の有理点の値で $Z_L$ が決まる**（次数 $+1$ 点あれば十分。示すべき最初の主張） |
| 既約分解の型（因子の次数と重複度） | $\mathbb{Z}[x]$ | 零点の最小多項式の次数の多重集合を決める。逆は決めない（示すべき）。**既約因子は原始的かつ最高次係数が正になるよう正規化して一意に取る** |
| 零点の集合（$\overline{\mathbb{Q}}$ の元として） | $\overline{\mathbb{Q}}$ | 最高次係数と重複度を除いて $Z_L$ を決める（示すべき）。**零点の最小多項式は既約因子をモニックにしたもの**である |
| 分解体の次数・Galois 群 | 体の次数は $\mathbb{N}$、**群は有限置換群**（$\overline{\mathbb{Q}}$ の元ではない） | 一般には $Z_L$ を決めない（反例を出すべき）。可約な多項式全体の群と、各既約因子の群を分けて扱う |
| 判別式とその素因数 | $\mathbb{Z}$ | 一般には $Z_L$ を決めない（反例を出すべき）。**重複因子があれば判別式は零になるので、square-free 部分または各既約因子の判別式を使う** |

**この表の右側を証明で埋めることが、最初の作業である。** どれも有限の対象についての主張であり、
$\mathbb{R}$ を含まない。**そして「決めない」側は反例を構成する**（存在の主張より安い）。

## 極限側で問う言明（脱出を宣言して書く）

決定関係の階層ができたら、**どの層までが極限量に効くか**を問う。極限量の候補と、
対応する問いを並べる。

| 極限量 | 問い | 現状 |
| --- | --- | --- |
| 自由エネルギー密度 | $\Phi_L(q)$ の列（$\Lambda$ 値）で決まるか。粗視化として十分な最小の層はどこか | 十分性は素直に出る見込み。**最小性が本題** |
| 臨界点 | 実軸へ最も近い零点の列で決まるか。既約分解の型は効くか | 標準的には効くとされるが、関係式自体は一般に未証明。**2026-08-22 に否定判定「2 次元から事前に予言が出ない」で候補から落とした**（`docs/discussion/臨界指数をFisher零点列で書く/何が厳密で何が非厳密か.md` が、道具の揃った 2 次元 Ising についてすら $\lvert u_1(L)-u_c\rvert\sim L^{-1/\nu}$ の関係式自体が未証明であると既に記録している。詳細は `countable-core-of-3d-ising/docs/tasks/auto-loop-state.md` の該当行） |
| 判別式・Galois 群 | これらは極限量に効くか、それとも完全に潰れるか | **いずれも極限量を決めない反例を四層で検証済み。** ずらした自由族 $Z'_L=Z_{L+1}$ は元の自由族と同じ極限量を持つ一方、判別式は $\mathrm{disc}(Z_3)=0$ と $\mathrm{disc}(Z_4)\ne0$ で異なり、Galois 群は $Z_2$ 側の位数が $4$、$Z_3$ 側の位数が $40$ の倍数なので同型でない。有限計算はそれぞれ `sagemath/check/discriminant-free-vs-periodic-differ/` と `sagemath/check/galois-group-shifted-free-family-nonisomorphic/` に置く |

**「潰れる部分」を一つでも厳密に同定できれば、それがこのゴール設定の最初の成果である。**
連続理論が落としたものを、具体的な可算不変量として名指しできることになる。

## 最初の三手（この順で進める）

1. **有限点での値が多項式を決めることを示す。** $\Lambda$ 値のデータ（有理点での素因数分解）が
   有限個で $Z_L$ を復元することを、一ステップ一定理で書く。これが
   「$\Lambda$ 側のデータが一次データと同等である」ことの根拠になる。
2. **決定関係の表を証明と反例で埋める。** 上の表の右側。**反例は小さい箱で厳密に作れる。**
3. **潰れる候補を一つ選び、極限量に効かないことを問う。** 最有力は判別式と Galois 群である
   （$\mathbb{R}$ 側の自由エネルギーの表式にこれらが現れないため、潰れている可能性が高い。
   ただし**これは推測であり、示すべき対象である**）。

## 否定判定（着手前に決める。判定できる形にする。後から緩めない）

**前の版の否定判定は「規則性が無い」「何も見えない」のように未定義で、
判定を先延ばしにできた。** 次の形に置き換える。

- **強制で尽きる**：帰無モデル（回文性・$Z_L(1)$ の値・対称性からの等式・
  Galois 群の超八面体上限）を除いた残余に、**全ての $L$ について成り立つ全称命題として
  書ける構造が見つからない**。判定手続き：残余について立てた全称命題が、
  到達できる最大の箱までの厳密計算で 1 つでも反例を出したら棄却し、
  棄却が続いて新しい候補が出せなくなった時点で降りる。
- **2 次元から事前に予言が出ない**：測る量の候補それぞれについて、
  **2 次元の閉形式から導かれる具体的な代数的命題を、測定の前に導出する**。
  導出できない量は「何を見ているか分からない量」なので、その時点で候補から落とす。
- **既知である**：**同じ定理が文献にある**場合に降りる。
  関連する不変量を扱った論文が 1 件あることは降りる理由にしない
  （近い研究の存在は差分の書き方を変える理由にはなる）。
- **極限側が予想へ帰着する**：依存関係の主張が有限サイズスケーリング仮説のような
  未証明の前提に依存する形しか取れない。この場合、有限側の決定関係と強制構造の確定だけが
  成果として残る（小さいが負ではない）。
