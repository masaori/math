# 3 次元 Ising を可算側で書く

**2 次元 Ising 模型を Λ と Fisher 零点の立場で書いてきた枠組み
（[exact-solution-of-2d-ising-model-lambda](../../../exact-solution-of-2d-ising-model-lambda/README.md)）を、
3 次元へ進めるときに何を標的にするかを決めるための方針文書。**

現状は探索フェーズである。定理も検算もまだない。
出典の既読・未読は [文献と確認状況](文献と確認状況.md) に分けて書いた。
本方針は Codex（gpt-5.6-sol）によるレビューを一度受けており、
そこで指摘された誤りを反映した版である（経緯は同ファイルの末尾）。

## 結論（先に書く）

**「3 次元 Ising 模型の厳密解を求める」を標的にしない。** 代わりに、
**臨界点の位置を有限格子の有理数演算で挟む証明書**を主題に置く。
その中で、意味のある未解決の問いは次の一つである。

> **低温側（$q<x_c$）を有限の計算で証明する、漏れのない証明書は存在するか。**

高温側（$q>x_c$）については既存の定理から証明書が作れ、その評価は $\mathbb{Q}$ で閉じる。
したがって高温側は**本体ではなく、校正と機械検証の課題**である。
低温側が解ければ「$x_c$ は計算可能実数である」が言え、
2 次元で $x_c=\sqrt2-1\in\overline{\mathbb{Q}}$ だったことに代わる可算な指定が得られる。

| 標的 | 位置づけ | 可算側で閉じるか |
| --- | --- | --- |
| **低温側の漏れのない有限証明書** | **本体（未確定）** | 経路によって違う。分類することが内容 |
| **高温側の証明書を厳密計算と Lean で回す** | 校正・形式化。数学的な新規性はない | 評価は $\mathbb{Q}$ で閉じる（licence は $\mathbb{R}$ 側の定理から借りる） |
| **有限格子の双対性を $\mathbb{Z}[x]$ の等式として書く** | 校正題材。内容は既知 | 閉じる |
| **有限格子の零点列と $\Lambda$ 値エントロピーの厳密データ** | 最低順位。述べるべき命題がまだない | 閉じる |

詳細は [有限体積判定条件で臨界点を挟む](有限体積判定条件で臨界点を挟む.md) に書いた。

## なぜ「厳密解」を標的にしないか

**閉形式の非存在が証明されているからではない。** ここは正確に書く。

- 非平面格子の Ising 分配関数の計算は NP 完全である（Istrail 2000）。
  ただしこの困難性は、**辺ごとに結合定数を変えられる族**に難しいインスタンスを符号化することで示される。
  **全辺 $J=1$ の一様強磁性の立方格子の列について、閉じた式が存在しないことを示してはいない。**
  同じ理由で「自由フェルミオン構造はない」も定理としては言い過ぎであり、
  正確には「知られていない」である。
- したがって理由は「不可能だから」ではなく、**我々の道具が効く標的ではないから**である。
  閉形式の探索は、機械検証と厳密計算が寄与できる形になっていない
  （[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件のうち、
  「機械にかけられるか」を満たさない）。
- **「厳密解を得た」と主張する文献は係争中である。** Zhang の一連の主張（2007 以降、
  2021 の再主張を含む）に対して Perk が誤りを指摘し、応答と再反論が繰り返されている。
  本リポジトリはこの係争に立ち入らず、**これらを前提として引かない**。

## 2 次元で得ていたものが 3 次元で何に置き換わるか

2 次元では臨界点そのものが可算な対象だった。$x_c=\sqrt2-1\in\overline{\mathbb{Q}}$ であり、
自己双対方程式 $x^2+2x-1=0$ の根として代数的に取り出せる。**これは 3 次元では失われる**
（[2次元から3次元で失われる道具](2次元から3次元で失われる道具.md)）。
$x_c$ が代数的数であるという主張は、3 次元では知られていない。

代わりに残るのは、**臨界点を有限のデータで挟む手続き**である。ただし程度を正確に書く。

- 各証明書の検査は決定可能である（有限格子上の整数演算と有理数の比較）。
- しかし証明書の探索が停止するのは片側だけなので、得られるのは
  **$\{q\in\mathbb{Q}:q>x_c\}$ の再帰的可枚挙性**である。
  「$q$ と $x_c$ の比較が決定可能」でも「$x_c$ が計算可能実数」でもない。
- 両側が揃えば $x_c$ は計算可能実数になる。**そこが本体の問いである。**

## この標的が満たしている条件

[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件で見る。

- **機械にかけられるか** — 高温側は○（判定量は整数係数多項式の比。`ZZ`/`QQ` の厳密演算、
  判定は有理数の不等式一本なので Lean へ落ちる）。低温側は経路次第で、そこを決めるのが調査項目である。
- **数学・物理として意味があるか** — 高温側だけでは×（既存の定理と高温展開に尽きる）。
  **両側が揃って「$x_c$ は計算可能実数である」となれば○。**
  この二条件を同時に満たすかどうかは、低温側の帰趨で決まる。
  **したがって最初に付けるべき判定は「低温側は可能か、既知か」である。**

新しさを主張してはならない部分を明示しておく。判定条件は既存の定理であり、
判定量を高温展開の有理式として書くことも標準的である。臨界温度が constructive であることは
Duminil-Copin–Tassion の帰結として、また Shlosman (2025) が Dobrushin–Shlosman 条件について
同じ形で述べている。**「同じ式を文献で見なかった」は差分の根拠にならない。**
差分になりうるのは、証明書の形の明示、両側の $\mathbb{R}$ 脱出の分類、そして機械検証である。

## 進め方

1. **低温側の調査を先に行う。** Häggström (2008) がパーコレーションで両側を揃えた手法を確認し、
   FK（$q=2$）へ移せるかを見る。Peierls 型が有理数で閉じることと、
   それが臨界点まで届かないことを確定させる。
   **ここで「既知」または「不可能」と判明したら、方針そのものを組み替える。**
2. **2 次元で高温側の証明書を厳密に回す。** $x_c=\sqrt2-1$ が既知なので、
   証明書が出す下界の近づき方を測れる。実装の検査になる。
3. **3 次元で同じ計算を行う。** 得られた有理数の下界を、数値的に知られている
   $\beta_c=0.221654626(5)$ と比較し、**差を正直に記録する**。届かなかったことも記録する。
4. **双対性の $\mathbb{Z}[x]$ 版を書く。** 有限格子の等式として四層検証にかける（校正題材）。
5. **零点列と $\Lambda$ の厳密データを取る。** 小さい $L$ に限る。述べるべき命題が見つかってから広げる。
