# 3 次元 Ising を可算側で書く

**3 次元 Ising 模型について、可算な世界だけで何を研究対象にするかを決めるための方針文書。**
2026-08-13 に一度書き、同日**全面的に書き直した**（経緯と理由は
[文献と確認状況](文献と確認状況.md) の「方針を書き直した理由」）。

現状は探索フェーズである。定理も検算も無い。出典の既読・未読は同ファイルで分けて書いた。

## 問い

[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の中心命題を
3 次元 Ising へ当てたものが、この方針の問いである。

> **3 次元 Ising 模型の相転移の内容を、実際に担っている可算な構造は何か。**

これは「どの問いなら機械で検査できるか」とは**別の問い**である。両者を混同してはならない。
同文書は帰属（可算に住むこと）・計算可能性・可解性を**独立な軸**と明記している。
機械にかけられることは、標的を選ぶ規則ではなく、標的が満たすべき制約の一方である
（[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件。主なのは「意味があるか」）。

## 最初のゴール設定: 可算コアの同定（2026-08-13 に確定）

**極限で効く部分と極限で潰れる部分を、有限格子の可算データの上で分離する。**
何をもって同定と呼ぶか、最初の三手、否定判定は
[可算コアの同定とは何か](可算コアの同定とは何か.md) に定めた。要点だけ再掲する。

- 「有限系の可算データが全部を決めている」は定義から従うので**主張として立てない**。
  内容があるのは逆向き、すなわち**潰れる情報の同定**である。
- 有限の箱ごとに「どの粗視化がどれを決めるか」の決定関係を、証明と反例で確定させる
  （ここは可算側で閉じ、脱出を含まない）。
- そのうえで、**どの層までが極限量に効くか**を問う。ここで初めて箱の大きさの極限を宣言する。
- **潰れる部分を一つでも厳密に名指しできれば、それが最初の成果である。**

下の「有限格子の可算データ」は、このゴール設定の**一次データと道具**であり、
測ること自体が目的ではない。

## 一次データ: 有限格子の可算データ

**有限の立方格子について厳密に決まる整数・代数的数・$\Lambda$ の元を一次データとして扱い、
それらが箱の大きさとともにどう振る舞うかを調べる。**

一次データは次である。どれも有限の数え上げから厳密に決まり、$\mathbb{R}$ を一切経由しない。

| データ | 住処 | 何であるか |
| --- | --- | --- |
| 多重度 $\Omega_L(m)$ | $\mathbb{N}$ | 破れボンド数が $m$ の配位の個数（状態密度） |
| 分配多項式 $Z_L(x)=\sum_m\Omega_L(m)x^m$ | $\mathbb{Z}[x]$ | 一次データの母関数。**この整数列が実体である** |
| $Z_L$ の $\mathbb{Q}$ 上の既約分解 | $\mathbb{Z}[x]$ | 既約因子の個数・次数・重複度。円分因子の有無 |
| Fisher 零点 | $\overline{\mathbb{Q}}$ | 既約因子の根。各零点の最小多項式の次数 |
| 分解体の次数と Galois 群 | 次数は $\mathbb{N}$、群は**有限置換群** | 零点全体の対称性。二部性からの回文性により、**高々超八面体群**に制約される |
| 判別式・終結式 | $\mathbb{Z}$ | **既約因子ごとの**判別式の素因数分解（重複因子があると $Z_L$ の判別式は零になる）。隣接する $L$ の間の終結式 |
| 有限系の自由エントロピー $\Phi_L(q)=\log Z_L(q)$ | $\Lambda$ | 有理点での値の素因数分解の指数ベクトル |

**この主標的には $\mathbb{R}$ への脱出が一切要らない。** 対象が有限の箱ごとに決まる可算な量だからである。
前の版の方針（有限の証拠で臨界点の切断を定める）は、有限の量を無限体積の言明へ渡す
「健全性の橋」を必要とし、それが無いままだった。**主標的を移した理由の一つがこれである。**

## この標的が満たしていること・満たしていないこと

[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件で正直に見る。

- **機械にかけられるか** — ○。すべて `ZZ` / `QQ` / `QQbar` の厳密計算で決まる。
  浮動小数点は要らない。命題化すれば Lean へも落ちる。
- **数学・物理として意味があるか** — **条件付き。** 二段に分けて書く。
  - **数学としては、立場に依らず意味がある命題を立てられる。**
    「整係数多項式の族 $\{Z_L\}$ の既約分解・判別式・Galois 群がこう振る舞う」は、
    この立場を共有しない読者にも成立する主張である。
  - **物理の内容を担っているかは仮説である。** 測って構造が見つかったとして、
    その構造が相転移と対応することは別に問う必要がある。
    **「可算データだから物理の実体である」を根拠として使わない**（それは立場の表明であって証明ではない）。

**掃かれていない空間であることが、この標的を選ぶ実質的な理由である。**
既存研究は 3 次元の零点を浮動小数点で求めて分布を見ている。
**代数的な量（最小多項式の次数、判別式の素因数、Galois 群、因数分解の型）として記録した文献を
私は見つけていない**（探索は限定的である。[文献と確認状況](文献と確認状況.md) の「未調査」）。
一方で、閉形式や holonomic な漸化式を整数列から探す方向は、級数解析の分野が大規模に掃いており、
否定的な証拠もある。**同じ道具を、掃かれた場所ではなく掃かれていない場所へ向ける。**

## 問いの具体形（反証可能な形で書く）

測るだけでは成果にならない。**次のような形の言明を立て、成り立つか崩れるかを決める。**

1. **強制される部分を先に分離する（帰無モデル）。** 二部性からの回文性
   $\Omega_L(m)=\Omega_L(\#E_L-m)$、全スピン反転、格子の対称性、$Z_L(1)=2^{\#V_L}$ から
   何が強制されるかを証明する。**測定の前に済ませる**（強制された構造を「発見」と呼ばないため）。
   詳細は [可算コアの同定とは何か](可算コアの同定とは何か.md) の「強制される構造」。
2. **強制されない部分に規則性があるか。** 既約因子の次数の分布、円分因子の出現、
   判別式に現れる素数の集合、Galois 群の型が、$L$ とともに規則的に振る舞うか。
   規則があるなら述べ、無いなら「無い」と述べる（負の結果も記録する）。
3. **2 次元で校正する。** 同じ測定を 2 次元で行う。あちらは零点の軌跡が閉じた式で書けるので、
   「構造がある」場合の代数的データの見え方が分かる。3 次元のデータをそれと比べる。
4. **$\Lambda$ 側**：$\Phi_L(q)$ の素因数の集合と指数が $L$ とともにどう増えるか。
   箱の体積に比例するのか、現れる素数が有界なのか。

**規模の制約を正直に書く。** 3 次元の $Z_L(x)$ を厳密に持てる箱は小さい（文献では $3\times3\times3$、
$4\times5\times5$、状態密度で $5^3$ 程度。いずれも要旨のみ確認）。
**どこまで届いたかを毎回記録し、届かなかったことを傾向と言い換えない。**

## 従属する標的（本体にしない）

- **有限の証拠で臨界点の切断を定める**
  （[有限の証拠で臨界点の切断を定める](有限の証拠で臨界点の切断を定める.md)）。
  高温側・低温側それぞれに有限の証拠を与えて有理数の集合を枚挙する枠組み。
  **健全性の橋（有限の証拠から、許される唯一の脱出＝箱の大きさの極限を 1 回だけ使って
  無限体積の言明へ渡す部分）が無いので、現状では模型と結びついていない。**
  橋が架かるまで本体にしない。
- **有限格子の双対性を $\mathbb{Z}[x]$ の等式として書く**（Wegner 双対）。校正題材。内容は既知。
- **閉形式・可積分性・臨界指数の厳密値**。標的にしない。不可能性が示されたからではなく、
  到達経路が知られておらず、機械が噛む形（整数列から ansatz を枚挙して検査する形）は
  既に掃かれているためである。

## 立場（記述の制約）

- **明示的に宣言した脱出以外で $\mathbb{R}/\mathbb{C}$ を使わない。
  許される非可算への脱出は、有限格子の量の列について箱の大きさを大きくする極限だけである。**
- 主標的の言明は有限の箱ごとの主張なので、**脱出は原則として現れない**。
  現れる場合は、そのブロックで宣言する。
- $\mathbb{R}$ 側の内容（Onsager 解、共形ブートストラップの数値、鋭さの定理など）は
  **辞書として別に書き、本文の命題の前提にも根拠にもしない**。
- 記号の濫用を排除する。多項式とその値を区別する。同一視は写像を定義してから行う。

## 進め方

1. **文献の位置づけを確定する**（最優先）。3 次元（および 2 次元）の分配多項式の
   代数的データ——既約分解・判別式・Galois 群・最小多項式の次数——を扱った研究があるかを調べる。
   **あるなら差分が消えるので、その時点で方針を組み替える。**
2. **強制される構造（帰無モデル）を証明する。** 回文性・値の恒等式・対称性からの等式・
   Galois 群の上限。ここは可算側で閉じ、四層検証に載る。
3. **小さい箱で厳密に測る**（`ZZ`/`QQ`/`QQbar`）。到達した箱の大きさを記録する。
4. **2 次元で同じ測定を行い、比較する。**
5. **規則性があれば反証可能な形の予想として述べ、無ければ無いと記録する。**
