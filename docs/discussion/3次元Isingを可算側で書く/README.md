# 3 次元 Ising を可算側で書く

**2 次元 Ising 模型を Λ と Fisher 零点の立場で書いてきた枠組み
（[exact-solution-of-2d-ising-model-lambda](../../../exact-solution-of-2d-ising-model-lambda/README.md)）を、
3 次元へ進めるときに何を標的にするかを決めるための方針文書。**

現状は探索フェーズである。定理も検算もまだない。
出典の既読・未読は [文献と確認状況](文献と確認状況.md) に分けて書いた。
本方針は Codex（gpt-5.6-sol）のレビューを一度受け、さらに立場を強めた版である（経緯は同ファイル末尾）。

## 立場（最初に確定させる）

**明示的に宣言した脱出箇所以外では、$\mathbb{R}/\mathbb{C}$ を正当化されたものとして使わない。
そこに属する数のようなものを、定義・命題・証明の論理に一切登場させない。**

**許される脱出は、有限格子の量の列について格子サイズを大きくする極限（熱力学極限）だけである。**
それ以外の脱出は使わない。

この立場は、姉妹プロジェクトで採ってきた「脱出を宣言して使う」より強い。帰結は次である。

- **臨界点という実数を主語にしない。** 主語にするのは有理数の集合である。
- **主張はすべて有限格子ごとの主張の族として書き、極限は最後に 1 回だけ取る。**
  無限和・無限級数を書かず、格子サイズに依らない一様な有理数の不等式を要求する。
- **上限・下限・積分・微分・実対数・指数関数を、定義や証明に置かない。**
  これらは格子サイズの極限ではないので脱出として認めない
  （例：赤外評価は Brillouin 帯上の積分を含むので採らない。乱流表現も指数と無限和を含むので採らない）。
- **$\mathbb{R}$ 側の定理を含意の根拠として借りない。** 借りていた部分は、
  有限格子の族＋極限 1 回として書き直すか、辞書へ隔離するかのどちらかにする。
- **$\mathbb{R}$ 側の内容は「辞書」として別の節に隔離する。** 動機づけと比較のために書くが、
  本文の命題の前提にも根拠にもしない。

## 結論（先に書く）

**臨界点を、有理数の二つの集合の対（切断）として定める。**
どちらの集合も「有限の証拠が存在すること」で定義する。

| 集合 | 定義 | 状態 |
| --- | --- | --- |
| 高温側の有理点 $\mathcal{H}_d$ | 有限集合 $S$ について $\Phi_S(q)<1$（有理数の不等式 1 本）が成り立つとき $q$ を入れる | **定義済み。構成から再帰的可枚挙** |
| 低温側の有理点 $\mathcal{C}_d$ | 有限の数え上げデータについての有理数の不等式で定める（族の確定が未了） | **未確定。ここが本体** |

そして本体の問いは次の一つである。

> **$\mathcal{H}_d\cup\mathcal{C}_d$ は $\mathbb{Q}\cap(0,1)$ の高々 1 元を除く全体か。**

これが言えたとき初めて「切断が定まった」と言える。言えなければ、
$\mathbb{Q}\cap(0,1)$ には**どちらの証拠も付かない有理数の隙間**が残る。
2 次元では切断の境目が $\sqrt2-1$（$\overline{\mathbb{Q}}$ の元、すなわち可算側の対象）として
知られているので、両側とも決定可能である。3 次元にこれに当たるものはない。

詳細は [有限の証拠で臨界点の切断を定める](有限の証拠で臨界点の切断を定める.md) に書いた。

## 標的と優先順位

| 標的 | 位置づけ |
| --- | --- |
| **低温側の証拠の族を定め、覆うことを示す** | **本体（未確定）**。有限の数え上げから箱の大きさに依らない一様な不等式を出す部分が中身 |
| **高温側が上向きに閉じることを $\mathbb{Z}[x]$ の議論で示す** | 技術的な核。$\mathbb{R}$ 側の不等式（GKS）に頼らず書けるかが要点 |
| **高温側の証拠を厳密計算と Lean で回す** | 校正・形式化。数学的な新規性はない |
| **有限格子の双対性を $\mathbb{Z}[x]$ の等式として書く** | 校正題材。内容は既知 |
| **有限格子の零点列と $\Lambda$ 値エントロピーの厳密データ** | 最低順位。述べるべき命題がまだない |

## なぜ「厳密解」を標的にしないか

**閉形式の非存在が証明されているからではない。** ここは正確に書く。

- 非平面格子の Ising 分配関数の計算は NP 完全である（Istrail 2000）。
  ただしこの困難性は**辺ごとに結合定数を変えられる族**について示されており、
  **全辺 $J=1$ の一様な立方格子の列について閉じた式が存在しないことを示してはいない。**
  同じ理由で「自由フェルミオン構造はない」も言い過ぎで、正確には「知られていない」である。
- 理由は「不可能だから」ではなく、**我々の道具（厳密計算と機械検証）が効く形になっていないから**である。
- **「厳密解を得た」と主張する文献は係争中である。** Zhang の一連の主張（2007 以降、2021 の再主張を含む）に
  対して Perk が誤りを指摘し、応答と再反論が繰り返されている。
  本リポジトリはこの係争に立ち入らず、**これらを前提として引かない**。

## 2 次元で得ていたものが 3 次元で何に置き換わるか

2 次元では切断の境目が代数的数として取り出せた（自己双対方程式 $x^2+2x-1=0$ の正根）。
有理数と代数的数の比較は決定可能なので、両側の所属が判定できる。
**3 次元ではこの構造が失われる**（[2次元から3次元で失われる道具](2次元から3次元で失われる道具.md)）。
代わりに残るのは、両側それぞれに有限の証拠を与えて集合を枚挙することであり、
そのとき問題になるのが「覆うか」である。

## この標的が満たしている条件

[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件で見る。

- **機械にかけられるか** — 高温側は○（検査は有理数の不等式 1 本。`ZZ`/`QQ` の厳密演算、Lean へ落ちる）。
  低温側は候補次第で、そこを決めるのが調査項目である。
- **数学・物理として意味があるか** — 高温側だけでは×（既存の定理と高温展開に尽きる）。
  **両側が揃い「切断が定まる」となれば○。** 同時に満たすかは低温側の帰趨で決まる。
  **したがって最初に付けるべき判定は「低温側の族は作れるか、覆えるか、既知か」である。**

新しさを主張してはならない部分を明示する。判定条件は既存の定理であり、
判定量を高温展開の有理式として書くことも標準的である。臨界温度が constructive であることは
Duminil-Copin–Tassion の帰結として、また Shlosman (2025) が Dobrushin–Shlosman 条件について
同じ形で述べている。**「同じ式を文献で見なかった」は差分の根拠にならない。**
差分になりうるのは、$\mathbb{R}$ を論理から外した定式化、両側の脱出の分類、そして機械検証である。

## 進め方

1. **低温側の調査を先に行う。** Peierls 型が有理数の不等式で書けることを確定させ、
   それが覆えない範囲を明示する。FK（$q_{\mathrm{FK}}=2$）の粗視化から有限の判定条件を
   取り出せるかを調べる。Häggström (2008) がパーコレーションで両側を揃えた手法を確認する。
   **ここで「不可能」または「既知」と判明したら方針を組み替える。**
2. **高温側の単調性を $\mathbb{Z}[x]$ の議論として書く。** 上向きに閉じることの可算側の証明。
3. **2 次元で証拠を厳密に回す。** 境目が $\sqrt2-1$ と分かっているので実装の検査になる。
4. **3 次元で同じ計算を行う。** 証拠が付いた有理数を記録する。届かなかったことも記録する。
5. **双対性の $\mathbb{Z}[x]$ 版を書く。** 有限格子の等式として四層検証にかける（校正題材）。
6. **零点列と $\Lambda$ の厳密データを取る。** 述べるべき命題が見つかってから広げる。
