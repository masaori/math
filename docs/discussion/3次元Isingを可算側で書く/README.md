# 3 次元 Ising を可算側で書く

**2 次元 Ising 模型を Λ と Fisher 零点の立場で書いてきた枠組み
（[exact-solution-of-2d-ising-model-lambda](../../../exact-solution-of-2d-ising-model-lambda/README.md)）を、
3 次元へ進めるときに何を標的にするかを決めるための方針文書。**

現状は探索フェーズである。定理も検算もまだない。
記述は文献の読み取りと、そこからの演繹だけで構成している。
出典の既読・未読は [文献と確認状況](文献と確認状況.md) に分けて書いた。

## 結論（先に書く）

**「3 次元 Ising 模型の厳密解を求める」を標的にしない。** 代わりに標的を三つ置く。
優先順位はこの順である。

| 標的 | 何を主張するか | 可算側で閉じるか |
| --- | --- | --- |
| **臨界点を有限体積の証明書で挟む** | 臨界点 $x_c$ の切断（どの有理数がその上下にあるか）を、有限格子上の整数演算で判定できる述語として書く | 高温側は閉じる（$\mathbb{Q}$ で決定可能）。低温側は未確定 |
| **双対性が 3 次元で何を与え、何を与えないか** | Wegner 双対は 3 次元 Ising を $\mathbb{Z}_2$ ゲージ理論へ移す。自己双対でないので $x_c$ を代数方程式で決めない——これを有限格子の $\mathbb{Z}[x]$ の等式として厳密に述べる | 閉じる |
| **有限格子の零点列とエントロピーの厳密データ** | 小さい $L$ で $Z_L(x)\in\mathbb{Z}[x]$、その零点 $\in\overline{\mathbb{Q}}$、$\Phi_L=\log Z_L(q)\in\Lambda$ を厳密に構成し、2 次元で成り立っていた命題がどこで崩れるかを測る | 閉じる |

第一の標的が本体である。理由は次節に書く。

## なぜ「厳密解」を標的にしないか

**計算量の側から閉じている。** 非平面格子の Ising 分配関数を有限部分格子について計算することは
NP 完全である（Istrail 2000。平面格子が多項式時間で解けることの裏返しとして述べられている）。
Barahona (1982) の 3 次元 Ising の基底状態問題の NP 困難性がその先行結果にあたる。
したがって「閉じた式で $Z_L(x)$ が書ける」形の目標は、我々が物量をかけて到達する対象ではない。

**「厳密解を得た」と主張する文献は係争中である。** Zhang の一連の主張（2007 以降、2021 の
再主張を含む）に対して Perk が誤りを指摘し、応答と再反論が繰り返されている。
本リポジトリはこの係争に立ち入らない。**これらを前提として引かない**、が方針である。

以上は否定的な事実だが、[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の立場からは驚きではない。決定不能性・困難性の指摘はすでに大量にあり、我々が探すのはその裏返し、
すなわち **物理の内容を担っている決定可能な可算部分**である。3 次元 Ising でそれが何かを決めるのが、
この方針文書の仕事である。

## 2 次元で得ていたものが 3 次元で何に置き換わるか

2 次元では臨界点そのものが可算な対象だった。$x_c=\sqrt2-1\in\overline{\mathbb{Q}}$ であり、
自己双対方程式 $x^2+2x-1=0$ の根として代数的に取り出せる。**これは 3 次元では失われる**
（[2次元から3次元で失われる道具](2次元から3次元で失われる道具.md)）。
$x_c$ が代数的数であるという主張は、3 次元では知られていないし、予想もされていない。

ではその代わりに何が可算なのか。**臨界点そのものではなく、臨界点の切断を判定する述語である。**

> 有理数 $q$ が与えられたとき、「$q>x_c$ である」ことを、
> 有限格子の整数係数多項式の値の比較として判定する。

この述語が決定可能で、しかも $x_c$ に対して漏れがない（すべての $q>x_c$ が有限の計算で判定される）なら、
$x_c$ は**可算なデータの族によって完全に指定されている**ことになる。
2 次元の「$x_c$ は代数的数」という可算性が、3 次元では「$x_c$ の切断は計算可能」という可算性へ移る。

これが第一の標的であり、詳細は
[有限体積判定条件で臨界点を挟む](有限体積判定条件で臨界点を挟む.md) に書いた。
そこで示すのは次の二点である。

1. Duminil-Copin–Tassion (2016) の判定量は、変数を $x=e^{-2\beta J}$ に取ると
   **整数係数多項式の比**になる。したがって有理数 $x$ に対して値は有理数であり、
   $\mathbb{R}$ 脱出なしで厳密に判定できる。この形で書き直すこと自体が可算側の内容である。
2. 判定は**高温側（$x>x_c$）にしか効かない**。低温側の有限証明書が何であり、
   それが $\mathbb{R}$ をどこで要求するかは未確定である。ここが未解決の論点として残る。

## この標的が満たしている条件

[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件で見る。

- **機械にかけられるか** — ○。判定量は有限格子上の整数係数多項式の比であり、
  `ZZ`/`QQ` の厳密演算で計算できる。判定は有理数の不等式一本なので Lean へも落ちる。
- **数学・物理として意味があるか** — ○。3 次元 Ising の臨界点は厳密値が知られていない量であり、
  その「どこまで可算な言葉で指定できるか」は既存文献に断片的にしか書かれていない
  （[文献と確認状況](文献と確認状況.md) の「計算可能性」の節）。

**新しさを主張してはならない部分**を先に書く。判定条件そのものは既存の定理であり、
臨界温度が constructive であることは Duminil-Copin–Tassion の帰結として、
また Shlosman (2025) が Dobrushin–Shlosman 条件について同じ形の結論を出している。
我々の差分は次の三点に限られる。

1. **判定量を $\mathbb{Q}$ 上の厳密計算として書き直すこと**（既存の適用例は実数の評価として書かれている）。
2. **両側の証明書を分けて扱い、それぞれの $\mathbb{R}$ 脱出を明示すること**。
   高温側と低温側で可算性の質が違うことは、既存文献では論点になっていない。
3. **機械検証すること**。判定条件を Lean へ落とし、有限計算部分を検査に載せる。

## 進め方

作業は 2 次元での校正から始める。3 次元へ直接行かない。

1. **2 次元で判定条件を厳密に回す。** $x_c=\sqrt2-1$ が既知なので、
   証明書が出す有理数の下界が $x_c$ へどう近づくかを測れる。判定量の実装が正しいかの検査になる。
2. **3 次元で同じ判定条件を回す。** 得られた有理数の下界を、数値的に知られている
   $\beta_c\approx0.2216595$ と比較し、**差を正直に記録する**。
   （証明書が到達できる範囲は計算資源で決まる。届かなかったことも記録する。）
3. **双対性の $\mathbb{Z}[x]$ 版を書く。** 有限格子の等式として、四層検証にかける。
4. **零点列と $\Lambda$ の厳密データを取る。** 小さい $L$ に限る。
5. **低温側の証明書を調査する。** 反射正値性・Peierls・FK の粗視化のどれが
   有限の証明書になり、$\mathbb{R}$ をどこで使うかを確定させる。

1〜4 は着手できる。5 は調査が先である。
