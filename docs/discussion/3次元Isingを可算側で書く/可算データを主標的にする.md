# 可算データを主標的にする

**有限の立方格子について厳密に決まる可算な量を一次データとして扱い、何を測り、
どういう形の言明を立てるか**を決める。[README](README.md) の主標的の詳細である。

この文書には $\mathbb{R}$ の元が現れない。すべて有限の箱ごとに決まる量である。

## 一次データの定義（記号は 1 つの意味に固定する）

$L\in\mathbb{N}$、$L\ge1$。**境界条件を族の添字に含める**（自由境界・偶数周期・外側を固定は
別の族であり、同じ記号で書かない。下記「境界条件で別の族になる」）。
境界条件を $\mathrm{bc}$ と書き、箱を $V_{L}^{\mathrm{bc}}$、辺の集合を $E_{L}^{\mathrm{bc}}$ とする。
以下、族を固定して議論するときだけ添字を省く。

- **配位**：写像 $\sigma:V_L\to\{+1,-1\}$。配位全体の集合を $\Sigma_L$ と書く。
- **破れボンド数** $m_L(\sigma)\in\mathbb{N}$：両端の値が異なる辺の本数。
- **多重度** $\Omega_L(m)=\#\{\sigma\in\Sigma_L: m_L(\sigma)=m\}\in\mathbb{N}$。
- **分配多項式** $Z_L(x)=\sum_{m}\Omega_L(m)\,x^{m}\in\mathbb{Z}[x]$（$x$ は不定元。代入しない）。
- **既約分解**：$Z_L=c\cdot\prod_{j\in J_L} P_{L,j}^{e_j}$。ここで $J_L$ は有限な添字集合、
  $c\in\mathbb{Z}$、各 $P_{L,j}\in\mathbb{Z}[x]$ は $\mathbb{Q}$ 上既約で、
  **原始的かつ最高次係数が正になるよう正規化する**（この正規化で分解は一意）。$e_j\ge1$。
- **Fisher 零点**：既約因子の根。$\overline{\mathbb{Q}}$ の元。
  各零点の**最小多項式**は、対応する $P_{L,j}$ を**モニックにしたもの**である（$P_{L,j}$ 自身ではない）。
- **分解体** $K_L$：$Z_L$ の根が生成する $\mathbb{Q}$ 上の体。次数 $[K_L:\mathbb{Q}]\in\mathbb{N}$ と
  Galois 群 $G_L$（**有限置換群**。$\overline{\mathbb{Q}}$ の元ではない）。
  可約な $Z_L$ 全体の群と、各既約因子の群を区別する。
- **判別式**：各既約因子の $\operatorname{disc}(P_{L,j})\in\mathbb{Z}$ とその素因数分解。
  **$Z_L$ に重複因子があれば $\operatorname{disc}(Z_L)=0$ になるので、
  square-free 部分または既約因子ごとの判別式を使う。**
- **有限系の自由エントロピー**：$q\in\mathbb{Q}$、$0<q<1$ に対し $\Phi_L(q)=\log Z_L(q)\in\Lambda$。
  すなわち $Z_L(q)$ の素因数分解の指数ベクトル（$\log$ は級数ではなく素因数分解そのもの）。

**多項式とその値を区別する。** $Z_L$ は多項式、$Z_L(q)$ は代入の結果である。

## 測る量（すべて厳密。浮動小数点を使わない）

| 量 | 何が見えるか |
| --- | --- |
| $\Omega_L(m)$ の整数列 | 一次データそのもの。対称性の帰結が直接読める |
| 既約因子の個数・次数の分布・重複度 | 「零点が特別な曲線に乗る」ことの代数的な影 |
| 円分因子（1 の冪根を根に持つ因子）の有無と種類 | 格子の周期性・対称性に由来する構造 |
| 各既約因子の判別式の素因数 | どの素数が分岐するか。素数の集合が有界かどうか |
| $[K_L:\mathbb{Q}]$ と $G_L$ の型 | 零点全体の対称性。一般の多項式と同じか、制約されているか |
| 隣接する $L$ の間の終結式 | 異なる箱の零点が共通の代数的関係を持つか |
| $\Phi_L(q)$ の素因数の集合と指数 | $\Lambda$ に住む量の増え方。**$q=a/b$ の分母から強制される成分（$b^{\deg Z_L}$ 由来）を先に除く正規化を決めてから測る。決めるまでこれは命題になっていない** |

## 反証可能な問いの形

**測って眺めるだけでは成果にならない。** 次の順に、崩れうる形の言明を立てる。

### 対称性から強制される部分を先に証明する

測定の前に、次を証明して分離する。**強制された構造を「発見」と呼ばないため**である。

- **二部性からの回文性**：座標の和の偶奇で点を二つに分け、片側だけ値を入れ替える写像を取ると、
  どの辺も一致と不一致が入れ替わるので $\Omega_L(m)=\Omega_L(\#E_L-m)$ が成り立つ
  （自由境界と偶数周期。奇数周期では二部性が崩れて成り立たない。**数値でも確認済み**）。
- 全スピン反転（すべての値を入れ替える写像）は $m_L$ を保ち、不動点を持たないので
  $\Omega_L(m)$ は偶数である。
- 格子の対称性（平行移動・回転・鏡映）から $\Omega_L(m)$ に強制される等式。
- 破れボンド数の取りうる範囲と、$\Omega_L(m)$ の台の端（最小・最大）の値。
- $Z_L$ の定数項と最高次の係数、$Z_L(1)=2^{\#V_L}$ のような値の恒等式。
- 上から従う $Z_L$ の自明な因子（例: $Z_L(1)\ne0$ なので $x-1$ は因子でない、など）。

これらは有限の数え上げで示せるので、**四層検証（記述・SageMath・Lean 具体版・必要十分版）に載る**。

### 強制されない部分の規則性を問う

以下は**仮説であり、崩れうる**。崩れたら崩れたと記録する。

- **既約分解の型が $L$ とともに規則的か。** 例: 因子の個数が $L$ の関数として決まるか。
  無関係にばらつくか。2 次元では零点が閉じた曲線に乗るので、そこに何らかの影が出るはずである
  （出ないことも結論になる）。
- **円分因子が現れるか。** 現れるなら、どの位数か。格子の周期と対応するか。
- **判別式に現れる素数が有界か。** 有界なら、その素数の集合は何で決まるか。
- **Galois 群が一般の多項式と同じ（対称群）か。** そうでないなら何に制約されているか。
- **$\Phi_L(q)$ に現れる素数の個数・最大素数が、箱の体積に対してどう増えるか。**

### 2 次元で校正する

同じ測定を 2 次元で行う。ただし**熱力学極限の零点の軌跡が既知であることから、
有限格子の既約分解や Galois 群に特徴が出ることは従わない**（有限格子で零点が厳密な曲線に
乗るかどうかは境界条件に強く依存する）。したがって校正の要求は次の形にする。

> **測る量それぞれについて、2 次元の閉形式から導かれる具体的な代数的命題を、測定の前に導出する。**
> 導出できない量は候補から落とす。

これができない量を測っても、何を見ているか分からない。**判定を先に済ませる。**

## 境界条件で別の族になる（混ぜない）

$Z_L$ は境界条件を変えると別の多項式になる。**族を混ぜて比べない。**

- **自由境界**（箱の外と相互作用しない）：純粋な数え上げとして最も素直。
- **周期境界**（トーラス）：転送行列の跡として書ける。2 次元の閉形式はこちらの族で語られる。
- **外側を固定**（$+1$ など）：Peierls 型の議論に要る。従属標的の側で使う。

**どの族で測ったかを毎回書く。** 比べるときは同じ族どうしで比べる。

## 規模の制約

- 素朴な全数列挙は配位数 $2^{\#V_L}$ に比例する。$L=3$ で $2^{27}$、$L=4$ で $2^{64}$。
  後者は全数列挙では届かない。
- $\mathbb{Z}[x]$ 上の転送行列の**次元**は $2^{L^2}$（$L=3$ で 512、$L=4$ で 65536）。
  多項式の次数と混同しない。
- 文献の到達サイズは、**境界条件と断面・長さを固定しないと比較できない**。
  3 回目のレビューが挙げた一次情報では、Bhanot–Sastry が自由境界の
  $5\times4\times L_z$（$L_z\le5$）で各エネルギーの状態数を厳密計算しており、
  Valani の学位論文には特殊な境界条件で $5\times5\times19$ などの厳密な多項式がある。
  1987 年の $5^3$ の仕事は良い近似を与える数値法であって厳密な状態密度ではない。
  **私はこれらの原論文を読んでいない**（レビューが示した出典の記述に依っている）。
- **到達した箱の大きさを毎回記録する。届かなかったことを傾向と言い換えない。**
  対称性による削減や転送行列の使い分けで届く範囲が変わるので、方法も併記する。

## この標的が空になる場合

次のいずれかが判明したら、方針を組み替える。**先に判定する。**

- **既に掃かれている**：分配多項式の代数的データを扱った研究が既にある。
- **測っても対称性の帰結しか出ない**：強制される部分を除くと何も残らない。
  これは負の結果として記録する価値はあるが、小さい。
- **2 次元でも何も見えない**：測定が鈍い。量の選び方を変える必要がある。

## 物理との対応は別に問う（ここを曖昧にしない）

**可算データが物理の内容を担っているというのは、この立場の前提であって証明ではない。**
測定で構造が見つかったとして、それが相転移と対応することは別の問いである。
対応を主張したくなったら、そのときに初めて**箱の大きさの極限**（許される唯一の脱出）を宣言し、
極限を取る言明として書く。順序を逆にしない。
