# 何を予想として出すか

**この経路の出力は証明ではない。** 証明でないものを証明と呼ばないための規律を先に決める。

## なぜ規律を先に決めるのか

この手法は**大量の「それらしい一致」を生む**。
項数を増やせば必ず何かが見つかり、精度が足りなければ偽陽性が混じる。

放置すると、[docs/context/成果の出し方.md](../../context/成果の出し方.md) が禁じている
「物量を成果と言い換える」状態にそのまま落ちる。**出力の形式を先に固定しておく。**

## 出力の形式

検出した関係は、次の三つの水準に分けて記録する。**混ぜない。**

### 定理

証明がついたもの。四層（[docs/context/証明の書き方.md](../../context/証明の書き方.md)）を適用する。

この経路から直接ここへ来ることは**まずない**。数値からは証明が出ないからである。
来るとすれば、検出した関係が既知の定理の言い換えだった場合か、
検出後に独立に証明できた場合である。

### 予想

数値的な証拠があり、理論的な理由も期待できるもの。次をすべて書く。

- **主張**：$x = \frac{a}{b}\,m(P)$ のような形で、係数まで明示する
- **数値的証拠**：何桁で検出したか、精度を上げても保たれたか
- **偽陽性の見積もり**：項数・係数上限・精度から、偶然一致の可能性をどう評価したか
- **理論的な理由**：なぜこの形の関係が期待されるのか。
  **理由が書けない場合は、その旨を明記する**（下の「観察」に落とすべき場合が多い）
- **反証の仕方**：どうすればこの予想が否定されるか

最後の項目が重要である。`成果の出し方.md` の「反証可能な形（潰れ方を書く）にする」に従う。

### 観察

数値的な一致はあるが、理論的な理由がないもの。

**予想と呼ばない。** 「これこれの精度でこれこれの関係が見つかった」という事実だけを記録する。
理由が後から見つかったら予想へ昇格させる。

**大半はここに留まるはずである。** それでよい。

## 書いてはいけないこと

- 「$x$ は Mahler 測度**である**」（証明していないのに断定する）
- 「数値的に確認した」を検証の完了として扱う
- 精度と項数を書かずに関係だけを書く
- 見つからなかった関係を記録しない（**否定的な結果も情報である**）

## 記録の様式

一つの定数につき一つのエントリを作り、次を並べる。

```
定数名
  値（何桁まで計算したか、計算方法）
  探索した項の集合（先に固定したもの）
  検出された関係（なければ「なし」）
  精度を上げたときの挙動
  偽陽性の見積もり
  水準（定理 / 予想 / 観察）
  理論的な理由（あれば）
  反証の仕方
```

**「なし」も必ず記録する。** どの項集合で探して見つからなかったかは、
次に別の項集合を試すときの前提になる。

## 既存の予想との照合

検出した関係が**既知の定理・予想と一致しているか**を必ず確認する。

- Boyd の予想の一覧と照合する
  （[`docs/research/Boyd-Deninger-Beilinson/`](../../research/Boyd-Deninger-Beilinson/)）
- 既知の恒等式の言い換えでないか確認する

**再発見を新発見として出さない。** これは信用の問題であり、
一度やると以降の主張がすべて割り引かれる。

ただし、**再発見であっても機械的に再現できたことは記録に値する**。
手法の検証になるからである。その場合は「既知の関係を再検出した」と明記する。

## 昇格の道

観察 → 予想 → 定理 の昇格条件を決めておく。

| 昇格 | 条件 |
|---|---|
| 観察 → 予想 | 理論的な理由が書ける、かつ精度を上げても関係が保たれる |
| 予想 → 定理 | 証明がつく。四層を適用する |

**逆向きの降格もありうる。** 精度を上げて関係が壊れたら、観察ごと取り消して記録に残す。
[docs/context/成果の出し方.md](../../context/成果の出し方.md) の
「仮説が否定された場合も必ず記録する」に従い、**消さない**。
