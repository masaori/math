# 整数関係検出の道具

**与えられた実数 $x$ が、既知の定数たちの整数係数の組合せで書けるか**を機械的に探す方法。

## 問題設定

実数 $x_1,\dots,x_n$ が与えられたとき、すべてが $0$ ではない整数 $a_1,\dots,a_n$ で

$$
a_1x_1+\cdots+a_nx_n=0
$$

を満たすものを見つける（あるいは、一定の大きさ以下には存在しないことを示す）。

これを **整数関係検出（integer relation detection）** という。

**用途に落とすと**：

| 問い | 設定の仕方 |
|---|---|
| $x$ は代数的数か（次数 $d$ 以下） | $(1,x,x^2,\dots,x^d)$ に関係があるか |
| $x$ は $\log$ の有理数係数の組合せか（$\Lambda$ 的か） | $(x,\ell_2,\ell_3,\ell_5,\dots)$ に関係があるか |
| $x$ は $L$ 値の有理数倍か | $(x, L(E,2), \pi^2, \dots)$ に関係があるか |
| $x$ は Mahler 測度 $m(P)$ と一致するか | $(x, m(P))$ に関係があるか |

## 使う道具

### PSLQ

- Ferguson–Bailey–Arno (1999)。整数関係検出の標準的なアルゴリズム
- 必要精度：**関係式の係数の桁数 × 項数** 程度が目安。
  係数が $10^k$ 程度なら $nk$ 桁以上が要る ［要確認：正確な要件］
- SageMath / mpmath の `pslq` で使える

### LLL

- Lenstra–Lenstra–Lovász (1982)。格子基底簡約。整数関係検出にも使える
- **代数的数の判定（最小多項式の推測）にはこちらが標準的**。
  `algdep` / `algebraic_dependency` が SageMath にある
- PSLQ より汎用だが、目的特化では PSLQ が速い場合がある

### SageMath での入口

```
# 概略（実コードではない）
algdep(x, degree)              # x の最小多項式の候補（LLL ベース）
mpmath.pslq([x, log(2), log(3)], tol=..., maxcoeff=...)
```

## 精度の要件が本質的である

**この手法の成否は精度で決まる。** 精度が足りないと関係が見つからず、
過剰な関係（偽陽性）が見つかる。

- 求めたい関係の係数が大きいほど、必要精度が高い
- 項数 $n$ が多いほど、必要精度が高く、かつ**偽陽性が増える**
- 目安：$n$ 項・係数 $10^k$ の関係を検出するには $\gtrsim nk$ 桁 ［要確認］

したがって、**定数を高精度で計算できることが前提条件**になる。
これができない定数は標的にならない。

### 高精度計算ができる定数の条件

| 定数の型 | 高精度計算の可否 | 方法 |
|---|---|---|
| 有限行列の固有値 | ○ | `QQbar` で厳密、または任意精度 |
| Mahler 測度 $m(P)=\int\log\lvert P\rvert$ | ○ | 収束の速い級数表示がある場合が多い |
| 転送行列の最大固有値の $\log$ | ○ | 有限 $L$ なら厳密、極限は外挿 |
| 熱力学極限の自由エネルギー | **場合による** | 閉形式があれば○、なければ外挿の精度に依存 |
| 数値的にしか知られていない臨界指数 | × | 精度が足りない。標的外 |

**熱力学極限を外挿で求めた値は精度が出ない**ので、この手法の標的にしにくい。
閉形式または高速収束する表示があるものに限られる。

## 偽陽性の扱い

**これが最大の落とし穴である。**

項数を増やせば、有限精度の数値には必ず何らかの関係が「見つかる」。
$n$ 項・係数上限 $C$ の探索空間は $C^n$ 程度あるので、
精度 $P$ 桁に対して $C^n\gtrsim 10^P$ なら偶然の一致が起きる。

**規律**：

1. **探索する項の集合を先に固定する。** 見つからないからといって項を足さない
2. **見つかった関係を、さらに高い精度で検証する。**
   精度を 2 倍にしても関係が保たれるかを確認する。これが最も効く篩
3. **項数と精度から、偶然一致の確率を見積もって記録する**
4. **理論的な理由がある関係を優先する。**
   Beilinson 予想が予言する形の関係と、無関係な定数との関係では、信頼度が違う

3 と 4 を怠ると、**それらしい数値的一致の山ができるだけ**になる。
[docs/context/成果の出し方.md](../../context/成果の出し方.md) の
「物量そのものに価値があるのではない」が最も効く場面である。

## 出力の帰属を記録する

検出した関係は、**どの可算集合への帰属を主張しているか**で分類する。

| 検出した関係 | 帰属の主張 |
|---|---|
| $(1,x,\dots,x^d)$ に関係 | $x\in\overline{\mathbb{Q}}$（次数 $\le d$） |
| $(x,\ell_2,\ell_3,\dots)$ に整数係数の関係 | $x\in\Lambda$ |
| $(x,\ell_2,\dots)$ に代数的係数の関係 | $x\in\bigoplus_p\overline{\mathbb{Q}}\ell_p$（**Baker が要る領域**） |
| $(x, m(P))$ に関係 | $x$ は Mahler 測度と有理関係 |
| $(x, L(E,s),\pi^k)$ に関係 | $x$ は $L$ 値と有理関係 |

3 行目に注意する。[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の方針では**代数的係数へは原則進まない**（Schanuel/Baker 依存を避ける）。
検出結果がこの型になった場合は、**方針の外にあることを明示して記録する**。
