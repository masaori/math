# 物理定数の帰属を機械で当てる

**統計力学に現れる定数が、どの可算集合の元なのかを、高精度計算と整数関係検出で当てる**
という探索プログラムの研究ノート。

## 問い

格子模型のエントロピー密度・自由エネルギー・臨界点といった定数は、
$\mathbb{R}$ の元として書かれる。しかし実際には、

- 代数的数である場合がある（六角格子の connective constant $=\sqrt{2+\sqrt2}$）
- Mahler 測度である場合がある（ダイマー模型のエントロピー）
- $L$ 関数の特殊値と関係する場合がある（Boyd の予想）
- 何でもない（そう見える）場合がある

**どれなのかは、多くの場合わかっていない。** これを機械的に当てにいく。

> **この物理量は、どの可算集合の元か。**

これが本ノートの問いである。[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の「$\mathbb{R}$ 脱出の台帳」を、**受動的な記録から能動的な発見プログラムへ変える**ことに当たる。

## 方法

古典的な手筋である。

1. 定数を**高精度**（数百〜数千桁）で計算する
2. **整数関係検出**（PSLQ、LLL）で、既知の定数との整数係数関係を探す
3. 関係が見つかれば予想として提示し、証明を試みる

**これは発見の経路であって証明ではない。**
[docs/context/成果の出し方.md](../../context/成果の出し方.md) のガードレール
「数値検証が通ったことを証明と呼ばない」が直接効く。出力は**予想**として書く。

## 先例

この手筋で数学の予想が生まれた実例がある。**新しい方法ではない。**

- **Boyd の予想**（1998）— Mahler 測度と楕円曲線の $L$ 関数の特殊値の関係を、
  高精度数値から発見した。Deninger (1997) による Beilinson 予想との接続が理論的背景
- **BSD 予想** — Birch と Swinnerton-Dyer が EDSAC での計算から立てた
- **Ramanujan 型の恒等式の機械発見** — PSLQ による多数の実例

差分があるとすれば、**標的の選び方**である。統計力学の定数を系統的に走査した記録を私は知らない
［要調査］。個別の定数についての研究はあるが、台帳として埋めた例が見当たらない。

## 立場依存性

**立場に依存しない。** 出力は「この定数は $\overline{\mathbb{Q}}$ の元／Mahler 測度／$L$ 値である」
という主張で、[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md)
の前提を共有しない読者にとっても意味がある。

むしろこの標的は、**立場を説明せずに成果だけ提示できる**点で使いやすい。
