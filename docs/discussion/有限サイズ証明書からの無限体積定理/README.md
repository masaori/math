# 有限サイズ証明書からの無限体積定理

**有限系についての厳密な計算を証明書として、無限体積についての定理を出す**という経路の研究ノート。

## 問い

無限体積のスペクトルギャップの有無は、一般には決定不能である（Cubitt–Pérez-García–Wolf,
*Nature* 2015、および 1 次元版 Bausch–Cubitt–Lucia–Pérez-García 2020）。
それでもなお、**特定の模型についてはギャップの存在を証明できる**。どうやって、そしてどこまでか。

答えの型は決まっている。**片側の証明書**である。

> サイズ $n$ の有限系についてある不等式が成り立てば、無限体積でギャップが開く。

この形の定理があれば、有限次元行列の厳密な計算で仮定を検査でき、
発火すれば**得られるのは推定値ではなく定理**になる。発火しなければ何も言わない——
だから一般の決定不能性と矛盾しない。

## なぜこの経路か

[docs/context/成果の出し方.md](../../context/成果の出し方.md) の二条件を両方満たす。

| 条件 | 判定 | 理由 |
|---|---|---|
| 機械にかけられるか | ○ | 有限次元・整係数行列。固有値は $\overline{\mathbb{Q}}$。`QQbar` で厳密、Lean で `decide` に載る |
| 数学・物理として意味があるか | ○ | ギャップの存在は未解決の模型が多数ある。物性・量子情報の中心的な問い |

加えて、**物量が直接効く**。判定条件が発火するサイズまで押し上げられるかどうかが勝負で、
それは計算資源と厳密性の問題だからである。

そして重要な性質として、**この経路は立場に依存しない。**
[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の前提
（自然は有限）を共有しない読者にとっても「無限体積の定理」として成果になり、
前提を共有する読者にとっては「有限側の主張を有限のまま証明した」ことになる。
本リポジトリの標的の中で、**両方の立場から価値が認められる数少ない項目**である。

## 何が新しいのか（正直な差分）

**有限サイズ判定条件そのものは既存の道具である。** Knabe (1988) 以来 30 年以上の蓄積があり、
六角格子 AKLT のギャップ証明（Lemm–Sandvik–Wang 2020）のように実際に使われている。
ここで新しいものを主張してはならない。

差分があるとすれば次の三点で、いずれも**方法論の側**にある。

1. **判定条件の検査が厳密でない場合がある。** 既存の適用例では、有限系の対角化を
   浮動小数点で行い、誤差評価を別途つけている。`QQbar` による厳密計算に置き換えれば、
   誤差評価の議論そのものが不要になる（[厳密計算とLeanへの落とし方](厳密計算とLeanへの落とし方.md)）。
2. **判定条件が形式検証されていない。** Knabe 型の定理を Lean で形式化した例を私は知らない。
   形式化すれば「有限計算 → 無限体積定理」の全体が機械検証済みになる。
3. **未適用の模型が残っている。** 判定条件は模型ごとに手で回すものだったので、
   総当たりで適用した記録がない。物量が効くのはここ。

## 次の一歩

[既知結果の再現から始める](既知結果の再現から始める.md) に書いた順で進める。要約すると：

1. Knabe の判定条件の主張を、定数まで含めて原論文で確定する（本ノートの記述は**未確認**）
2. 1 次元 AKLT 模型で、判定条件の左辺を `QQbar` で厳密に計算し、発火することを再現する
3. 再現できたら Lean で判定条件を形式化し、有限計算の部分を `decide` に載せる
4. そこまでできてから、未証明の模型へ向ける
