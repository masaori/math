# 厳密計算と Lean への落とし方

有限サイズ判定条件を、**浮動小数点を使わずに検査し、機械検証済みにする**ための設計。

## なぜ厳密計算にこだわるのか

判定条件は $\gamma_n>\theta(n)$ という**不等式**である。
浮動小数点で $\gamma_n$ を求めると、不等式の判定に誤差評価が要る。
既存の適用例はここで別途の議論を挟んでいる ［要確認：具体例ごとの扱い］。

一方、模型の重みが整数・有理数なら、**この不等式は代数的数の比較に過ぎない**。
$\overline{\mathbb{Q}}$ の順序は根分離で決定可能なので、誤差の議論そのものが消える。

> [docs/context/成果の出し方.md](../../context/成果の出し方.md)：
> 「SageMath は `ZZ`/`QQ`/`QQbar`・素因数分解。**丸めが原理的に入らない**」

## 何が $\overline{\mathbb{Q}}$ で閉じるか

スピン鎖の局所ハミルトニアン $h$ が有理数成分をもつとき（AKLT の射影子は有理数成分）：

| 対象 | 帰属 | 理由 |
|---|---|---|
| $n$ サイトのハミルトニアン行列 $H_n$ | $\mathbb{Q}^{d^n\times d^n}$ | 局所項の和。有理数成分 |
| 特性多項式 $\chi_{H_n}(x)$ | $\mathbb{Q}[x]$ | 有理数成分行列の行列式 |
| 固有値 $\lambda_i$ | $\overline{\mathbb{Q}}\cap\mathbb{R}$ | $\chi_{H_n}$ の根。エルミートなので実 |
| ギャップ $\gamma_n=\lambda_2-\lambda_1$ | $\overline{\mathbb{Q}}$ | 代数的数の差 |
| 閾値 $\theta(n)$ | $\mathbb{Q}$ | $1/(n-1)$ 等の有理式 |
| 判定 $\gamma_n>\theta(n)$ | **決定可能** | 代数的数と有理数の比較＝根分離 |

**$\mathbb{R}$ 脱出はどこにもない。** これが本経路の核心である。

### SageMath での実装方針

```
# 概略（実コードではない）
H = matrix(QQ, ...)              # 有理数成分で構成
chi = H.charpoly()               # QQ[x]
roots = chi.roots(QQbar)         # QQbar で厳密に
gamma = roots[1] - roots[0]      # QQbar の元
gamma > threshold                # 厳密な比較（根分離）
```

**注意すべき点**：

- `QQbar` の演算は次数が上がると急速に重くなる。$d^n$ 次元の特性多項式は
  $n$ が二桁になると現実的でない可能性が高い ［未検証：どこまで回るか］
- 対称性（並進不変性、スピン回転対称性）でブロック対角化してから対角化する。
  ブロック分解自体も有理数・円分体の範囲でできる（$x^n-1$ の因数分解）
- **最小固有値だけでなく第 2 固有値が要る**ので、Perron–Frobenius 型の反復では足りない。
  特性多項式の根を分離する方向になる
- 特性多項式を全部展開せず、**Sturm 列や根の分離だけで不等式を判定できれば十分**である。
  $\gamma_n>\theta$ は「$\chi$ の 2 番目に小さい根が $\lambda_1+\theta$ より大きい」という主張なので、
  $\chi$ の $(\lambda_1+\theta,\infty)$ での符号変化を数えれば足りる ［未検証］

最後の点は重要で、**代数的数を構成せずに不等式だけ判定できる**なら計算量が大きく下がる。
Sturm の定理は有理数係数多項式について完全に決定可能である。

## Lean への落とし方

四層（[docs/context/証明の書き方.md](../../context/証明の書き方.md)）のうち、この標的では
**Lean 具体版が「判定条件の定理そのもの」**になる。人手証明は Knabe の論文の再構成である。

### 何を形式化するか

```
定理（形式化の目標）
  仮定: H は フラストレーションフリー・並進不変・有限レンジ
        γ_n > θ(n)
  結論: γ_∞ > 0
```

この定理は**無限系についての主張**なので、Lean 側では無限鎖の扱いが必要になる。
そこが最大の難所である。

### 難所の見積もり

| 部分 | 難易度 | 理由 |
|---|---|---|
| 有限次元の線形代数（固有値・変分原理） | 中 | mathlib に `Matrix`・`IsHermitian`・`eigenvalues` がある |
| 有理数成分行列の固有値が代数的であること | 中 | `Polynomial` と根の理論。mathlib にある |
| Sturm 列による不等式判定 | 中〜高 | mathlib に Sturm の定理があるか未確認 ［要確認］ |
| フラストレーションフリーの定義と基本性質 | 高 | 物理側の定義。mathlib に前例なし。自前で書く |
| 無限鎖のハミルトニアンとギャップの定義 | **最高** | 準局所代数・GNS・非有界作用素。mathlib の整備状況が不明 ［要確認］ |
| Knabe の帰納的な評価 | 高 | 論文の議論を追う。技術的だが有限的 |

**無限鎖の定式化が最大のリスクである。** mathlib に $C^*$ 代数と GNS 構成はあるが、
量子スピン系の準局所代数と無限体積のギャップを扱った前例を私は知らない ［要確認］。

### 分割案

全体を一度に形式化しない。**有限の部分だけを先に切り出す。**

1. **有限部分だけを Lean にする**：「$H_n$ が与えられたとき $\gamma_n>\theta(n)$ が成り立つ」を
   `decide` あるいは Sturm 列で証明する。無限鎖には一切触れない
2. Knabe の定理は**引用**として扱い、その仮定が満たされることだけを機械検証する
3. 無限鎖の定式化は別プロジェクトとして切り出し、できたら接続する

この分割なら、**1 は今すぐ着手できて、それだけでも意味がある**。
「この模型についてこのサイズで判定条件が発火することを、機械検証済みで示した」は成果である。

`docs/context/成果の出し方.md` の「各段でどこまで進んだかを明示する」に従い、
1 だけできた段階では**「有限部分のみ機械検証。Knabe の定理は引用」**と書く。
