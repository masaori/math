# 既知結果の再現から始める

未証明の模型へ向ける前に、**既に証明されている模型で判定条件が発火することを再現する**。
足場作りであって成果ではないが、ここを飛ばすと何が失敗したのか切り分けられない。

## なぜ再現から始めるのか

この経路には失敗しうる箇所が三つあり、どれで失敗したかを区別する必要がある。

1. **判定条件の記述が違っている**（定数・仮定の読み違い）
2. **計算が現実的なサイズで回らない**（`QQbar` の次数爆発）
3. **その模型にはギャップがない**（あるいはこの判定条件では届かない）

既知の模型なら 3 が除外されるので、1 と 2 だけを切り分けられる。

## 着手順

### 第一段階：一次元 AKLT 模型

**最初の標的。** 判定条件が発火することが確実で、規模も小さい。

- **模型**：スピン 1 の鎖、$H=\sum_i P^{(2)}_{i,i+1}$（隣接ペアのスピン 2 成分への射影子）
- **既知**：ギャップは存在する（Affleck–Kennedy–Lieb–Tasaki 1987、
  Fannes–Nachtergaele–Werner 1992 で厳密化）
- **なぜ良いか**：
  - 射影子の成分が**有理数**（Clebsch–Gordan 係数から）
  - 基底状態が MPS で厳密に書けるので、転送作用素経路も試せる
  - フラストレーションフリー（各局所項が基底状態を消す）
  - $d=3$、$n$ サイトで $3^n$ 次元。$n=8$ で 6561 次元、$n=10$ で 59049 次元
- **確認すること**：
  - [ ] $H_n$ が有理数成分で構成できるか（Clebsch–Gordan の有理性 ［要確認］）
  - [ ] 特性多項式を `QQ[x]` で出せる $n$ の上限
  - [ ] $\gamma_n$ の厳密値が `QQbar` で得られる $n$ の上限
  - [ ] Sturm 列だけで $\gamma_n>\theta(n)$ を判定した場合、どこまで $n$ を上げられるか
  - [ ] Knabe の閾値で発火する最小の $n$（文献値と一致するか）

**並進不変性でブロック対角化**すれば次元は $3^n/n$ 程度に落ちる。
ブロック分解の基底は $1$ の $n$ 乗根で書けるので、円分体 $\mathbb{Q}(\zeta_n)$ の範囲。
**$\mathbb{R}$ に出ない。**

### 第二段階：転送作用素経路（MPS）

同じ AKLT について、Fannes–Nachtergaele–Werner の経路で計算する。

- **入力**：AKLT の MPS 表現の転送作用素（$4\times4$ 行列 ［要確認：次元］）
- **利点**：サイズを上げる必要がない。**有限次元一つで閉じる**
- **確認すること**：
  - [ ] 転送作用素の成分が有理数か
  - [ ] スペクトルギャップの下界が $\overline{\mathbb{Q}}$ の不等式として書けるか

**可算側との相性はこちらのほうが良い可能性が高い。**
Knabe 経路が計算量で詰まった場合の代替になる。

### 第三段階：六角格子 AKLT

既知の適用例（Lemm–Sandvik–Wang 2020）を再現する。

- **既知**：ギャップが存在する
- **なぜ良いか**：**既存の適用例が厳密計算だったか数値計算だったかを確認できる**。
  数値だったなら、厳密化そのものが差分になる
- **懸念**：2 次元なので次元が急速に大きくなる。
  元論文がどの程度のサイズを扱ったかを確認する必要がある ［要確認］

### 第四段階：Lean 形式化

第一段階が回ったら、[厳密計算とLeanへの落とし方](厳密計算とLeanへの落とし方.md) の分割案に従い、
**有限部分だけ**を Lean にする。

- [ ] $H_n$ の構成を Lean で書く
- [ ] $\gamma_n>\theta(n)$ を Sturm 列あるいは `decide` で証明する
- [ ] Knabe の定理は引用とし、仮定の充足だけを機械検証する

この段階で「有限部分のみ機械検証」と明示して記録する。

## 再現ができたあとの標的（未着手）

ここから先は再現ではなく本番になる。**まだ何も調べていない。**

- ギャップの有無が未解決のフラストレーションフリー模型のリスト ［未調査］
- 二次元 AKLT の他の格子（正方格子、装飾格子）での既知・未知の切り分け ［未調査］
- ギャップの存在が数値的にしか知られていない模型 ［未調査］

**リストを作るところから物量が効く。** ただし
[docs/context/成果の出し方.md](../../context/成果の出し方.md) のガードレールどおり、
「候補を大量に列挙した」は成果ではない。発火したものだけが成果である。

## 記録の規律

各段階で必ず記録する。

- **発火しなかった場合も記録する。** どのサイズまで計算して発火しなかったかは情報である
- **計算が詰まった場合も記録する。** どの次元で `QQbar` が現実的でなくなったかは、
  次の設計判断に使う
- 文献値と食い違った場合は、**判定条件の記述を疑う**（本ノートの ［要確認］ が回収される）
