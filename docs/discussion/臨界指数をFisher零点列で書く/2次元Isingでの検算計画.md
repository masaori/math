# 2 次元 Ising での検算計画

辞書の**検証水準**（[何が厳密で何が非厳密か](何が厳密で何が非厳密か.md)）を回す手順。
厳密解が既知なので、計算が正しいかを独立に確認できる。

## 目的

**証明ではなく、道具が回るかの確認と、命題の候補探しである。**
これを成果と呼ばない。

得たいものは二つ。

1. `QQbar` が現実的に回る $L$ の上限（実測）
2. 零点列の構造で、連続体側に対応物のない量が何か見えるか

## 手順

### 分配多項式の構成

有限格子 $\Lambda_L$（$L\times L$、周期境界）の分配関数を、変数 $u=\tanh\beta J$ で構成する。

構成法は三つあり、計算量が違う。

| 方法 | 計算量 | 備考 |
|---|---|---|
| 全配置の総和 | $O(2^{L^2})$ | $L=5$ で $2^{25}$。**すぐ詰まる** |
| 転送行列 $Z_L=\mathrm{Tr}\,T^L$ | $O(L\cdot 2^{3L})$ ［要確認］ | $T$ は $2^L\times2^L$。$L=12$ 程度まで？ |
| Kac–Ward 行列式 / Kasteleyn の Pfaffian | 多項式時間 | **$4L^2\times4L^2$ 程度の整係数行列式** |

**三つ目が本命。** 帰属の観点でも良い：Kac–Ward は向き付き辺の行列 $\det(I-uD)$ で、
$D$ の成分は $1$ の冪根（円分体 $\mathbb{Q}(\zeta)$）。**$\mathbb{R}$ に出ない。**

→ 一次情報は
[`docs/discussion/対数順序群上の統計力学/10_Step3の厳密化_KacWardとPfaffian.md`](../対数順序群上の統計力学/10_Step3の厳密化_KacWardとPfaffian.md)

**確認すること**：
- [ ] 三つの方法で小さい $L$（$L=3,4$）の結果が一致するか（実装の検算）
- [ ] Kac–Ward 経路で $L$ をどこまで上げられるか
- [ ] 係数が本当に整数になるか（前因子の扱い ［要確認］）

### 零点の計算

$Z_L(u)\in\mathbb{Z}[u]$ の根を `QQbar` で求める。

**確認すること**：
- [ ] `QQbar` で全根を分離できる次数の上限（次数は $2L^2$ 程度）
- [ ] 実軸最近接零点 $u_1(L)$ の同定（複素平面での距離比較は $\overline{\mathbb{Q}}$ で厳密にできる）
- [ ] $u_c=\sqrt2-1$ との距離 $\lvert u_1(L)-u_c\rvert^2\in\overline{\mathbb{Q}}$ を厳密に出す

**注意**：全根を求める必要はないかもしれない。実軸最近接の一つが欲しいだけなら、
根の分離だけで足りる可能性がある。計算量が大きく変わるので設計時に検討する ［未検討］。

### 増大率の確認

$\lvert u_1(L)-u_c\rvert$ の列を $L=3,4,5,\dots$ について並べ、$L^{-1}$（$\nu=1$）と整合するかを見る。

**ここで初めて $\mathbb{R}$ 脱出が起きる**（漸近形の比較）。
[docs/context/証明の書き方.md](../../context/証明の書き方.md) の規律どおり、
**脱出した箇所として記録する**。

有効な書き方は、比を取ることである。

$$
r_L:=\frac{\lvert u_1(L)-u_c\rvert}{\lvert u_1(L+1)-u_c\rvert}\ \in\ \overline{\mathbb{Q}}
$$

$r_L$ は**代数的数のまま**であり、$\nu=1$ なら $r_L\to (L+1)/L$。
**比較したい相手が有理数なので、$\overline{\mathbb{Q}}$ の中で比較できる。**
$\mathbb{R}$ 脱出を極限の一点だけに隔離できる。

### 命題の候補探し

検算の副産物として、次を記録する。**連続体側に対応物がない量である。**

- [ ] $u_1(L)$ の**最小多項式の次数**は $L$ とともにどう振る舞うか
- [ ] その多項式の**判別式**・**係数の増大**はどうか
- [ ] $Z_L$ の因数分解のパターン（円分多項式が分離するか）
- [ ] 零点が代数的数として**どの体に住むか**（$L$ に応じた体の族があるか）

**これらは可算側でしか問えない量である。** 何か規則性が見えれば、
[何が厳密で何が非厳密か](何が厳密で何が非厳密か.md) の「再定式化水準」で述べうる命題の候補になる。
見えなければそれも記録する。

## 失敗の記録

以下は**必ず記録する**（[docs/context/成果の出し方.md](../../context/成果の出し方.md)：
「仮説が否定された場合も必ず記録する」）。

- `QQbar` が詰まった次数と、そのときの $L$
- 三つの構成法の結果が食い違った場合、どこで食い違ったか
- 増大率が $\nu=1$ と整合しなかった場合（実装の誤りか、規約の誤りかの切り分け）
- 命題の候補が何も見つからなかった場合、**何を見て見つからなかったか**
