# Fisher 零点と有限サイズスケーリングの辞書

**連続体側の量**と、**有限系の厳密なデータ**の対応表。

> 記述は文献からの読み取りであり、指数の対応・規約は未確認の箇所がある。［要確認］ を付けた。

## 設定

有限格子 $\Lambda_L$（$L\times L$、周期境界）上の 2 次元 Ising 模型を基準にする。

- スピン配置 $\sigma\in\{-1,+1\}^{\Lambda_L}$（**有限集合**、$\#=2^{L^2}$）
- 分配関数 $Z_L(u)=\sum_\sigma\prod_{\langle x,y\rangle}(\cdots)$。
  高温展開の変数 $u=\tanh\beta J$ を取ると $Z_L(u)\in\mathbb{Z}[u]$ ［要確認：前因子の扱い］
- **係数は整数、次数は辺数 $2L^2$**

$Z_L$ の複素根を **Fisher 零点**という。定義から $\overline{\mathbb{Q}}$ の元。

## 対応表

| 連続体側の概念 | 有限側の厳密なデータ | 帰属 |
|---|---|---|
| 分配関数 $Z$ | $Z_L(u)\in\mathbb{Z}[u]$ | $\mathbb{Z}$ 係数多項式 |
| 自由エネルギー密度 $f$ | $\frac{1}{L^2}\log Z_L(u)$、有理点 $u\in\mathbb{Q}$ なら $\Lambda$ の元 | $\Lambda$ |
| 相転移＝$f$ の非解析性 | **有限 $L$ では存在しない。** 零点が実軸に接近する現象として現れる | — |
| 臨界点 $u_c$ | 零点列の集積点。2 次元 Ising では $u_c=\sqrt2-1\in\overline{\mathbb{Q}}$ | $\overline{\mathbb{Q}}$ |
| 相関長 $\xi$ | 転送行列の第 1・第 2 固有値の比。有限 $L$ では代数的数 | $\overline{\mathbb{Q}}$ |
| 相関長臨界指数 $\nu$ | 実軸最近接零点の**接近率**：$\lvert u_1(L)-u_c\rvert\sim L^{-1/\nu}$ | 列の増大率 |
| 比熱指数 $\alpha$ | 零点の**密度**の振る舞い ［要確認：正確な関係式］ | 列の増大率 |
| 磁化指数 $\beta$ | Lee–Yang 零点（フガシティ平面）の実軸への接近 ［要確認］ | 列の増大率 |
| 感受率指数 $\gamma$ | Lee–Yang 零点のギャップ指数 ［要確認］ | 列の増大率 |
| 中心電荷 $c$ | 有限 $L$ の自由エネルギーの $1/L^2$ 補正の係数 ［要確認：Blöte–Cardy–Nightingale の関係式］ | 列の係数 |

**この表の右列は、すべて有限系についてのデータである。** 左列は右列から読み取られた要約であり、
逆ではない。これが本ノートの主張の内容である。

## 各行の補足

### 臨界点 $u_c$ が代数的であること

2 次元 Ising の自己双対点は $\sinh 2\beta J=1$、すなわち $u_c=\sqrt2-1$。
**これは代数的数であり、$\overline{\mathbb{Q}}$ に住む。**
一方、対応する温度 $\beta_c J=\frac12\log(1+\sqrt2)$ は $\Lambda$ にも $\overline{\mathbb{Q}}$ にも属さない
（$\ell_p$ の $\overline{\mathbb{Q}}$ 係数の組合せですらない）。

**変数の取り方で帰属が変わる**という重要な例である。
$u$（あるいは $z=e^{-2\beta J}$）を変数に取れば代数的、$\beta$ を変数に取れば超越的。
本リポジトリの立場では、**$u$ 側が一次データであり、$\beta$ 側が像である**と読む。

（Kramers–Wannier 双対性が代数的に書けるのもこの変数の選び方による。
→ [`docs/discussion/対数順序群上の統計力学/08_KW双対性_補足.md`](../対数順序群上の統計力学/08_KW双対性_補足.md)）

### $\nu$ が列の増大率であること

主張の形は

$$
\bigl\lvert u_1(L)-u_c\bigr\rvert\ \sim\ C\,L^{-1/\nu}\qquad(L\to\infty)
$$

左辺は各 $L$ について**厳密に計算できる代数的数**である（$u_1(L)$ も $u_c$ も $\overline{\mathbb{Q}}$、
絶対値の $2$ 乗は $\overline{\mathbb{Q}}$）。したがって

- 各 $L$ での値：**可算側で厳密**
- $L\to\infty$ の漸近形：**$\mathbb{R}$ 脱出**（極限と冪の比較）
- $\nu$ の値：像

2 次元 Ising では $\nu=1$ で**有理数**である。「指数が有理数になる」という事実は、
可算側から見ると自然だが、$\mathbb{R}$ 側の定式化からは説明されない。

### 中心電荷が有限サイズ補正から出ること

周期境界の帯状格子で、自由エネルギー密度の有限サイズ補正が
$f_L=f_\infty-\frac{\pi c}{6L^2}+o(L^{-2})$ の形になる（Blöte–Cardy–Nightingale、Affleck、1986 ［要確認：係数と幾何］）。

**$c$ が有限 $L$ のデータ列の係数として現れる**という点で、上の表と同じ構造である。
2 次元 Ising では $c=1/2$ で有理数。
