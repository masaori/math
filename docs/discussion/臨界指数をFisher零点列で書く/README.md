# 臨界指数を Fisher 零点列で書く

**臨界指数は連続体側の量ではなく、有限系の厳密なデータ列の性質として書けるのではないか**、
という問いの研究ノート。

## 問い

臨界指数は「連続極限でしか定義できない、$\mathbb{R}$ 側の量」として扱われる。
[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の前提に立つと、
この扱いは前提を逆に置いている。

有限系には非解析性も発散する相関長も存在しない。存在するのは**有限 $L$ の厳密なデータ列**だけである。
そして臨界指数が読み取られる先は、まさにその列の振る舞いである。

> **有限 $L$ の厳密な代数的データ列の、どの構造を、連続体側は「指数」と呼んで読み取っているのか。**

これが本ノートの問いである。「$\nu$ という実数は何か」ではない。

## なぜ Fisher 零点なのか

有限格子の分配関数は**整係数多項式**である。2 次元 Ising なら、$u=\tanh\beta J$ を変数として

$$
Z_L(u)\in\mathbb{Z}[u]
$$

（境界条件により定数倍や変数変換が入る）。この多項式の**複素根が Fisher 零点**であり、
定義から $\overline{\mathbb{Q}}$ の元である。有限 $L$ では

- $Z_L$ の係数は $\mathbb{Z}$
- 零点は $\overline{\mathbb{Q}}$
- 零点どうしの比較・距離の $2$ 乗は $\overline{\mathbb{Q}}$

すべて `QQbar` で厳密に扱える。**$\mathbb{R}$ 脱出がない。**

そして有限サイズスケーリングの標準的な主張は、**実軸に最も近い零点 $u_1(L)$ が臨界点 $u_c$ へ
$L^{-1/\nu}$ で近づく**というものである。つまり

$$
|u_1(L)-u_c|\ \sim\ L^{-1/\nu}
$$

$u_1(L)$ も $u_c$ も代数的数である（2 次元 Ising では $u_c=\sqrt2-1$）。
**指数 $\nu$ は、代数的数の列の増大率として現れている。**

これは $\mathbb{R}$ の中の一つの実数ではなく、**可算なデータ列についての主張**である。

## 何が本ノートの主張で、何が既存か

**既存**：Fisher 零点の有限サイズスケーリングは 1960 年代からある標準的な道具である
（Fisher 1965、Itzykson–Pearson–Zuber 1983 ほか）。数値的に指数を求める手法として
広く使われている。ここに新しさを主張してはならない。

**本ノートの主張（位置づけの変更）**：これを「指数を数値的に求める便法」ではなく、
**指数の可算側での正体そのもの**として読む。すなわち

- 連続体側の $\nu$ は、可算側の列 $\{u_1(L)\}_L$ の増大率の**像**である
- 一次データは列のほうであり、$\nu$ はそこから読み取られた要約である
- したがって、**厳密に扱えるのは列のほうであり、$\nu$ ではない**

**差分になりうるところ**：有限サイズスケーリングの関係式自体が、
物理では大部分が**非厳密**である。厳密に証明されている場合が限られる ［要調査：どこまで厳密か］。
**辞書の厳密化そのものが標的になる。**

## 立場依存性

- **問いの立て方は立場に依存する。** 「指数は圧縮の側の性質」という読みは前提の反転から来る
- **出力する命題は立場非依存にできる。**
  「$Z_L\in\mathbb{Z}[u]$ の実軸最近接零点の列は、これこれの増大率をもつ」は、
  誰にとっても意味のある主張である

[docs/context/物理を記述する数学の選び方.md](../../context/物理を記述する数学の選び方.md) の
「前提と成果物を分離する」に従い、**成果物は後者の形で書く。**
