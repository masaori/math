# 何が厳密で何が非厳密か

辞書の各行について、**証明があるのか、物理的な議論なのか**を切り分ける。
ここを曖昧にすると「厳密化した」と言えなくなる。

> 判定は私の理解に基づくもので、文献の系統的な確認をしていない。
> 「証明がない」は**「見つけていない」の意味**であり、存在しないことの証明ではない
> （[docs/context/成果の出し方.md](../../context/成果の出し方.md) のガードレール）。

## 切り分け

| 主張 | 状態 | 備考 |
|---|---|---|
| $Z_L(u)\in\mathbb{Z}[u]$ である | **証明あり（自明）** | 有限和。定義から |
| Fisher 零点が $\overline{\mathbb{Q}}$ の元である | **証明あり（自明）** | 整係数多項式の根 |
| 2 次元 Ising の $u_c=\sqrt2-1$ | **証明あり** | 自己双対性（Kramers–Wannier）＋転移の一意性 |
| Lee–Yang 零点が単位円上にある（強磁性） | **証明あり** | Lee–Yang の円定理（1952） |
| Fisher 零点が特定の曲線上に乗る（2 次元 Ising、正方格子） | **証明あり** ［要確認：どの境界条件で］ | Fisher (1965)、Lu–Wu ほか |
| 熱力学極限で $f$ が存在する | **証明あり** | 劣加法性（Fekete）。$\mathbb{R}$ の完備性を使う |
| $f$ が $u_c$ で非解析的である（2 次元 Ising） | **証明あり** | Onsager 解から |
| $\nu=1$（2 次元 Ising） | **証明あり** | 厳密解から相関長の漸近形が出る |
| $\lvert u_1(L)-u_c\rvert\sim L^{-1/\nu}$ という**関係式そのもの** | **不明** ［要調査］ | 有限サイズスケーリング仮説。一般には物理的な議論 |
| 有限サイズスケーリング仮説の一般形 | **物理的な議論** | くりこみ群からの導出は非厳密 |
| $f_L=f_\infty-\frac{\pi c}{6L^2}+\cdots$（中心電荷） | **物理的な議論** ［要確認］ | 共形場理論からの導出。厳密な模型では検算されている |
| 3 次元 Ising の指数の値 | **数値のみ** | 共形ブートストラップは高精度だが証明ではない |

## 決定的なのは 9 行目

> $\lvert u_1(L)-u_c\rvert\sim L^{-1/\nu}$ という関係式そのもの

**ここが厳密でないなら、辞書は辞書として機能していない。**

私の理解では、この関係式は有限サイズスケーリング仮説の帰結として物理では標準的に使われるが、
**一般の模型について証明された定理ではない**。ただし：

- 2 次元 Ising のように厳密解がある場合、両辺を独立に計算して一致を確認できる。
  これは**特定の模型についての検証**であって、関係式の証明ではない
- 厳密に証明された場合があるか ［要調査］。
  パーコレーションや特定の可解模型で、零点の位置の漸近形が厳密に出ている可能性がある

**したがって最初にやるべきことは、この行の文献調査である。**
「有限サイズスケーリング関係式が厳密に証明されている場合の一覧」が本ノートの最初の成果物になる。

## 厳密化の三つの水準

「辞書を厳密化する」と言ったとき、少なくとも三つ異なることを指しうる。混同しない。

### 検証水準：厳密解のある模型で両辺を厳密に計算して一致を見る

- 2 次元 Ising で $u_1(L)$ を `QQbar` で厳密に計算し、$\nu=1$ と整合することを確かめる
- **これは証明ではない。** 一つの模型についての一致の確認である
- ただし**すぐできる**。[2次元Isingでの検算計画](2次元Isingでの検算計画.md) がこれ

### 定理水準：関係式そのものを特定のクラスについて証明する

- 「これこれの条件を満たす模型では、$\lvert u_1(L)-u_c\rvert$ の漸近形はこれこれである」
- **これが本来の標的だが、難易度が高い。** 現時点で見通しがない

### 再定式化水準：$\nu$ を経由せずに、列そのものについての命題を立てる

- $\nu$ を定義せずに「$\{u_1(L)\}_L$ という代数的数の列は、これこれの性質をもつ」と述べる
- 連続体側の概念を一切使わないので、**可算側で完結する**
- ただし「これこれ」に何を入れるかが未定。**問いの形が定まっていない**

三つ目が本リポジトリの立場に最も合うが、**中身が空である**。
[docs/context/成果の出し方.md](../../context/成果の出し方.md) の
「2 だけなら我々がやる理由がない、1 だけなら計算しただけ」で言えば、
現状は 1（機械にかけられる）だけで 2（意味がある）が未確定という状態である。

## 正直な現状評価

- **検証水準はすぐ着手でき、確実に回る。** ただしそれ自体は成果ではない
- **定理水準は難しく、見通しがない**
- **再定式化水準は方向としては正しいが、述べるべき命題が見つかっていない**

したがって当面は検証水準を回しながら、
**再定式化水準で述べうる命題の候補を探す**のが現実的な進め方になる。
検算の過程で列の構造（零点の分布、代数的数としての次数、最小多項式の族としての規則性）に
何か見えれば、それが命題の候補になる。

**零点の最小多項式の次数や判別式が $L$ とともにどう振る舞うか**は、
連続体側には対応物がない量であり、可算側でしか問えない。ここに何かある可能性はある ［未検討］。
