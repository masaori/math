# 00 問いの設定と記法

このノート全体が答えようとしている問いは一つである：**「場の量子論」と呼ばれているものは、数学的対象としては何なのか。**
本章では、その問いが素朴には答えられない理由を述べ、以降の各章が提示する互いに異なる答えを比較するための共通の土俵（記法・所属集合の規約・「$\mathbb{R}$ 脱出」の追跡規則）を固定する。

---

## 0.1 問いが素朴には答えられない理由

「群とは何か」には一意な答えがある：公理系 $(G,\cdot_G,e_G,\mathrm{inv}_G)$ を満たす構造である。
「場の量子論とは何か」には、**現時点で一意な答えがない**。理由は次の三点に分けられる。

1. **物理側の定義が数学的な定義になっていない。** 物理で場の量子論を定義する標準的な書き方は
   $$
   Z=\int_{\Gamma} \mathcal{D}\phi\; e^{iS[\phi]/\hbar}
   $$
   であるが、$\mathcal{D}\phi$ は無限次元空間 $\Gamma$ 上の測度を指す記号であり、**そのような測度は存在しない**（[01](01_古典場と作用_経路積分は何でないか.md) §4）。したがってこの式は定義ではなく、**記法**である。

2. **数学側の定式化が複数あり、互いに同値であることが証明されていない。**
   Wightman 公理系（[02](02_Wightman公理系と再構成定理.md)）、Haag–Kastler ネット（[03](03_代数的QFT_Haag–Kastler.md)）、Osterwalder–Schrader 公理系（[04](04_ユークリッド化と構成的場の理論.md)）、Atiyah–Segal の関手（[06](06_関手的QFT_Atiyah–Segal.md)）、頂点作用素代数（[07](07_共形場理論と頂点作用素代数.md)）、因子化代数（[09](09_因子化代数とBV形式.md)）は、それぞれ独立した数学的定義である。一部の対（Wightman ⇔ OS、共形ネット ⇔ VOA）には同値定理があるが、全体を貫く同値は**ない**。

3. **物理が扱っている当の対象（4 次元の相互作用する模型）が、どの定式化でも構成されていない。**
   4 次元 Yang–Mills 理論が Wightman 公理を満たす対象として存在するかは未解決（Clay ミレニアム問題、[08](08_ゲージ理論_幾何と位相不変量.md) §7）。$\phi^4_4$ に至っては、**存在しない**（自由場に潰れる）ことが定理として証明されている（[04](04_ユークリッド化と構成的場の理論.md) §5）。

したがって本ノートの答えは「場の量子論とは X である」という単文にはならない。答えは
**「どの定式化を採るかで、数学的対象としての正体が変わる」** という表であり、その表を [README](README.md) に置く。

## 0.2 本ノートの厳密性方針

[`../従順群と非従順群の基礎論/00_記法と集合論的規約.md`](../従順群と非従順群の基礎論/00_記法と集合論的規約.md) の方針を踏襲する。要点のみ再掲する。

- **すべての元は所属を明示**する。$\phi$ とだけ書かない。$\phi\in\Gamma(M,E)$、$\phi\in\mathcal{S}'(\mathbb{R}^d)$、$\phi(f)\in\mathrm{End}(\mathcal{D})$ は互いに別の対象であり、場の量子論ではこの三者が同じ記号 $\phi$ で書かれるため、混同が起きやすい。
- **すべての写像は始域・終域を明示**する。$f\colon A\to B$。とくに**非有界作用素については定義域 $\mathcal{D}(T)\subseteq\mathcal{H}$ を明示**する（場の量子論の作用素はほぼすべて非有界であり、定義域を書かない等式は意味をもたない）。
- **確立した定理／予想・未解決／定義が存在しないもの**を区別する。本ノートでは次のラベルを使う。
  - **［定理］** — 証明が公表され、専門家の合意がある。
  - **［予想］** — 未証明。物理側で広く信じられているものを含む。
  - **［未定義］** — その概念に数学的定義が与えられていない。
  - **［部分的］** — 特定の次元・特定の模型でのみ確立している。
- **比喩を使わない。** 物理側の慣用表現（「粒子が生成される」「真空が揺らぐ」等）を引くときは、慣用表現であると断り、対応する数学的主張（作用素の作用、状態の期待値）を並記する。

## 0.3 可算・非可算の追跡規則（本ノートの中心的関心）

リポジトリ [CLAUDE.md](../../../CLAUDE.md) の原則により、**議論の土台にしている集合が可算か非可算か、どこで非可算集合や解析の道具へ移行したか**を常に追跡する。場の量子論はこの追跡が最も苛烈に効く分野である。本文中で次の印を使う。

> **［ℝ 脱出］** — この箇所で、可算的・代数的に閉じた議論から、$\mathbb{R}$/$\mathbb{C}$ の非可算性（極限・上限・積分・測度・完備化・連続な添字族）へ移行した。

逆に、代数的・有限的に閉じている箇所は積極的に指摘する。場の量子論には、意外なほど広い「$\mathbb{R}$ を使わない層」が存在する。

| 層 | 対象 | 可算性 |
|---|---|---|
| 有限格子・有限スピン | 分配関数 $=$ 有限和 | **有限**。係数が $\mathbb{Q}$ なら $\mathbb{Q}$ で閉じる |
| Feynman 図式の組合せ論 | 有限グラフの集合、Hopf 代数 | **可算**（[05](05_摂動論とくりこみの数学.md) §4） |
| 形式的べき級数としての摂動級数 | $\mathbb{C}[[\lambda]]$ の元 | 係数は可算個。収束は主張しない |
| 頂点作用素代数 | $\mathrm{End}(V)[[z,z^{-1}]]$、各次数有限次元 | **代数的**。解析を使わない（[07](07_共形場理論と頂点作用素代数.md) §3） |
| TQFT | 有限次元ベクトル空間への対称モノイダル関手 | **有限次元・代数的**（[06](06_関手的QFT_Atiyah–Segal.md) §1） |
| 位相不変量 | Chern 数、Donaldson/Seiberg–Witten 不変量 | 値は**整数**（[08](08_ゲージ理論_幾何と位相不変量.md) §4） |
| — 以下、非可算 — | | |
| 熱力学極限 | $\lim_{N\to\infty}\frac{1}{N}\log Z_N\in\mathbb{R}$ | $\mathbb{R}$ の完備性が要る |
| 連続極限・超関数 | $\mathcal{S}'(\mathbb{R}^d)$ 上の確率測度 | 非可算 |
| 局所代数 | III$_1$ 型 von Neumann 環 | 弱閉包。最小射影が存在しない |
| Segal の CFT | Riemann 面の moduli 上の連続族 | 非可算な射の空間 |

この表の上半分と下半分の**境界がどこにあるか**を各章で特定することが、本ノートのリポジトリ固有の目的である。総括は [10](10_可算性から見た場の量子論.md) に置く。

## 0.4 共通記法

### 0.4.1 数体系・集合

- $\mathbb{Z}_{\ge0}$（非負整数、可算）、$\mathbb{Z}$、$\mathbb{Q}$（可算）、$\overline{\mathbb{Q}}$（代数的数、可算）。
- $\mathbb{R}$（非可算、濃度 $2^{\aleph_0}$）、$\mathbb{C}$（非可算）。
- 埋め込みは名前をつける：$\iota_{\mathbb{Z}\hookrightarrow\mathbb{R}}$, $\iota_{\mathbb{Q}\hookrightarrow\mathbb{R}}$, $\iota_{\mathbb{R}\hookrightarrow\mathbb{C}}$。比・極限・上限を取る文脈でのみ明示する。
- 集合 $X$ の濃度は $\operatorname{card}(X)$、有限集合の要素数は $\#X\in\mathbb{Z}_{\ge0}$（**整数であって実数ではない**）。

### 0.4.2 時空

- $M$：時空多様体。$\dim_{\mathbb{R}}M=d\in\mathbb{Z}_{\ge1}$。物理の 4 次元時空は $d=4$。
- Minkowski 時空 $\mathbb{M}^d=(\mathbb{R}^d,\eta)$、計量 $\eta=\mathrm{diag}(+1,-1,\dots,-1)$（符号規約は本ノートでは mostly-minus に固定する）。
- Euclid 空間 $\mathbb{E}^d=(\mathbb{R}^d,\delta)$、$\delta=\mathrm{diag}(+1,\dots,+1)$。
- 格子：$\Lambda_{N,\varepsilon}=\{x\in(\varepsilon\mathbb{Z})^d : \|x\|_\infty\le N\varepsilon\}$（$\varepsilon\in\mathbb{Q}_{>0}$, $N\in\mathbb{Z}_{\ge1}$）。**$\Lambda_{N,\varepsilon}$ は有限集合**であり、$\#\Lambda_{N,\varepsilon}\in\mathbb{Z}_{\ge0}$。
- 因果構造：$x,y\in\mathbb{M}^d$ が**空間的に分離**しているとは $\eta(x-y,x-y)<_{\mathbb{R}}0$。開領域 $\mathcal{O}_1,\mathcal{O}_2\subseteq\mathbb{M}^d$ が空間的に分離しているとは、任意の $x\in\mathcal{O}_1$, $y\in\mathcal{O}_2$ が空間的に分離していること。

### 0.4.3 対称性の群

- Lorentz 群 $\mathrm{O}(1,d-1)$、その単位元成分 $\mathcal{L}^\uparrow_+=\mathrm{SO}^+(1,d-1)$。
- Poincaré 群 $\mathcal{P}^\uparrow_+=\mathbb{R}^d\rtimes\mathcal{L}^\uparrow_+$（並進と Lorentz 変換の半直積）。
- $d=4$ での普遍被覆 $\widetilde{\mathcal{P}^\uparrow_+}=\mathbb{R}^4\rtimes\mathrm{SL}(2,\mathbb{C})$。スピノル場を扱うにはこちらが要る。
- Euclid 群 $\mathrm{E}(d)=\mathbb{R}^d\rtimes\mathrm{SO}(d)$。

これらはすべて**非可算な Lie 群**である。**［ℝ 脱出］** 場の量子論の標準的な定式化は、出発点の対称性群の時点ですでに非可算集合を仮定している。この仮定を落とせるか（有限群・可算群のゲージ理論、格子上の離散対称性）が [10](10_可算性から見た場の量子論.md) の主題の一つ。

### 0.4.4 関数空間・超関数

- $C^\infty_c(\mathbb{R}^d)=\mathcal{D}(\mathbb{R}^d)$：コンパクト台の滑らかな複素数値関数。
- $\mathcal{S}(\mathbb{R}^d)$：Schwartz 空間（急減少関数）。Fréchet 空間であり、**核型（nuclear）**。
- $\mathcal{S}'(\mathbb{R}^d)$：緩増加超関数、$\mathcal{S}(\mathbb{R}^d)$ の連続双対。
- 超関数 $T\in\mathcal{S}'(\mathbb{R}^d)$ と試験関数 $f\in\mathcal{S}(\mathbb{R}^d)$ の対 $\langle T,f\rangle\in\mathbb{C}$。
- **核型性が本質的に効く**：Minlos–Bochner の定理（[04](04_ユークリッド化と構成的場の理論.md) §3）は $\mathcal{S}'$ では測度を作れるが Hilbert 空間では作れない、という形で核型性を使う。

### 0.4.5 Hilbert 空間・作用素

- $\mathcal{H}$：複素 Hilbert 空間。内積 $\langle\cdot,\cdot\rangle_{\mathcal{H}}\colon\mathcal{H}\times\mathcal{H}\to\mathbb{C}$（第 1 変数について共役線形とする）。
- **可分性**：Wightman 公理は $\mathcal{H}$ の可分性を課す（可算稠密部分集合が存在する）。これは「可算個のデータで $\mathcal{H}$ を近似できる」という主張であり、本ノートの関心上、重要な仮定である。一方 [03](03_代数的QFT_Haag–Kastler.md) の非真空セクターには非可分なものが現れうる。
- 非有界作用素 $T$：定義域 $\mathcal{D}(T)\subseteq\mathcal{H}$（稠密部分空間）と線形写像 $T\colon\mathcal{D}(T)\to\mathcal{H}$ の対。**$T$ と $\mathcal{D}(T)$ の組で一つの対象**であり、定義域を変えれば別の作用素になる。自己共役性 $T=T^*$ は定義域の一致まで含めた主張であり、対称性（$\langle T\psi,\varphi\rangle=\langle\psi,T\varphi\rangle$）より真に強い。
- $\mathcal{B}(\mathcal{H})$：有界線形作用素の全体（$C^*$ 代数）。
- 作用素値超関数：$\mathcal{D}\subseteq\mathcal{H}$ を稠密部分空間として、線形写像 $\phi\colon\mathcal{S}(\mathbb{R}^d)\to\mathrm{End}(\mathcal{D})$, $f\mapsto\phi(f)$ で、任意の $\Psi,\Phi\in\mathcal{D}$ について $f\mapsto\langle\Psi,\phi(f)\Phi\rangle_{\mathcal{H}}\in\mathbb{C}$ が $\mathcal{S}(\mathbb{R}^d)$ 上の連続線形汎関数（すなわち $\mathcal{S}'(\mathbb{R}^d)$ の元）になるもの。
  **「点 $x\in\mathbb{R}^d$ での場の値 $\phi(x)$」は作用素として存在しない**。$\phi(x)$ は記法であり、意味をもつのは $\phi(f)=\int\phi(x)f(x)\,dx$ の方である。これは場の量子論における最も基本的な「素朴な定義の失敗」であり、[05](05_摂動論とくりこみの数学.md) の発散の起源でもある。

### 0.4.6 場の配位空間

- ファイバー束 $\pi\colon E\to M$、切断の集合 $\Gamma(M,E)=\{\phi\colon M\to E\mid \pi\circ\phi=\mathrm{id}_M,\ \phi\ \text{は滑らか}\}$。
- スカラー場：$E=M\times\mathbb{R}$（実スカラー）あるいは $M\times\mathbb{C}$、$\Gamma(M,E)\cong C^\infty(M,\mathbb{R})$。
- ゲージ場：主 $G$ 束 $P\to M$ の接続の集合 $\mathcal{A}(P)$。これは**アフィン空間**であってベクトル空間ではない（[08](08_ゲージ理論_幾何と位相不変量.md) §1）。
- 作用汎関数 $S\colon\Gamma(M,E)\to\mathbb{R}$。**［ℝ 脱出］** $S$ の定義には $M$ 上の積分が入るため、この時点で $\mathbb{R}$ の完備性と測度論が要る。格子版では有限和に置き換わる。
