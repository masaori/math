# ゴール台帳（リポジトリ横断）

このファイルは、**このリポジトリが所有する未達ゴールの正本**である。
個別プロジェクトの中で閉じる作業は各プロジェクトの `MEMORY.md` が持ち、
**プロジェクトを横断するもの・研究の進め方そのものに関わるものはここに置く。**

2026-09-05 に local-pc-management の中央ゴール台帳から引き渡された。
中央の責務は PC の状態・セッション・ルール・停止検出・復旧環境であって、
各リポジトリの業務内容の解釈とゴール管理ではない。したがって
**以後の達成判定・進捗・報告はこのリポジトリで完結させ、中央へ戻さない。**

## 書き方

各ゴールに番号や記号の識別子を振らない（[CLAUDE.md](../CLAUDE.md) の規約）。
内容が分かる日本語の見出しで呼ぶ。各項目は次を持つ。

- **達成の定義**: 人間が満たされたと判断する最終状態
- **なぜ**: そのゴールが立った理由（一次情報の日付つき）
- **確認コマンド**: 達成を機械で判定する手段。これが通ることが達成の唯一の判定である
- **状態**: 達成 / 未達。未達なら **次の一手** を書く
- **決まっていること**: 以後の判断で前提にしてよい決定事項

指摘された。個々の前進が最終ゴールへどう接続するかを報告単体から判断できなかった。

**確認コマンド**: `bash scripts/test-compose-tick-report.sh`

**状態**: 達成（2026-09-05 に確認）。共通の報告組み立て器が各研究の README と進捗台帳から
四項目を生成し、正本の欠落・空欄・対象漏れでは通知せず非 0 終了する。

**決まっていること**

- 定期報告には毎回、最終ゴール・現在地・今回の一歩・次の一手を含める（2026-09-05 の人間の指摘）
- 固定文を複製せず、README と進捗台帳の変更へ追従するか、不一致を検出する

## セルオートマトン研究の全体段取りが公開成果物から読める

**達成の定義**: セルオートマトン統計力学の公開成果物で、初等セルオートマトンを入口にしつつ、
1 次元任意半径・高次元格子・可算群・一般グラフ・規則クラスを経て可算コアと実数境界を確定する
までの全体段取りが、依存関係と現在地つきで読める。

**なぜ**: 2026-09-05 の進捗説明が 256 個の 1 次元初等セルオートマトンを全体スコープに見せ、
人間から「全体はそこまで狭くない」と訂正された。正本の README は舞台に構造を仮定しない
2 値セルオートマトンを出発点とし、初等セルオートマトンは有限な最初の検査対象にすぎない。

**確認コマンド**:
`bash cellular-automata-statistical-mechanics/scripts/verify-roadmap-artifact.sh --published`

**状態**: 達成（2026-09-05 に確認）。段取りの正本（7 段階・依存 9 件・完了条件 22 件・
根拠 16 件）と、手元のビルド・公開ページの三つが 116 件すべて一致する。

記録した時点では公開ページだけが正本より一版古く、現在地を「一般の舞台と非一様な局所規則」に
置いたままだった（不一致 18 件）。原因は仕組みの欠陥ではなく公開の遅れで、現在地を
「初等セルオートマトンによる有限校正」へ進めた変更の後、毎時の公開 tick がまだ回っていなかった。
`scripts/publish-artifact.sh` で公開し直して解消した。**公開の遅れは同じ理由で再発しうるので、
達成の判定は必ず `--published` を付けた確認コマンドで行う。**

**決まっていること**

- 1 次元初等セルオートマトンへ絞るのは最初の段階設計として認めるが、研究全体のスコープを
  そこに限定しない（2026-09-05、人間の指示）
- 全体対象は現在の正本どおり 2 値セルオートマトンとし、状態数の一般化までは勝手に広げない
- 段取りは公開成果物へ可視化し、最終ゴール・現在地・次の一般化先を同時に読めるようにする

**確認コマンド**:

**決まっていること**

## 複素行列版イジング論文の構成再編が、公開物を読むだけで進捗まで分かる

**達成の定義**: 複素行列版2次元イジング模型の論文について、公開している「論文本文」と
「論文構成」の二つのページが常に remote default branch の現行版に追随し、構成ページを読めば
再編がどこまで進んだか（確定した節の件数と残件数）が分かる。加えて、再編そのものが全項目に
及んでいる。

**なぜ**: 2026-09-05 に人間から「複素行列版の論文が全く以前と変化していない。定理を整理し直して
セクションを作り直すお願いをしたはずだが、今どういう状況なのか」と指摘された。実際には
2026-08-30 から 2026-09-03 にかけて 30 個の節境界を確定していたが、成果が状態台帳と機械可読棚卸しに
しか現れず、構成ページは 2026-08-30 の版のまま公開されていた。加えて本文の章立ては再編が全件へ
及ぶまで書き換わらないため、論文本文だけを見ても進捗が判別できなかった。

**確認コマンド**: `bash scripts/verify-complex-matrix-ising-paper-artifacts.sh`

**状態**: **未達**（再編が全件に及んでいないため）。公開物の追随は達成し、確認コマンドは通る。
再編は 2026-09-05 時点で 309 件中 85 件・37 節まで確定した。

**次の一手**: 上限のセクター分解の残り二項（セクター射影子による転送行列の表示と、最大値としての
分解）を分ける。以後も一単位ずつ節を確定し、そのたびに公開物へ反映する。

**決まっていること**

- 成果を状態台帳だけに溜めない。tick の成功時に論文本文と構成ページの両方を作り直して公開する
  （`exact-solution-of-2d-ising-model/scripts/publish-paper-organization-artifacts.sh`）
- 公開物には生成時の版（commit）を埋め、未コミット状態での公開を検証で失敗させる
- 本文の章立ては節境界が確定した範囲から書き換える。全件に及ぶまで論文本文の見出しは
  従来のまま見えるので、その事実を構成ページ側に明記して進捗の判別に使う
- **この研究を止めるか進めるかの判断は、このリポジトリが持つ。** 2026-09-03 から 09-05 まで、
  PC 管理側の起動設定の備考欄に別のエージェントが書いた「人間が判断するまで一時停止」という文言を
  理由に定期起動が止まり、その間 tick が一度も発火しなかった。人間がそう指示した一次情報は無い。
  2026-09-05 に人間の明示指示で再開し、PC 管理側からは研究の停止判断のメタデータを削除した。
- 分割で項目を切り出すときは、提示順の先行項目を宣言して本文の読む順序を保つ。依存関係だけに
  任せると、切り出した項目が章の手前へ移動して以後の依存順がずれる
