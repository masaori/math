# docs/context — リポジトリ全体の前提（着手前に必ず全て読む）

このフォルダは、**このリポジトリのすべてのプロジェクトに共通する研究哲学・語彙・判断基準**の正本である。
個別プロジェクトの目的（`<project>/README.md`）や作業手順（`<project>/docs/tasks/`）より**上位**にあり、
それらと矛盾した場合はこのフォルダが勝つ。

> **厳守**: このリポジトリで作業を始める前に、**このフォルダのファイルを全て読むこと。**
> 数学の議論・証明・コード・調査・レビューのいずれであっても例外はない。
> サブエージェントに委譲するときは、**指示にこのフォルダを読ませることを含める。**

## このフォルダの位置づけ（他ディレクトリとの区別）

- `docs/context/` — **前提**。全プロジェクト共通の哲学・語彙・判断基準。滅多に変わらない。
- `docs/discussion/` — **議論**。特定テーマの壁打ち記録。結論が固まれば `docs/research/` へ昇格。
- `docs/research/` — **研究ノート**。プロジェクト横断の確立した知見。
- `<project>/` — **成果**。個別プロジェクトの証明・検証・出力。

## 更新規約

- このフォルダの内容を変更するときは、**変更が全プロジェクトに波及する**ことを意識する。
  個別プロジェクトの都合で書き換えない。プロジェクト固有の話は `<project>/README.md` に書く。
- 変更したら [CLAUDE.md](../../CLAUDE.md) / [AGENTS.md](../../AGENTS.md) の該当記述と整合するか確認する。
- 「これは前提なのか、それとも一つのプロジェクトの方針なのか」で迷ったら、**プロジェクト側に書く**。
  ここへ昇格させるのは、2 つ以上のプロジェクトで同じ判断が必要になったときとする。
