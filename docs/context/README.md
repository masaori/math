## 三レイヤーの関係

```
   理論物理レイヤー  ──「可算な世界を研究対象にする」
        │  ↑
        │  └────────────────┐
   （何を）                  （同じ境界線を別方向から指している）
        │                      │
        ↓                      │
    数学レイヤー ──（形を与える）→ 方法論レイヤー
   「帰属と ℝ 脱出を         「機械にかけられる標的を選ぶ」
     一行ずつ書かせる」
```

**理論物理 → 数学**
理論物理レイヤーが要求する「記号の帰属を書く／$\mathbb{R}$ 脱出を明示する」は、
数学レイヤーの記述の規律によって**一行ずつ強制される**。
数学レイヤーがなければ、可算コアという立場はただの心構えで終わり、監査できない。

**数学 → 方法論**
機械（SageMath・Lean）が検査できるのは、数学レイヤーの規律が
**検査可能な形にしたものだけ**である。一ステップ一定理とラベル参照が守られていない証明は、
どれだけ道具があっても機械にかけられない。規律が技術的優位の前提条件になっている。

**理論物理 ↔ 方法論（この方針の骨格）**
機械が信頼できるのは**等号が決定可能な世界**だけである。
それは理論物理レイヤーが**物理の実体があると考える世界**と同じ領域である。
哲学が先で道具が後でも、道具があって哲学を後付けしたのでもなく、
**同じ境界線を別方向から指している。** この一致がこの研究方針が成立している根拠。

## レイヤーを分けている理由

- **独立に改訂できるようにするため。** 数学レイヤーは理論物理レイヤーの前提に依存しない。
  「自然は有限」を採らない人でも、証明の規律はそのまま採用できる。逆も同じ。
- **可変性が違うため。** 理論物理と数学はほぼ不変。方法論は道具の進化とともに変わる。
- **混ぜると効かなくなるため。** 前提（証明できない立場表明）と規律（守れば守れる規則）と
  戦略（状況依存の判断）は、守り方も改訂の仕方も違う。

## 役割の切り分け（衝突したときの読み方）

| 判断 | 決めるレイヤー |
|---|---|
| その対象を研究する価値があるか | 理論物理 |
| その主張をどう書き、どこまで検証するか | 数学 |
| いま何に手を付けるか、どの標的を優先するか | 方法論 |

「意味はあるが機械にかけられない標的」は、理論物理レイヤーでは価値があり、
方法論レイヤーでは後回しになる。**これは矛盾ではなく役割の違い**である。
