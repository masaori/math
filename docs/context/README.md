# docs/context — このリポジトリの思想（着手前に必ず全て読む）

このフォルダは、このリポジトリで何をどう研究するかの**前提**を置く場所である。
個別プロジェクトの目的（`<project>/README.md`）や作業手順より上位にあり、矛盾したらここが勝つ。

思想は性格の異なる**三つのレイヤー**に分かれる。混ぜて書かない。

| ファイル | レイヤー | 問い | 一言 |
|---|---|---|---|
| [証明の書き方.md](証明の書き方.md) | 数学 | 証明をどう書くか | 一ステップ一定理。人が追えることと機械が検査できることを同時に満たす |
| [物理を記述する数学の選び方.md](物理を記述する数学の選び方.md) | 理論物理 | どの数学で物理をやるか | **自然は有限。可算な世界で書く。$\mathbb{R}/\mathbb{C}$ は道具であって研究対象ではない** |
| [成果の出し方.md](成果の出し方.md) | 方法論 | どうやって価値を出すか | AI・SageMath・Lean が効くのは決定可能な世界だけ。そこが我々の戦場 |

## 三つのレイヤーの関係

- **理論物理レイヤー**が「何を研究対象にするか」を決める（可算な世界）。
- **数学レイヤー**が「それをどう書くか」を決める（証明の規律と四層の検証）。
- **方法論レイヤー**が「なぜそれを我々がやるのか」を決める（機械が効く領域と一致する）。

理論物理レイヤーと方法論レイヤーは**同じ境界線を別方向から指している**。
物理の実体があると考える領域（可算）と、機械が信頼できる領域（等号が決定可能）は同じ領域である。
この一致がこの研究方針の骨格である。

## 読み方の注意

- ここに書いてあるのは**前提と方針**であって、研究成果ではない。
  個別の定理・調査結果は `docs/research/`・`docs/discussion/`・各プロジェクトに置く。
- 前提のうち存在論的な部分（自然は有限）は**証明できない立場表明**である。
  一方、そこから出る命題は**この立場を共有しない読者にも通用する形で書く**
  （[物理を記述する数学の選び方.md](物理を記述する数学の選び方.md) の「前提と成果物を分離する」）。

## 更新規約

- 変更は全プロジェクトへ波及する。個別プロジェクトの都合で書き換えない。
- 「これは前提か、一つのプロジェクトの方針か」で迷ったら**プロジェクト側に書く**。
  ここへ上げるのは 2 つ以上のプロジェクトで同じ判断が要ったときとする。
- 変更したら [CLAUDE.md](../../CLAUDE.md) / [AGENTS.md](../../AGENTS.md) と整合するか確認する。
