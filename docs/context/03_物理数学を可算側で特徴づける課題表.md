# 03. 物理数学を可算側で特徴づける課題表

[00](00_基本方針_可算コアとℝ脱出.md) §4 の **(II) 逆方向** の作業。物理で当然のように使われる
道具について、**「そのどの部分が可算側で言えるのか」を確定する**未完課題のリストである。

この作業をやらないと、ある命題が可算側で書けないときに、
「原理的に書けない」のか「まだ書き方を知らないだけ」なのかが区別できない。

## 0. 表の読み方

- **状態**: ✅ 済（可算側の特徴づけが確定）／🟡 部分的／⬜ 未着手／❌ 原理的に不可（根拠つき）
- 「不可」と書くときは、**なぜ不可か**（どの非可算性が本質的か）を必ず添える。
  不可の証明が付いた項目も成果である（$\mathbb{R}$ が本当に要る場所の特定になる）。

## 6. 優先度の高い未着手項目（次に手を付けるなら）

1. **2.4 準局所代数の可算化** — 局所代数の帰納系（各段は有限次元、係数 $\overline{\mathbb{Q}}$）で
   どこまで物理が言えるか。完備化が本当に要るのはどの命題か。
2. **4.6 中心電荷の可算化** — 有理 CFT では $c\in\mathbb{Q}$、$c_-\bmod8$ は有限群値。
   一方 1D QCA の GNVW 指数は $\mathbb{Q}_{>0}\cong\Lambda$。この 2 つを結ぶ $\Lambda$ 値の
   「情報流」不変量の定式化（→ `cellular-automata-statistical-mechanics/docs/ideas/` 種 S1）。
3. **3.6 熱力学極限の存在** — 劣加法性の議論のどこに完備性が要るか。
   有限 $N$ の不等式列（可算）だけで言える部分の切り出し。
4. **3.10 臨界指数** — 「$\mathbb{R}$ が本質的に必要」の証明が付けば、それ自体が成果。
   足跡命題（$\forall\in\mathbb{Q}\exists\in\mathbb{N}$ 型）でどこまで代替できるかの上限を決める。

## 7. 更新の仕方

- 各プロジェクトで新しく可算側の特徴づけが得られたら、**この表の状態を更新し、根拠へのリンクを張る。**
- 「❌ 原理的に不可」を追加するときは、どの非可算性（完備性・選択公理・超越性）が
  本質的かを必ず書く。単に「できなかった」は ⬜ のままにする。
