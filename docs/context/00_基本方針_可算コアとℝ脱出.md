# 00. 基本方針 — 理論のコアは可算、$\mathbb{R}$ は応用のための便宜

## 1. 中心テーゼ

> **理論のコアは、対数順序群 $\Lambda$ を含む可算な世界（$\mathbb{N}\subset\mathbb{Q}\subset\Lambda\subset\overline{\mathbb{Q}}$）の言葉だけで記述する。
> 非可算な世界（$\mathbb{R}/\mathbb{C}$）への移行は、理論の内容ではなく「応用のための便宜」として扱う。**

これは哲学的な好みではなく、**操作的な区別**である。可算／非可算の境界は、そのまま

$$
\text{決定可能性}\ \big/\ \text{計算可能性}\ \big/\ \text{形式検証可能性}
$$

の境界だからである（根拠は [`docs/discussion/可算性の効用/`](../discussion/可算性の効用/)）。したがって
「どこで $\mathbb{R}$ が要るか」を明示する作業は、そのまま「どこで機械が扱えなくなるか」を明示する作業になる。

## 2. なぜこの立場を取るか（4 つの理由）

1. **$\mathbb{R}$ の元のほとんどは議論に不要**。$\mathbb{R}$ は非可算で、そのほとんどの元は計算不能である。
   有限個のスピン・有限グラフ・整数重みから出発した議論の結論が、なぜ計算不能な実数を
   経由しなければならないのか——経由していないなら、経由しない書き方をすべきである。
2. **素朴な操作は無料ではない**。微積分・テイラー展開・極限・連続性は高校で習うが、
   いずれも $\mathbb{R}/\mathbb{C}$ の完備性という強い前提を暗黙に使っている。
   前提を明示しないまま使うと、結論のうちどこが「物理の中身」でどこが「解析的理想化」かが混ざる。
3. **可算側は機械検証できる**。$\Lambda$ の等号は素因数分解の一致、順序は 2 整数の比較。
   $\overline{\mathbb{Q}}$ の等号は根分離。いずれも決定可能で、SageMath の `ZZ/QQ/QQbar` と
   Lean の `decide` にそのまま乗る。$\mathbb{R}$ の等号は決定不能である。
4. **証拠が手渡せる**。可算側の証明は構成的で、witness（この整数・この零点・この凸包頂点）を
   具体的に提示できる。非構成的存在証明にはこの性質がない。

## 3. スタンス（この立場が主張すること／しないこと）

**主張する**:

- 理論の**コア**（定義・主要命題・不変量・保存量・可解性の判定）は可算側で書ける、あるいは
  書けるはずである。書けないなら、それは「なぜ書けないか」自体が一つの結果である。
- $\mathbb{R}$ への脱出は**局所化できる**。一つの理論の中で脱出が起きるのはたいてい数箇所であり、
  それを特定すれば残りは全て決定可能な世界に置ける。

**主張しない**:

- $\mathbb{R}$ を使ってはいけない、とは言わない。構成主義・有限主義の立場を全面採用するのでもない。
  熱力学極限・臨界指数・連続極限は**応用として重要**であり、放棄しない。
- 既存の解析的結果が間違っている、とも言わない。$\mathbb{R}$ 側の結果（Onsager 解、Mahler 測度＝
  自由エネルギー、CFT）は正しく深い。本リポジトリの仕事は**それを可算側から読み直す**ことである。

**要点は「使うな」ではなく「使った場所を必ず記録しろ」である。**

## 4. 二つの向きの作業

この方針からは、向きの異なる 2 種類の作業が出る。両方をやる。

### (I) 順方向 — 可算側で理論を建てる

新しい定義・命題は、まず $\Lambda/\overline{\mathbb{Q}}$ の言葉で述べる。極限・積分・指数関数を
使わずに済む定式化を探す。済まないなら、済まない一点を切り出す。

例（確立済み）: 分配関数 $Z_N=\operatorname{Tr}T^N\in\mathbb{Z}$ と Massieu 自由エントロピー
$\Phi_N=\log Z_N\in\Lambda$、その傾き $M=\sum_p\mu_{\min}(p)\ell_p$（Newton 多角形で計算、
$\mathbb{R}$ 不使用）。→ [`docs/research/R-Lambda-duality/`](../research/R-Lambda-duality/)

### (II) 逆方向 — 既存の物理数学を可算側で特徴づける

物理で当たり前に使われている道具（Hilbert 空間、作用素代数、Boltzmann 重み $e^{-\beta E}$、
スペクトル分解、経路積分、繰り込み群、共形対称性）について、
**「その道具のどの部分が可算側で言えるのか」を確定する**。これは (I) と独立に必要な作業で、
やらないと「可算側で書けない」のか「まだ書き方を知らないだけ」なのかが区別できない。

課題表は [03_物理数学を可算側で特徴づける課題表.md](03_物理数学を可算側で特徴づける課題表.md)。

## 5. 実務ルール（作業中に守ること）

1. **登場するすべての記号について、どの集合に属するかを書く。** $x\in\mathbb{Z}$ なのか
   $x\in\overline{\mathbb{Q}}$ なのか $x\in\mathbb{R}$ なのかを曖昧にしない。
2. **$\mathbb{R}/\mathbb{C}$ に出た箇所は、その場で明示する。** 「ここで $\mathbb{R}$ へ脱出する（理由: 連続極限）」
   と本文に書く。脱出の分類と書式は [02_ℝ脱出の台帳と判定手順.md](02_ℝ脱出の台帳と判定手順.md)。
3. **可算で済むものを不用意に持ち上げない。** 有限和で足りるところに積分を持ち込まない。
   差分商で足りるところに微分を持ち込まない。整数比較で足りるところに実数の大小を持ち込まない。
4. **中間の非可算化にも同じ規律を適用する。** $\mathbb{Q}_p$・$\mathbb{C}_p$ は $p$ 進的だが濃度 $2^{\aleph_0}$ で、
   導入は $\mathbb{R}$ 脱出と同格である。$p$ 進的な議論は数体 $K=\mathbb{Q}(\lambda)$ の
   素イデアル分解と Newton 多角形（有限・代数的手続き）で書く。
5. **「決定可能」を主張するときは手続きを書く。** 何を入力に何を有限回の操作で出すのかを述べる。
   列挙が困難でも素点ごとのアクセスが安いなら、そう書く（計算量と決定可能性を混同しない）。

## 6. よくある落とし穴

| 落とし穴 | 正しい扱い |
|---|---|
| $e^{-\beta E}$ を定義として使う | カノニカル分布の定義は**熱浴の状態数比** $\Omega_B(U-E)/Z\in\mathbb{Q}$。指数形は導出物であり近似の像（[`00_記号と定義`](../discussion/対数順序群上の統計力学/00_記号と定義.md) §7–8） |
| 「$\log$」と書いて実対数を意味する | $\log:\mathbb{Q}_{>0}\to\Lambda$（素因数分解）と $\log_{\mathbb{R}}:\overline{\mathbb{Q}}_{>0}\to\mathbb{R}$ を**記号で区別**する |
| 極値を微分で取る | 有限集合上の $\arg\max$ で済むなら微分を使わない |
| $p$ 進の議論に $\mathbb{Q}_p$ を持ち出す | $v_p$ は整数上の割り切れ回数、根の付値は Newton 多角形。$\mathbb{Q}_p$ は説明の足場にすぎない |
| 「$\Lambda$ で書けた」＝「解けた」 | $\Lambda$-閉形式（定義 X）と解析的閉形式（定義 Y）は別物。[`R-Lambda-duality/README`](../research/R-Lambda-duality/README.md) §8.5 |
| 可算性と可解性を同一視 | 帰属（$\Lambda$ に住むか）・可積分性・閉形式は**独立な軸**（同 §8.3） |
