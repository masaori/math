# $\mathbb{R}$ 脱出の台帳と判定手順

**脱出を禁止するのではなく、脱出を記録する。** 記録さえあれば、どの結論が可算側で厳密に
成立し、どの結論が解析的理想化に依存しているかが後から機械的に分離できる。

## 脱出の分類

### 見かけの脱出（実は脱出していない）

実数記号が現れているが、可算側に落とせるもの。**書き換えて脱出を消す。**

| 見かけ | 実体 | 落とし先 |
|---|---|---|
| $|\lambda|$（複素固有値の絶対値） | $|\lambda|^2=\lambda\bar\lambda\in\overline{\mathbb{Q}}$ | $\overline{\mathbb{Q}}$ |
| $p$ 進の議論での $\mathbb{Q}_p,\overline{\mathbb{Q}_p}$ | 数体 $\mathbb{Q}(\lambda)$ の素イデアル分解 | 有限・代数的 |
| $\log$ の一般論 | $\mathbb{Q}_{>0}$ 上の素因数分解 | $\Lambda$ |
| 「連続な」対称性 | 有限位数の巡回群・1 の冪根 $\mu_L$ | $\overline{\mathbb{Q}}$ |
| Fourier 変換（有限 $L$） | $x^L-1$ の根による固有空間分解 | $\overline{\mathbb{Q}}$ |
| 極値の探索 | 有限集合上の $\arg\max$ | $\mathbb{N}$ |
| 微分 $\partial S/\partial U$ | 差分商 $S(U+1)-S(U)$ | $\Lambda$ |

**規約**: 「見かけの脱出」を見つけたら書き換える。「$\mathbb{R}$ を使っているが本質的でない」で放置しない。

### 実現の脱出（$\rho$ / $\log_{\mathbb{R}}$ の一点）

可算な値 $\alpha\in\overline{\mathbb{Q}}_{>0}$ に $\log_{\mathbb{R}}$ を施す箇所。**極限は含まない。**

- 例: $-\beta f_L=\frac1L\log_{\mathbb{R}}\lambda_{\max}$（$\lambda_{\max}\in\overline{\mathbb{Q}}$）。
- Baker により、代数的 $\alpha\ne0,1$ で $\log_{\mathbb{R}}\alpha$ は超越的。ゆえに一般に消せない。
- **消える条件**: $\alpha\in\mathbb{Q}_{>0}$ のときに限り $\log_{\mathbb{R}}\alpha=\sum_p v_p(\alpha)\ell_p\in\Lambda\otimes\mathbb{Q}$ に落ちる。
- **隔離の質**: 「実現の脱出」は「一点」なので、それ以外の全命題は可算側に残せる。**最も良い脱出**。

### 指数評価（$\exp$ による丸め）

$\Omega_B$ 比などの $\mathbb{Q}$ 値の重みを $e^{-\beta E}$ に置き換える箇所。

- 標準カノニカル分布はここで生じる。$\Lambda$ 内に留まるなら比表示 $w(\sigma)\in\mathbb{Q}$ を使う。
- $2^{-\sqrt2}\in\mathbb{R}\setminus\overline{\mathbb{Q}}$（Gelfond–Schneider）のように、値が $\overline{\mathbb{Q}}$ すら出る。
- **注意**: $\beta$ の定数化そのものは $\Lambda$ 内の操作。脱出するのは指数評価の側
  （[`01_β定数化はΛを出るか`](../discussion/対数順序群上の統計力学/01_β定数化はΛを出るか.md)）。

### 極限・積分（熱力学極限・連続極限・スケーリング極限）

$N\to\infty$、$L\to\infty$、$\frac1L\sum\to\int$、連続時空極限、繰り込み群の固定点。

- 自由エネルギー密度、臨界指数、CFT、Mahler 測度、Onsager 解はすべてここ。
- 収束の主張自体が $\mathbb{R}$ の完備性を要求する。逆数学では WKL₀/ACA₀ 領域。
- **最も重い脱出**。有限系の主張と極限後の主張を、命題として分けて書く。

### 完備性・可分性を要する解析的構造

無限次元 Hilbert 空間の自己共役作用素のスペクトル定理、連続スペクトル、
Gelfand–Naimark、GNS 構成、経路積分、無限体積 Gibbs 状態の存在（DLR）。

- 有限系では 「完備性」は現れない（有限次元は代数的）。無限体積・連続場に行くと現れる。
- **課題**: どこまでが有限次元・可算の代数で代替できるか
  → [物理数学を可算側で特徴づける課題表.md](物理数学を可算側で特徴づける課題表.md)。

## 判定手順（作業中に回す）

命題を 1 つ書くたびに、次を順に確認する。

```
1. 登場する記号それぞれについて所属集合を書いたか？
     ℕ / ℤ / ℚ / Λ / Q̄ / ℝ / ℂ / その他（明示）
2. ℝ・ℂ が現れたら、脱出の型のどれかを判定する。
3. 「見かけの脱出」なら → 書き換えて消す。消した記録を残す。
4. それ以外（「実現の脱出」「指数評価」「極限・積分」「完備性」）なら → 本文にその場で明示する（書式は「書式（本文への記録の仕方）」節）。
5. 有限系の主張と極限後の主張が混ざっていないか確認する。
     混ざっていたら命題を 2 つに割る。
6. 「決定可能」と書いたなら、入力と有限手続きを述べたか確認する。
```

## 書式（本文への記録の仕方）

本文中に次の形で 1 行入れる。証明の中なら proof 側に書く。

> **($\mathbb{R}$ 脱出 「実現の脱出」)** ここで $\log_{\mathbb{R}}:\overline{\mathbb{Q}}_{>0}\to\mathbb{R}$ を用いる。
> 以降の主張は $\mathbb{R}$ 上のものであり、決定可能性は保証されない。
> $\lambda_{\max}\in\mathbb{Q}_{>0}$ の場合に限りこの脱出は消える。

- **型**（五つの型）と**理由**（何のために出たか）を書く。
- 脱出以降の命題には、それが $\mathbb{R}$ 側の主張であることが分かる印を付ける。
- 脱出を**消した**場合も記録する（「$|\lambda|^2\in\overline{\mathbb{Q}}$ により 「見かけの脱出」を除去」）。
  後から「なぜここに $\mathbb{R}$ が無いのか」を問われたときの答えになる。

## 脱出の質の順位（設計指針）

理論を組むとき、同じ結論に至る複数の道があるなら、脱出の**質**が良いものを選ぶ。

| 順位 | 状態 | 例 |
|---|---|---|
| 最良 | 脱出なし | $\Phi_N=NM+R(N)$、Newton 多角形による $\mu_{\min}(p)$ |
| 良 | 「実現の脱出」が一点だけ | $-\beta f_L=\frac1L\log_{\mathbb{R}}\lambda_{\max}$（$\lambda_{\max}\in\overline{\mathbb{Q}}$ は可算） |
| 可 | 「指数評価」・「極限・積分」が明示的に切り出されている | 有限 $L$ の厳密結果＋極限は別命題 |
| 不可 | 脱出が理論全体に散らばっている | 最初から $\mathbb{R}$ 上の解析で書く |

**「隔離できているか」が評価軸である。** 脱出の個数ではなく、脱出が理論のどこに閉じ込められて
いるかを見る。

## 既知の脱出台帳（統計力学のコア部分）

[`00_記号と定義`](../discussion/対数順序群上の統計力学/00_記号と定義.md) の結論を再掲する。
ミクロカノニカル〜カノニカルの本体（状態数 $\Omega$、エントロピー $S$、確率 $P$、
逆温度 $\beta$、$\Lambda$ 上カノニカル分布）は**すべて $\mathbb{N}/\mathbb{Q}/\Lambda$ で閉じる**。
脱出が不可避になるのは次の 3 箇所のみ：

| 記号 | 箇所 | 型 |
|---|---|---|
| (a) | $\beta$ 定数化＋指数丸め（標準カノニカル $e^{-\beta E}$） | 「指数評価」 |
| (b) | 示量極限 $N\to\infty$ | 「極限・積分」 |
| (c) | エネルギー群 $G\cong\mathbb{Z}^r$（$r\ge2$）で最小正元がないときの方向微分 | 「極限・積分」 |

さらに転送行列の議論では

| 記号 | 箇所 | 型 |
|---|---|---|
| (d) | $\log_{\mathbb{R}}\lambda_{\max}$（自由エネルギー密度の実現） | 「実現の脱出」 |
| (e) | スペクトル曲線の Mahler 測度 $m(P)=\frac{1}{(2\pi i)^2}\oint\oint\log|P|\frac{dz}{z}\frac{dw}{w}$ | 「実現の脱出」・「極限・積分」 |

を追加する。新しいプロジェクトでこの表に載らない脱出を見つけたら、**この表を更新する。**
