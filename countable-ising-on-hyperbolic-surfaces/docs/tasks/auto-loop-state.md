- 二段の係数がともに正である次数と指定素数を入力とし、細段・粗段の整数付値を返す係数付値対写像を定義した。次数 `0,2` と素数 `2,3,5,7` の全八組で反復除算と厳密付値を照合した。
- 二段 Ising 係数付値対の細段成分から粗段成分を引く整数値写像を定義した。次数 `0,2` と素数 `2,3,5,7` の全八組で差を厳密検算し、値域を整数全体として符号や単調性を仮定しないことを明示した。
- 固定した共同正係数次数で二段 Ising 係数付値差が非零となる素数は、細段係数と粗段係数の積を割る素数に限られるため有限個であることを証明した。次数 `0` の台が空、次数 `2` の台が `{2,3}` であることを厳密検算した。
- 固定した共同正係数次数で、有限台上の二段 Ising 係数付値差を整数係数とする有限和を対数順序群の元として定義した。次数 `0` では零元、次数 `2` では `ell_2 + ell_3` となることを有限台の整数座標として厳密検算した。
- 二段の分配多項式の Fisher 零点台の和集合を定義域とし、各代数的数へ細段・粗段の零点重複度を零延長した自然数対を返す写像を定義した。四頂点サイクルと二頂点二重辺グラフの例では二つの零点台が交わらず、細段だけの四つの単根が `(1,0)`、粗段だけの二つの単根が `(0,1)` となることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点重複度対の細段成分から粗段成分を引く整数値写像を定義した。共有零点 `-1` で差が `0`、細段だけの四根で `1`、粗段だけの二根で `-1` となることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点重複度差が非零となる零点の集合を定義し、二段零点台の有限部分集合であることを証明した。互いに素な二段零点台では六元全て、共有零点 `-1` を加えた七元零点台では `-1` を除く六元が有限台になることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点重複度差の有限台上で、重複度差を整数係数とする形式的因子を定義した。互いに素な二段零点台と共有零点 `-1` を加えた例はいずれも六項となり、共有零点の係数が零として相殺されることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点形式的因子の段別差表示をレビューし、自然数値重複度どうしを直接減算していた一行を、両項を自然数から整数への標準単射で移した後の整数差へ修正した。対応する SageMath 検算も、各零点でこの整数係数差を明示的に照合する形へ強化した。
- Ising 分配多項式の次数が、有限スピン配位全体で実現する最大破れ辺数に等しいことを証明した。三角形、四頂点サイクル、二本の平行辺の全配位で、非零多重度の台と破れ辺数写像の有限像、および `ZZ[x]` の次数を厳密検算した。

- 空でない頂点集合をもつ任意の有限グラフで、大域スピン反転が各破れ辺数ファイバーを保つ不動点のない対合になることから、Ising 分配多項式の全係数が偶数であることを証明した。一頂点無辺、一辺、三角形、四頂点サイクル、二本の平行辺で厳密検算した。

- 任意の有限グラフで、`-1` が Ising 分配多項式の零点であることと、奇数本の辺が接続する頂点が存在することが同値だと証明した。逆向きには全接続辺数が偶数なら評価が正整数 `2^{|V|}` になる既存定理を用い、一頂点無辺、一辺、二本・三本の平行辺、三頂点道、三角形、四頂点サイクル、奇接続辺数頂点をもつ四頂点五辺グラフで厳密検算した。
