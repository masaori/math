# 正則型を固定した有限商と二段被覆の比較

READMEが指定する型 `{3,7}` の有限セル分割から、既存の「商の塔への依存」へ進む。
積差ごとの型の追加をせず、既存の有限証明書を先に照合する。本文の
`theorem_generated_quotient_cellulation_is_hyperbolic_regular` と
`sagemath/check/generated-quotient-cellulation-finite-check/overview.md` には、
八点上の置換による型 `{3,7}` のセル分割がある。以下の行列商候補との役割生成子・作用の対応を
確かめ、同じ入力の再構成だけを新しい研究成果と数えない。対応未確認のまま同一視しない。

候補入力は `F_7` 上の行列 `A=((0,-1),(1,0))` と `B=((0,-1),(1,1))` が生成する群を
中心の `±I` で割った有限群と、その右乗算による置換である。候補の位数・積・軌道から
辺・面・頂点の接続データを生成する。生成前に閉曲面性を仮定しない。
各辺への二面の接続、各頂点の巡回リンク、向き、連結性、境界の境界が零、型 `{3,7}` を
全て有限データで判定する。失敗した場合はその入力と証人を残し、この候補を閉じる。

成功した場合に限り、生成済みの鎖複体で非自明な `F_2` 一次コホモロジー類の代表を
固定した辺順の辞書式最小で選び、その零・一の辺値から二枚の持ち上げを構成する。
被覆写像、連結性、局所接続の保存と鎖写像を有限検査してから、二段を比較対象として採用する。
単にサイズの異なる二つの商を塔と呼ばない。
さらに、本文の `def_two_stage_finite_quotient_tower_input` が要求する有限置換群と二つの
正規部分群の包含、商への全射、役割生成子、射影の可換性をこの被覆に対して提示する。
局所条件と鎖写像の成立だけではこの入力を満たしたとしない。提示できなければ既存の商の塔の
定理は適用せず、不足する入力を記録して候補評価を閉じる。

両段で外場なし・同じ辺変数・自由な全スピン和を使う。比較する正規化は、頂点数で割った
係数の有理ベクトルと、次数で割った代数的根の重複度因子として別々に定義し、保存を仮定しない。
まずホモロジー類の押し出しと類別多項式の有限な対応を問う。保存しないなら反例の係数・類を残す。
零点集積・規格化極限の存在はこの二段比較の結論に含めない。
既存の形式因子差の消滅判定
`theorem_quotient_tower_two_stage_fisher_zero_formal_divisor_vanishing_criterion` は、
重複度を次数で割らない因子差を最高次係数で正規化した多項式の等号へ戻す。
この判定の利用と、上で提案した次数で割る比較とは区別する。後者へ定理を無断で流用しない。

完了は、固定入力と被覆写像・有限証明書・同じ正規化での保存または非保存の結果がそろうこと。
プログラミングによる検証は有限データの真偽と厳密計算、LLMによる検証は比較の意味と極限との分離を担う。
候補具体化時点では未着手だった。この文書の作成では定期起動の登録・停止解除は行っていない。現在の判定結果は末尾に記す。

## 固定入力の判定結果（2026-09-05）

最初の有限判定は成功。行列商168元から24頂点・84辺・56面を得た。
[判定記録と証明書](../../sagemath/check/fixed-f7-matrix-cellulation/overview.md) に
生成規約、本文の合成順への移送、全セル条件と鎖条件のプログラミングによる検証を保存した。
二枚被覆に使う辺順は証明書の `cell_cosets.edge` の順に固定する。

今回監督の追加照合: 固定行列商の判定結果は取り込み済みである。既存証明書との照合を同じ生成の再実行へ戻さず、現在の次対象は上記証明書を使う二枚被覆候補とする。正規商入力の適合条件は比較の前提として残す。

## 二枚被覆の判定結果（2026-09-05）

固定辺順の辞書式最小の非余境界コサイクルから、48頂点・168辺・112面の連結二枚被覆を採用した。
[被覆の判定記録と証明書](../../sagemath/check/fixed-f7-double-cover/overview.md) に
代表最小性の証人、全セル、射影、局所接続と整数・二元体の鎖写像を保存した。
二段ホモロジー類・分配多項式の比較は未着手であり、今回の有限判定から保存を仮定しない。

次は段間比較の前提である正規商入力への適合を判定する。今回の被覆証明書だけで
本文の正規部分群包含・商射影の仮定が成立したとは扱わない。

## 正規商入力への適合判定（2026-09-06）

固定した基底の指定行列 A による左作用が二枚被覆へ持ち上がらないため、
本文の正規商の塔への適合を否定した。
[不適合の証人と理由](../../sagemath/check/fixed-f7-double-cover-normal-quotient-obstruction/overview.md)
に二元体方程式の階数23・拡大階数24と零境界サイクルへの異なるペアリングを保存した。
プログラミングによる検証は全セル作用と有限方程式、LLMによる検証は
本文の全射商・役割剰余類から持ち上げが必要となる理由を担う。
連結二枚被覆としての採用は維持する。正規商入力が不成立なので、依存する二段比較は
非適用として閉じ、別の被覆・型・入力群を自動で選ばない。保存性・非保存性は未判定である。
