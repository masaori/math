# Ising 分配多項式

## 概要

有限グラフ上の各スピン配位を破れ辺数で数え、整係数分配多項式を構成する。指数重みを入口に置かない。

## 背景と前提

有限の頂点集合、辺集合、端点写像が定義済みであること。

## スコープ

- 形式的スピンラベル集合と整数実現写像
- スピン配位集合
- 破れ辺集合と破れ辺数
- 多重度係数
- `Z[x]` に属する分配多項式
- 全係数和と大域スピン反転から従う帰無的恒等式
- 正の有理評価の単調性と、辺をもつ場合の厳密単調性
- 辺をもつ場合に正の有理評価値が評価点を一意に決めること
- 辺をもつ場合に正の有理評価値の狭義順序が評価点の狭義順序を反映すること
- 辺をもつ場合に正の有理評価値の弱順序が評価点の弱順序を反映すること
- 辺をもつ場合に正の有理評価値が全配位数以下であることによる評価点 `1` 以下の特徴付け
- 辺をもつ場合に正の有理評価値が全配位数以上であることによる評価点 `1` 以上の特徴付け
- 辺をもつ場合に正の有理評価値が全配位数に等しいことによる評価点 `1` の特徴付け
- 辺をもつ場合に正の有理評価値が全配位数より小さいことによる評価点 `1` 未満の特徴付け
- 零点 `-1` と一次因子 `x+1` による奇接続辺数頂点の特徴付け
- 高温展開に使う二変数の形式多項式

## 記号の帰属と非可算への脱出

有限集合、`N`、`Z[x]`、`Z[u,v]` で閉じる。スピン状態は形式的ラベルに置き、整数係数の式へ入れる箇所だけ明示した写像で `Z` へ移す。`x=e^{-2 beta J}`、`cosh`、`sinh`、実指数は使わない。

## 作業内容

- 定義を構造化本文へ書く。
- 多重度表示と係数和を証明する。
- 非負な多重度係数から正の有理評価の単調性を証明し、辺を一つ選んで正次数の非零係数を構成することで、辺をもつ場合の厳密単調性を証明する。
- 辺をもつ場合の厳密単調性から、二つの正の有理評価値が等しいことと評価点が等しいことの同値性を証明する。
- 正の有理評価の単調性と、辺をもつ場合の厳密単調性から、二つの評価値の狭義順序と評価点の狭義順序の同値性を証明する。
- 正の有理評価の単調性と、辺をもつ場合の厳密単調性から、二つの評価値の弱順序と評価点の弱順序の同値性を証明する。
- 正の有理評価の弱順序反映と `Z_G(1)=2^{|V|}` から、評価値が全配位数以下であることと評価点が `1` 以下であることの同値性を証明する。
- 正の有理評価の弱順序反映と `Z_G(1)=2^{|V|}` から、評価値が全配位数以上であることと評価点が `1` 以上であることの同値性を証明する。
- 正の有理評価点の一意性と `Z_G(1)=2^{|V|}` から、評価値が全配位数に等しいことと評価点が `1` であることの同値性を証明する。
- 正の有理評価の狭義順序反映と `Z_G(1)=2^{|V|}` から、評価値が全配位数より小さいことと評価点が `1` より小さいことの同値性を証明する。
- `x+1` による除法の余りを `-1` 評価へ同定し、奇接続辺数頂点の存在との同値性を証明する。
- 高温展開の有限和恒等式を、辺部分集合の展開とスピン和の消滅に分けて証明する。
- 小さい有限グラフを全列挙し、両辺を `ZZ[u,v]` で検算する。
