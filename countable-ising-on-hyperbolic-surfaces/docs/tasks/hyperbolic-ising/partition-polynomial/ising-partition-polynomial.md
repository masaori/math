# Ising 分配多項式

## 概要

有限グラフ上の各スピン配位を破れ辺数で数え、整係数分配多項式を構成する。指数重みを入口に置かない。

## 背景と前提

有限の頂点集合、辺集合、端点写像が定義済みであること。

## スコープ

- スピン配位集合
- 破れ辺集合と破れ辺数
- 多重度係数
- `Z[x]` に属する分配多項式
- 全係数和と大域スピン反転から従う帰無的恒等式
- 高温展開に使う二変数の形式多項式

## 記号の帰属と非可算への脱出

有限集合、`N`、`Z[x]`、`Z[u,v]` で閉じる。`x=e^{-2 beta J}`、`cosh`、`sinh`、実指数は使わない。

## 作業内容

- 定義を構造化本文へ書く。
- 多重度表示と係数和を証明する。
- 高温展開の有限和恒等式を、辺部分集合の展開とスピン和の消滅に分けて証明する。
- 小さい有限グラフを全列挙し、両辺を `ZZ[u,v]` で検算する。
