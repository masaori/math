# 有限セル分割の入力と検査

## 概要

向き付けられた閉曲面の有限セル分割を、有限集合と写像だけで入力し、後続の Ising・ホモロジー・双対格子が依存する条件を有限手続きで検査する。

## 背景と前提

有限グラフの頂点・辺・端点写像を定義済みであること。群商から得たデータを無条件に曲面と呼ばない。

## スコープ

- 頂点、辺、面の有限集合
- 各辺の始点・終点
- 各面の向き付き境界語
- 各辺が互いに逆向きの二つの面境界に現れること
- 頂点リンクが一つの巡回列になること
- 連結性、Euler 標数、向き付け可能性
- 正則型 `{p,q}` と双曲型の有理不等式

## 記号の帰属と非可算への脱出

有限集合、`N`、`Z`、`Q` だけを使う。双曲計量による実現は本タスクの証明に使わず、別の `R` 脱出ブロックで扱う。

## 作業内容

- 構造化本文に入力データを一ブロック一定義で追加する。
- 各検査条件を決定可能な述語として定義する。
- `{p,q}` の incidence 数と Euler 標数の等式を一ステップ一定理で証明する。
- 小さい既知のセル分割で検査器の正例・負例を SageMath で作る。
