# 有限セル分割の入力と検査

## 概要

向き付けられた閉曲面の有限セル分割を、有限集合と写像だけで入力し、後続の Ising・ホモロジー・双対格子が依存する条件を有限手続きで検査する。

## 背景と前提

有限グラフの頂点・辺・端点写像を定義済みであること。群商から得たデータを無条件に曲面と呼ばない。

## スコープ

- 頂点、辺、面の有限集合
- 整数添字ではない形式的な辺端ラベルと端点写像
- 整数符号ではない形式的な向きラベル、端点選択写像、向き反転写像
- 形式的位置集合と後者写像からなる各面の向き付き境界語
- 各辺が互いに逆向きの二つの面境界に現れること
- 頂点リンクが一つの巡回列になること
- 連結性、Euler 標数、向き付け可能性
- 面次数写像・頂点次数写像からなる正則型集合と、自然数不等式で切り出す双曲正則型集合

## 記号の帰属と非可算への脱出

有限集合、`N`、`Z`、`Q` だけを使う。端点、向き、角での役割、巡回位置は相異なる有限ラベル集合に置き、ラベルへ整数環の構造を入れない。異なる集合の間を移るときは始域・終域を持つ写像を定義する。双曲計量による実現は本タスクの証明に使わず、別の `R` 脱出ブロックで扱う。

## 作業内容

- 構造化本文に入力データを一ブロック一定義で追加する。
- 各検査条件を決定可能な述語として定義する。
- `{p,q}` の incidence 数と Euler 標数の等式を一ステップ一定理で証明する。
- 小さい既知のセル分割で検査器の正例・負例を SageMath で作る。
