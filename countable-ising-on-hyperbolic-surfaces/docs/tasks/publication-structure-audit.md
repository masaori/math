# 本文二章構成の境界監査

## 分類基準

全ての既存見出しを除き、定義・主張・定理を一度フラットな集合として扱った。任意の有限グラフまたは有限セル分割を対象とし、双曲型・特定の有限商格子・スピン・Ising 分配多項式・Fisher 零点を指定しないものを「数学的道具立て」とした。有限文字と Fourier 反転は一般の有限セル分割の第一ホモロジー群を入力とするため、この基準に含む。それ以外を「有限双曲曲面上のイジング模型のセマンティクスを持つもの」とした。

出版順は `structured-latex/tools/publication-order.ts` が正本である。全ブロックを一度だけ分類し、ラベル参照と定義上の暗黙依存から得た依存関係で各節をトポロジカルソートする。後の節への参照、章内循環、未分類、重複は検査でエラーになる。さらに、本文ファイルごとの全ブロック ID 集合を SHA-256 で固定し、同数の未知 ID への置換も拒否する。

## 境界監査で直したもの

- 一般セル分割が参照する辺端ラベルと有限グラフ入力を、Ising 側から数学的道具側へ移した。
- 境界偶奇、偶辺部分集合、偶部分グラフ多項式、偶辺部分集合のホモロジー類写像と再結合は、スピンや Ising 分配多項式を用いないため数学的道具側へ移した。「高温生成多項式」という題名は「偶部分グラフ生成多項式」へ改めた。
- 主セルから双対セルへのコホモロジー・ホモロジー移送は双曲性や Ising を用いないため、全件を数学的道具側へ移した。
- 対数順序群の定義が二段 Ising 係数付値差の定義に埋め込まれていたため、独立した一般定義へ分離した。
- 二段有限商群と段間全射の入力は双曲型や Ising を仮定しないため数学的道具側へ移した。役割生成元以後の塔は具体的な剰余類セルへ依存するため模型固有側に残した。
- 外部の有限グラフ一般理論から輸入した `formal_high_temperature_` で始まる機械用 ID は参照安定性のため維持したが、出版上の題名と本文から物理的な呼称を除き、偶部分グラフの一般定義として配置した。

## 相互レビューで縮めた節ゴール

独立した二レビューを行い、分類と節ゴールを再監査した。未証明の到達点を新規証明で埋めず、現本文が実際に示した範囲へ入力・出力を限定した。

- 曲率 `-1` 計量の存在・構成は証明済みとしない。
- 積差分類は `5` から `132` までの個別分類であり、全双曲正則型の列挙とは呼ばない。
- 正有理数から対数順序群への写像は well-defined 性までとし、準同型性・単射性を主張しない。
- Ising 分配多項式と偶部分グラフ多項式を結ぶ恒等式は未証明であるため、節の出力に含めない。
- 主第一コホモロジーと双対第一ホモロジーの全単射を、Ising 多項式の双対変換と呼ばない。
- 商の塔では奇数面位置ファイバー条件を入力に明記し、局所全単射性・被覆次数・閉曲面性の保存を主張しない。
- 一般の有限置換商については剰余類セルデータの定義までとし、閉曲面かつ双曲正則型である有限証明書は固定した八点上の `Q_{3,7}` の例だけに限定した。

この監査後、二レビューの指摘を全て再照合し、数学的道具へ模型固有対象を参照する逆向き依存がないことを生成時検査で確認した。
