# 本文二章構成の境界監査

## 論理主線

本文は次の一方向の依存だけを採る。

```text
有限置換商
→ 向き付け閉曲面セル分割の有限検査
→ 正則型の双曲不等式と負の Euler 標数
→ 一次骨格上の Ising 分配多項式
→ 偶部分グラフのホモロジー類別
→ 有限 Fourier 反転と主・双対セルの移送
→ 固定格子の係数算術と Fisher 零点
→ 明示した二段有限商に沿う有限比較
```

数学的道具立てには、この連鎖で実際に使う有限群、剰余類、有限グラフ、有限セル、二元体上の鎖複体、有限 Fourier 変換、素指数写像だけを置く。標準数学を集合論から構成する章は置かない。

## 本文から外したもの

- Grothendieck 宇宙、自然数の集合論的構成、遺伝的有限集合、順序対の集合論的構成は、どの主定理にも必要ないため撤去した。
- 滑らかな曲面、Riemann 計量、曲率、測地線による実現は、有限セル分割の正しさにも Ising の有限恒等式にも使わない。双曲計量による実現は外部の幾何学的解釈とし、本文の入力・定義・定理には含めない。
- 積差を固定して個別列挙した分類群は、上位到達点へ依存しない自動追加だったため出版対象から外した。一般の積差判定と、双曲正則型と負の Euler 標数の同値性だけを本文に残す。個別分類の構造化データと検算は、判断履歴を失わないよう正本内に保存するが、論文生成では使用しない。

## 出版順の検査

`structured-latex/tools/publication-order.ts` が出版順の正本である。出版対象ブロックを二章へ分類し、ラベル参照と明示した依存関係で各節をトポロジカルソートする。最終配置後に全参照を再走査し、前方参照、循環、重複分類があれば生成を停止する。

本文ファイルごとの全ブロック ID 集合は SHA-256 で固定する。出版対象から外した個別積差分類もこの監査対象に含め、無断の置換や消失を拒否する。二元体、有限置換群、元の位数、群作用、剰余類、辺端・向きラベル、閉曲面セル分割述語については、本文での最初の出現が対応する定義であることも検査する。

## 到達点の境界

- 一般の有限置換商から閉曲面性を仮定しない。固定した八点上の型 `{3,7}` の例だけを有限検査する。
- 双曲性は自然数不等式 `2(p+q)<pq` と負の Euler 標数の同値性として扱い、曲率 `-1` 計量の存在を証明済みとしない。
- Ising 分配多項式と偶部分グラフ多項式を結ぶ恒等式は未証明なので、節の出力に含めない。
- 主第一コホモロジーと双対第一ホモロジーの全単射を、Ising 多項式の双対変換と呼ばない。
- 商の塔では奇数面位置ファイバー条件を入力に明記し、局所全単射性、被覆次数、閉曲面性の保存を主張しない。
- 正有理数から素指数加法群への写像は、本文で証明した範囲を超えて準同型性や単射性を主張しない。

この境界により、未定義語を基礎論の追加で覆うのではなく、主定理で不要な対象そのものを導入しない。
