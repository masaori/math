# 有限双曲曲面上の Ising 模型の可算構造

このプロジェクトで作業する前に、リポジトリ直下の `docs/context/` を全て読む。
本プロジェクトの判断は、その三つの思想レイヤーとこの README に従う。

## ゴール

有限群・剰余類データから閉双曲曲面の有限セル分割を生成し、その上の Ising 模型について、
次の対象を有限集合・有限体・整係数多項式の中で構成する。

- 有限商から得る主格子と双対格子
- 独立プロジェクトで定義した有限グラフ上の Ising 分配多項式を、有限セル分割の一次骨格へ適用したもの
- 高温展開の偶部分グラフと、その第一ホモロジー類別の生成多項式
- 第一ホモロジー群上の有限 Fourier 変換としての主格子・双対格子間の変換
- 係数、素因数付値、Fisher 零点、有限商の塔に沿う変化

最初の到達点は、これらの定義と有限恒等式を、実数座標や指数関数を用いずに証明することである。
双曲平面の計量的実現は、有限セル分割の正しさを決める入力ではなく、有限群データが
双曲型の閉曲面を与えることを確認するための外部の実現と位置づける。

## 本文の論理主線

本文は、有限置換商から一つのセル分割を生成して有限検査し、その一次骨格上の Ising 分配多項式、
ホモロジー類別、有限 Fourier 変換、係数算術、二段有限商での比較へ進む。この依存列に使わない
標準数学を集合論から再構成しない。滑らかな曲面、Riemann 計量、曲率、測地線は有限側の本文で
定義せず、必要になった別成果でだけ外部の幾何学として扱う。

双曲正則型について本文に必要なのは、自然数不等式による判定、Euler incidence 等式、負の Euler
標数との同値性、および固定した型 `{3,7}` の有限検査である。積差を固定して型を順次列挙する作業は、
これらの到達点を前進させないため論文の主線に含めない。

## 研究対象を固定する

扱う格子は、向き付けられた閉曲面の有限正則セル分割である。初期段階では次を入力とする。

- 有限の頂点集合、辺集合、面集合
- 各辺の始点・終点を与える写像
- 各面の向き付き境界語
- 全ての面が同じ辺数をもち、全ての頂点が同じ次数をもつことを示す有限証明書
- セル鎖複体の条件 `境界の境界 = 0` と、閉曲面であることを示す有限証明書

有限群からの生成では、三角群または旗への推移的な有限置換作用を入力し、頂点・辺・面を
部分群の剰余類集合として取り出す。群の表示だけから閉曲面性を仮定せず、生成後の有限データに対して
セル分割の条件を機械検査する。

向き付け閉曲面セル分割データ `X` に対し、正則型集合 `RegularTypes(X)` を正整数対の集合として定める。
`(p,q)` がその元であるとは、各面が `p` 辺、各頂点に `q` 面が接するという意味であり、従来の
Schläfli 記法では型 `{p,q}` と書く。双曲正則型集合は、この集合から

\[
2(p+q)<pq
\]

を満たす対だけを取り出した部分集合である。この自然数不等式は
`1/p + 1/q < 1/2` と同値であり、判定自体に逆数、双曲関数、実数座標を要しない。

## 可算側の正本

有限セル分割を `X`、その一次骨格を `G` とする。

| 対象 | 住処 |
| --- | --- |
| スピン配位、辺部分集合、セル鎖 | 有限集合 |
| 破れ辺数、係数、多重度 | `N` |
| Ising 分配多項式 | `Z[x]` |
| 偶部分グラフとホモロジー類 | `F_2` 上の有限ベクトル空間 |
| ホモロジー類別生成多項式 | `Z[t]` |
| 有限 Fourier 変換 | `Z` 係数多項式の有限和。逆変換だけ `Q` を用いる |
| 係数の素因数付値 | `Z` |
| 有限系の Fisher 零点 | `Qbar` |

最初から物理変数 `x=e^{-2\beta J}` や `t=\tanh(\beta J)` を置かない。
`x` と `t` は不定元であり、多項式とその評価値を区別する。

## 非可算への脱出

本プロジェクトで `R/C` を使う可能性がある箇所は、可算側の成果と別ブロックにする。

- 双曲計量による幾何学的実現
- 有限系の Fisher 零点を複素平面へ描画する数値近似
- 商の塔に沿う零点列の集積、自由エネルギー密度、非解析性
- 測地長、距離、スペクトル密度など計量的な極限量

有限系の Fisher 零点そのものは整係数多項式の根なので `Qbar` に属する。`C` への脱出は、
零点を近似して描画すること、距離や集積を解析することにある。

## Ising から始める理由

Ising ではスピンが `F_2` と対応し、高温展開の偶部分グラフが一次サイクル空間になる。
閉曲面では一次サイクル空間が第一ホモロジー群の有限個の類へ分かれ、その類の集合上で
有限 Fourier 変換を直接定義できる。この連鎖が、有限商・分配多項式・位相・双対性を
一つの決定可能な対象へ結ぶ。

dimer と Potts は、Ising の定義・検証・双対性が成立した後に別の章として扱う。
Ising の語彙へ混ぜない。

### 章の到達点だけに主定理の印を付ける

定理・主張のブロックは `standing: "mainTheorem"` を宣言できる（入力言語の正本は
リポジトリ直下の [structured-latex](../structured-latex/README.md)）。宣言が無ければサブ定理
として扱うため、印を付けるのは各章の到達点にあたるものだけとする。判断に迷うものは
サブ定理のままにする。定義・注意・ノートには宣言できない。

HTML では各見出しの冒頭にその範囲の主定理を列挙し、サブ定理は題名だけを見せて既定で閉じる。
PDF の出力は印の有無で変えない。

## 進める順序

| 先に行う作業 | その次に行う作業 | 理由 |
| --- | --- | --- |
| 有限セル分割の入力形式と検査 | 有限群・剰余類からの生成 | 不正な商を格子として受理しないため |
| Ising 分配多項式 | 高温展開 | 同じ有限配位集合に二つの数え上げを与えるため |
| `F_2` セル鎖複体 | ホモロジー類別生成多項式 | 類別の well-defined 性を先に確定するため |
| ホモロジー類別生成多項式 | 有限 Fourier 双対 | 変換の始域・終域を確定するため |
| 一つの有限商での全検証 | 商の塔 | 境界条件や被覆写像を混同しないため |
| 係数と素因数付値 | Fisher 零点と極限 | 有限の決定可能データを正本にするため |
