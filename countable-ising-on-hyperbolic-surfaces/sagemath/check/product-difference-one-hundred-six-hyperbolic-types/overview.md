# 積差百六をもつ双曲正則型の分類の検算

**対象ラベル**: `theorem_product_difference_one_hundred_six_hyperbolic_types`
- 対象: 百六の正整数因数対から面次数と頂点次数を復元する有限分類
- 記号の所属: 因数と次数は `NN`、積差は標準単射で `ZZ` に移して計算する

| 検算 | 状態 | 結果 |
|---|---|---|
| 百六の正の因子対の全列挙 | PASS | `(1,106)`, `(2,53)`, `(53,2)`, `(106,1)` だけである |
| 次数対の復元 | PASS | 各因子へ二を加えると本文の四つの次数対と一致する |
| 双曲不等式 | PASS | 四つの次数対すべてで `2(p+q)<pq` が成り立つ |
| 整数積差 | PASS | 四つの次数対すべてで `(p-2)(q-2)=106` が成り立つ |
