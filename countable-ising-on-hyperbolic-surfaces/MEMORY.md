- 二段の分配多項式の Fisher 零点台の和集合を定義域とし、各代数的数へ細段・粗段の零点重複度を零延長した自然数対を返す写像を定義した。四頂点サイクルと二頂点二重辺グラフの例では、細段の四つの単根からなる台と粗段の二つの単根からなる台が交わらず、重複度対がそれぞれ `(1,0)` と `(0,1)` になることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点重複度対の細段成分から粗段成分を引く整数値写像を定義した。共有零点 `-1` で差が `0`、細段だけの四根で `1`、粗段だけの二根で `-1` となることを `QQbar` 上で厳密検算した。差の符号、零点台の包含、段間単調性は仮定していない。
- 二段 Fisher 零点重複度差が非零となる零点の集合を定義し、二段零点台の有限部分集合であることを証明した。互いに素な二段零点台では六元全て、共有零点 `-1` を加えた七元零点台では `-1` を除く六元が有限台になることを `QQbar` 上で厳密検算した。初回の集合対称差演算子に対する SageMath 前処理の型エラーは検算台帳に保存し、集合メソッドへ修正した。
- 二段 Fisher 零点重複度差の有限台上で、重複度差を整数係数とする形式的因子を定義した。互いに素な二段零点台では六項の形式和となり、共有零点 `-1` を加えた例でもその係数が零となって形式和から消えることを `QQbar` 上で厳密検算した。
- 二段 Fisher 零点重複度差の形式的因子が、細段の零点重複度形式和から粗段の零点重複度形式和を引いた差に一致することを証明した。互いに素な二段零点台と共有零点 `-1` を加えた例の両方で、段別形式和の差と重複度差の形式的因子を `QQbar` 上で係数ごとに厳密検算した。
- 二段 Fisher 零点形式的因子の段別差表示をレビューし、自然数値重複度どうしを直接減算していた一行を、両項を自然数から整数への標準単射で移した後の整数差へ修正した。対応する SageMath 検算も全零点でこの整数係数差を照合する形へ強化した。
- 二段 Fisher 零点重複度差の形式的因子について、係数総和が細段分配多項式と粗段分配多項式の次数差に等しいことを証明した。有限台の零延長、整数有限和の分配、段別零点台への制限、代数閉体上の零点重複度総和と次数の一致を分離し、互いに素な零点台と共有零点をもつ例で `QQbar` と `ZZ` による一行ごとの厳密検算を追加した。
- 二段 Fisher 零点重複度差の形式的因子が零であることと、細段・粗段分配多項式が非零定数倍だけ異なることの同値性を証明した。互いに素な零点台、共有零点をもつ零点台、非零定数倍だけ異なる多項式の三例で、重複度一致、モニック一次因子積、最高次係数の交差乗算を一行ずつ厳密検算した。
- 二段 Fisher 零点形式的因子の消滅条件をレビューし、整数へ移した重複度差の零性と自然数から整数への標準単射の単射性を一行で処理していた箇所を、重複度差の定義による整数差の零性、整数加法の消去律による像の一致、標準単射による自然数重複度の一致へ分離した。対応検算も三つの同値性を個別に照合する形へ強化した。

## 判断の固定事項

- 一般有限グラフ理論から取り込むのは双曲曲面固有本文が参照する内容名ラベルの依存閉包だけであり、一般理論の見出しは取り込まない。接続層の見出しは「双曲曲面の格子に用いる有限グラフ入力」として、このプロジェクトが所有する。

- `x` と `t` は不定元であり、指数関数や双曲関数から定義しない。
- 端点・向き・角での役割・巡回位置・スピン状態は相異なる形式的ラベル集合に置く。異なる集合の間の移行や整数係数演算への移行は、始域・終域を明記した写像だけを通す。
- 群表示から閉曲面性を仮定せず、生成後の有限セル分割を検査する。
- 主格子と双対格子の変換は、ホモロジー類別多項式を定義してから扱う。
- Fisher 零点そのものは `Qbar`、零点の数値描画と集積は `C` への脱出として分ける。
- dimer と Potts は Ising の初期到達点まで本文へ混ぜない。
