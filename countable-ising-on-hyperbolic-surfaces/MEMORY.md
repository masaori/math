# 引き継ぎメモ

## 現在地

- 有限双曲曲面上の Ising 模型を、有限セル複体・整係数多項式・`F_2` ホモロジー・有限 Fourier 変換として扱うゴールを確定した。
- 最初の構造化本文として、有限グラフ上のスピン配位、破れ辺数、分配多項式、高温展開の有限和恒等式を書いた。
- 有限セル分割の頂点・辺・面を、互いに素な三つの空でない有限集合として定義した。
- 辺端、境界辺の向き、角での役割、面境界の位置を相異なる形式的有限ラベル集合に置いた。有限グラフの端点写像、向きから始点・終点を選ぶ写像、向き反転写像、位置の後者写像だけでこれらを関係付け、整数添字や整数符号による暗黙の選択を廃止した。
- スピン状態も形式的ラベル集合に置き、高温展開の整数係数演算へ移る箇所に限って整数実現写像を明記した。
- 各辺が面境界語全体でちょうど二回、互いに逆向きで現れる有限述語を定義し、二面三角形の正例と三種の負例を SageMath で検算した。
- 各辺端へ二つの角が接し、各頂点の角が辺端の共有で一つにつながることにより、各頂点リンクが一つの巡回列になる有限述語を定義した。二面三角形の球面を受理し、一頂点で二球面を貼った非多様体を拒否することを SageMath で検算した。
- 一次骨格の連結性を、任意の二頂点を結ぶ有限辺列の存在として定義した。二面三角形の球面を受理し、互いに素な二つの三角形を拒否することを SageMath で検算した。
- 有限セル分割の Euler 標数を、頂点数・辺数・面数から定まる整数として定義した。二面三角形の球面で `2`、`3 x 3` 周期正方格子トーラスで `0` となることを SageMath で検算した。
- 辺の逆向き二回出現、頂点リンク単巡回、一次骨格連結の三条件をまとめ、向き付けられた閉曲面セル分割を判定する有限述語を定義した。二面三角形の球面を受理し、同方向の面貼り、一頂点で二球面を貼った非多様体、互いに素な二球面を拒否することを SageMath で検算した。
- 正則型 `{p,q}` を、各面の境界語に現れる辺出現数が `p`、各頂点に接する角出現数が `q` であるという有限述語として定義した。二面三角形の球面を `{3,2}` として受理し、三種の不一致を拒否することを SageMath で検算した。
- 正則型 `{p,q}` が双曲型であることを、正則型述語と有理不等式 `1/p + 1/q < 1/2` の連言として定義した。双曲型二例と非双曲型・正則型不成立の四例を `QQ` 上で厳密検算した。
- `F_2` 上の一次境界写像を、頂点集合で行、辺集合で列を添字付け、各成分を端点写像の逆像にわたる `F_2` の有限和とする incidence 行列として定義した。三角形の全ての辺部分集合で、行列積と端点偶奇の直接計数が一致することを厳密検算した。
- `F_2` 上の二次境界写像を、辺集合で行、面集合で列を添字付け、各成分を面境界語における当該辺の出現位置にわたる `F_2` の有限和とする incidence 行列として定義した。逆向きの三角形二面と同一辺が二回現れる面を用い、全ての面部分集合で行列積と境界位置の直接計数が一致することを厳密検算した。
- 二つの境界写像の積が `F_2` 上の零行列であることを、面境界語の接続条件、後者写像の全単射性、標数二での相殺から証明した。六つの式変形を三角形二面と自己ループ面の全成分で一行ずつ厳密検算した。
- `F_2` 上の一次サイクル空間を、一次境界行列で零へ写る辺係数写像の核として定義した。既存の偶辺部分集合とは同一視せず別記号に置き、三角形の全ての辺係数列で厳密検算した。
- `F_2` 上の面境界空間を、二次境界行列の像として定義した。境界の境界が零であることから一次サイクル空間への包含を明示し、反対向きの三角形二面の全ての面係数列で像の定義と核への包含を厳密検算した。
- 第一ホモロジー群を、一次サイクル空間を面境界空間で割った剰余集合の有限商として定義し、各サイクルをその剰余集合へ送る商写像の始域・終域・作用を明示した。四元の一次サイクル空間と二元の面境界空間の例で、二元の商、商写像の全射性、同じ像を持つ条件を厳密検算した。
- 辺部分集合から `F_2` 辺係数写像への変換を、有限冪集合から `F_2` 辺係数空間への写像として定義した。三辺の全ての部分集合を列挙し、定義の二場合と八つの係数列への対応を厳密検算した。
- 偶辺部分集合の係数写像が一次境界写像の核へ入ることを、境界行列積、係数写像による有限和の制限、境界偶奇との一致、偶辺条件の順に証明した。四頂点五辺グラフの全辺部分集合を用い、四つの等号を一行ずつ厳密検算した。
- 偶辺部分集合の第一ホモロジー類写像を、辺係数写像の制限と第一ホモロジー群への商写像の合成として定義した。三本の平行辺からなる有限グラフの全ての偶辺部分集合で、合成写像と面境界剰余集合の直接構成が一致することを厳密検算した。
- 第一ホモロジー類別の高温生成多項式を、類写像による商集合の各元のファイバーにわたる `Z[u,v]` の有限和として定義した。代表サイクルを選ばない定義であることを明記し、二元の第一ホモロジー群をもつ有限例で零類と非零類の多項式を厳密検算した。
- 有限群からの格子生成は、生成結果のセル分割検査を先に定義してから実装する。
- 記述と SageMath の検算を先に起動する。Lean は未着手である。
- 構造化本文は、他の数学プロジェクトと同じ KaTeX・共通章ナビゲーションのレンダラーで自己完結 HTML に生成する。公開用 HTML は外部 CDN に依存しない。

## 判断の固定事項

- `x` と `t` は不定元であり、指数関数や双曲関数から定義しない。
- 端点・向き・角での役割・巡回位置・スピン状態は相異なる形式的ラベル集合に置く。異なる集合の間の移行や整数係数演算への移行は、始域・終域を明記した写像だけを通す。
- 群表示から閉曲面性を仮定せず、生成後の有限セル分割を検査する。
- 主格子と双対格子の変換は、ホモロジー類別多項式を定義してから扱う。
- Fisher 零点そのものは `Qbar`、零点の数値描画と集積は `C` への脱出として分ける。
- dimer と Potts は Ising の初期到達点まで本文へ混ぜない。
