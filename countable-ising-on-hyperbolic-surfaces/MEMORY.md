# 引き継ぎメモ

## 現在地

- 有限双曲曲面上の Ising 模型を、有限セル複体・整係数多項式・`F_2` ホモロジー・有限 Fourier 変換として扱うゴールを確定した。
- 最初の構造化本文として、有限グラフ上のスピン配位、破れ辺数、分配多項式、高温展開の有限和恒等式を書いた。
- Ising 分配多項式の次数が、有限スピン配位全体で実現する最大破れ辺数に等しいことを、非零多重度の台を介して証明した。三角形、四頂点サイクル、二本の平行辺の全配位による厳密検算が PASS した。
- Ising 分配多項式の次数が、頂点部分集合とその補集合を横切る辺数の最大値に等しいことを、スピン配位を上向きスピン頂点の部分集合へ送る全単射から証明した。三角形、四頂点サイクル、完全四頂点グラフ、二本の平行辺の厳密検算が PASS した。
- 空でない頂点集合をもつ任意の有限入力グラフで、大域スピン反転が各破れ辺数ファイバーを保つ不動点のない対合になることから、Ising 分配多項式の全係数が偶数であることを証明した。一頂点無辺、一辺、三角形、四頂点サイクル、二本の平行辺の厳密検算が PASS した。
- 奇数本の辺が接続する頂点をもつ任意の有限入力グラフで、その一頂点だけのスピン反転が破れ辺数の偶奇を反転し、全配位の二元軌道内で符号が相殺することから、Ising 分配多項式が `-1` を零点にもつことを証明した。一辺グラフ、三頂点道、三本の平行辺、奇数次数頂点をもつ四頂点五辺グラフの全配位による厳密検算が PASS した。
