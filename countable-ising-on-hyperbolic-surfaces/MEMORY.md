# 引き継ぎメモ

## 現在地

- 有限双曲曲面上の Ising 模型を、有限セル複体・整係数多項式・`F_2` ホモロジー・有限 Fourier 変換として扱うゴールを確定した。
- 最初の構造化本文として、有限グラフ上のスピン配位、破れ辺数、分配多項式、高温展開の有限和恒等式を書いた。
- 有限セル分割の頂点・辺・面を、互いに素な三つの空でない有限集合として定義した。
- 有限グラフの端点写像をセル分割の頂点・辺集合へ等号で接続し、各面の向き付き境界語を符号付き辺の非空有限列と巡回接続条件として定義した。
- 有限群からの格子生成は、生成結果のセル分割検査を先に定義してから実装する。
- 記述と SageMath の検算を先に起動する。Lean は未着手である。
- 構造化本文は MathJax で数式を inline SVG 化した自己完結 HTML に生成できる。公開用 HTML は外部 CDN に依存しない。

## 次に行うこと

- 各辺が互いに逆向きの二つの面境界へ現れることと、各頂点リンクが一つの巡回列になることを決定可能な述語として定義する。
- `F_2` 上の境界写像、サイクル空間、面境界空間を定義する。
- 第一ホモロジー類別の高温生成多項式を定義する。
- 文字直交関係と有限 Fourier 逆変換を証明する。
- 最初の `{p,q}` 有限商を一次情報から選び、群表示・剰余類・セル分割検査の全データを保存する。

## 判断の固定事項

- `x` と `t` は不定元であり、指数関数や双曲関数から定義しない。
- 群表示から閉曲面性を仮定せず、生成後の有限セル分割を検査する。
- 主格子と双対格子の変換は、ホモロジー類別多項式を定義してから扱う。
- Fisher 零点そのものは `Qbar`、零点の数値描画と集積は `C` への脱出として分ける。
- dimer と Potts は Ising の初期到達点まで本文へ混ぜない。
