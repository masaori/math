### Step 3 — $\Delta$ の内訳（点ごと）

$\sum_{\text{低レベル点}}\bigl(v_\ell(E)-k/\varphi(\ell^M)\bigr)$ が定義 3.1 の $\Delta$ に一致することを確認:
D1 で 8、D2 で 14、D3 で 6 — **3 件とも一致**。

「Newton 下限が一意に達成されるのに $v\neq$ 下限」だった点: **3 件とも 0 件**
（非アルキメデス的評価が鋭いことの確認）。

ずれの機構は $\ell$ によって異なる。

- **$\ell=2$（D1・D2）**: 低レベル点で Newton 下限そのものが $k/\varphi(\ell^M)$ **より小さい**
  （下限を達成する $(p,q)$ が 1 個）。例: D1 の $M=1$ の 2 点で下限 3 に対し予言 4、実測 3。
  すなわち低次項が支配して付値が**下がる**。
- **$\ell=3$（D3）**: 下限は $k/\varphi(\ell^M)$ と**一致する**が、下限を達成する $(p,q)$ が
  複数あり（2 個または 8 個）、**打ち消しによって実測が下限より上がる**（予言 2 に対し実測 3）。

## 副産物: $\ell=2$ の非退化塔は存在する

cycle 14 report §8.5 は「**非退化な塔が $\ell=2$ で存在するかを決めていない**（注 8.9）。
§11 の標本 30 件で $\ell=2$ の非退化例が 0 件だったのは 0 件の観察であって、非存在の証明ではない」と
明示的に未決事項として記録していた。本サイクルの掃引で **$\ell=2$ の非退化塔が実在する**ことが分かった。

- `delta_examples.out` Step 2: 有効 1844 件中 **20 件**が非退化（約 1.1%）。
- `search_examples.out` 探索 1: 2652 件中 24 件、探索 2: 3685 件中 43 件。
- 最小の例（D1）: 1 頂点 5 ループ、voltage $(3,-1),(0,2),(0,-3),(1,1),(-2,3)$。
  $H=T^4+T^2S^2+S^4=(T^2+TS+S^2)^2$ で、$\mathbb{P}^1(\mathbb{F}_2)$ の 3 点
  $(1:0),(0:1),(1:1)$ のいずれでも $H=1\neq0$。

**掃引で見つかった $\ell=2$ の非退化例はすべて $k\ge4$ だった**（非退化 20 件の内訳は $k=4$ が 17 件、
$k=6$ が 3 件。全体では $k=3,5,7,11$ も出るがいずれも退化していた。$k\le3$ の非退化例が 0 件なのは
0 件の観察であって不可能性の証明ではない）。$k\ge4>\ell=2$ は系 A′ の外側なので、
$\ell=2$ の非退化塔がそのまま $\Delta\neq0$ の住処になっている
（`delta_examples.out` Step 2 で $\ell=2$ の非退化 20 件は全件 $\Delta\neq0$）。

## 検証できていないこと（結論の射程外）

1. **$\Delta\neq0$ の完全な判定条件は無い。** 命題 A は十分条件（$\delta>0\Rightarrow\Delta=0$）であって、
   $\delta\le0$ のとき $\Delta$ が 0 か否かは個別計算に依る（$\ell=3$ で 8 件中 4 件が $\Delta=0$）。
2. **$\Delta$ の閉じた式は無い。** 有限計算で決まること（cycle16 定理 N2）は既に証明済みで、
   本サイクルはそれが非自明であることを示しただけである。
3. **掃引は網羅ではない。** 頂点数 $\le3$・辺数 $\le7$・voltage $\in[-3,3]^2$、$\ell\le11$。
   $\ell\ge17$ は掃引していない。系 A′ から $\ell\ge17$ で $\Delta\neq0$ には $k\ge18$ が要るので
   出にくいと予想されるが、**予想であって確認していない**。
4. **退化ケースには一切触れていない。** cycle16 の $\ell$ 奇の退化塔（仮説 6.1）・型 II の実例・
   一般の退化 $P$ の閉形式は、本サイクルでも未解決のままである。
5. **$\ell=2$ の非退化塔について、$k=2,3$ で非退化が不可能かどうかは証明していない。**
   掃引で $k\le3$ の非退化例が 0 件だったのは 0 件の観察である。
