## 何を確かめたか

cycle 19 定理 J7 の $n\ell^n$ 係数 $b=\sum_{P\in S_\infty}j^*(P)$ は、cycle 20 の時点で
仮定 **(B\*)**（定理 B′ の最小点の一意性）だけが残っていた。(B\*) は実際に破れる
（cycle 20 §8.1 の反例 2 件）。本検証は、その (B\*) を落とした**定理 Q1** を支える。

証明の骨格（report §3–§6）:

1. $\bmod\ \ell$ の因数分解 $\bar{\tilde E}=c\chi^{w_0}\prod_i(\chi^{v_i}-1)^{m_i}\bar G_0$ を
   **整数へ持ち上げて** $\tilde E=B\,G+\ell H$ と書く（補題 Q1′）。
2. $G$ 側の消滅深度 $\theta_G$ は一様に浅い（補題 Q2）ので、
   $\varphi(\ell^M)$ が大きいレベルでは仮定なしに $v_{\mathfrak l}(G(\omega_P))=\theta_G(P)$。
3. $B$ 側と $\ell H$ 側の付値が拮抗しない点（「良い点」）では
   $\hat\theta_M(P)=\beta_P+\theta_G(P)$ が**等号で**成り立つ（定理 Q4）。
4. 拮抗する点（「悪い点」）は $M$ に依らず $O(1)$ 個（補題 Q5）で、
   粗上界（補題 Q0）で押さえると $O(\ell^M)$ しか動かせない。
5. 数え上げ（補題 Q3）で $\Theta_M=b\,M\varphi(\ell^M)+O(\ell^M)$（定理 Q1）。

## 実測量の独立性

$\hat\theta_M(a,b)$ は**整数終結式**で厳密に計算している（cycle 20 定理 L4）:

$$\hat\theta_M(a,b)=v_\ell\Bigl(\mathrm{Res}_y\bigl(\Psi_{\ell^M}(y),R_{(a,b)}(y)\bigr)\Bigr),\qquad
R_{(a,b)}(y)=\sum_{(p,q)}c_{pq}y^{(pa+qb)\bmod\ell^M}.$$

**本 report の理論（分解 $\tilde E=BG+\ell H$）を一切使っていない**ので、
予言と実測の照合は自己参照になっていない。

健全性の確認: $\ell=2$ トーラスの $\Theta_3=44$ は cycle 19 step 1 §5.4 の記録と一致し、
$b$ の分布は cycle 20 §7.2 (c) の表と完全に一致した（独立実装での再現）。
