# cycle 14 / T1: 2 変数 $P$ の $\mathbb{Z}_p^2$ 塔での $v_p(a_{p^n})$

スクリプト `vp_two_var.sage`、出力 `vp_two_var.out`（SageMath 10.6、`sage vp_two_var.sage`）。

証明本体は `outputs/reports/cycle14_T1_vp_growth_two_variable.md`。
**本ディレクトリは証明の確認と、証明していない部分（増大の完全な形）の探索であって、計算が証明なのではない。**

## 対象（何を検証したか）

$P\in\mathbb{Z}[z,w]$、$a_L:=\prod_{z^L=1,\,w^L=1}P(z,w)=\mathrm{Res}_z\bigl(z^L-1,\mathrm{Res}_w(w^L-1,P)\bigr)$
（$z^L-1$, $w^L-1$ はモニックなので終結式は厳密に積を与える）。$L=p^n$ の塔について:

1. **判定式（命題 V）** $v_p(a_{p^n})>0\iff p\mid P(1,1)$。
2. cycle 13 step 2 の判定式 $\mu_\ell=v_\ell(\mathrm{content})$ が $d=2$ では成立しないこと。
3. Deninger の条件との関係（命題 V の方が適用範囲が広いこと。ただし「Deninger $\Rightarrow v_p\equiv0$」は偽で、反例 $2zw$ を含める）。
4. 増大の形が DuBose–Vallières Thm A の $P(\ell^n,n)$ 型に当てはまるか（**フィットのみ**）。
5. **補題 V0** $a_{p^n}\equiv P(1,1)^{p^{2n}}\pmod p$ の直接照合。命題 V の実体。

## 手順（どのスクリプトを何の設定で実行したか）

`vp_two_var.sage` を実行する。設定はスクリプト内に固定。

- 対象 $P$: 17 個（本プロジェクトの主例 $5-(z+z^{-1})-(w+w^{-1})$ とその $2,4$ 倍、
  $3-z-w$, $6-z-w$, $2+z+w$, $1+z+2w$, $3+z+w$, $5+z+w$, $2+3z+3w$, $1+2z+4w$, $3+3z+w$,
  $7-2z-2w$, $9-z-w$, $4-z-2w$、および Deninger の条件を満たすが content が $p$ で割れる $2zw$, $6zw$）。素数 $p\in\{2,3,5,7\}$。
- $n$ の範囲: (1)(3)(5) は $L^2\le300$（$p=2$ で $n\le3$、$p=3$ で $n\le2$、$p=5,7$ で $n\le1$）。
  (4) の同定のみ $p=2$ で $n\le5$（$L=32$）まで伸ばした。
- 計算はすべて `ZZ` 上の終結式（厳密整数）。浮動小数点も $\mathbb{Q}_p$ も使わない。
- Laurent 多項式は単項式を掛けて多項式にしてから扱う。$a_L$ は**変わらない**
  （$\prod_{z^L=1,w^L=1}z^aw^b=((-1)^{L+1})^{(a+b)L}$ で $L(L+1)$ が常に偶数だから $+1$）。

## 結論（実行ログから読み取れる事実）

- **(1)** 17 個の $P$ × 4 素数 = **68 組すべてで判定式が成立**（「判定式に反した組: 0 件」）。
  $a_L=0$ となる退化例（$2+z+w$ の $p=2$、$n\ge1$ など）も含む。
- **(2)** $\mathrm{content}=1$ にもかかわらず $v_p(a_{p^n})$ が増大する例が **8 件**。
  例: $6-z-w$, $p=2$ で $2,7,16,37$。$7-2z-2w$, $p=3$ で $1,8,23$。
  ⇒ cycle 13 の $(☆)$（$\mu=v_\ell(\mathrm{content})$）は $d=2$ へ素朴に拡張できない。
  一方 $P\mapsto cP$ とすると $v_p$ にちょうど $v_p(c)p^{2n}$ が加わる（`2*(上)`: $1,4,16,64$、
  `4*(上)`: $2,8,32,128$）。**ただし「一般の $P$ の $X^2$ 項の係数が $v_p(\mathrm{content})$」は
  観察であって証明していない**（report §4 末）。
- **(3)** $P\bmod p$ が単項式でない（Deninger 不適用）のに $p\nmid P(1,1)$ ゆえ $v_p\equiv0$ となる例が **43 件**。
  ⇒ 命題 V は Deninger の枠外の $P$ にも適用できる。**なお「Deninger の条件 $\Rightarrow v_p\equiv0$」は偽**
  （反例 $2zw$: $v_2=1,4,16,64$）。正しい含意は「Deninger かつ $p\nmid c$ $\Rightarrow$ $p\nmid P(1,1)$」（report §5）。
- **(4)** **4 段だけのフィットは誤ることを実データで示した**: $6-z-w$, $p=2$ を $n\le3$ で解くと
  $2n2^n-4\cdot2^n+5n+6$ が得られるが、$n=4,5$ の真値 $86,199$ に対しこの式は $90,223$ を与えて外れる。
  $n\ge1$ の 5 段から一意に解くと $(a,b,c,d,e)=(0,1,1,1,2)$ すなわち $n2^n+2^n+n+2$ で、
  $n=1..5$ に一致するが $n=0$ では外れる（$6-z-w$ の場合）。$2+3z+3w$ では $n=0$ からずっと一致。
  **5 未知数を 5 方程式で解いた同定であって証明ではない。**
- **(5)** 補題 V0 $a_{p^n}\equiv P(1,1)^{p^{2n}}\pmod p$ を **187 件で直接照合、不一致 0 件**。
  Deninger の条件を満たすが $v_p>0$ になる $2zw$（$v_2=1,4,16,64$）も含む。

## 限界

- **(1)(5) は有限標本である。** ただし命題 V と補題 V0 は report §3 で**証明済み**なので、
  標本範囲は主張の根拠ではなく、証明の書き間違いを検出するための整合性確認である。
- **(4) は証明ではない。** 増大の完全な形（$P(\ell^n,n)$ の全係数）は未証明であり、
  002 の G1 の残る未達点である（report §6）。$n\le5$ の 2 例しか見ておらず、
  $n\ge6$ で崩れる可能性を排除できない（実際 $n\le3$ のフィットは $n=4$ で崩れた）。
- **$P(1,1)=0$ のレジーム（離散ラプラシアン＝全域木数）は本ディレクトリの対象外**。
  そこでは $a_L\equiv0$ で、$\tau$ 型の簡約積を使う別の量になる（report §3.4 の注、§6.2）。
- **新規性は主張しない。** 証明は初等的で folklore の可能性が高く、文献本文で既出を確認できていない
  （report §7）。
