# cycle 14 / T1: 2 変数 $P$ の $\mathbb{Z}_p^2$ 塔での $v_p(a_{p^n})$

スクリプト `vp_two_var.sage`、出力 `vp_two_var.out`（SageMath 10.6、`sage vp_two_var.sage`）。

証明本体は `outputs/reports/cycle14_T1_vp_growth_two_variable.md`。
**本ディレクトリは証明の確認と、証明していない部分（増大の完全な形）の探索であって、計算が証明なのではない。**

## 対象（何を検証したか）

$P\in\mathbb{Z}[z,w]$、$a_L:=\prod_{z^L=1,\,w^L=1}P(z,w)=\mathrm{Res}_z\bigl(z^L-1,\mathrm{Res}_w(w^L-1,P)\bigr)$
（$z^L-1$, $w^L-1$ はモニックなので終結式は厳密に積を与える）。$L=p^n$ の塔について:

1. **判定式（命題 V）** $v_p(a_{p^n})>0\iff p\mid P(1,1)$。
2. cycle 13 step 2 の判定式 $\mu_\ell=v_\ell(\mathrm{content})$ が $d=2$ では成立しないこと。
3. Deninger の条件（$P\bmod p$ が単項式）より命題 V の方が真に鋭いこと。
4. 増大の形が DuBose–Vallières Thm A の $P(\ell^n,n)$ 型に当てはまるか（**フィットのみ**）。
5. **補題 V0** $a_{p^n}\equiv P(1,1)^{p^{2n}}\pmod p$ の直接照合。命題 V の実体。

## 手順（どのスクリプトを何の設定で実行したか）

`vp_two_var.sage` を実行する。設定はスクリプト内に固定。

- 対象 $P$: 15 個（本プロジェクトの主例 $5-(z+z^{-1})-(w+w^{-1})$ とその $2,4$ 倍、
  $3-z-w$, $6-z-w$, $2+z+w$, $1+z+2w$, $3+z+w$, $5+z+w$, $2+3z+3w$, $1+2z+4w$, $3+3z+w$,
  $7-2z-2w$, $9-z-w$, $4-z-2w$）。素数 $p\in\{2,3,5,7\}$。
- $n$ の範囲: $L^2\le300$ まで（$p=2$ で $n\le3$、$p=3$ で $n\le2$、$p=5,7$ で $n\le1$）。
- 計算はすべて `ZZ` 上の終結式（厳密整数）。浮動小数点も $\mathbb{Q}_p$ も使わない。
- Laurent 多項式は単項式を掛けて多項式にしてから扱う（$a_L$ は $\pm1$ 倍しか変わらない。
  $\prod_{z^L=1}z=(-1)^{L+1}$ を $L$ 個掛けると平方になり $1$）。

## 結論（実行ログから読み取れる事実）

- **(1)** 15 個の $P$ × 4 素数 = **60 組すべてで判定式が成立**（「判定式に反した組: 0 件」）。
  $a_L=0$ となる退化例（$2+z+w$ の $p=2$、$n\ge1$ など）も含む。
- **(2)** $\mathrm{content}=1$ にもかかわらず $v_p(a_{p^n})$ が増大する例が **8 件**。
  例: $6-z-w$, $p=2$ で $2,7,16,37$。$7-2z-2w$, $p=3$ で $1,8,23$。
  ⇒ cycle 13 の $(☆)$（$\mu=v_\ell(\mathrm{content})$）は $d=2$ へ素朴に拡張できない。
  一方 $\mathrm{content}$ を $c$ 倍すると $v_p$ に $v_p(c)p^{2n}$ が加わる（`2*(上)`: $1,4,16,64$、
  `4*(上)`: $2,8,32,128$）。$X^2$ 項の係数は content で決まるが、それとは別に $XY$ 項がある。
- **(3)** $P\bmod p$ が単項式でない（Deninger 不適用）のに $p\nmid P(1,1)$ ゆえ $v_p\equiv0$ となる例が **43 件**。
  ⇒ Deninger の条件は $v_p\equiv0$ の十分条件だが必要条件でない。
- **(4)** $a=0$ を仮定したフィットが 4 段一致した例が 2 件
  （$6-z-w$, $p=2$: $2n2^n-4\cdot2^n+5n+6$／$2+3z+3w$, $p=2$: $n2^n+2^n+n+2$）。
  **未知数 5 個に方程式 4 本なので一意でない。フィットであって証明ではない。**
- **(5)** 補題 V0 $a_{p^n}\equiv P(1,1)^{p^{2n}}\pmod p$ を **165 件で直接照合、不一致 0 件**。

## 限界

- **(1)(5) は有限標本である。** ただし命題 V と補題 V0 は report §3 で**証明済み**なので、
  標本範囲は主張の根拠ではなく、証明の書き間違いを検出するための整合性確認である。
- **(4) は証明ではない。** 増大の完全な形（$P(\ell^n,n)$ の全係数）は未証明であり、
  002 の G1 の残る未達点である（report §6）。$n=4$ 以降を計算していないのでフィットは識別できていない。
- **$P(1,1)=0$ のレジーム（離散ラプラシアン＝全域木数）は本ディレクトリの対象外**。
  そこでは $a_L\equiv0$ で、$\tau$ 型の簡約積を使う別の量になる（report §3.4 の注、§6.2）。
