# cycle 13 / T1: 観察 T（奇 $L$ で $v_2(\tau(L))=2(L-1)$）の検証

スクリプト `tau_v2_verify.sage`、出力 `tau_v2_verify.out`（SageMath 10.6、`sage tau_v2_verify.sage`）。

証明本体は `outputs/reports/cycle13_T1_observation_T_settlement.md`。**本ディレクトリはその証明の
各段の前提を計算で確認するものであり、計算が証明なのではない。**

## 対象（何を検証したか）

$\tau(L)$ を $L\times L$ トーラス（周期境界の正方格子 $C_L\times C_L$）の全域木数とする。

1. $\tau(L)$ の厳密整数計算と $v_2(\tau(L))$（**奇 $L$ と偶 $L$ の両方**）。
2. 証明で使う分解 $\tau(L)=\prod_{j=1}^{L-1}\bigl(r_j^{L}+r_j^{-L}-2\bigr)$、
   ここで $r_j+r_j^{-1}=4-\zeta^{j}-\zeta^{-j}$。
3. 証明の核 $v(m_j)=1$ の前提、すなわち $m_j$ の満たす 2 次方程式
   $\zeta^{j}m^2+(3\zeta^{j}+\zeta^{-j}-4)m-2(1-\zeta^{j})(1-\zeta^{-j})=0$ の
   3 係数の $P$ 進付値が $(0,0,1)$ であること（Newton 多角形が $(1,0)$ の傾きを与えるための条件）。
4. 偶 $L$ で証明の前提が壊れる箇所。

## 手順（どのスクリプトを何の設定で実行したか）

`tau_v2_verify.sage` を実行する。設定はスクリプト内に固定。

- $\tau(L)$: $(\mathbb{Z}/L)^2$ 上のラプラシアンを `matrix(ZZ, L^2, L^2)` で構成し、
  1 行 1 列を削って `determinant()`（**厳密整数**。浮動小数点は使わない）。$L=2,\dots,15$ と $L=17$。
- 分解の確認: `CyclotomicField(L)` 上で $s_n=A s_{n-1}-s_{n-2}$（$s_0=2,s_1=A$）により $s_L$ を生成し、
  $\prod_j(s_L-2)$ と $\tau(L)$ を**体の元として**比較。$L=3,4,5,6,7,9$。
- 付値: `K.primes_above(2)[0]` で $P$ を取り、`x.valuation(P)` で各係数の付値、
  `P.ramification_index()` / `P.residue_class_degree()` で $e,f$ を取得。$L=3,5,7,9,11,13$（全 $j$）。
- 偶 $L$: $L=4,6,8$ で $e$、$v_P(1-\zeta^{L/2})$、$v_2(L)$ を出力。

## 結論（実行ログから読み取れる事実）

- **(1)** 奇 $L=3,5,7,9,11,13,15,17$ の全例で $v_2(\tau(L))=2(L-1)$（一致）。
  偶 $L=2,4,6,8,10,12,14$ の $v_2$ は $5,19,29,61,53,83,77$ で、$2(L-1)$ とは一致せず単調でもない。
- **(2)** $L=3,4,5,6,7,9$ の全例で $\prod_{j=1}^{L-1}(s_L(A_j)-2)=\tau(L)$（体の元として厳密一致）。
  この分解は偶 $L$（4, 6）でも成立する（分解自体は $L$ の偶奇に依らない）。
- **(3)** $L=3,5,7,9,11,13$ で 2 は不分岐（$e=1$）。全 $j=1,\dots,L-1$ で
  $v(\text{最高次})=0$, $v(1\text{ 次})=0$, $v(\text{定数})=1$。剰余次数 $f$ は $L$ に応じ $2,4,3,6,10,12$。
- **(4)** $L=4$: $e=2$, $v_P(1-\zeta^2)=2$, $v_2(4)=2$。$L=6$: $e=1$, $v_P(1-\zeta^3)=1$, $v_2(6)=1$。
  $L=8$: $e=4$, $v_P(1-\zeta^4)=4$, $v_2(8)=3$。いずれも証明が使う 2 条件
  （$v(1-\zeta^m)=0$ と $v(L)=0$）が破れている。
