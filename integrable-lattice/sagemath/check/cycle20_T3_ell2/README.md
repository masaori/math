# cycle 20 / T3 Pure: $\ell=2$ の決着（ell_equals_2）— 対象・手順・限界

対応する証明本体: [`outputs/reports/cycle20_T3_ell_equals_2.md`](../../../outputs/reports/cycle20_T3_ell_equals_2.md)

## 何を確かめるか

cycle 19 の 2 本はどちらも $\ell$ が奇であることを仮定して閉じており、$\ell=2$ を射程外に残していた。
本検証は「**$\ell=2$ が構造的に射程外なのか、道具が足りないだけなのか**」を決着させるために、

1. 族 $X(p,q)$（1 頂点 bouquet、voltage $(1,0)$ の loop $p$ 本と $(0,1)$ の loop $q$ 本）について、
   $\ell=2$ での**全レベル・全点の付値**（定理 Y）と**閉形式**（定理 Y′）を照合する。
2. cycle 19 step 2 注 5.2 が挙げた「$\ell$ 奇」の 3 つの使用箇所が、$\ell=2$ でどう破れるかを**実測**する。
3. cycle 16 補題 5.5（$\ell=2$ トーラスの直接計算）を cycle 19 の道具の言葉で読み直せることを、
   レベルごとの層別内訳で確認する。
4. 定理 J7 の仮定 (B\*) が破れる場所を数え、それでも $b=\sum_{P\in S_\infty}j^*(P)$ が当たることを見る。
5. **族の外**の一般 $\ell=2$ 塔について、母集団を全走査して観察を出す（**数値支持であって証明ではない**）。

## 独立性（何が「実測側」か）

本検証で「予言」と呼ぶのは定理 Y / 定理 Y′ の値であり、「実測」と呼ぶのは次の 3 経路である。
いずれも **cycle 20 の理論を一切使わない**。

- **円分体での点ごとの付値** `point_val`（cycle 16 実装）: $\mathbb{Q}(\zeta_{2^n})$ の $2$ の上の
  素点での付値を直接計算する。
- **塔の値** `tower_ords`（cycle 16 実装）: Matrix–Tree 定理・2 段終結式で $\kappa_n$ を厳密に計算する。
  **フィットパラメータ 0 個**。
- **円分体の $\Theta_m$ 経路** `ords_via_sigma`（本ファイル `_defs20.sage`）:
  cycle 19 step 1 補題 J1（$\Sigma_n=\sum_m\Theta_m$、$\Theta_m$ は $\mathbb{P}^1(\mathbb{Z}/2^m)$ 上の単純和）と
  cycle 14 $(1.1)$ から $\mathrm{ord}_2(\kappa_n)$ を組み立てる。塔の値を使わないので**より深い段まで届く**。

## 限界（正直に書く）

- **段数の壁は 2 つある。**
  - 塔の値（次数 $4^n$ の 2 段終結式）: 本検証では $n\le4$ に留めた（Step B2）。
  - 円分体経路（$\mathbb{Q}(\zeta_{2^m})$ は次数 $2^{m-1}$）: $n\le9$ まで（Step B3 は $n\le8$、Step G は $n\le9$）。
    **$n=10$ は PARI のスタック上限（1 GB）で計算できない。**
- **Step G は数値支持であって証明ではない。** 母集団（430 塔）の全走査だが、母集団の外については
  何も主張しない。$b$ 以外の係数（$c,d,e$）は 4 パラメータを 4 点で解いて 2 点で照合しただけなので、
  支持の強さが $b$ とは違う。検出力の議論は report §7 にある。
- 仮定 (H)（塔の全段が連結）が破れる塔は対象外とし、件数を出力する（Step G）。
- $\det L=0$ の塔（voltage 格子が $\mathbb{Z}^2$ を張らない等）も対象外とし、件数を出力する。
- 壁時計上限は Step G に 3000 秒、1 塔あたり 120 秒を置いてある。
  **打ち切った塔は件数と名前を必ず出力する**（前サイクルの反省。黙って落とさない）。
- $d\ge3$ は対象外（$(1.1)$ 自体が $d=2$ の式）。
