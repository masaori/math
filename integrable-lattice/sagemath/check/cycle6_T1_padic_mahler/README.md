# cycle 6 / T1: 岩澤塔 $L=p^n$ での $v_p(a_{p^n})$ の数値観察

スクリプト `iwasawa_tower.sage`、出力 `iwasawa_tower.out`（SageMath）。

## 対象（何を検証したか）

$P(z,w)=5-(z+z^{-1})-(w+w^{-1})\in\mathbb{Z}[z^{\pm1},w^{\pm1}]$ の $L$-周期点数
$$a_L=\prod_{z^L=1,\ w^L=1}P(z,w)\in\mathbb{Z}$$
について、

1. アルキメデス側の量 $\dfrac{1}{L^2}\log|a_L|$ の $L$ 依存、
2. $\Lambda$ 側の量 $v_p(a_L)$（$p=2,3,5,7$）、とくに岩澤塔 $L=p^n$（$p=2$: $L=2,4,8$／$p=3$: $L=3,9$）に沿った $v_p(a_{p^n})$ の並び

を、同一の整数多項式 $P$ から実際に計算する。

## 手順（どのスクリプトを何の設定で実行したか）

`iwasawa_tower.sage` を実行する。設定は以下（スクリプト内に固定）。

- $a_L$ は `ComplexField(prec=500)` 上で $L^2$ 個の因子の積として計算し、実部を整数へ丸める。丸め誤差 $<10^{-4}$ を `assert` で検査する（全 $L$ で通過）。
- $L\in\{2,3,4,8,9\}$。
- 各 $L$ について $v_2,v_3,v_5,v_7$ と $\frac{1}{L^2}\log|a_L|$ を出力する。

## 結論（実行ログから読み取れる事実）

`iwasawa_tower.out` に現れる値は次のとおり。

| $L$ | $v_2$ | $v_3$ | $v_5$ | $v_7$ | $(1/L^2)\log|a_L|$ |
|---|---|---|---|---|---|
| 2 | 0 | 2 | 2 | 0 | 1.35403 |
| 3 | 8 | 0 | 0 | 4 | 1.48098 |
| 4 | 0 | 6 | 6 | 4 | 1.50200 |
| 8 | 0 | 6 | 14 | 8 | 1.50795 |
| 9 | 8 | 0 | 0 | 4 | 1.50797 |

- 塔に沿った値: $p=2$ 塔 $(L=2,4,8)$ で $v_2=[0,0,0]$、$p=3$ 塔 $(L=3,9)$ で $v_3=[0,0]$。すなわち**この標本の範囲内では、塔に沿った $v_p$ の増加は観測されなかった**。
- $\frac{1}{L^2}\log|a_L|$ は $L=2\to9$ で $1.35403\to1.50797$ と単調に増加した。
- $a_L$ が整数であること（丸め誤差 $<10^{-4}$）は全 $L$ で `assert` を通過した。

## 限界

- **これは数値検証であって証明ではない。** 標本は $L\in\{2,3,4,8,9\}$、素点は $p\in\{2,3,5,7\}$、多項式は $P=5-(z+z^{-1})-(w+w^{-1})$ 1 個に限られる。
- 塔の段数は $p=2$ で 3 段（$n=1,2,3$）、$p=3$ で 2 段（$n=1,2$）にすぎない。この長さの列が一定であることから、極限量である岩澤 $\mu_p$ の値を結論することはできない。**$v_p=0$ という 0 の観察を「$\Lambda$ 側は自明」「$\mu_p=0$ が一般に成り立つ」等の仮説の支持根拠として用いてはならない**（本プロジェクトは cycle 5→6 で 0/43 の非有意な観察から立てた仮説を、標本を 572 件へ拡大して棄却した経緯をもつ）。
- $\frac{1}{L^2}\log|a_L|$ の増加は有限個の $L$ での数値であり、収束の証明ではない。極限が Mahler 測度 $\log m(P)$ に一致することは Lind–Schmidt–Ward の**既知定理**に帰する事柄であって、本ディレクトリの計算がそれを示したのではない。
- $p$ 進エントロピー（Deninger）・$p$ 進 Mahler 測度（Besser–Deninger）・岩澤 $\mu_p$ の同一視は**既知の理論**であり、それがどのクラスの $P$ に適用できるかは本ディレクトリでは検証していない（`outputs/paper-plans/002_R_Lambda_duality.md` §8-1 の未確定事項）。スクリプト末尾の「読み」のテキストはこの既知理論への位置づけを述べたもので、実行結果から導かれた結論ではない。
- $a_L$ は複素数値の積を丸めて得ており、厳密整数演算ではない。整数性は誤差評価 $<10^{-4}$ による間接的な確認にとどまる。
