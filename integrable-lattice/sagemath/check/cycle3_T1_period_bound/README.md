# cycle 3 / T1: 切断付値 $\min(v_p(Z_N),k)$ の最終周期性の検証（命題 A）

スクリプト `period_bound.sage`、出力 `period_bound.out`（SageMath）。

## 対象（何を検証したか）

六頂点模型の整数転送行列 $T\in M_d(\mathbb{Z})$（$d=2^L$）と $Z_N=\operatorname{Tr}T^N$ について、

- $T^N \bmod p^k$ が有限モノイド $M_d(\mathbb{Z}/p^k)$ 上で最終周期的であること（前周期と周期 $\pi$ の実測）、
- 切断付値 $\min(v_p(Z_N),k)$ の列が、その周期 $\pi$ を周期として最終周期的であるかどうか

を有限区間で確認する。これは `outputs/paper-plans/002_R_Lambda_duality.md` の**命題 A**（$\min(v_p(Z_N),k)$ の最終周期性、周期は $\pi(p,k)$ を割る）に対応する検査である。

## 手順（どのスクリプトを何の設定で実行したか）

`period_bound.sage` を実行する。設定はスクリプト内に固定されている。

- 転送行列: 六頂点の $L$ 型作用素 $L(a,b,c)$ をサイト方向にテンソル積して構成し、補助空間のトレースを取って $T=\operatorname{tr}_a\prod_i L_i$ を得る（$d=2^L$）。
- 重みと鎖長: $(a,b,c,L)=(1,1,2,2),\ (1,1,1,2),\ (2,1,1,2),\ (1,1,2,3)$ の 4 例。
- 素点と切断: $p\in\{2,3,7\}$、$k=3$（すなわち法 $p^3$）。
- 周期検出: $T^N \bmod p^k$ を $N=1$ から進め、行列が既出になった時点で（前周期, 周期）を返す。上限 $N\le 2000$。
- 付値列の判定: $N=1,\dots,\mathrm{pre}+3\pi+5$ の範囲で $Z_N$ を厳密整数として計算し、$tv_N=\min(v_p(Z_N),k)$ が $tv_i=tv_{i+\pi}$（$i\ge\mathrm{pre}$）を満たすかを全て確認する。

## 結論（実行ログから読み取れる事実）

`period_bound.out` の 4 例 × 3 素点＝**12 ケースすべてで、切断付値列は実測周期 $\pi$ で最終周期的（判定 True）**であった。検出された周期・前周期は次のとおり。

| $(a,b,c)$, $L$ | $d$ | $p=2$（前周期, $\pi$） | $p=3$ | $p=7$ |
|---|---|---|---|---|
| $(1,1,2)$, $L=2$ | 4 | $(3,\ 1)$ | $(3,\ 18)$ | $(1,\ 294)$ |
| $(1,1,1)$, $L=2$ | 4 | $(3,\ 4)$ | $(3,\ 18)$ | $(1,\ 294)$ |
| $(2,1,1)$, $L=2$ | 4 | $(1,\ 2)$ | $(3,\ 18)$ | $(1,\ 294)$ |
| $(1,1,2)$, $L=3$ | 8 | $(3,\ 1)$ | $(1,\ 54)$ | $(1,\ 294)$ |

周期内の切断付値パターンの例（ログに出力されているもの）:

- $(1,1,2), L=2, p=2$: $tv=[3]$（定数。$k=3$ に張り付いており $v_2(Z_N)\ge3$ を意味する）。
- $(1,1,1), L=2, p=2$: $tv=[1,2,1,2]$。
- $(2,1,1), L=2, p=2$: $tv=[2,1]$。
- $(1,1,1), L=2, p=3$: $tv=[1,0,1,0,3,0,1,0,1,0,2,0,1,0,1,0,2,0]$（$\pi=18$）。
- $(1,1,2), L=3, p=3$: $tv$ は長さ 54 の全 0 列。
- $p=7$ の 4 例はいずれも $\pi=294$ で、$0$ を主体に $1,2,3$ のスパイクが混じるパターン。

$\pi$ の実測値は $p=3$ で 18 または 54、$p=7$ で全例 294 であった。

## 限界

- **これは有限区間での数値検証であって証明ではない。** 付値列の周期性判定は $N\le \mathrm{pre}+3\pi+5$ の範囲だけを見ており、それ以降で破れないことは確認していない（命題 A 自体の証明は鳩の巣原理による別の議論であり、`outputs/reports/cycle3_T1_D-U2_rigorous.md` にある。本ディレクトリはその整合性検査にすぎない）。
- 標本は六頂点の重み 4 組、鎖長 $L\in\{2,3\}$、素点 3 個、切断 $k=3$ のみ。ここから他の重み・$L$・$p$・$k$ への一般化はできない。
- 周期検出は上限 $N\le2000$ に依存する。この上限内で周期が見つからないケースは「検出失敗」として扱われる設計であり、本実行では全ケースが上限内に収まった。
- スクリプトは $p\mid\det T$ の場合を除外していない。実際 $p=2$ の各例は $\det T$ が 2 で割れる側であり、$(1,1,2)$ の 2 例では $tv$ が定数 $k=3$（切断に飽和）となっている。飽和した列の周期性は $v_p$ そのものの周期性を意味しない。この意味で、$p\nmid\det T$ を仮定する命題 A の仮説を満たすのは $p=3,7$ の各ケースである。
- 切断 $k$ の外側（$v_p(Z_N)\ge k$ となる $N$）で $v_p$ がどう振る舞うかは、この検査では見えない。
