# cycle 15 / T3: $d=3$, $p=2$ の追加解の構造 — $v_2(\tau_3(L))$ の分解の検証

スクリプト `tau_d3_structure.sage`、出力 `tau_d3_structure.out`（SageMath 10.6、`sage tau_d3_structure.sage`）。

証明本体は `outputs/reports/cycle15_T3_tau_d3_structure.md`。
**本ディレクトリはその証明の各段の前提と帰結の整合性、および証明できていない部分（散発解 $V_{\mathrm{IV}}$）の
標本を計算で確認するものであり、計算が証明なのではない。**

## 対象（何を検証したか）

$\tau_3(L)$ を 3 次元離散トーラス $C_L^3$（周期境界の 3 次元正方格子、頂点数 $L^3$、次数 6）の全域木数、
$L$ を奇数、$p=2$、$P\mid2$ を $\mathbb{Q}(\zeta_L)$ の素点とする。

cycle 14 は下界 $v_2(\tau_3(L))\ge6(L-1)$ を証明し、$L=9,15,17,21,27$ で等号が破れることを観察した。
本 step はその「追加解」（$v_P(\lambda_\chi)>0$ となる指標のうち下界を与える族の外にあるもの）を分類する。
report の主結果は分解公式

$$v_2(\tau_3(L))=\underbrace{6(L-1)}_{V_{\mathrm I}}+\underbrace{8(L-3)[3\mid L]}_{V_{\mathrm{II}}}
+\underbrace{144[15\mid L]}_{V_{\mathrm{III}}}+\sum_{\chi\in V_{\mathrm{IV}}}v_P(\lambda_\chi)$$

であり、第 3 項までは証明済み、第 4 項（散発解）は**閉形が得られていない**。

1. **(0)** 3 つの族が与える $\lambda$ の値の記号的確認（型 I: $2(1-t)(1-t^{-1})$、型 II: $\lambda=6$、型 III: $\lambda=8$）。
   および定理 G の証明で使う係数条件 $\alpha+\beta+\gamma=0$ かつ $\alpha^{-1}+\beta^{-1}+\gamma^{-1}=0$ の解が
   $\alpha\{1,\omega,\omega^2\}$ に限ることの $\mathbb{F}_4$ での総当り確認。
2. **(1)** **厳密整数経路**: $\tau_3(L)$ を 2 段の終結式で厳密な整数として計算し $v_2$ を取る（$L=3,\dots,27$ 奇）。
3. **(2)(3)** 消える指標の分類 $V=V_{\mathrm I}\sqcup V_{\mathrm{II}}\sqcup V_{\mathrm{III}}\sqcup V_{\mathrm{IV}}$ と、
   個数・付値の予測との一致（$L=3,\dots,105$ 奇）。
4. **(4)** 対称性: $V(L)$ の $(\mathbb{Z}/L)^\times$ 安定化群が $\langle2,-1\rangle$ であること
   （$\Rightarrow$ $V_{\mathrm{IV}}$ は $P$ に依存する）と、$V_{\mathrm I},V_{\mathrm{II}},V_{\mathrm{III}}$ が
   $(\mathbb{Z}/L)^\times$ 全体で安定であること。
5. **(5)** $V_{\mathrm{IV}}$ の点で $\lambda$ が有理数にならないこと（標本内）。

## 手順（どのスクリプトを何の設定で実行したか）

`sage tau_d3_structure.sage` を実行する。設定はスクリプト内に固定。

- **厳密整数経路（終結式）**: cycle 14 補題 2 の $s_L(A)-2=(A-2)G_L(A)^2$（$L$ 奇）を使って
  $\tau_2(L)=Q^2$、$Q=\mathrm{Res}_w\bigl(s_L(w)-2,\ G_L(4-w)\bigr)$、
  $\tau_3(L)=\tau_2(L)\cdot P^2/L$、$P=\mathrm{Res}_w\bigl(s_L(w)-2,\ F(w)\bigr)$、
  $F(u)=\mathrm{Res}_v\bigl(s_L(v)-2,\ G_L(6-u-v)\bigr)$ として計算する。
  $s_L(A)-2$ は $w$ についてモニックなので、終結式は根における値の積にちょうど一致する。
  **すべて $\mathbb{Z}$ 係数多項式の演算であり、厳密整数。浮動小数点は使わない。**
  $L=3,5,7$ では matrix-tree（$L^3-1$ 次の**厳密整数**行列式）とも一致を確認する。
  $L=27$ で $\tau_3(27)$ は 14303 桁になる。
- **分類（有限体）**: $x^L-1$ の $\mathbb{F}_2$ 上の既約因子 $h$（次数 $f=\mathrm{ord}_L(2)$、**根の位数がちょうど $L$**）
  を取り $k_P=\mathbb{F}_2[x]/h$ とする。$T(x)=x+x^{-1}$ の値でハッシュを引いて
  $T(\bar x_1)+T(\bar x_2)+T(\bar x_3)=0$ を満たす指標を全列挙する（cycle 14 定理 A の $d=3,p=2$ の場合）。
  次数 $f$ の因子でも根の位数が $L$ の真の約数になりうるので、**位数を必ず検査**している
  （検査を外すと $L=85$ 等で誤った $\mu_L$ を使ってしまう）。
- **付値（$p$ 進）**: **同じ $h$** を法として不分岐環 `Zq(2^f, 60, modulus=h)` を作り、
  $\zeta=$ `teichmuller` $(x)$ とする。$V(L)$ は $2$ の上の素点 $P$ に依存する（report 定理 K）ので、
  分類と付値で**同じ $P$** を見ることが必須である（異なる生成元を使うと $V_{\mathrm{IV}}$ が別の集合になり、
  付値の合計が厳密整数と食い違う）。付値が精度未満（$<55$）であることを `assert` で確認している。
- **有理性判定**: `CyclotomicField(L)` 上で $\lambda$ を厳密に構成し、`lam in QQ` で判定する。

## 結論（実行ログから読み取れる事実）

- **(0)** 型 I で $\lambda=2(1-t)(1-t^{-1})$、型 II で $\lambda=6$、型 III で $\lambda=8$ が
  それぞれ Laurent 環・$\mathbb{Z}[\omega]$・$\mathbb{Q}(\zeta_{15})$ 上の**恒等式**として成立する。
  定理 G の係数条件の解は $\mathbb{F}_4$ で 6 個あり、すべて $\alpha\{1,\omega,\omega^2\}$ の形である。
- **(1)** $L=3,5,7$ で終結式経路と matrix-tree 経路が一致（2 経路が独立に一致）。
  $L\le27$（奇）の厳密整数 $v_2(\tau_3(L))$ は
  $12,24,36,96,60,72,324,288,108,264,132,144,348$。
- **(2)(3)** $L\le105$（奇）の全標本で
  $|V_{\mathrm I}|=6(L-1)$、$|V_{\mathrm{II}}|=8(L-3)[3\mid L]$、$|V_{\mathrm{III}}|=48[15\mid L]$ が成立し（`assert`）、
  付値は $V_{\mathrm I},V_{\mathrm{II}}$ で全点 $1$、$V_{\mathrm{III}}$ で全点 $3$ である。
  $(6.1)$ の総和は $L\le27$ で (1) の厳密整数と一致した。
  $V_{\mathrm{IV}}\neq\emptyset$ となったのは $L=17,31,33,43,51,63,65,73,85,91,93,99$ の 12 件のみで、
  残り 40 件では $v_2$ が閉形 $6(L-1)+8(L-3)[3\mid L]+144[15\mid L]$ に一致した。
  $V_{\mathrm{IV}}$ の付値は 11 件で全点 $1$ だが、**$L=63$ では 3120 点中 240 点で $v_P=3$** である
  （散発解の寄与は点の個数だけでは決まらない）。
- **(4)** $L=9,15,17,21,27,31,33,43,51$ で $V(L)$ の $(\mathbb{Z}/L)^\times$ 安定化群はちょうど $\langle2,-1\rangle$ であり、
  $V_{\mathrm I},V_{\mathrm{II}},V_{\mathrm{III}}$ は $(\mathbb{Z}/L)^\times$ 全体で安定である。
  すなわち $V_{\mathrm{IV}}$ は $P$ に依存する。
- **(5)** $V_{\mathrm{IV}}$ の点で $\lambda$ が有理数になったものは標本内に 1 つも無い
  （型 II の $\lambda=6$、型 III の $\lambda=8$ が有理数であることと対照的）。

## 限界

- **標本は上記の範囲に限られる**（厳密整数: $L\le27$ 奇 / 分類: $L\le105$ 奇 / $d=3$、$p=2$、$L$ 奇のみ）。
  範囲外について何も主張しない。
- 証明が付いているのは report の定理 G, H, I, J, K だけである。**数値一致は証明ではない。**
  とくに **$V_{\mathrm{IV}}$ の個数・付値の閉形も上界も得ていない**。
  「$V_{\mathrm{IV}}=\emptyset$ となる $L$ の分類」は標本の観察であって法則ではない。
- $V_{\mathrm{IV}}$ の点で $\lambda$ が無理数であることも**証明していない**（標本の観察）。
- $p\mid L$（分岐）、$p$ が奇素数、$d\ne3$、$L$ 偶数の場合はいずれも本 step の対象外である。
- $p$ 進計算は固定精度（60）である。付値が精度に達していないことは `assert` で保証しているが、
  精度不足で `assert` が落ちる範囲までは走査していない。
- 終結式経路は $L\le27$（奇）までしか回していない（$L=27$ で $\tau_3$ は 14303 桁）。
  それ以上の $L$ は有限体＋$p$ 進経路のみで、$L\le27$ での一致確認が独立検証の役割を果たす。
- **新規性は主張しない。** 本 step で本文を取得できた文献は無い。report §10 参照。
