# cycle 16 / T1 step 2: $\lambda=l_0(f)$ の有限手続き（アルゴリズム）の検証

スクリプト `l0_algorithm.sage`（アルゴリズム本体）＋ `run.sage`（検証ドライバ）、
出力 `run.out`（SageMath 10.6、`sage run.sage`、本 step で実行）。

本体（定義・定理・証明・境界）は `outputs/reports/cycle16_T1_lambda_l0_computability.md`。
**本ディレクトリは定理 C1（群環の元に対する $l_0$ の有限手続き）の実装と、その反証試行である。**
定理の証明はレポート §2 にあり、数値には依存していない。ここでの数値は
「証明が間違っていれば壊れる形の検査」として置いている。

> 記号の注意: 本プロジェクトで $\Lambda$ は対数順序群を指す。岩澤代数は $\mathbb{Z}_p[[\Gamma]]$,
> $\mathbb{F}_p[[\Gamma]]$ と明示的に書く（$\Lambda$ とは書かない）。

## 対象（何を検証したか）

$0\neq P\in\mathbb{Z}[z_1^{\pm},\dots,z_d^{\pm}]$、$f=P(1+T_1,\dots,1+T_d)\in\mathbb{Z}_p[[\Gamma]]$、$\Gamma=\mathbb{Z}_p^d$ とする。
Kataoka Definition 2.2（＝Cuoco–Monsky Definitions 1.1, 1.2）の
$$l_0(\bar f)=\sum_{\mathfrak p=(\gamma-1),\ \gamma\in\Gamma\setminus\Gamma^p}\mathrm{ord}_{\mathfrak p}(\bar f)$$
を、$\mathbb{F}_p$ と $\mathbb{Z}^d$ 上の有限計算だけで求めるアルゴリズム（レポート定理 C1）を実装した。

検証したのは次の 3 命題である（レポート §2）。

1. **補題 L1**: $(\gamma_v-1)\mid\bar f$ となる $v$ は $\bar P$ の台の差の原始整数方向に限る（有限個）。
   とくに**無理方向の素イデアルは Laurent 多項式を割らない**。
2. **命題 L2**: 有理方向 $v$ について、$(\gamma_v-1)\mid\bar f$ $\iff$ $\mathbb{Z}^d\to\mathbb{Z}^d/\mathbb{Z}v$ の各ファイバー上で
   $\bar P$ の係数和が $0$。
3. **補題 L3**: $\mathrm{ord}_{(\gamma_v-1)}(\bar f)$ は $U v=e_1$ なる $U\in GL_d(\mathbb{Z})$ で座標を取り替えた後の
   $T_1$ 次数の最小値として有限計算できる。

## 結論（実行ログから読み取れる事実）

- **(1)** cycle 15 の上界 $(4.1)$ の**違反 0 件**（$l_0>B$ が出ればアルゴリズムが誤りだが、出なかった）。
- **(2)(7)** A と独立実装 B の**不一致 0 件**（掲載例、および無作為 399 試行・方向 738 件）。
  重複度の 2 実装も全件一致。
- **(3)** 6 例すべてで、$\mathbb{P}^1(\mathbb{Z}/p^3)$ 全被覆の残存ボールが A の出した有理方向と**完全一致**。
  すなわち**無理方向が割る例は見つからなかった**（補題 L1 の反証試行に失敗した＝補題 L1 と整合）。
- **(4)** 10 例すべてで、フィットに使っていない $n$ でも予測が的中（外れ 0）。
  $l_0$ を 1 ずらせば $n p^n$ 項が変わり必ず外れるので、これは $l_0$ の値の実効的な検査である。
  例: $P=z+w^2-2w$, $p=3$ で $0,5,20,65,200=\tfrac52(3^n-1)$、$l_0=0$（$n3^n$ 項なし）。
- **(5)** $p=2,3,5,7$、$m=1,2,3$ すべてで $l_0(f_m)=0$。$f_m\to z-1$（$(T,S)$ 進位数 $\ge p^m$）だが $l_0(z-1)=1$。
  **$l_0$ は不連続**であり、有限個の係数を読むだけのアルゴリズムでは決定できない（レポート定理 C2 の土台）。
- **(6)** $d=3$ でも期待通り（$(x-1)(y-1)(u-1)$ で $l_0=3$、$xyu-1$ で $l_0=1$ 等）。
- **(8)** 線ごとの不等式 $(5.1)$ の**反例 0 件**（掲載 14 例 + 無作為 599 例）。
  上界 $B$ が等号になるのは無作為 599 例のうち 563 件（**94.0%**）、差 1 が 35 件、差 2 が 1 件。
  等号が崩れる掲載例: $z+w^2-2w$（$p=3,5$、差 1）、$7-2z-2w$（$p=3$、差 1）、
  トーラス $4-z-z^{-1}-w-w^{-1}$（$p=5$、差 2）。

### 手計算で独立に確認した値

数値実装を無検証で信用しないため、次の 4 つはログを見ずに手で確認した（レポート §3, §6-7）。

- $P=z^3-1$, $p=3$: $\bar f=(1+T)^3-1=T^3$ より $l_0=3$。ログ一致。
- $P=z^2+zw+w^2$, $p=3$: $\equiv(z-w)^2$ より方向 $(1,-1)$ で重複度 2、$l_0=2$。ログ一致。
- $P=7-2z-2w$, $p=3$: $\equiv1+z+w$、台 3 点・係数すべて 1・非共線なので必ず 1 点ファイバーが生じ $l_0=0$。
  一方 $H=T+S$ で $B=1$。ログ一致（差 1）。
- $P=z+w^2-2w$, $p=3$（cycle 15 の反例）: $\equiv z+w^2+w$、候補方向 $(0,1),(1,-1),(1,-2)$ のいずれでも
  あるファイバーの係数和が $2\neq0$ なので $l_0=0$。ログ一致。

## 限界（この検証がしていないこと）

- **定理の証明は数値ではない。** 補題 L1/L2/L3 の証明はレポート §2 にあり、
  ここでの数値は反証試行にすぎない。とくに (3) は $K=3$ の**有限精度**の被覆であって、
  無理方向を排除する証明ではない（証明は補題 K による）。
- **(8) の「94.0% で等号」は観察であって命題ではない。** 等号成立の必要十分条件は得られていない。
- 検証した $P$ は $d\le3$、係数・指数とも小さいものに限る。アルゴリズム自体は $d$ 任意で動くが、
  重複度の段が指数の大きさに対して重いので、大きな台では実用性を確認していない。
- Cuoco–Monsky / Monsky の原論文本文は未取得（cycle 16 step 1 の課題）。
  本ディレクトリが依拠するのは Kataoka Definition 2.2 の引用として確認済みの $l_0$ の**定義**だけである。
