## 使った判定（既存の定理。本 step は道具として使うだけ）

cycle 22 定理 D2 は $\delta_M:=\Theta_M-\Theta^\mathrm{as}_M$、$S(n):=\sum_{M=1}^{n}\delta_M$、
$T_\mathrm{def}:=\sum_{M\ge1}\delta_M$（有限和）と置いて次を与える。

> **レベル $n$ で $(1.1)$ が成り立つ $\iff S(n)=T_\mathrm{def}$。**
> とくに $n=0$ では $S(0)=0$ なので、$(1.1)$ が $n=0$ で成り立つ $\iff T_\mathrm{def}=0$。

本 step はこの**レベルごとの判定**を、Matrix–Tree 定理で独立に計算した $\mathrm{ord}_\ell(\kappa_n)$ と
突き合わせる。従来の照合（cycle 22 Step E）は $n\ge n_0$ に限っていたので、
**$n=0$ と $n<n_0$ は 1 度も突き合わされていなかった。**

量の帰属: $\Theta_M,\delta_M,S(n),T_\mathrm{def}\in\mathbb{Q}$、$\kappa_n,\mathrm{ord}_\ell(\kappa_n)\in\mathbb{Z}$。
整数行列式・有理数演算・$\ell$ 進付値だけで閉じる。**$\mathbb{R}$ へは一度も脱出しない**（浮動小数点 0 箇所）。

母集団は cycle 22 Step L と同一（133 塔 $\times\ \ell\in\{2,3\}$、うち有効 191 組）。
件数が cycle 22 の実測（$T_\mathrm{def}=0$ が 108、$\ne0$ が 83）と一致することを最初に確かめてある。

## 持ち越し (i) の結果

### 帰結そのもの（Step C）

191 組すべてで**同値「$T_\mathrm{def}=0\iff(1.1)$ が $n=0$ で成り立つ」の破れ 0 件**。
うち $T_\mathrm{def}=0$ で実際に $(1.1)$ が $n=0$ で成り立った塔が **108 件**。
**注 3.1 が「Step L では確認していない」と書いた帰結は、これで確認された。**

### 実際にはもっと強かった（Step A）

$T_\mathrm{def}=0$ の 108 本を「$\delta_M$ が全て $0$」と「$0$ でない $\delta_M$ があるのに総和だけ $0$」に分けると

| 区分 | 件数 | 意味 |
|---|---|---|
| $\delta_M$ が全て $0$ | **108** | 過渡が一切無い。$(1.1)$ は**全ての $n\ge0$** で成り立つ |
| 総和だけ $0$ | **0** | $n=0$ では成り立つが $n\ge1$ は保証されない、という場合 |

**注 3.1 は「$n\ge1$ でも成り立つことは意味しない」と正しく限定していたが、
この母集団に関する限り、108 本すべてで $n\ge1$ でも成り立っている。**
限定が不要だったのではない——限定は論理として正しい。ただし**実測では差が出なかった**。

### 証明の但し書き（Step A）

定理 D2 の証明は、$T_\mathrm{def}=0$ でも $S(n)\ne0$ になる例を $\Theta$ を任意に取って作り、
**「実在の塔で $\delta_M$ の符号が混ざる例は確認していない」**と限定していた。実測:

- **符号が混ざる塔は 47 本実在する**（例: $\ell=2$、`BQ3 (1,0),(1,0),(0,1)` は $\delta=(-1,2,0)$）。
  **限定の前半は解消した。混ざる塔は珍しくない。**
- **そのうち $T_\mathrm{def}=0$ のものは 0 本。** すなわち
  **証明が構成した反例の配置（総和 $0$・部分和 $\ne0$）は、この母集団では実現していない。**

**したがって但し書きは「符号は混ざる。ただし打ち消して総和 $0$ になる塔は見つかっていない」へ
更新されるべきである。**「実在の塔では起こらない」と断定はできない（母集団の外は見ていない）。

### レベルごとの判定そのもの（Step B）

191 組 $\times$ $n=0,\dots,N_{\max}$（$\ell=2$ で $4$、$\ell=3$ で $3$）＝ **860 件**を照合し、
**判定（$S(n)=T_\mathrm{def}$ か）と実測（$\mathrm{ord}_\ell(\kappa_n)$ が $(1.1)$ と一致するか）の
食い違いは 0 件**。内訳:

| 内訳 | 件数 |
|---|---|
| 判定「一致する」かつ実測も一致 | 721 |
| 判定「一致しない」かつ実測も不一致 | **139** |

**139 という数が重要である。** これが 0 なら、判定は「常に一致する」と言っているだけで
中身が無いことになる。実際には $139/860$（16%）のレベルで $(1.1)$ は**成り立っておらず**、
判定はそれを 1 件残らず当てている。**判定は空振りではない。**
