# cycle 27 step 3: 日本語版 PDF の素のアスタリスクを計測した（本文は 1 文字も変えていない）

**この step は計測と提示だけを行う。正本 PDF の見た目を変える判断はユーザーの価値判断なので、
自動ループでは決めない。** 変更したファイルは本 report と `docs/tasks/auto-loop-state.md` だけである。

## 現象

日本語版の PDF は、本文の強調 `**…**` を**素のアスタリスクとしてそのまま印字している**。
たとえば「（\*\*対数順序群\*\*）」がそのまま組まれる。

原因は `tools/editions.ts` が日本語版を `bold: false` と宣言していることで、
生成器の `applyBold` が `if (!edition.bold) return value;` で**何もせずに返す**ためである。
`bold: false` は「変換しない」であって「落とす」ではない。

cycle 26 step 3 がこの現象を発見して記録し、cycle 27 へ送った。

## 実測

| 量 | 日本語版 | 英語版 |
|---|---|---|
| 生成物 `document.tex` の `**`（コメント行を除く） | **1246 個** | **0 個** |
| `**` を含む行 | **413 行** | 0 行 |
| `\textbf` | 8 個（文書骨格の見出しだけ） | **643 個** |
| 本文の強調の総数 | **623 対** | 643 対 |
| うち 1 つの地の文ノードで閉じている強調 | **466 対** | 643 対 |
| うち数式ノードをまたぐ強調 | **157 対**（地の文ノード 306 件にまたがる） | 0 対 |

**51 頁の日本語正本の全体にわたる。** cycle 26 が記録した「410 箇所」は行数のことで、
いま測ると 413 行である（cycle 26 step 5・6 と本サイクル step 1 の加筆で 3 行増えた）。

## 変えた場合に何がどう変わるか（可逆な実験で確かめた）

`tools/editions.ts` の日本語版を `bold: true` にして実際に走らせ、**元に戻した**。

1. **`verify:emphasis` が違反 306 件で落ちる。** 数式ノードをまたぐ強調 157 対が、
   開き側と閉じ側の地の文ノード（計 306 件）で `**` を閉じないまま残るためである。
2. **生成器 `build-latex.ts` が「対応の取れない `**` が地の文にある」で停止する。**
   PDF は作られない。
3. したがって、切り替えるには**本文の 157 対を数式の前後で分けて書き直す**必要がある
   （日本語版のみ。英語版は既に分けてある）。残り 466 対はそのまま `\textbf` へ変換される。

**読者から見た変化**: 623 箇所の強調が「`**…**` というアスタリスク付きの文字列」から
「太字」に変わる。頁数も変わりうる（太字はわずかに幅が広い）。
**157 対を書き直すまで PDF が作れないので、頁数の実測はできていない。**

## 判断が要る点（管理役へ上げる 1 点）

**日本語版の正本 PDF の見た目を変えるかどうか。** 選べる形は 3 つある。

| 案 | 本文の書き直し | 読者から見た結果 |
|---|---|---|
| **太字にする** | 157 対を数式の前後で分ける（日本語版のみ） | 623 箇所が太字になる。英語版と同じ見た目 |
| **アスタリスクを落とす** | 不要 | 623 箇所の強調が**消える**（アスタリスクも太字も出ない）。生成器に「変換せず落とす」動作を足すだけで済み、またぐ強調も問題にならない |
| **現状のまま** | 不要 | 51 頁の全体にアスタリスクが出続ける |

「アスタリスクを落とす」は書き直しが要らないが、**強調という情報そのものを失う**。
「太字にする」は情報を保つが、正本 PDF の見た目が変わる。
どちらを取るかは**何を正本 PDF に求めるか**の判断であり、一次情報からは決まらない。

なお**英語版（投稿稿）はこの問題を持たない**ので、投稿には影響しない。
