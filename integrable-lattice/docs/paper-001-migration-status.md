## 生成器の適用で見つかり、生成器側で直したもの

いずれも**本文（content）は書き換えていない**。表示の問題は生成器の責務として処理した。

1. **★ が PDF から無言で消えていた。** 本文の記号として数式の中に `(★_2)` の形で使われているが、
   欧文数式フォントに ★ が無い。xeCJK の文字クラス指定は本文モードにしか効かないため、
   数式中の ★ を和文フォントの箱（`\jpstar`）へ置き換えるようにした（`tools/unicode-math.ts`）。
2. **長いパスが版面から 93pt はみ出していた。** `$\texttt{sagemath/tools/verify-check-linkage.ts}$` が
   数式の箱になり、どこでも改行できなかった。中身が `\texttt{...}` だけの行内数式は
   `\path{...}`（url パッケージ）で組み、区切りで改行できるようにした。
3. **ℚ̄ が ℚ に化けていた**（結合マクロン U+0304 を捨てていた）。合成文字を単字置換より先に処理し、
   対応表に無い結合文字はビルドを落とすようにした。

これらはいずれも「ビルドは通るのに PDF 上で内容が失われる」類であり、
Ising 側から移植した検査（組めない文字・版面外へ出た行をビルド失敗にする）が実際に検出した。

## Typst の扱い（確認結果）

`integrable-lattice/_old/typst/` に退避済みで、**追跡対象に `.typ` は 1 つも残っていない**
（`find . -name "*.typ" -not -path "./_old/*"` が 0 件）。退避物の中身も確認した。

- `main.typ` は 17 行。`#theorem` / `#definition` / `#claim` / `#proof` / `#remark` / `#note` の
  出現は **0 件**で、定理・定義・主張・証明を 1 つも含まない（タイトルと目的の散文のみ）。
- `parts/` は `.gitkeep` だけで、証明の部品は 1 ファイルも無い。

したがって「Typst 原本に証明があるのに構造化側へ運ばれていない」という移行漏れは**原理的に起こらない**。
Ising 側にある `tools/verify-no-lost-proofs.ts` を本プロジェクトへ移植していないのはこのためである。
退避先の位置づけ（正本は構造化テキスト側・新規に Typst で書かない）は `_old/typst/README.md` に記録済み。
