- 2026-11-19（主経路の書式統一）: 「極大な順序付き部分体では二つの平方の和が平方である」で零と正錐の場合を分け、結論の等号を行末の根拠付きの式鎖にした。
- 2026-11-19（主経路の書式統一）: 「代数的数の部分体は有理数をすべて含む」の有理数の段で、商の所属、選んだ表示の等号、所属の移送を別々の行にした。
- 2026-11-19（主経路の書式統一）: 「代数的数の部分体は有理数をすべて含む」の負の整数の段で、符号反転による所属、二重否定の等号、所属の移送を別々の行にした。
- 2026-11-19（主経路の書式統一）: 「配位の重みは、行に沿った転送行列の成分の積である」で剰余類の代表への置換を独立した式の行にし、整数の行番号から剰余類への射影を明記した。
- 2026-11-19（主経路の書式統一）: 「構成した置換の第一の対の族は元の第一マッチングに等しい」の三つの式鎖末尾から、根拠括弧の後の句点を除いた。
