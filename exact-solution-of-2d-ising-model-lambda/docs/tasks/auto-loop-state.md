## 前進の記録

- 2026-08-08（tick 15）: 章「固有値の代数性」の続きとして、特性多項式を定義し、
  それがモニックな次数 $2^{L}$ の元であることを四層すべてで検証した。
  定義は 5 件である。$\mathbb{Z}[x][t]$ を成分とする行列 $\mathrm{Mat}_{R_L}(\mathbb{Z}[x][t])$、
  その行列式 $\mathrm{det}_{t}$、不定元 $t$ 自身が定める元（係数で書いたもの）、
  特性行列 $\mathrm{ch}(A)$、特性多項式 $\chi_A=\mathrm{det}_{t}(\mathrm{ch}(A))$ である。
  成分の住む集合が違うので、既に書いた行列と行列式（成分が $\mathbb{Z}[x]$）をそのまま使わず、
  同じ形をもう 1 度書き下した。一般の可換環へ持ち上げないのは人手証明の規律に従ったもので、
  抽象化は Lean の必要十分版の側で行っている。記号も $\det$ と $\mathrm{det}_{t}$ で分けた。
  **特性行列を $t+\iota(-A_{\tau,\tau'})$ と書くことにした。** 通常 $tI-A$ と書かれる行列だが、
  符号の反転を $\mathbb{Z}[x]$ の中で先に済ませておくと、以降の議論に $\mathbb{Z}[x][t]$ の
  引き算が一度も現れない。$\mathbb{Z}[x]$ の元を $\mathbb{Z}[x][t]$ の元として扱う経路が
  $\iota$ だけであるという前 tick の約束も、この書き方だと自然に守られる。
  主張は 3 件で、$\iota(a)\in\mathcal{D}_0$、$t+\iota(a)\in\mathcal{M}_1$、
  そして $\chi_A\in\mathcal{M}_{2^{L}}$ である。最後の証明は準備を 3 つ置いた。
  恒等置換の項がモニックな次数 $2^{L}$ の元であること（前 tick のモニックな元の有限積）、
  恒等でない置換の項が $\mathcal{D}_{2^{L}-2}$ の元であること（動かされる添字の因子が
  $\mathcal{D}_0$、それ以外が $\mathcal{D}_1$ で、動かされる添字が 2 つ以上あること）、
  そしてその総和が $\mathcal{D}_{2^{L}-2}$ の元であること（前 tick の有限和）である。
  そのうえで本体を 5 つの等号の一続きの式にし、モニック + 低次で結論した。
  この範囲にも $\mathbb{R}/\mathbb{C}$ は現れない（係数は $\mathbb{Z}[x]$、次数と添字は $\mathbb{N}$）。
  Lean は `AlgebraicEigenvalue/CharacteristicPolynomial.lean`・
  `NecSuf/AlgebraicEigenvalue/CharacteristicPolynomial.lean`・
  `AlgebraicEigenvalue/CharacteristicPolynomialFromNecSuf.lean` の 3 ファイルを追加し、
  検査対象の定理を 85 件から 98 件へ増やした。mathlib の `Matrix.det` / `Matrix.charpoly` は
  引いていない（引くと「置換にわたる和として定める」「係数の条件として次数を定める」という
  人手証明の定義そのものが消える）。必要十分版のために `DegLe.mono`（$n\le n'$ なら
  $\mathcal{D}_n\subset\mathcal{D}_{n'}$。人手証明が定義の中で述べていること）を
  必要十分版の側にも足した。
  必要十分版が示したのは、この証明が重みに要求するのが $w(\mathrm{id})=1$ と
  「重みの次数が $0$ 以下であること」の 2 つだけだということである。すなわち
  **符号の乗法性も、符号が $\pm1$ であることも、転倒数で定まることも使っていない。**
  係数環に要求するのは可換半環だけで、引き算を一度も使っていない（符号の反転を係数環の側で
  済ませたことがここで効いている）。行配位であること・格子の形・スピンの値が $\pm1$ であることも
  使っていない。削れなかった仮定は添字が空でないこと（$\mathbb{N}$ の引き算が切り詰められると
  最後の $|R_L|-2<|R_L|$ が偽になる）で、その理由をファイルに書いた。
  SageMath 検証は `sagemath/check/characteristic-polynomial/` を作り、$L=1,2,3$ で
  行列 3 種（転送行列・成分がすべて異なる $x$ の冪・対角行列）について確かめた（厳密計算。
  **行列の全体は無限集合なので標本であることを overview に明記した**。置換は全列挙）。
  本文の $\mathrm{det}_{t}$ が SageMath 自身の `Matrix.determinant()` と一致すること、
  本文の特性行列が $\mathbb{Z}[x][t]$ の引き算で書いた $tI-A$ と同じ元であること、
  そして人手証明の 3 つの準備そのもの（恒等の項・恒等でない項・その総和）も別々に確かめた。
  最終の主張だけを見ると、途中の見積もりが誤っていても結論がたまたま成り立つ場合を見逃すためである。

- 2026-08-08（tick 14）: 章「固有値の代数性」の続きとして、特性多項式を書く場所
  （$\mathbb{Z}[x]$ を係数環とする、もう 1 つの不定元 $t$ の多項式環 $\mathbb{Z}[x][t]$）と、
  そこでの次数の上界・モニック性の基本性質を四層すべてで検証した。

  次数を扱う道具までを 9d、特性多項式そのものを 9e へ割り直した。割り方の理由は、特性多項式の
  次数を数える議論が「モニックな次数 $|R_L|$ の項に、次数 $|R_L|-2$ 以下の項を足す」という形をとり、
  そのために要る 4 つの性質（有限和の次数・有限積の次数・モニックな元の有限積・モニック + 低次）が
  いずれも多項式環の演算の定義だけで閉じた独立な論法だからである。
  **不定元を $\lambda$ と書かないことにした。** $\lambda$ は章「有限系の自由エントロピー」で
  対数順序群 $\Lambda$ の元を表す記号として固定してあり、同じ記号に 2 つの意味を持たせることは
  README「1 つの記号は 1 つの意味に固定する」に反する。$t$ を使い、README の章立ての表と、
  前 tick に書いた注意書き（恒等置換の項が不定元を $|R_L|$ 個ぶん含むこと）も直した。
  定義は 4 件である。$\mathbb{Z}[x][t]$ と係数写像 $\mathrm{cf}_k$（和と積の係数の形を含む）、

  モニックな次数 $n$ の元の全体 $\mathcal{M}_n$ である。1 ブロック 1 定義の規律に従って
  4 つのブロックへ分けた（これまでのように束ねていない）。
  次数を写像として定めなかったのは、零多項式の次数をいくつと決めるかという約束が要らなくなり、
  以降で必要になるのが上界だけだからである。$\mathcal{M}_n$ については、$n$ が元に対して
  高々 1 つであること（この呼び方が意味をもつこと）を定義の中で示した。
  主張は 4 件で、いずれも証明は「和の係数は係数の和」「積の係数は畳み込み」の 2 つの等式だけから出る。
  この範囲にも $\mathbb{R}/\mathbb{C}$ は現れない（係数は $\mathbb{Z}[x]$、次数と添字は $\mathbb{N}$）。
  Lean は `AlgebraicEigenvalue/SecondPolynomial.lean`・`NecSuf/AlgebraicEigenvalue/SecondPolynomial.lean`・
  `AlgebraicEigenvalue/SecondPolynomialFromNecSuf.lean` の 3 ファイルを追加し、検査対象の定理を
  69 件から 85 件へ増やした。mathlib の `Polynomial.Monic` / `Polynomial.degree` は引いていない
  （引くと「係数の条件として定める」という人手証明の定義そのものが消える）。使ったのは
  `Polynomial.coeff_add` / `Polynomial.coeff_mul` / `Polynomial.finsetSum_coeff` で、これらは
  多項式環の演算の定義そのものである。
  必要十分版が示したのは、この 4 主張の証明が係数環に**半環しか要求しない**ことである。
  すなわち引き算を一度も使っておらず（環である必要がない）、零因子が無いことも使っていない
  （次数の主張が上界の形であり、モニック性が「最高次の係数が単位元である」ことから直接に出るため）。
  係数が整数であることも、不定元 $x$ があることも使っていない。
  さらに、2 つの元についての補題（`degLe_mul` / `monicDeg_mul`）は積の可換性さえ使っておらず、
  そこは `[Semiring S]` のまま証明した。可換性を仮定するのは有限積の版だけで、これは mathlib の
  $\prod$ が可換モノイドにしか定義されていないという記法上の都合である。
  SageMath 検証は `sagemath/check/second-polynomial-degree/` を作り、係数を $\mathbb{Z}[x]$ の
  6 元に限って 4 主張を確かめた（厳密計算。**標本であることを overview に明記した**。
  係数環も次数も無限にあるので総当たりできない）。係数に $x^2-1$ と $\kappa(2)$ を入れたのは、
  主張が零因子の非存在や係数の可逆性に依存していないことを見るためである。
  加えて、本文の述語（係数で書いた $\mathcal{D}_n$・$\mathcal{M}_n$）が SageMath 自身の
  `degree()` / `leading_coefficient()` の判定と一致することを確かめた。作り方が独立なので、
  上界の向きの取り違え（$k>n$ と $k\ge n$）を検出できる。境界も 2 つ見た。上界が一般には
  等号でないこと（因子が零元のとき次数が落ちる）と、「モニック + 低次」の仮定 $n'<n$ が
  空でないこと（$n'=n$ では $t^2+t^2$ が反例になる）である。

## cron（launchd）

- ラベル: `com.masaori.ising-lambda-auto-loop`
- 定義: `~/Library/LaunchAgents/com.masaori.ising-lambda-auto-loop.plist`
- 実体: `exact-solution-of-2d-ising-model-lambda/scripts/auto-loop-tick.sh`（毎時 23 分と 53 分。25 分で打ち切る）
- ログ: `exact-solution-of-2d-ising-model-lambda/logs/auto-loop.log`（git 管理外）
- 各 tick は `claude -p` で**独立した新しいセッション**として走る（文脈を持ち越さない。
