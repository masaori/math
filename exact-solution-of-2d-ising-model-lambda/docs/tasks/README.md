# 作業指示書

このディレクトリにタスクの作業指示書を置く。書式はリポジトリ共通の `task-rules` に従う。

## 指示書を書くときの必須事項（このプロジェクト固有）

各タスクの完了条件に、次を必ず含めること。

1. **記述**: 一ステップ一定理・根拠のラベル参照・記号の帰属。
   すべての本文ブロックに住処 `habitat` を宣言し、非可算なら `realEscape` に理由を書く。
   **記号の濫用がないこと**（1 記号 1 意味、添字集合と構造を与える写像の分離、多項式と値の区別。
   式の簡潔さより曖昧さの排除を優先する。README「記号の濫用を排除する」）。
2. **SageMath 検証**: 式変形の各行に対応する検算があり、`overview.md` に対象ラベルと結果がある。
   厳密計算で行う（浮動小数点を使ったら理由を書く）。
3. **Lean**: 具体版（人手証明と 1 対 1）と必要十分版の 2 本立て。`sorry` を残さない。
4. **どこまで済んだかの明示**: 四層を全部満たせないなら、どの層まで済んだかを書く。
   黙って未検証のまま「証明した」と書かない。
