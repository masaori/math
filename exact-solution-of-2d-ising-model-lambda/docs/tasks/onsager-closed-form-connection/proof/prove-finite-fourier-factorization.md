# ねじれた有限 Fourier 因数分解を証明する

## 概要

四つの Kac--Ward 行列を二方向の有限巡回移動で同時にブロック対角化し、行列式をモード別小行列式の有限積へ分解する。

## 背景・前提

- Kac--Ward データ定義と有限トーラス公式に依存する。
- `1` の冪根による有限 Fourier 行列を使い、解析的 Fourier 変換を持ち込まない。
- 着手前に対象プロジェクトの README、MEMORY、CLAUDE.md、`docs/context/` を読むこと。

## スコープ

ブロック対角化と行列式の積への分解まで。小行列式の展開は後続タスクへ分ける。

## 記号の帰属と ℝ 脱出の見込み

- ねじれモードは `ζ_{2L}` の冪、Fourier 行列と小行列は `QQ(ζ₈,ζ_{2L})(x)` に住む。
- 正規化に平方根 `1/√L` を使わず、逆行列を `1/L` と冪根直交和で具体化する。実数への脱出はない。

## 作業内容

### 巡回移動の対角化

- 周期・反周期の各方向について許される冪根集合を定義する。
- 有限幾何級数から指標直交性と Fourier 行列の可逆性を証明する。
- 向き成分を残した小行列へ共役し、行列式の積公式を得る。
