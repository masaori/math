# 正方格子のモード別分散因子を計算する

## 概要

Fourier 分解で得た向き成分の小行列式を一行ずつ展開し、正方格子 Ising 模型の分散因子を Laurent 多項式として導く。

## 背景・前提

- 「ねじれた有限 Fourier 因数分解を証明する」に依存する。
- `docs/discussion/対数順序群上の統計力学/09_2DIsing閉形式の可算的導出.md` の分散式は照合先であり、引用だけで済ませない。
- 着手前に対象プロジェクトの README、MEMORY、CLAUDE.md、`docs/context/` を読むこと。

## スコープ

小行列式の代数計算と対称化まで。平方根の全体符号と有限積の合成は後続タスクへ分ける。

## 記号の帰属と ℝ 脱出の見込み

- `x` は不定元、モード変数 `u,v` は有限位数の元として `QQ(ζ₈,ζ_{2L})(x)` に住む。
- `cos θ` は使わず `(u+u⁻¹)/2` という代数的略記から始める。実数への脱出はない。

## 作業内容

### 小行列式の展開

- 行列式を置換ごとの有限和へ展開し、同類項の統合を一行一操作で行う。
- `u u⁻¹=v v⁻¹=1` を使って反転不変な Laurent 多項式へ整理する。
- 後の実数脱出で使う分散量との代数的対応を定義するが、`arccosh` は導入しない。
