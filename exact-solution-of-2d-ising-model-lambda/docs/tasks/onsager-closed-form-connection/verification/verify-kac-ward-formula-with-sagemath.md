# Kac--Ward 有限トーラス公式を SageMath で厳密検算する

## 概要

本文の Kac--Ward 公式を小さい周期格子で係数ごとに厳密検算し、四ねじれの符号・定数項一の多項式平方根・正規化を固定する。

## 背景・前提

- 「四つの Kac--Ward 行列式による有限トーラス公式を証明する」に依存する。
- `sagemath-checker` と既存の `sagemath/check/` の一行一ファイル規約に従う。
- 着手前に対象プロジェクトの README、MEMORY、CLAUDE.md、`docs/context/` を読むこと。

## スコープ

本文の各等式に対応する厳密検算だけを行い、新しい数学的主張を数値観察から追加しない。

## 記号の帰属と ℝ 脱出の見込み

- `CyclotomicField(8)` と多項式環で計算する。浮動小数点と数値平方根は使わない。
- 実数への脱出はない。

## 作業内容

### 係数比較

- 四行列を座標定義どおり生成し、$D^{a,b}_L=\det K^{a,b}_L$ を `CyclotomicField(8)` 上の多項式として計算する。
- 全偶部分グラフを独立に列挙し、本文の巻き付き偶奇と符号から $Q^{a,b}_L\in\mathbb Z[x]$ を構成する。四ねじれの全てで $Q^{a,b}_L(0)=1$ と $(Q^{a,b}_L)^2=D^{a,b}_L$ を全係数で比較する。
- 全配位から低温変数の分配多項式 $Z_L$ を独立に構成し、$2Z_L=\sum_{(a,b)\in\mathcal S}Q^{a,b}_L$ を係数ごとに比較する。Arf 符号、双対変数への置換、高温展開の前因子は加えない。
- 定数項からの再帰を補助計算に使う場合も、得た有限多項式の平方と行列式が完全に一致することを検査する。有限次数までの級数一致だけで多項式平方根の存在を確認したことにしない。任意の定数項一の多項式には多項式平方根がある、という主張はしない。
- 辺長 $L=1,2,3$ を対象とし、一辺一のループと一辺二の多重辺を本文の辺番号で区別する。退化を理由に一辺一を除外しない。
- 各本文ラベルと検算ファイルの対応、実行コマンド、PASS 結果を `overview.md` に記録する。
