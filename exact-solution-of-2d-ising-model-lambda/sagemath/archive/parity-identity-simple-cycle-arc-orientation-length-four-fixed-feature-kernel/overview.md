# SageMath Check: 語長四の解空間で固定される特徴係数

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 通過。候補系の解空間では、3,240 個の一次・二次特徴係数のうち全解で固定される係数は零個だった。

## 何を確かめるか

80 個の一次特徴と全二特徴積を許した全 7,085 鍵の可解な合同系について、係数行列の被約行階段形を計算する。
ある座標が全解で固定されることは、その座標の標準基底ベクトルが係数行列の行空間に属することと同値なので、
被約行階段形の一成分だけが非零である行から固定座標を全て取り出す。

係数行列は 11,208 列、階数 6,793 で、解空間の次元は 4,415 だった。特徴係数に対応する
3,240 座標には固定座標が無かった。従って、前回得た 248 項の支持は列順に依存する一代表にすぎず、
個々の特徴係数から語位置の巡回移動に沿う非零の核を抽出することはできない。

次は個々の係数ではなく、解空間上で固定される線形結合を語位置の巡回移動で類別する。

## 実行方法

```sh
sage check.sage
```
