# 語長三の同じ署名位置の単一辺所属の積で足りるか

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵だけを対象とする有限存在判定。語長三の 2,044 弧型の値へ
純二次式を課し、切断旗を含む 1,150 項と、同じ署名位置の単一辺所属同士の 30 項だけを許す。
語の三位置と二つの切断端点を五つのブロックとして区別する。各ブロックの四方向のうち
相異なる二方向を選ぶ六項ずつを残し、異なるブロック間の 160 項を除く。
他の語長・閉路型の値は自由未知数、定数項・一次項は零である。

語は切断の始点を含み終点を含まない。語と端点対は別々に正準化されているため、
語の位置と端点との間に同一頂点という対応を追加しない。この判定の「同じ位置」は
五つの特徴ブロック内を意味し、実頂点の同一性による全ての同定を含むとは主張しない。

| `check.sage` | 特徴名とビット位置から列を別々に選び照合し、階数と解または左核の証拠を判定する | PASS（2026-09-06 初回・観測固定後の全再実行） |

一般の辺長の命題と Lean 二版は未追加。整数・有限体・上流の円分体で厳密に計算する。

初回のプログラミングによる検証: 9,129 行・11,278 未知数の系の両階数は 8,819 で可解。
全 7,085 鍵を復元した。一解の非零項は切断旗を含む積 104 項と同じ語位置の単一辺所属同士の積 5 項。
この一解では端点ブロック内の非切断項も零だが、切断旗を含む項は異なる位置間にも残る。
項数の最小性は主張しない。係数の全リストは実行時に特徴名の対で出力する。

LLM による検証: 前回可解だった系から異なる位置間の非切断項だけを除いており、
一つの解の削減ではなく残る全未知数の存在判定になっている。各許可積は同じ頂点の
署名内なので、この結果は同じ頂点内の非切断項による十分性を与える。逆向きの必要性は述べない。
次は、非切断項を語の三位置に限り、同じ四方向の組の係数を三位置で共通にしても可解かを判定する。

初回起動はリポジトリ直下で行ったため相対パスが見つからず終了コード 2 だった。
プロジェクト直下へ作業ディレクトリを直し、同じ SageMath スクリプトで上記の結果を得た。

観測を固定した assertion 付きの全再実行も終了コード 0 で通過し、同じ階数・項数・全鍵の復元を再現した。
