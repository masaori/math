# SageMath Check: 非負係数条件と負の第二係数条件の和

**対象ラベル**: `claim_quadratic_positive_add_nonnegative_negative_second`

## 検証内容

- 非負係数条件と負の第二係数条件を満たす有理係数対について、和の第二係数が非負なら第一条件、負なら第二条件を満たすことを検査する。
- 負の場合は $b'\le b+b'<0$ から平方が増えないことと、$0<a'\le a+a'$ から平方が減らないことを中間段ごとに検査する。
- 浮動小数点と実数体は使わない。
