# SageMath Check: 二つの軌道係数を決める最小端点局所量

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

辺長二・三から得た有限合同系の全弧型について、巡回・反転で
正規化した内部語が同じで、二つの正準支持の係数対が異なる弧型対を
全て作る。各対を区別する端点局所成分を少なくとも一つ選ぶ問題を
二値整数計画へ移し、必要な端点成分数の最小値を厳密に判定する。

これは一般の辺長についての係数式ではなく、端点32成分のうち有限範囲で
両係数の決定に必要な最小成分集合を切り分ける判定である。

プログラミングによる検証では、同じ内部語を持ちながら係数対が異なる
2,640 対から 1,605 種の相違成分集合を得た。これらを全て区別するには
端点局所成分が少なくとも 18 個必要であり、実際に 18 成分を選ぶと
9,739 弧型は 9,660 個の記述へ圧縮され、二つの支持のどちらにも係数衝突は
残らなかった。
