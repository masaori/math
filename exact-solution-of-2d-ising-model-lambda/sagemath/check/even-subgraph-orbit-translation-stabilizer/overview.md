# 二候補と平行移動の対称性

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像
- 実行: `sage sagemath/check/even-subgraph-orbit-translation-stabilizer/check.sage`
- 状態: PASS（2026-09-03、覆えない 16 ファイバーの二候補を持つ置換 1,984 個）

覆えない 16 ファイバーのどれも、非自明な平行移動（一辺 2 の 3 通り）で
$(D,E)$ が固定されない。従って $(D,E,\varphi)$ を固定する非自明な平行移動は存在せず、
二候補を入れ替える平行移動もない。すなわち、平行移動と可換な選択規則が二候補から
一方を選ぶことを妨げる対称性の障害は無い。

さらに、覆えない 16 ファイバーの集合は平行移動で閉じており、固定するものが無いので
大きさ 4 の軌道がちょうど 4 本に分かれる。ただし、この検算は異なるファイバー間で候補辺集合が
平行移動と可換であることを確かめていないので、代表での選択を残りへ延長できるとは結論しない。
計算は有限集合と有限写像の等号だけで完結し、浮動小数点は使わない。
