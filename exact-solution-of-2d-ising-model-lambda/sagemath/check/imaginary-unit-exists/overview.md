# 代数的数には平方が負の単位元になる元がある

**対象ラベル**: `claim_imaginary_unit_exists`

2026-11-21、SageMath で `check.sage` が PASS（係数の五段、評価の十二段を二根それぞれで、負の検査二根）。

`QQbar[t]` の多項式 $g=t^2+\widehat{1}$ について、本文の係数の五行と、代数閉性で取った根それぞれに対する評価の十二行を厳密に検算する。
負の検査として、定数項を $-1$ に変えた $t^2-1$ の根では $\omega\cdot\omega=-1$ が成り立たないことを確かめる。浮動小数点と根の大小は使わない。
検算は本文と Lean による証明の代わりではない。
