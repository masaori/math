# SageMath Check: 有限サイズスケーリングの検算と可算な命題候補の観察

**対象ラベル**: `def_finite_size_scaling_reading`

一辺 $L=2$ の周期境界分配多項式を $\mathbb Z[x]$ で厳密に作り、全 Fisher 零点を
`QQbar` で分離する。臨界点 $x_c=\sqrt2-1$ への距離の二乗を `AA` で計算し、
256 bit の包含区間が複素共役な候補以外の全距離から分離することにより、先頭零点を認証する。
先頭零点と先頭距離の最小多項式、その次数・判別式、$\mathbb Z[x]$ 上の因数分解を厳密に出す。

読みの値

$$
a_\rho(L)=-\frac{\log_{\mathbb R}d_1(L)}{2\log_{\mathbb R}L}
$$

の表示だけは `RealBallField(128)` を使う。この行は実対数による実数体への脱出であり、
最小多項式等の可算な観察とは区別する。

```sh
sage sagemath/check/finite-size-scaling-observation/check.sage
```

**2026-08-18 実行結果**:

- $Z_2=2(x^8+6x^4+1)$。相異なる零点は 8 個。
- 先頭零点は複素共役な 2 個。最小多項式は $x^8+6x^4+1$、次数 8、判別式 $68719476736$。
- $d_1(2)$ の最小多項式は $x^4-8x^3+48x^2-48x+8$、次数 4、判別式 $-110166016$。
- $a_\rho(2)$ は 128 bit ball で
  $[1.1299803986682887381052127334405035332\mathbin{+/-}4.07\cdot10^{-38}]$。

一辺 $L=3$ も同じコードで二度試した。全距離を直接比較する経路と、包含区間で先頭候補を
分離して候補距離だけを最小多項式へ変換する経路のどちらも、PARI が数体を統合する段階で
スタック上限 1 GiB に達した。したがって、この方法で再現可能に完了した上限は $L=2$ である。
$L=2$ の一点だけから次数・判別式・因数分解の一般則は立たず、本文へ昇格できる可算な命題候補は
まだ得られていない。

**2026-08-18 追試（切り分け）**: `l3-enlarged-stack-experiment.sage` で PARI スタックを
`pari.allocatemem(1 << 33, 1 << 34)`（8 GiB、上限 16 GiB）へ拡張し、同じ全根分離経路を
再実行した。540 秒（`timeout 540`）内にはスタック超過が再発しなかったが、完了せず時間切れで
打ち切られた。この回は各段階の標準出力を永続化しておらず、停止箇所は未確定だった。

**2026-08-18 追試（段階別ログによる停止箇所の確定）**: 同スクリプトへ段階・根ごとの
経過秒つきログ（`l3-stage-log-2026-08-18.txt` へ永続化）を入れて再実行した。
分配多項式の構成（次数 12）、全 12 根の `QQbar` での分離、距離の二乗の 256 bit 包含区間の構成、
先頭候補と他の全根との分離検証まで、**すべて開始から 0.1 秒以内に完了した**。
停止しているのは最後の 1 段階、先頭距離 $d_1(3)$ の `AA` 上の最小多項式計算
（`candidate_distance.minpoly()`）であり、この段階だけが 480 秒（`timeout 480`）内に
完了しなかった（スタック超過は再発していない）。したがって律速は根の分離でも区間分離でもなく、
距離の二乗という合成的な代数的数の最小多項式化（PARI の数体統合）である。
$L=3$ を完了させるには、`AA` の最小多項式計算に頼らず、終結式など $\mathbb Z[x]$ 上の
消去計算で $d_1(L)$ の定義多項式を直接構成する別経路が要る（未着手）。
