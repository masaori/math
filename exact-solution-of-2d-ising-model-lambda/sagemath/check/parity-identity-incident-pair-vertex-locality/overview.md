# 共有端点対と局所位相の頂点量の局所性

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

標準形配向の動辺集合について、端点を共有する動辺対の反転指示値を共有頂点
（二つ共有する対は辞書式最小の共有頂点）へ割り付け、その頂点の局所行列式と
合わせた頂点量

\[
  w(v) = (\text{局所行列式 } \det_v)\times(-1)^{v\text{ へ割り付けた共有端点対の寄与和}}
\]

を定義した。頂点の署名を「四つの辺スロット（上・下・左・右）の動辺の出入り」と
「四つの切断隣接旗（行が $0$ か $L-1$ か、列が $0$ か $L-1$ か）」の組とすると、
$w(v)$ は署名だけで決まり、鍵にも位置にも依らない（混在する署名は零）。
切断隣接旗を落とした局所配置だけの分類では決まらない。

- 一辺二: $369$ 鍵・頂点延べ $1{,}444$。旗つき署名 $160$ 類・混在 $0$。
  旗なし署名 $49$ 類のうち混在 $28$。
- 一辺三: $677$ 鍵・頂点延べ $5{,}184$。旗つき署名 $116$ 類・混在 $0$。
  旗なし署名 $14$ 類は全て混在。

併せて、頂点量の積と非共有端点対の和・動辺数から従来の符号指数が再構成される
ことを全鍵で検算した。従って偶奇恒等式の左辺は「頂点ごとの局所量（切断隣接旗
つき署名で決まる）＋非共有端点対の軌道項と座標切断横断項」へ完全に局所化され、
切断に触れる項だけが標的の巻き付き偶奇・交差対と結ばれるべき残りである。

検査は一辺二・一辺三の切断隣接旗の意味が退化している（全頂点が何らかの旗を
持つ）ため、旗が全て零の内部頂点の署名は一辺三の中央頂点だけから得ている。
一般の辺長での規則の同一性は未検査である。
