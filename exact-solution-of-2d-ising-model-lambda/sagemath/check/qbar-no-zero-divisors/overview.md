# SageMath Check: 代数的数の積が零元ならば、零元でない方で割って他方が零元と分かる

## 対象

**対象ラベル**: `claim_qbar_no_zero_divisors`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の主張 1 件
- 併せて引く定義: `def_algebraic_numbers`（代数的数の全体 $\overline{\mathbb{Q}}$。体であること）

### 何を確定させるための検証か

伸縮の等式（`claim_qbar_geometric_telescope`）の左辺が零元であることから
$\sum_{k=0}^{n-1}z^{k}=0$ を出すとき、および 1 の冪根の全体にわたる冪の和 $S_{n,m}$ について
$(w^{m}-1)S_{n,m}=0$ から $S_{n,m}=0$ を出すときに、**零元でない方で割る**段がある。
本検証はその段だけを見る。$\mu_n$ の元の個数も、和の値そのものも、ここでは扱わない。

確かめるのは次の 5 である。

1. **鎖の各段**。$b=1\cdot b=(a^{-1}a)b=a^{-1}(ab)=a^{-1}\cdot 0=0$ を段ごとに分けて確かめる。
2. **主張そのもの**。標本の全ての組について、$a\ne0$ かつ $ab=0$ ならば $b=0$。
3. **仮定 $a\ne0$ が要ること**。$a=0$ ならば $ab=0$ はどの $b$ でも成り立ち、$b=0$ は出ない。
4. **可換でない環でも通ること**。必要十分版が積の可換性も体であることも仮定せず、
   $a$ が左逆元を持つことだけを仮定していることの裏取りである
   （2 次整数行列環の、互いに可換でない可逆な 3 元で確かめる）。
5. **左逆元が無いと結論が出ないこと**。同じ 2 次整数行列環で、行列式が 0 の元を取ると
   $ab=0$・$a\ne0$・$b\ne0$ が同時に起こる。必要十分版の仮定 `hinv` が削れないことの裏取りである。

計算はすべて厳密（`QQbar` / `MatrixSpace(ZZ,2,2)`）で、浮動小数点は使わない。

## 実行

```sh
sage sagemath/check/qbar-no-zero-divisors/check.sage
```
