# 平行移動固定ファイバーの辺軌道による可除条件

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、自然数
- 実行: `sage sagemath/check/translation-fiber-stabilizer-orbit-divisibility/check.sage`
- 状態: PASS（2026-09-03、辺長 $L=2,\ldots,8$ の全非零平行移動 $168$ 個）

一辺 $L$ のトーラスの平行移動 $(a,b)$ の位数は

$$
\operatorname{lcm}\left(
  \frac{L}{\gcd(L,a)},
  \frac{L}{\gcd(L,b)}
\right)
$$

である。非零平行移動は水平辺と垂直辺の各集合へ自由に作用するので、全ての基底辺軌道は
この位数と同じ長さを持つ。従ってファイバー $(D,E)$ がこの平行移動で固定されるなら、
$D$ と $E$ はそれぞれ辺軌道の和であり、$|D|$ と $|E|$ はともにこの位数で割り切れる。

$L=2,\ldots,8$ で可能な非自明位数と平行移動の個数は順に
$\{2:3\}$、$\{3:8\}$、$\{2:3,4:12\}$、$\{5:24\}$、
$\{2:3,3:8,6:24\}$、$\{7:48\}$、$\{2:3,4:12,8:48\}$ だった。
特に素数辺長では、固定ファイバーの $|D|,|E|$ はともに $L$ の倍数でなければならない。

この可除条件は必要条件であって十分条件ではない。一辺二の未被覆 $16$ ファイバーの辺数分布は
$(|D|,|E|)=(0,4)$ が $4$ 個、$(2,4)$ が $8$ 個、$(4,4)$ が $4$ 個で全て可除条件を満たすが、
既存検算 `even-subgraph-orbit-translation-stabilizer` では固定する非零平行移動は零だった。
従って一般の辺長では、辺数で候補を除いた後も $D,E$ が辺軌道の和そのものかを調べる必要がある。
