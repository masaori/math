# 非自明文字鍵の K=U=0 を一般の辺長で閉じる合成

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`
- 住処: 有限集合、整数、$\mathbb F_2$、$\mathbb Q(\zeta_8)$
- 実行: `sage sagemath/check/translation-nontrivial-key-general-composition/check.sage`
- 状態: PASS（2026-09-04。一辺四の偶部分グラフ $131{,}072$ 個の文字全数調査、
  一辺四・五の交差一周路対の全ファイバー展開で実行済み）

一般の辺長 $L$ の鍵 $(D,E)$ で選択文字が非自明なものについて、四つのねじれ
$(a,b)$ 全てで $\mathcal K^{a,b}_L(D,E)=\mathcal U^{a,b}_L(D,E)=0$ を閉じる。

選択側は文字評価そのもので、非自明文字の選択和は辺長によらず零である。
置換側は次の五段の合成である。ファイバーの各置換は各頂点での非後退局所全単射の
積であり、その単純通過部分は $E$ の均衡配向を誘導する（辺長に依存しない）。
非自明文字の $E$ の全ての均衡配向には曲がり型の次数 $4$ 頂点が存在する
（前 tick の一般証明）。曲がり型頂点は $E$ の次数 $4$ 頂点の曲がり配向に限り
$D$ に依存しない（反転対辺は同じ頂点へ入方向 $d$ と出方向 $d+2$ を与えるが、
曲がり二方向の対はこの二方向を同時に含めない。記号的・局所的）。曲がり型頂点の
非後退局所全単射はちょうど $2$ つで、交換は両位置を入れ替える互換であり四半回転和を
保つ（記号的・局所的）。従って辞書式最小の曲がり型頂点での交換は、動辺集合
（ゆえに曲がり型頂点集合と辞書式最小の選択、ねじれ符号の積）と総回転数を保ち、
巡回数の偶奇だけを反転する不動点のない対合になり、位相ベクトルが反転して
ファイバーの位相和は四つのねじれ全てで零になる。局所的事実は辺長に依存せず、
存在定理は一般証明済みなので、合成は全ての辺長で成立する。

検算は、局所分類（曲がり四型・反転対辺の排除・局所全単射数 $2$ と回転和の保存）を
記号的に固定した上で、既検査の一辺三を越える標本を全展開する。一辺四では
偶部分グラフ $2^{17}=131{,}072$ 個の文字を全数調査して非自明 $50{,}320$ 個を確定し、
辺数 $8$ 以下の非自明文字が交差一周路対 $16$ 個に限ることを確かめ、その全てで
$D=\varnothing$ のファイバー（合計 $128$ 置換）と、辞書式最小の対に閉路状の反転対
（第 $1$ 行・第 $1$ 列・その和）を付けたファイバー（合計 $696$ 置換）を全展開して、
対ごとの位相ベクトル反転と位相和の零、選択和の零を等号 assert した。一辺五でも
交差一周路対で同じ検査を行った（$D=\varnothing$ で $8$ 置換、閉路状反転対で
$696$ 置換）。浮動小数点は使わない。
