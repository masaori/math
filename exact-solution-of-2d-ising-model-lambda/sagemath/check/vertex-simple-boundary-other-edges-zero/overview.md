# 頂点単純閉路の通過頂点における前後二辺以外の寄与

**対象ラベル**: `claim_vertex_simple_boundary_other_edges_zero`

二つの標識付き端点寄与と全項の端点寄与の和がともに二であるとき、別の標識付き項の寄与が零であることを整数の有限例で確認する。閉路の幾何と境界係数の支持は本文で既存の二補題を引く。これは有限例の検算であり、一般の閉路の形式証明ではない。
