# 曲がり型を持たない均衡配向の重み付き数

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

自明文字で選択集合が非空な一辺二の各ファイバーについて、曲がり型頂点を
持たない均衡配向 $o$ に重み $2^{s(o)}$ を付けた。ここで $s(o)$ は直進型の
次数 $4$ 頂点数であり、前の局所行列式分類から、この重みは配向類の位相和の
絶対値に等しい。

全 $369$ ファイバーで次を厳密検査した。

- 重み付き数 $sum_{o:\,曲がり型なし}2^{s(o)}$ は
  $2^{|E|-|V(E)|+c(E)}$、すなわち $E$ の巡回空間の位数および選択集合の
  元数に等しい。
- 四つのねじれそれぞれで、曲がり型を持たない全配向類の位相和は同符号で、
  その符号は選択和 $mathcal U_L^{a,b}(D,E)$ の符号に等しい。
- 従って、曲がり型を持つ零和の類を除いた配向類の総和は、選択和そのものに
  等しい。

これは一辺二の有限観察であり、一般の辺長での重み付き数の全単射と符号の
同定はまだ証明していない。

- 実行: `sage sagemath/check/trivial-character-curved-free-orientation-weight/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
