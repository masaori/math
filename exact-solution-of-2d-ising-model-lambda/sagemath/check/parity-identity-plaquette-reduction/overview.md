# プラケット変形だけでは全ての鍵を切断非接触代表へ運べない

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

固定した反転対 $D$ ごとに、許される鍵 $(D,E)$ をプラケット対称差で結んだ有限グラフを作り、
各連結成分で $E$ の巻き付き偶奇と切断辺数の最小値を計算した。

- 一辺三・$D=\varnothing$ では四つの連結成分が巻き付き偶奇の四類に一致し、零巻き付きの
  一成分だけが切断辺数零の代表を持つ。非零巻き付き三成分の最小切断辺数は $1,1,2$ である。
- 一辺二では $96$ 個の $D$ に対して $324$ 成分があり、零巻き付き $94$ 成分のうち $48$ 成分にも
  切断辺数零の代表が無い。したがって障害は非零巻き付きだけではなく、$D$ を固定し、変形後も
  曲がり型なし配向を持つ許された鍵に留める制約からも生じる。

従って「任意の鍵を切断に接しない代表へ運ぶ」という前 tick の次手は、そのままでは成立しない。
一般証明には、切断辺を消すことではなく、各巻き付き類と $D$ の制約に適合する標準代表を選び、
その代表値を直接評価する必要がある。

- 実行: `sage sagemath/check/parity-identity-plaquette-reduction/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、$\mathbb F_2$、整数の厳密演算のみ。浮動小数点は使わない。
