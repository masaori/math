# 平行移動固定ファイバーの固定部分群不変な完全マッチング

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、円分体 $\mathbb{Q}(\zeta_8)$ の等号
- 実行: `sage sagemath/check/translation-fixed-fiber-invariant-matching/check.sage`
- 状態: PASS（2026-09-03。約 6 分。全数値を等号 assert で固定して再実行済み）

一辺 $L=2$ で、置換を持つ全 $609$ ファイバー鍵のうち非零平行移動の固定部分群が
非自明なものは $89$ 個ある（方向別の固定鍵は軸 $35$・$35$、対角 $37$）。このうち
$81$ 個は有効な偶部分グラフ $H$（$E$ に含まれ偶で巻き付き対 $1$）を持たず、
一様被覆検査（巻き付き文字が非自明な $64$ 鍵）の対象外である。特に対角方向の
固定鍵 $37$ 個は全て対象外だった。

対象に入るのは軸方向固定の $8$ 鍵（固定部分群の位数 $2$、ファイバーの大きさは
$32$ が $4$ 個・$288$ が $4$ 個）で、その全てについて、四スピン構造すべてで位相寄与を
反転する全候補辺の集合に**固定部分群不変な完全マッチングが存在しない**。
候補を持たない置換は無く、完全マッチング自体は単一 $H$ の一様マッチング
（even-subgraph-fiberwise-uniform-matching で $48$ 被覆鍵すべてに存在）があるのに、
不変なものが無い。

判定は次の同値による。候補辺は正位相と負位相の置換を結ぶ（二部性。固定部分群が
位相寄与を保つことも assert で確認）ので、不変な完全マッチング $M$ の対 $(u,v)$ と
固定部分群の元 $s$ について $s\cdot(u,v)\in M$ が $u$ の像を含むことから、
$s\cdot u=u$ ならば $s\cdot v=v$。従って対の両端の点別固定部分群は一致し、$M$ は
点別固定部分群が一致する候補辺だけを使って頂点軌道の商二部グラフの完全マッチングへ
落ちる。逆に商の完全マッチングの各辺の witness 候補辺を軌道で運ぶと不変な
完全マッチングになる（well-defined 性は点別固定部分群の一致から従う）。

従って一辺二の時点で、平行移動群全体と可換な符号反転完全マッチング族は
位相反転候補辺からは作れない。共変性の要求は固定部分群が自明な軌道
（未被覆 $16$ 鍵を含む）に限るか、これら $8$ 鍵で候補辺以外の構造を使う必要がある。

商二部グラフで孤立する負位相側の頂点軌道は、固定部分群が置換を点別に固定する軌道と
ちょうど一致する。大きさ $32$ の各ファイバーでは正負の軌道数が $8$ と $12$ で、
正側 $4$ 軌道・負側 $8$ 軌道が孤立する。大きさ $288$ の各ファイバーでは軌道数が
$72$ と $84$ で、正側の孤立はなく、負側の点別固定 $24$ 軌道が孤立する。

巻き付き文字が非自明な $64$ 鍵のうち、二つの軸平行移動はそれぞれ $4$ 鍵を固定するが、
対角平行移動 $(1,1)$ が固定する鍵は零である。従ってこの $64$ 鍵上では対角部分群の作用は
自由であり、各軌道の代表で完全マッチングを一つ選んで運べば、対角部分群と可換な
位相反転完全マッチング族を構成できる。一方、どちらの軸部分群にも上の孤立軌道を持つ
$4$ 鍵があるので、候補辺だけの共変族は存在しない。よって一辺二で候補辺だけを使える
非自明な平行移動部分群は対角部分群に絞られる。
