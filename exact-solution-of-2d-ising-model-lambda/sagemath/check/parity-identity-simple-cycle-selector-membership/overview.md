# 選択所属を加えた合同局所符号式の非存在

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二の全 $320$ 鍵と一辺三の対象 $7{,}085-320=6{,}765$ 鍵について、
上下左右の各スロットの $D/E$ 所属・切断隣接旗に、辞書式最小の選択
$C$（`key_terms` が使う選択子と同じ規約）への所属 $c_s$ を加えた
$16$ 変数の頂点署名を作り、頂点項がその任意関数の頂点和で書けるかを
合同の $\mathbb F_2$ 線型系で判定した。

選択所属を加えても直接衝突は無いが、現れる署名 $452$ 種・所属行列の
階数 $408$ の合同線型系に解は無い。辺長ごとに分けると、一辺二は署名
$172$ 種・階数 $122$ で解を持つ一方、一辺三は署名 $432$ 種・階数 $378$
で単独でも解を持たない。従って一辺三の $D\ne\varnothing$ を含む鍵の
頂点項は、選択集合の所属を含めた頂点局所署名だけでは決まらない。
不足は頂点単位の情報ではなく、閉路に沿って伝わる大域的な情報にある。
次は閉路を $\partial D$ の頂点で切った弧ごとの寄与など、頂点より粗い
局所単位での分解を検査する。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-selector-membership/check.sage`
- 状態: PASS（2026-09-05。合同系は署名 $452$・階数 $408$ で解なし。
  一辺二は署名 $172$・階数 $122$ で解あり、一辺三は署名 $432$・階数 $378$ で解なし）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
