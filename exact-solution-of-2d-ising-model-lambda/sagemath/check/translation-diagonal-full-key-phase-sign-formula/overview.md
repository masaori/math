# 全辺鍵の位相ベクトルの符号公式

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限群作用、$\mathbb Q(\zeta_8)$、整数
- 実行: `sage sagemath/check/translation-diagonal-full-key-phase-sign-formula/check.sage`
- 状態: PASS（2026-09-03。約 4 分 23 秒。全数値を等号 assert で固定して実行済み）

全辺鍵のファイバーの置換 $\varphi$ の四つのスピン構造の位相寄与を三つの積へ分解する。
巡回ごとの符号 $(-1)$ の積は $(-1)^{c(\varphi)}$（$c$ は巡回数）。巡回ごとの回転積は、
非後退な閉歩道の四半回転の和が $4$ の倍数であることから $\zeta_8^{4k}=(-1)^k$
（$k$ は回転数）で、積は $(-1)^{T(\varphi)}$（$T$ は総回転数）。ねじれ $(a,b)$ の
縫い目寄与は、動く辺集合が全基底辺を各一度ずつ使うことから水平・垂直とも合計 $L$ 本で、
成分ごとに $(-1)^{aL+bL}$ になる。

従って位相ベクトルは、$\varepsilon(\varphi)=(-1)^{c(\varphi)+T(\varphi)}$ を用いて、
奇数辺長では $\varepsilon(\varphi)\cdot(1,-1,-1,1)$、偶数辺長では
$\varepsilon(\varphi)\cdot(1,1,1,1)$ に等しい。一辺三で観察した位相の二値性は
偶然ではなく、全ての奇数辺長で構造的に成り立つ。

検査では、一辺二・三の全ファイバーと一辺三・五・七の対角固定置換の全てについて、
各巡回の四半回転の和が $4$ の倍数であること、縫い目合計が $(L,L)$ であること、
位相ベクトルが符号公式と一致することを等号 assert で固定した。$\varepsilon$ の分布は
一辺二の全ファイバーで $+1$ が $160$・$-1$ が $128$（偶数辺長は文字が自明なので
均衡しなくてよい）、一辺三の全ファイバーで各 $37{,}888$、対角固定置換の層で
一辺三が各 $40$、一辺五が各 $544$、一辺七が各 $8{,}320$ だった。

帰結として、位相が二値なので、対角共変な位相反転完全マッチングの存在は
$\varepsilon$ の $+1$ と $-1$ の個数が対角平行移動の軌道サイズの各層
（素数辺長では固定点と自由軌道の二層）で均衡することへ帰着する。固定置換の層の均衡は
一辺三・五・七で確定済みであり、残る判定対象はファイバー全体での均衡
$\sum_\varphi\varepsilon(\varphi)=0$ を一般の奇数辺長で示すことである。
