# SageMath Check: 部分体の正錐に従う前錐

## 対象

**対象ラベル**: `def_subfield_precone`

- 実行日: 2026-11-17
- 結果: 二つのモデルの有限標本で四条件が通過し、反例が平方の条件を満たさないことも確認した
- 帰属: `QQ` の厳密計算。浮動小数点を使わない。

## 何を確かめるか

前錐の四条件（和で閉じる・積で閉じる・$E$ の元の平方を含む・$C_F$ を含む）が、次の二つのモデルで
成り立つことを有限標本で確かめる。普遍量化された条件そのものの証明ではない。

- $F=E=\mathbb Q$、$C_F=\mathbb Q_{>0}$、$T=\mathbb Q_{\ge0}$。標本 8 点。
- $F=\mathbb Q\subseteq E=Q_s$（$s\cdot s=2$）、$C_F=\mathbb Q_{>0}$、$T=P_s\cup\{0\}$。標本 64 点。

あわせて、$T=\mathbb Q_{>0}$ は $0\cdot0=0\notin T$ なので平方の条件を満たさないことを確かめる。
