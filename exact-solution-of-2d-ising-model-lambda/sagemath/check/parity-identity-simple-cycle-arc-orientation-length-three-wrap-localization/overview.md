# 語長三だけの切断旗局在

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵を対象に、語長三の弧型の値だけを、切断旗を含む
相異なる二成分の積の和で書けるか判定する。語長一・二を含む他の語長と閉路型の値には
局在も多項式の次数も要求しない。前回の三語長同時拘束の障害が、語長三だけでも
現れるのかを切り分ける有限探索である。

特徴抽出と合同系の構成は、前回の `construction.sage` をそのまま用い、
拘束する語長の集合だけを `{3}` に変える。2,044 弧型、68 特徴ビット、
切断旗を含む二次単項式 1,150 個に対し、連立系は 9,129 行・11,248 未知数となる。
定数項・一次項・切断旗を含まない二次項の係数は、最初から零に固定して除く。

得られた左核ベクトルを掛けると、左辺の係数は全て零になり、右辺は一になる。
従って語長三だけでも、指定した局在二次式を満たす解は存在しない。
前回の障害は語長一・二との同時拘束だけに起因するものではない。
切断旗を含まない項も許した二次式の可否はまだ判定していない。
次は語長三だけで定数項・一次項・全ての二次項を許して切り分ける。

LLM による検証: 前回と同じ構成で拘束語長だけを変え、他の弧型の値を自由に残していること、
左核の証拠がこの限定した候補の不存在を示し、一般の二次式の不存在を含意しないことを確認した。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-three-wrap-localization/check.sage
```
