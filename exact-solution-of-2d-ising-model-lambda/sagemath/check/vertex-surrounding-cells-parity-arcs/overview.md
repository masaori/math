# SageMath Check: 訪問頂点の内側セルと外側セルはそれぞれ一つの弧をなす

**対象ラベル**: `claim_vertex_surrounding_cells_form_parity_arcs`

原点から始まる長さ $10$ 以下の頂点単純な閉じた非後退単位格子歩をすべて列挙する。
各訪問頂点に接する四セルについて、右半直線と縦辺の交差数を辺の列から直接数え、
巡回順で内外がちょうど二回変わることを検査する。同時に、接する四辺の通過回数を
独立に数え、$0,0,1,1$ の並びであること、および奇数回通過の辺と内外が変わる共有辺が
一致することを検査する。

- 実行: `sage sagemath/check/vertex-surrounding-cells-parity-arcs/check.sage`
- 状態: PASS（2026-08-31。頂点単純な閉じた非後退歩道 704 本・訪問頂点 6,672 個）
- 計算: 単位格子歩の有限列挙と `ZZ` の比較・加法・奇偶だけ。浮動小数点は使わない。
