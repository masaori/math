# SageMath Check: 訪問頂点の内側セルと外側セルはそれぞれ一つの弧をなす

**対象ラベル**: `claim_vertex_surrounding_cells_form_parity_arcs`

原点から始まる長さ $10$ 以下の、点が二つずつ相異なる閉じた非後退単位格子歩をすべて列挙する
（この点列は主張の「一周期の持ち上げ点が二つずつ相異なる」仮定の持ち上げ点列そのものであり、
主張に現れる量は全て持ち上げ点の列だけから定まる）。
各点に接する四セルについて、右半直線と縦辺の交差数を辺の列から直接数え、
巡回順で内外がちょうど二回変わることを検査する。同時に、接する四辺の通過回数を
独立に数え、$0,0,1,1$ の並びであること、および奇数回通過の辺と内外が変わる共有辺が
一致することを検査する。さらに、$L=1,2,3$ のトーラスへ射影すると接触対数
$n_{\mathrm{ct}}>0$ となる歩（旧仮定 $n_{\mathrm{ct}}=0$ では扱えなかった対象）が
実在することを数えて確認する。

- 実行: `sage sagemath/check/vertex-surrounding-cells-parity-arcs/check.sage`
- 状態: PASS（2026-09-01。持ち上げ点相異の閉じた非後退歩道 704 本・訪問頂点 6,672 個。
  射影後に $n_{\mathrm{ct}}>0$ となる歩は $L=1$: 704 本、$L=2$: 696 本、$L=3$: 592 本）
- 計算: 単位格子歩の有限列挙と `ZZ` の比較・加法・剰余・奇偶だけ。浮動小数点は使わない。
