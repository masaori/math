# SageMath Check: 末尾の変数に零を代入すると基本対称式は一つ少ない変数の基本対称式になる

## 対象

**対象ラベル**: `claim_last_variable_zero_elementary_symmetric`

- 実行日: 2026-11-18
- 結果: 全検査通過（PASS 370。$n=0,\dots,5$、$j=0,\dots,n+2$ の総当たり）
- 帰属: 係数環は `QQbar`。多項式環 $\overline{\mathbb Q}[X_{<n}]$ の等号は係数の比較で厳密に判定する。浮動小数点は使わない。
- 読み替え: 変数の無い $\overline{\mathbb Q}[X_{<0}]$ は、係数の族が指数（空写像）一つで決まるので `QQbar` で表す。

## 何を確かめるか

本文の証明の式変形の五つの等号を、各 $(n,j)$ で一行ずつ確かめる。

- 第一の等号: 基本対称式 $\mathrm{es}_{n+1,j}$ の定義。
- 第二の等号: $j$ 元部分集合を、末尾 $n$ を含む $B_1$ と含まない $B_0$ に分ける。
- 第三の等号: $\mathrm{lz}_n$ は和と積を保つ。
- 第四の等号: $\mathrm{lz}_n(X^{(n+1)}_k)=X^{(n)}_k$（$k<n$）、$\mathrm{lz}_n(X^{(n+1)}_n)=0$。
- 第五の等号: $B_1$ の項は零、$B_0$ は $\mathbb N_{<n}$ の $j$ 元部分集合の全体。
- $j=n+1$ では $\mathrm{es}_{n,n+1}=0$（空和）。

有限個の $(n,j)$ の検算であり、普遍量化された主張の証明ではない。
