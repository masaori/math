# 切断・接合位置の局在数による候補選択と候補辺の逆向き

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、$\mathbb{Q}(\zeta_8)$
- 実行: `sage sagemath/check/even-subgraph-orbit-locality-selection/check.sage`
- 状態: PASS（2026-09-03、共変な全候補辺 $6{,}400$ 本）

一辺 $L=2$ の単一の偶部分グラフでは覆えない $16$ ファイバーの、全ての位相反転候補を
保持した共変な候補辺集合について、各候補辺の逆向き辺（終点を始点とする候補辺）の有無、
候補元ごとの一頂点変更（局在頂点数 $1$）の候補の本数、そして一頂点変更の候補が
ちょうど一本の候補元だけにその候補を選ばせる規則が候補辺の両端で一致するかを数えた。
局在頂点数と軌道変化は平行移動で不変なので、この規則は候補が一意に定まる限り
平行移動と可換である。計算は有限集合・有限写像と $\mathbb{Q}(\zeta_8)$ の等号だけで
完結し、浮動小数点は使わない。

全 $6{,}400$ 本の候補辺のうち逆向き辺が集合に含まれるものは $0$ 本であり、候補関係は
完全に反対称だった。候補元 $2{,}624$ 置換の一頂点変更の候補の本数は、$0$ 本が $576$ 個、
$1$ 本が $1{,}280$ 個、$2$ 本が $768$ 個だった。一頂点候補が一意な $1{,}280$ 個のうち、
選んだ先が候補元でない（位相反転候補を一本も持たない置換である）ものが $640$ 個、
選んだ先が候補元だが別の置換を選ぶものが $640$ 個で、互いに選び合う対は $0$ だった。
選んだ先が候補元なのに一頂点候補が一意でない場合は無かった。

従って、一頂点変更の候補を優先する規則だけでは両端の一致する選択にならない。
候補関係が反対称なので、両端の一致は逆向き辺の相互選択ではなく、候補辺 $(\varphi,\psi)$ を
無向対として重複なく選ぶこと（候補元と選ばれた先が他の選ばれた対に現れないこと）として
問う必要がある。次は選んだ先が別の置換を選ぶ $640$ 個の衝突の構造を調べる。
