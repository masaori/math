# 語長二の局在形と語長三の固定非切断項を両立させる

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に限った有限存在判定。
語長一の制約を外し、語長二では切断旗を含む二次単項式だけを許し、語長三では
それに各語位置の上辺所属と左辺所属の積の和を加える。
各語長には独立の係数を許す。語長一を含む他の語長と閉路型の値は自由未知数のままである。
定数項・一次項・他の非切断項は零。語と端点対を別々に正準化し、実頂点の同定を追加しない。
一般の辺長の命題と Lean 二版は未追加。整数・有限体・上流の円分体だけで計算する。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-two-three-fixed-interior/check.sage
```

初回は `--record` を付けて解または左核の矛盾証拠を保存し、通常実行で保存証拠を再判定する。
2026-09-06 初回のプログラミングによる検証: 終了コード 0 で通過。
10,971 行・12,008 未知数で、係数行列と拡大係数行列の階数はともに 10,625。
解を `certificate.json` へ保存し、全 7,085 鍵の値を復元した。
この一解の切断旗を含む積は語長二で 304 項、語長三で 197 項。最小性・一意性は主張しない。
保存証拠による再実行も終了コード 0 で通過し、両階数と全 7,085 鍵の復元を再現した。

LLM による検証: 指定語長は二・三だけで、右辺は二で零、三で固定語位置和である。
既存の語長一・二だけ、語長一・三だけの可解性と、三語長同時の非可解性を合わせると、
三条件は二つずつなら両立し、三つ同時には両立しない。別々の系の解を同じ解とは扱わない。
次は語長一の局在形と語長三の固定項を保ち、語長二には非切断項も含む純二次式を許した単一系の可解性を判定する。
