# 語長三の純二次式から所属の種類ごとに積を除く

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵を対象とする有限探索。語長三の弧型 2,044 種を表す
68 特徴は、二重辺への所属 20 個・単一辺への所属 20 個・選択辺への所属 8 個・
切断旗 20 個である。相異なる二特徴の積だけを許し、定数項・一次項は零とする。
切断旗を含む積 1,150 個は常に残す。含まない積 1,128 個を所属の種類の組で六分し、
一種類だけを全て零に固定する六つの独立した系を作る。
他の語長と閉路型の値は自由に残し、固定した一解の項を削るだけの判定はしない。

| ファイル | プログラミングによる検証の内容 | 状態 |
| --- | --- | --- |
| `check.sage` | 元の系との列の対応、各種類の零固定、階数、可解時の各弧型と全鍵の復元、非可解時の左核証拠 | PASS（2026-09-05 初回・階数を固定した全再実行） |

LLM による検証: 各特徴の意味は既存の弧署名の定義から読み、名前の中の D/E/C 所属を
実際のビット配置と照合した。六つの単独除去は同時除去とは異なる。
一般の辺長の命題と Lean 二版は未追加。計算は整数・有限体と上流の円分体の厳密演算で、浮動小数点は使わない。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-three-quadratic-kind-removal/check.sage
```

可解な五系は、各弧型を残した二次項から評価し、全 7,085 鍵の値を復元した。
非可解な系では、鍵の式 40 本と弧型の式 28 本を足した左核ベクトルについて、
係数側が零、右辺が一になることを照合した。台の番号は実行時に全て出力する。

LLM による検証: この有限集合の純二次式表示では、切断旗を含まない
単一辺所属同士の積を少なくとも一項は残す必要がある。他の五種類は
それぞれ単独では全て除ける。ただし五種類を同時に除けることや、
単一辺所属同士の個別係数の不可欠性は示していない。
次は切断旗を含まない積を単一辺所属同士だけに制限しても足りるかを判定する。
