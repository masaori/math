# SageMath Check: シフト行列と転送行列の可換性

## 対象

**対象ラベル**: `def_shift_matrix` / `claim_shift_matrix_left` /
`claim_shift_matrix_right` / `theorem_shift_matrix_commutes`
（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の定義 1 件
  （「シフト行列」）と主張 2 件・定理 1 件
- 併せて使う定義: `def_row_config_shift` / `claim_row_config_shift_bijective` /
  `def_constant_polynomial` / `def_matrix_over_row_configs` / `def_matrix_product` /
  `def_transfer_matrix` / `claim_transfer_matrix_shift_invariant`

### 何を確定させるための検証か

本文は、行配位の巡回シフト $S$ を成分に書き写した行列
$U_{\tau,\tau'}=\kappa(1)\ (\tau'=S(\tau))$、$\kappa(0)$（それ以外）を定め、
これが転送行列と可換であること $UT=TU$ を示している。
可換性は、次のセクションで転送行列を巡回シフトの固有空間へ分けるための足場である。
この検証は、定義と 3 つの主張を小さい $L$ で総当たりに固定する。

1. `def_shift_matrix`。$U$ の成分が $\kappa(1)$ か $\kappa(0)$ のいずれかであり、
   各行にちょうど 1 つだけ $\kappa(1)$ が現れること（$S$ が写像であることの帰結）。
   あわせて各列にもちょうど 1 つであること（$S$ が全単射であることの帰結）も見る。
2. `claim_shift_matrix_left`。$(UA)_{\tau,\tau''}=A_{S(\tau),\tau''}$。
3. `claim_shift_matrix_right`。$(AU)_{\tau,\tau''}=A_{\tau,S'(\tau'')}$。
4. `theorem_shift_matrix_commutes`。$UT=TU$（全成分の一致）。

2 と 3 は「任意の行列 $A$ について」の主張なので、行列を 3 種類で試している。
転送行列 $T$、成分がすべて異なる $x$ の冪である行列、そして単位行列 $I$ である。
2 種目を入れたのは、$T$ が対称な成分を多く持つため添字の順序を取り違えても値が
変わらない場合があり、$T$ だけでは左右の取り違え（$S$ と $S'$ の取り違えを含む）が
隠れるからである。**行列の全体は無限集合なので、これは標本であって総当たりではない。**

### 主張が空でないことの確認

$U$ が単位行列に一致してしまえば 2・3・4 は自明に成り立つ。そこで次を確かめている。

- $L=2,3,4$ で $U\ne I$ である（$S$ が恒等写像でないこと）。
- $L=3$ で $U$ と可換でない行列が存在する（可換性が転送行列の性質であって、
  $U$ がどんな行列とも可換なわけではないこと）。
- $L=3$ で $T$ の成分が行配位の対によって実際に異なる（$T$ が定数行列なら 4 は自明）。

### 走らせた範囲（打ち切りを隠さない）

| $L$ | 行配位 $\lvert R_L\rvert$ | 見た成分（各行列） | 試した行列 |
|---|---|---|---|
| 1 | 2 | 全 4 通り | 3 種 |
| 2 | 4 | 全 16 通り | 3 種 |
| 3 | 8 | 全 64 通り | 3 種 |
| 4 | 16 | 全 256 通り | 3 種 |

$L\le4$ については成分は**総当たり**である。$L$ の全体は無限集合なので $L$ は 4 つの値に、
行列の全体は無限集合なので $A$ は 3 種に限っている。

### 計算の厳密性

すべて `ZZ` / `ZZ[x]` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの範囲で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。
整数を成分に置く経路は本文と同じく `const_poly`（$\kappa$）だけを通す。
