# 自明文字ファイバーの配向差による類別と類和の構造

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

選択集合が非空で文字が自明な添字 $(D,E)$ について、ファイバーの各置換の
単純通過部分が誘導する $E$ の均衡配向を、ファイバーの辞書式最小置換の配向と
比較する。二つの均衡配向の不一致辺集合は各頂点で偶数次数なので、常に $E$ の
$\mathbb F_2$ 巡回空間の元である（一辺二の全 $18{,}880$ 置換で assert）。

この類別について一辺二で確定したこと。

- 巡回階数 $2$ 以下の $368$ ファイバーでは、類が巡回空間の全
  $2^{|E|-|V(E)|+c(E)}$ 元をちょうど尽くし、四つのスピン構造それぞれで
  各類の位相和が共通値 $\mathcal K^{a,b}_L(D,E)/2^{\text{階数}}\in\{+1,-1\}$
  に等しい（検査 $2{,}944$ 件）。ここでは置換側の位相和がそのまま
  巡回空間の元数の符号付き数え上げになる。
- **例外がちょうど一つある。** $E$ が全 $8$ 辺（$D=\varnothing$、階数 $5$）の
  ファイバーでは、類は誘導された均衡配向 $18$ 個に対応して巡回空間 $32$ 元を
  尽くさず、四つのスピン構造それぞれで位相和が零の類が $16$ 個、
  $\mathcal K^{a,b}_L(D,E)/2$ の類が $2$ 個に分かれる（総和は一致する）。

従って、一般の辺長で置換ファイバーの位相和を巡回空間の符号付き元数へ写す
数え上げは、巡回空間そのものではなく**誘導された均衡配向の類**を単位に組む
必要がある。次の一手は、均衡配向の類ごとの位相和を配向の局所データ
（曲がり・直進の頂点型）で書く一般式の構成である。

- 実行: `sage sagemath/check/trivial-character-fiber-orientation-classes/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
