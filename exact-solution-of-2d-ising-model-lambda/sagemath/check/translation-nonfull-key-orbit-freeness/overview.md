# 非自明文字鍵の対角軌道の自由性

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`
- 住処: 有限集合、GF(2) の線型代数、整数
- 実行: `sage sagemath/check/translation-nonfull-key-orbit-freeness/check.sage`
- 状態: PASS（2026-09-04。一辺三の偶部分グラフ $1{,}024$ 個と鍵 $148{,}033$ 個で実行済み）

鍵 $(D,E)$ の選択文字の非自明性は $E$ だけで決まる。一辺三の偶部分グラフ
（巡回空間の $2^{10}=1{,}024$ 個）を境界行列の核として列挙すると、
非自明な文字を持つものは $346$ 個で、非自明性は対角平行移動 $(1,1)$ と
可換である（軌道上で一定）。対角平行移動で固定される非自明文字の
偶部分グラフは全辺集合 $E_L$ ただ一つなので、全辺鍵 $(\varnothing,E_L)$
以外の非自明文字鍵は全て大きさちょうど $3$ の自由な対角軌道に入る。
鍵の総数は $\sum_{E}2^{18-\lvert E\rvert}=148{,}033$、固定鍵は全辺鍵の
$1$ 個、自由軌道は $49{,}344$ 個である。

従って、全辺鍵以外の非自明文字鍵では $\mathcal U^{a,b}_L(D,E)=0$ が
文字評価から軌道ごとに一括で従い、$\mathcal K^{a,b}_L(D,E)=0$ は
軌道代表 $1$ つでの符号反転完全マッチングを自由作用で運べば軌道全体へ
広がる（位相寄与は平行移動共役で不変。一辺二の全鍵と一辺三の全辺鍵で
既に等号 assert 済み）。残る課題は自由軌道の代表での相殺の構成である。

素数の奇数辺長では全ての非零対角平行移動が同じ部分群を生成するので、
固定鍵の分類は既存の `translation-diagonal-fixed-nontrivial-character`
（$L\le8$）と合わせて $L=5,7$ も覆う。最初の未検査は $L=9$
（真部分群 $(3,3)$ の固定集合）である。浮動小数点は使わない。
