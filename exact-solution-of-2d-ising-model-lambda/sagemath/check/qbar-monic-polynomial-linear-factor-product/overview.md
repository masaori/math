# SageMath Check: 最高次の係数が一の多項式の一次因子への分解

## 対象

**対象ラベル**: `claim_qbar_monic_polynomial_linear_factor_product`

- 実行日: 2026-11-20
- 結果: 全検査通過（PASS 502）
- 帰属: 係数は円分体 $\mathbb{Q}(\zeta_8)$（Sage の `CyclotomicField(8)`）と、$x^3-2$ の $\mathbb{Q}$ 上の分解体（数体）の元。どちらも $\overline{\mathbb{Q}}$ の部分体。根は各数体の中で多項式の根として取る（本文の代数閉性による根の存在の代わり）。浮動小数点は使わない。
- 標本: $1$（$d=0$）、$t-\zeta_8$、$t^2-\sqrt2\,t+1$、$(t^2-2)(t-\frac13)$、$t^4+1$、$(t-1)^3(t+i)$、$u^3-2$、$(u^3-2)(u^2+u+1)$、$(u^3-2)^2$。

## 何を確かめるか

本文の帰納法をそのまま再帰で実行し、各段で次を確かめる。

- 仮定（番号 $d$ より上の係数が零、番号 $d$ の係数が 1）。
- 出発点の式鎖の五つの値の一致（単項式分解、一項の和、$\widehat1\cdot1$、$1$、空積）。
- 一歩: 根 $w$ で $\mathrm{aev}_w(f)=0$、因数定理の商 $g=\sum_{k\le d}\widehat{\mathrm{ac}_k(f)}K_k(w)$ で $f=(t-\widehat w)g$、$g$ の番号 $d$ 以上の係数が零（本文の $d+1$ を $d$ と読んだ段）、先頭の係数の式鎖の三つの等号、帰納法の仮定で得た $\alpha'$ で $g=\prod(t-\widehat{\alpha'(i)})$、結論の式鎖の五つの等号。
- 結論: 根の個数が $d$ で、$f$ が一次因子の積に等しい。
- 対照: 番号 2 の係数が 2 の $2t^2+1$ は、その根の一次因子の積に一致しない。

有限個の標本の検算であり、普遍量化された主張の証明ではない。
