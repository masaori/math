# SageMath Check: 列挙に沿った前錐の増大列は符号の両側を覆う

## 対象

**対象ラベル**: `claim_enumerated_precone_chain_covers_signs`

- 実行日: 2026-11-17
- 結果: (A)〜(D) の全検査が通過
- 帰属: `QQ` 上の二次体 $\mathbb{Q}(s)$（$s\cdot s=2$）の厳密計算。符号は有理数の比較だけで決め、浮動小数点も実数体も使わない。

## 何を確かめるか

本文の証明は帰納法と部分集合の所属だけで閉じ、式変形の行を持たない。そこで、前錐を有限のデータで厳密に表せるモデルで、
列の作り方と三つの結論を確かめる。

- モデル: $F=\mathbb Q$、$C_F=\mathbb Q_{>0}$、$E=\mathbb Q(s)$。$E$ の二つの共役 $\sigma_\pm$ での符号を、$p+q\cdot s$ の $p,q$ の比較で決める。
  空でない $S\subseteq\{+,-\}$ について $T_S$ を「$S$ の各共役で符号が非負な元の集合」とする。
- (A) $T_S$ が前錐で $-1$ を含まないこと（標本 121 個で和・積・平方・正の有理数）。
- (B) $-1\in T_S\langle a\rangle$ と「$S$ の全ての共役で $a$ が負」の同値（証人 $t=0$、$t'=-1/a$ と符号）。
- (C) $a\ne0$ で $S'=\{\sigma\in S\mid \sigma(a)>0\}$ が空でないとき $T_S\langle a\rangle=T_{S'}$（両包含の証人を構成）。
- (D) 標本 121 個を列挙として本文の場合分けで $T_n$ を作り、各 $T_n$ が $-1$ を含まず単調に増え、
  和集合が列挙した全ての $z$ について $z$ か $-z$ を含むこと。

モデルは本文の主張の一例であって証明ではない（無限集合の性質を標本で見ている）。
