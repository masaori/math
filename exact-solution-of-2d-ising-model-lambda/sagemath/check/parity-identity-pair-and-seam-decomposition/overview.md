# 偶奇恒等式の辺対・切断線寄与への分解

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

未ねじれ符号の偶奇恒等式の左辺を、動辺数、内部の有向辺対が作る二つの
並べ替え反転、切断線に触れる有向辺対が作る二つの並べ替え反転、局所位相の
四寄与へ分ける。二つの反転数を有向辺対の指示値の和として
展開するため、残る一般証明で内部寄与と二本の切断線の寄与を別々に扱える。

- 実行: `sage sagemath/check/parity-identity-pair-and-seam-decomposition/check.sage`
- 状態: PASS（2026-09-04。一辺二 $738$ 配向、一辺三 $1{,}522$ 配向、
  二重辺つき一辺三 $660$ 鍵）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
- 失敗記録: 当初は各頂点の局所行列式を正規化すれば個別に $\pm1$ になると仮定したが、
  有限検算が反例を検出した。局所積全体についてのみ定義済みの $q(o)$ を使い、今回の主張を
  二つの並べ替え符号の辺対・切断線分解へ限定した。
