# 単純閉路鍵の局所符号式の一辺三への延長

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二で得た $16$ 項の局所符号式を固定し、一辺三の自明文字を持つ単純閉路
$E$ と、$E$ と互いに素で $1\le |D|\le2$、かつ選択集合が非空である反転対
$D$ の全てへ代入する。これにより、一辺二に固有の重複辺が作った式なのか、
通常の正方格子でも同じ式が頂点項を与えるのかを判定する。

一辺三の対象となる単純閉路は $312$ 個、許される非空反転対との鍵は
$6{,}453$ 件あり、そのうち $3{,}246$ 件で不一致になった。従ってこの式は
一辺二の重複隣接に依存しており、一般辺長の公式としては採用できない。
検算は辞書式最小の反例も出力する。次は一辺二と一辺三を同時に満たす
局所特徴を解く。
