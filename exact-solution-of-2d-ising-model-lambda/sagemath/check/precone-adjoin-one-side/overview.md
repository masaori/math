# SageMath Check: 前錐には元とその符号反転の少なくとも一方を負の単位元を含めずに付け足せる

## 対象

**対象ラベル**: `claim_precone_adjoin_one_side_avoids_minus_one`

- 実行日: 2026-11-17
- 結果: 移項の二式と $-1$ の書き直しの四行が通過し、モデルの標本でも結論が通過
- 帰属: `QQ` 上の多項式環の厳密計算。浮動小数点を使わない。

## 何を確かめるか

- 仮定の二式 $-1=t_1+a\cdot t_2$、$-1=t_3+(-a)\cdot t_4$ が生成するイデアルで、移項の二式を確かめる。
- $-1$ の書き直しの各行を、不定元 $t_1,t_2,t_3,t_4,a$ の多項式の等号として確かめる。
  代入の行だけは、差が仮定のイデアルに属することで確かめる。
- $F=E=\mathbb Q$、$C_F=\mathbb Q_{>0}$、$T=\mathbb Q_{\ge0}$ のモデルで、標本 8 個の $a$ について
  $-1\notin T\langle a\rangle$ または $-1\notin T\langle -a\rangle$ を確かめる。

## 実行方法

```sh
sage check.sage
```
