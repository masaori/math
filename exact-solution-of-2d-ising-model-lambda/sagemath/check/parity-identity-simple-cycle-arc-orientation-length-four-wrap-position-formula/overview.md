# SageMath Check: 位置ビット閉式の語長四判定

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 範囲: 一辺二・三から得た有限合同系に現れる語長四の弧型
- 内容: 同スロットの辺所属積と、二つの内部語位置へ反復した切断旗の八項規則で語長四の値を固定する
- 帰属: 有限集合と $\mathbb F_2$。浮動小数点を使わない

## 結果

2026-09-15 に実行した。有限合同系には弧型 10,098 種があり、そのうち語長四は 2,130 種だった。
語長四の値を候補式へ固定し、他の 7,968 種を自由未知数に残した系では、係数行列の階数が
6,302、拡大係数行列の階数が 6,303 となり、非可解だった。左核の台が五つの鍵の式からなる
矛盾証拠（鍵位置 634、654、670、696、698）について、係数行列との積が零、右辺との積が一であることも厳密に確認した。

したがって、同スロットの辺所属積と、二つの内部語位置へ反復した切断旗の八項規則だけでは、
一辺二・三から得た既存の有限鍵に現れる語長四を同時に書けない。この候補を一般語長の式としては
採用しない。次は五つの鍵の矛盾証拠を比較し、候補が落とした語長四の特徴を切り分ける。
一般の辺長・全語長についての命題ではなく、一般命題と Lean 二版は未追加である。
