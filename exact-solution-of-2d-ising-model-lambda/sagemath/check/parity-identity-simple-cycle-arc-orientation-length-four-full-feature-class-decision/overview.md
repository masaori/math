# SageMath Check: 語長四の一次・二次特徴候補クラス全体の有限判定

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 通過。係数行列と拡大行列の階数はいずれも 6,793 で、全 7,085 鍵を復元した。

## 何を確かめるか

語長四の完全署名をなす 80 個の一次特徴と、同じ特徴どうしも含む二特徴積を合わせた
3,240 単項式を有限候補クラスとする。先行二十特徴以外の 3,220 単項式を一括投入し、
全 7,085 鍵の合同系が可解かを階数で判定する。可解なら行階段形が選ぶ代表を元の合同系へ
再代入し、非可解なら全単項式を相殺する左核矛盾証拠を保存する。

行階段形が選んだ代表の支持は 248 項（一次 10 項、二次 238 項）だった。二次項のうち
237 項は先頭語位置の特徴を一方の因子に持ち、残る一項は第三語位置の切断旗と先頭端点の
切断旗の積である。この偏りは列順に依存する代表の観測であり、一般の語長の公式はまだ
主張しない。係数を含む証拠は `certificate.json` に保存した。

## 実行方法

```sh
sage check.sage
```
