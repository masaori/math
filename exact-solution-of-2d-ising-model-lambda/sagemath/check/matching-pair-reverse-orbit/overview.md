# SageMath Check: 復元した二歩軌道と元の置換の軌道

**対象ラベル**: `claim_matching_pair_reverse_orbit`

要素数 0・2・4・6 の偶数軌道だけを持つ置換を全列挙し、各始点について両包含を確かめる。有限検算は一般証明の代用ではない。

| ファイル | 本文との対応 | ステータス |
|---|---|---|
| `check_forward_closure.sage` | 元の軌道が二つの相手写像と二歩置換で閉じること、合併から軌道への包含 | PASS |
| `check_reverse_closure.sage` | 合併が二つの相手写像と元の置換で閉じること、軌道から合併への包含 | PASS |
| `check.sage` | 二つの包含による集合の等号 | PASS |

整数と有限集合の厳密な演算のみを使う。実数体への脱出はない。
実行日: 2026-10-24。SageMath 10.9 で 1,388 始点について通過。
