# SageMath Check: 偶数の次数の対の個数

## 対象

**対象ラベル**: `claim_pair_count_two_adic_valuation_decrease`

- 実行日: 2026-11-20
- 結果: 全検査通過（PASS 7420）
- 帰属: すべて自然数（Sage の `ZZ` の非負の元）。浮動小数点は使わない。
- 標本: $1\le k\le8$ と $m=j+j+1$（$0\le j<40$）の全ての組。$N$ は仮定 $N+N=d\cdot(d-1)$ を満たす自然数。

## 何を確かめるか

- 準備: $k=(k-1)+1$、$a:=2^{k-1}\cdot m\ge1\cdot1$、$a=b+1$ を満たす自然数 $b$。
- 第一の式鎖の六つの等号（$d=\dots=(b+b+1)+1$）と、$d-1=b+b+1$。
- 第二の式鎖の三つの等号（$m'=m\cdot(d-1)=(j+j+1)(b+b+1)=j'+j'+1$）。
- 第三の式鎖の三つの等号（$N+N=d\cdot(d-1)=(2a)(d-1)=a(d-1)+a(d-1)$）と、倍の消去 $N=a(d-1)$。
- 第四の式鎖の三つの等号（$N=\dots=2^{k-1}\cdot m'$）。
- 対照: $m'$ が奇数であること、$N$ の 2 進付値が $k-1$ であること（Sage の `valuation(2)`）。
- 倍の消去 $x+x=y+y\Rightarrow x=y$ を $0\le x,y<60$ で総当たり。

有限個の標本の検算であり、普遍量化された主張の証明ではない。
