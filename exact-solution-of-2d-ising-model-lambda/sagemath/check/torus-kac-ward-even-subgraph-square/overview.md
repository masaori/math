# SageMath Check: Kac--Ward 行列式は符号付き偶部分グラフ多項式の平方（観察）

**対象ラベル**: `def_kac_ward_determinants`

一辺 $L=2,3$ の周期正方格子で、四つの Kac--Ward 遷移行列から
$\det\bigl(I-x\,M^{a,b}\bigr)$ を円分体 $\mathbb Q(\zeta_8)$ 係数の多項式として厳密に計算し、
全頂点の次数が偶数である台の辺の部分集合（偶部分グラフ）$A$ の切断線偶奇
$(h(A),v(A))$ に符号 $(-1)^{c\,h+d\,v+e\,hv}$（$c,d,e\in\{0,1\}$ の全 8 候補）を付けた
多項式の平方と比較する。

- 実行: `sage sagemath/check/torus-kac-ward-even-subgraph-square/check.sage`
- 状態: PASS（2026-08-30）
- 結果: 四つのスピン構造すべてで、行列式は候補
  $(c,d,e)=(1+a\bmod2,\ 1+b\bmod2,\ 1)$ の平方に一致した。すなわち
  $\det\bigl(I-x\,M^{a,b}\bigr)=\Bigl(\sum_{A}(-1)^{(1+a)h(A)+(1+b)v(A)+h(A)v(A)}x^{|A|}\Bigr)^2$。
  スピン構造 $(0,1)$ と $(1,0)$ では候補 $(0,1,1)$ と $(1,0,1)$ の両方が一致するが、
  これは正方トーラスの軸対称でホモロジー類 $(1,0)$ と $(0,1)$ の類別和が
  多項式として一致するためである。
- 帰結（台帳の論点の決着）: 行列式の置換展開の項（向き付き辺が相異なる非後退閉路の族）の
  うち台の辺を両向きに使うものは、**相殺で消えるのではなく、平方の交差項を担う**。
  したがって両向きの閉歩道を除外する別の分解は不要で、目標は
  「行列式＝符号付き偶部分グラフ多項式の平方」という行列式レベルの恒等式である。
  頂点単純な閉路族への反復分解（済）は、この恒等式の証明で各閉路の回転位相符号を
  確定するために使う。

すべて $\mathbb Q(\zeta_8)$ 係数多項式の厳密計算であり、浮動小数点は使っていない。
