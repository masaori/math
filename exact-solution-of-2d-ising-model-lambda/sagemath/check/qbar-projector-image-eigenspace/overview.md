### 何を確定させるための検証か

シフト行列の固有空間たちが列ベクトルの全体を張ることを示すために、1 の $L$ 乗根 $z$ ごとに
落とす写像 $P_{A,z}(v)=\bigoplus_{k=0}^{L-1}z^{L-k}\odot(A^{k}\cdot v)$ を置いた。
その像が実際に固有空間へ入ること、すなわち $A^{L}=I^{\overline{\mathbb{Q}}}_L$ と $z^{L}=1$ のもとで
$A\cdot P_{A,z}(v)=z\odot P_{A,z}(v)$ であることが、この主張である。
前の主張が「作用が冪の指数を 1 つ進める」ところまでで止まっていたのに対し、ここでは
右辺の添字を 1 つずらし、$j=L$ の項を $k=0$ の項へ巻き戻す。**2 つの仮定を使うのはこの段が初めてである。**

確かめるのは次の 7 で、そのうち 2・3 は人手証明の準備と鎖の段に 1 対 1 で対応する。

1. 添字集合。行配位の全体 $R_L$ が $2^{L}$ 個の元をもつこと。
2. 準備 2（$a_L=a_0$）と準備 3（$z^{L+1}=z$）が仮定のもとで成り立つこと。
3. 鎖の各段（前の主張の右辺 → 添字のずらし $j=k+1$ → $j=L$ の項の分離 →
   準備 2・準備 3 の適用 → $k=0$ の項の復帰 → 分配則で $z$ を外へ出す → $z\odot P$ への戻し）。
4. 主張そのもの。$A\cdot P=z\odot P$ が全成分で一致すること。
5. 主張が空虚でないこと。$P$ が零ベクトルでない例があること。
6. **仮定が効いていること。** $z^{L}=1$ を落とすと破れる例と、$A^{L}=I^{\overline{\mathbb{Q}}}_L$ を
   落とすと破れる例が実際にあること。人手証明が「この段で初めて 2 つの仮定を使う」と書いたことの裏取りである。
7. 応用の形。$A$ をシフト行列の評価 $\mathrm{Ev}_{\xi}(U)$（$U^{L}=I$ を満たす置換行列）に、
   $z$ を 1 の $L$ 乗根に取ったものが、上の 4 で回している場合そのものであること。

### 計算をどこで行っているか（$\overline{\mathbb{Q}}$ の扱い）

代数的数の全体は SageMath の `QQbar`（厳密な代数的数の体）で表した。列ベクトルの成分には
有理数のほか $\sqrt2$・$-\sqrt3$・$\sqrt{-1}$・$\sqrt[3]{5}$ を混ぜ、1 の $L$ 乗根は
`QQbar.zeta(L)` の冪で取った。**浮動小数点は使っていない**。実数体にも複素数体にも入っていない。

## 走らせた範囲

- $L=1,2,3,4$（$R_L$ の元の個数はそれぞれ 2・4・8・16）。
  $A^{L}=I^{\overline{\mathbb{Q}}}_L$ を満たす行列として、行配位の巡回シフトの置換行列 $U$ と、
  $L$ が偶数のときはその $-1$ 倍（$(-U)^{L}=U^{L}=I$）を使った。
  $z$ は 1 の $L$ 乗根の全体、列ベクトルは 3 通り。すべての $\tau\in R_L$ で確かめた。
  成分は添字の番号から決まる規則で選んでいる（乱数を使わないので再現する）。
- 6（仮定が効いていること）は、$z=\sqrt2$（$z^{L}\ne1$）と、$A^{L}\ne I$ となる一般の行列 3 通りで、
  実際に等式が破れることを確かめた。
- 前の主張の検証（`sagemath/check/qbar-projector-action`）が $L=3$ までなのに対し
  $L=4$ まで回せているのは、ここで使う行列が置換行列（成分が 0 と $\pm1$）で、
  冪の厳密計算が軽いためである。
