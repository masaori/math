# 語長一の非切断項を単一辺所属の積へ制限する同時判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に限る有限判定。語長一・二・三の弧型値に同時に条件を課す。
語長一は切断旗を含む 450 項と、単一辺所属の相異なる二ビットの積 66 項だけを許す。
語長二は全 1,540 純二次項、語長三は切断旗を含む 1,150 項と、各語位置の上辺所属と左辺所属の積の和を許す。
定数項・一次項は零。係数は語長ごとに独立な $\mathbb F_2$ の元で、同じ語長の全弧型で共通とする。
弧型値 10,098 個を含む未知数は 13,304 個、鍵の式と追加制約は 12,220 本。
他の語長と閉路型の値は自由未知数のまま残す。

特徴列は既存の `arc_feature_bits` と `arc_feature_names` の順序を使う。
語長一で残す非切断項は語内四方向と両端点各四方向の単一辺所属 12 ビットの全ての二成分積で、同じ位置内には限らない。
語と端点対の既存の正準化を保ち、実頂点の同定は追加しない。
一般サイズの命題と Lean 二版は未追加。整数・有限体・上流の円分体で厳密に計算する。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-one-single-membership-joint/check.sage
```

初回は `--record` を付けて解または左核の矛盾証拠を保存し、通常実行で再構成した系と保存証拠を判定する。
構成とは独立に固定ビット位置から許す項を選び、全制約行・右辺・鍵の式の保存を照合する。
2026-09-06 の初回のプログラミングによる検証: 終了コード 0。語長一の非切断項を単一辺所属どうしの積 66 項だけへ制限し、語長二の純二次式と語長三の固定項を保つ系は、12,220 行・13,304 未知数、両階数 11,836 で可解となり、全 7,085 鍵を復元した。
13,304 成分の解を certificate.json へ保存した。一解の語長一の二次項は154項（切断旗あり144・なし10）、語長二は411項（切断旗あり267・なし144）、語長三は切断旗を含む372項と固定項。項数の最小性は主張しない。
LLM による検証: 語長一の非切断項について、単一辺所属以外の五種類を同時に除いても、他の二語長の条件と両立するという有限範囲の十分性である。一般命題と Lean 二版は未追加。
次は語長一・二の両方の非切断項を単一辺所属どうしの積だけへ制限し、語長三の固定項を保った系の可解性を同じ有限鍵集合で判定する。

実行記録: 初回はプロジェクト直下でなくリポジトリ直下からログを指定し、ログディレクトリが無いためシェルが終了コード 1 で停止した。SageMath は開始していない。プロジェクト直下で同じコマンドを再実行した。

保存証拠を含む再実行のプログラミングによる検証も終了コード 0 で通過し、両階数 11,836 と全 7,085 鍵の復元を再現した。本文一括検査・PDF・527 検算の対応・構成分離、Lean 全体ビルドと登録 1,635 定理の未証明依存のプログラミングによる検証も通過した。
