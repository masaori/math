# 非共有端点対の相対座標分類と軌道合計の偶奇

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

有向辺対の反転指示値の和は二つの有向辺だけで決まる関数なので、端点を
共有しない対を相対座標の類（二辺の種類・向きと位置の差ベクトル
mod $L$）で分類した。各類はちょうど一つの対角平行移動軌道である。

- 寄与は対の順序交換で不変だが、**類の上で一定ではない**（混在する類が
  一辺三で $28$、一辺七で $268$）。従って相対座標だけによる対ごとの
  直接対応は組めない。
- 平行移動不変量は**軌道合計の偶奇**である。辺長が偶数（$L=2,4,6$）では
  全ての類で偶になり、辺長が奇数（$L=3,5,7$）では奇の類が
  $20,\ 80,\ 172$ 個現れる。
- 奇数辺長の奇の類は、水平と垂直の混合対か、同じ列内の逆向き垂直対に
  限る。同種で同じ向きの辺対の類は全て偶である。
- 全配置が寄与する類は、辺長 $3$ 以上では同じ列の逆向き垂直対
  （相対座標 $(0,j)$、$j\neq 0$）にちょうど一致する。辺長 $2$ だけは
  対角位置の同じ向きの垂直対二類も全配置で寄与する。

この検査は全有向辺対の上での分類であり、恒等式に現れる対（鍵の動辺の
対）への適用は、動辺集合が平行移動不変な場合の軌道和にそのまま効き、
一般の鍵では動辺集合による制限を別に扱う必要がある。

- 実行: `sage sagemath/check/parity-identity-pair-translation-orbit/check.sage`
- 状態: PASS（2026-09-04。$L=2,\dots,7$ の全有向辺対。類の数は
  $12,44,106,172,266,364$）
- 方法: 有限集合と整数の厳密演算のみ。浮動小数点は使わない。
