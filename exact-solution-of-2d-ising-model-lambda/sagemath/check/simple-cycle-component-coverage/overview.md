# プラケット変形成分の単純閉路代表による被覆

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

固定した反転対 $D$ ごとに、許される鍵 $(D,E)$ をプラケット対称差
$E\mapsto E\triangle P$ で結んだ有限グラフの各連結成分について、
単一の単純閉路（全頂点次数 $2$・辺連結成分 $1$）である $E$ を含むかを
全数で検査する。含む場合、その閉路が選択集合の存在条件
$\partial D\subseteq V(E)$（`simple-cycle-selector-existence`）を満たすことも
鍵の定義から確認する。

結果。一辺三（$D=\varnothing$）では四成分の全てが単純閉路代表を含む
（直線合併を含むのは三成分）。一辺二では $324$ 成分中 $287$ 成分が含み、
直線合併を含むのは $108$ 成分、両方を含むのは $71$ 成分、どちらも含まない
成分は無い。単純閉路を含まない $37$ 成分は全て巻き付き偶奇が零で、うち
$27$ 成分は空集合の $E$ を含み、残る $10$ 成分の $E$ は全て辺連結成分二つ
以上である。従って単純閉路の一族だけでは代表系に足りず、直線ループの合併と
合わせた二族で全成分が代表を持つ。

- 実行: `sage sagemath/check/simple-cycle-component-coverage/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
