# SageMath Check: 歩道沿いの内側帯は空でなく辺連結である

**対象ラベル**: `claim_walk_side_interior_band_edge_connected`

原点から始まる長さ $10$ 以下の頂点単純な閉じた非後退単位格子歩をすべて列挙する。
各歩道について、訪問頂点を四隅に持つ内側セルの集合（歩道沿いの内側帯）を
右半直線と縦辺の交差奇偶から直接作り、空でないことと、辺隣接による幅優先探索が
帯全体に到達すること（辺連結性）を検査する。あわせて証明の部品である
各訪問頂点の内側セル集合の非空性と、歩の各辺を挟む二セルのうちちょうど一方が内側で、
それが隣り合う二つの訪問頂点の内側セル集合の共通元になること（橋）も検査する。

- 実行: `sage sagemath/check/walk-side-interior-band-connected/check.sage`
- 状態: PASS（2026-08-31。頂点単純な閉じた非後退歩道 704 本・橋 6,672 箇所・帯セル延べ 2,888 個）
- 計算: 単位格子歩の有限列挙と `ZZ` の比較・加法・奇偶だけ。浮動小数点は使わない。
