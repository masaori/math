# SageMath Check: 次数三以下の二つの矛盾証拠の構造比較

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: 端点だけの支持係数の証拠は上下方向、語位置・端点の支持係数の証拠は左右方向だけからなり、二証拠の有限構造に共有要素は無い
- 帰属: 有限集合と $\mathbb F_2$ 上の有限線形代数。浮動小数点を使わない。

## 何を確かめるか

次数三以下のブール式を一括判定した保存証拠を読み、各証拠が観測行を零へ、対応する標的を一へ送ることを再検算する。次に観測を弧型・巡回軌道・絶対境界方向・相対端点ベクトル・巡回三文字頻度の偶奇へ分解し、二証拠の共有部分を比較する。

## 結果

各証拠は十六個の相異なる観測・弧型・巡回軌道からなる。端点だけの支持係数の証拠では絶対境界方向が上八件・下八件、語位置・端点の支持係数の証拠では左八件・右八件だった。二証拠の観測、弧型、巡回軌道、候補記述、活性原始特徴ベクトルの共有数はいずれも零だった。

従って二証拠の直接の共通部分は無いが、互いに直交する方向対へ同じ八件ずつの分布を持つ。次は正方格子の四分の一回転が上下方向側の十六巡回軌道を左右方向側へ運ぶかを判定する。次数四や新しい原始特徴へは自動的に進まない。
