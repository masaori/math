# SageMath Check: 行列の冪の成分は、道に沿った成分の積の和である

## 対象

**対象ラベル**: `claim_matrix_pow_entry`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「転送行列」の主張
  「行列の冪の成分は、道に沿った成分の積の和である」
- 併せて使う定義: `def_row_configuration` / `def_matrix_over_row_configs` /
  `def_transfer_matrix` / `def_row_walk` / `def_walk_weight`

### 何を確定させるための検証か

1. 両端を指定した道の全体 $W_{L,k}(\tau,\tau'')$ の個数が $(2^L)^{k-1}$ であること
   （`def_row_walk`。道は長さ $k+1$ のタプルで表し、両端が指定されていることも確かめる）。
2. 本文の Step 1（$k=1$ の場合）。道がちょうど 1 つで、その重みが $A_{\tau,\tau''}$ に等しいこと。
3. 主張そのもの。$k=1,2,3$ について、すべての $\tau,\tau''$ で
   $(A^k)_{\tau,\tau''}=\sum_{p\in W_{L,k}(\tau,\tau'')}w_A(p)$ を確かめる。
   左辺は行列の積を $k-1$ 回繰り返して作り（`row_matrix_pow`）、右辺は道を全列挙して
   各道の成分の積を足す（`row_walks` と `walk_weight`）。両者の作り方は独立である。
4. 本文の Step 6・Step 7（帰納法の一歩）。道の延長 $\Phi$ の像が重複なく $W_{L,k+1}(\tau,\tau''')$ を
   尽くすこと、および $w_A(\Phi(\tau'',p))=w_A(p)\,A_{\tau'',\tau'''}$ が成り立つことを、
   $k=1,2$ について確かめる。

行列は 2 種類で試す。第一は転送行列 $T$（本文が実際に使うもの）。第二は成分がすべて異なる
$x$ の冪である行列である。$T$ は対称な成分を多く持つため、添字の順序（行と列）を取り違えても
値が変わらない場合があり、それだけでは誤りが隠れうる。第二の行列では成分 $(a,b)$ ごとに
違う指数を与えているので、順序の取り違えは必ず値の違いとして現れる。

$L=1,2,3$（行配位は $2,4,8$ 個）で総当たりする。

### 計算の厳密性

すべて `ZZ` と `ZZ[x]` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの章で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。

### 表現についての注意

本文は $R_L$ の元そのものを行列の添字に使い、道を写像 $p:\{0,1,\dots,k\}\to R_L$ として書くが、
検証側では行配位を「列番号の順に値を並べたタプル」で表し（`row_config_key`）、道を
その表現を並べた長さ $k+1$ のタプルで表している。前者は本文の $2^L$ 個の元への番号付けにあたり、
後者は写像を値の並びとして書いたものである。いずれも主張の内容には影響しない。

冪の添字は本文と同じ 1 始まりである（`row_matrix_pow(L, A, 1) == A`）。Lean 側だけは再帰が
`0` から始まるため引数を 1 つずらしてあり、その約束は
`lean/Ising2DLambda/TransferMatrix/WeightProduct.lean` の `rowMatrixPow` に書いてある。
