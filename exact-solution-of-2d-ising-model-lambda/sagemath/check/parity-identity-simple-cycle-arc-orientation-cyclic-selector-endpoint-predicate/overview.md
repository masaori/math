# SageMath Check: 切断候補を選ぶ端点ビット述語の反例

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。端点ビットだけから切断候補を選ぶ述語は、観測済み支持上でも
  定義できないことを二つの衝突で確定した。

## 何を確かめるか

語長二以上の支持 781 項について、二端点の全所属・切断旗と、二つの切断候補に
付随する反転正規化前の向き・境界位置・端点順を固定長 51 ビットへ展開する。
同じビット列を持つ候補対が常に同じ順位の候補を選ぶかを比較する。

候補対のビット列は 607 種で、そのうち 2 種は同じ入力に順位 0 と順位 1 の両方を
要求した。従って、次数や式の形にかかわらず、端点ビットだけを入力とする述語は
存在しない。一方、語長を入力へ戻すと 614 種の入力に衝突は無い。これは有限表が
語長を使えば定義できることだけを述べ、一般語長の閉じた規則を与えない。

次は二つの衝突証拠を比較し、語長のどの有限述語が端点ビットに追加で必要かを
切り分ける。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-selector-endpoint-predicate/check.sage
```
