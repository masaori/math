# SageMath Check: 符号の両側を覆う前錐から取り出す正錐

## 対象

**対象ラベル**: `claim_covering_precone_gives_positive_cone_extension`

同じ検証で、前段の `claim_precone_avoiding_minus_one_meets_negation_at_zero`（負の単位元を含まない前錐と
その符号反転の共通部分は零元だけである）も確かめる。

- 実行日: 2026-11-17
- 結果: (A)〜(D) の全検査が通過
- 帰属: `QQ` 上の有理関数体と二次体 $\mathbb{Q}(s)$（$s\cdot s=2$）の厳密計算。符号は有理数の比較だけで決め、浮動小数点も実数体も使わない。

## 何を確かめるか

- (A) 共通部分の主張の $-1$ の書き直しの三行を、有理関数体 $\mathbb{Q}(z)$ の等号として一行ずつ確かめる。
- (B) 延長の主張の和の段（$-a=-a+0=-a+(a+b)=b$、仮定 $a+b=0$ は代入で入れる）と積の段の恒等式の行を確かめる。
- (C) モデル $F=\mathbb Q$、$C_F=\mathbb Q_{>0}$、$E=\mathbb Q(s)$、$T$ を一つの共役での符号が非負な元の集合とする。
  標本 121 個で、$T$ が負の単位元を含まず符号の両側を覆う前錐であること、$T\cap(-T)=\{0\}$、
  $C_E=T\setminus\{0\}$ が和・積で閉じ三分法を満たすこと、$C_E\cap\mathbb Q=\mathbb Q_{>0}$ を確かめる。
- (D) 両方の共役で非負な元の集合（符号の両側を覆わない前錐）では、$s-1$ で三分法が崩れることを確かめる
  （第二の仮定が要ることの例）。

モデルは本文の主張の一例であって証明ではない（無限集合の性質を標本で見ている）。

## 実行方法

```sh
sage check.sage
```
