# SageMath Check: 行配位の辞書式順序は線形順序である

## 対象

**対象ラベル**: `def_row_config_order` / `claim_row_config_order_linear`
（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の定義
  「スピン値の番号と、行配位の辞書式順序」と主張「行配位の辞書式順序は線形順序である」
- 併せて使う定義: `def_spin_index` / `def_row_configuration` / `def_lattice`

### 何を確定させるための検証か

本文は、行列式を書くために添字集合 $R_L$ の上の線形順序を定めている。順序は
「値の異なる列番号のうち最小のもの $k_0$ を取り、そこでのスピン値の番号 $\varepsilon$ を比べる」
という形で定めており、線形順序であること（三分律と推移律）は主張として証明されている。
この検証は、その主張と証明が使う 2 つの準備を、小さい $L$ で総当たりに固定する。

1. `def_row_config_order`。$\tau\ne\tau'$ のとき $k_0(\tau,\tau')$ が定まり、
   $k_0$ の位置で値が異なり（証明の準備の第一）、$k_0$ 未満の位置では値が一致すること
   （証明の準備の第二）。あわせて $k_0$ が対称であることも見る。
2. `claim_row_config_order_linear` の三分律。$\tau\prec\tau'$・$\tau=\tau'$・$\tau'\prec\tau$ の
   うちちょうど 1 つが成り立つこと。行配位の全対（$2^L\times2^L$ 通り）を走る。
3. `claim_row_config_order_linear` の推移律。全 3 つ組（$2^L\times2^L\times2^L$ 通り）を走る。
4. この順序が「行配位を二進法で番号付けたときの番号の大小」と一致すること。
   番号は各位置 $k$ の $\varepsilon$ の値に重み $2^{L-1-k}$ を掛けて足して作っており、
   順序の定義（最初に違う位置を探す）を一切参照していない。すなわち 2 つの比較は作り方が独立である。
   あわせて、番号が $0,\dots,2^L-1$ を一度ずつ取ることも見る。

4 は本文の主張そのものではないが、順序の定義に取り違え（重みの向き、$\varepsilon$ の向き、
最小でなく最大を取る等）があれば必ず食い違う。定義の取り違えは三分律・推移律だけでは
検出できない（誤った向きの定義でも線形順序にはなる）ので、独立な作り方との一致を置いている。

標本を取らず全通りを走る。$L=4$ まで実行しており、3 つ組は $4096$ 通りである。

### 計算の厳密性

すべて `ZZ` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの章で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。

### 表現についての注意

本文は行配位を写像 $\tau:\mathbb{Z}/L\mathbb{Z}\to\{+1,-1\}$ として書くが、検証側では
列番号 $0,\dots,L-1$ を鍵とする辞書で表している。本文の射影
$\pi:\mathbb{Z}\to\mathbb{Z}/L\mathbb{Z}$ は `projection`（`n % L`）、代表を取る写像
$s$ は `representative` にあたる。剰余類を $0,\dots,L-1$ で表しているので `representative` は
恒等だが、本文と同じ名前を置いて $\mathbb{Z}$ と $\mathbb{Z}/L\mathbb{Z}$ の行き来を見えるようにしている。
