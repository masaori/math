# orient_d 署名の解の支持台

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

`parity-identity-simple-cycle-arc-orientation-membership` で、内部頂点を
スロット名順の $E$ 所属（向き）・切断旗・$D$ 所属の組へ圧縮した orient_d
署名は直接衝突なしで合同 $\mathbb F_2$ 線型系に解を持つと確定した。
ここではその解の支持台（値 $1$ を取る弧型の集合）を核ベクトルによる
貪欲な縮約で小さくし、支持台の構造——種別（閉路型か弧型か）・語長の分布・
内部頂点の $D$ 所属や切断旗が関与する割合——を観測して、弧型ごとの値の
閉じた式の候補を絞る。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-arc-orientation-support/check.sage`
- 状態: **PASS**（2026-09-05）。

  | 観測 | 値 |
  | --- | --- |
  | 生の解の支持台の大きさ | $2{,}904$ |
  | 核の次元 | $3{,}299$（$=10{,}098-6{,}799$） |
  | 核ベクトルで縮約した支持台の大きさ | $2{,}519$ |
  | 支持台の種別 | 閉路型 $87$・弧型 $2{,}432$ |
  | 支持台の語長分布（語長, 個数） | $(1,222)$ $(2,447)$ $(3,510)$ $(4,531)$ $(5,256)$ $(6,340)$ $(7,90)$ $(8,123)$ |
  | 内部の $D$ 所属が全て空の型 | $79$ |
  | 切断旗が全て空の型 | $20$ |

  読み方: 縮約しても支持台は $2{,}519$ 弧型と大きく、そのほとんど
  （$2{,}519$ 中 $2{,}440$）が内部頂点の $D$ 所属に、$2{,}499$ が切断旗に
  関与する。従って弧型ごとの値の閉じた式の候補は、向きだけでなく
  $D$ 所属と切断旗の両方に依存する形で立てる必要がある。語長は $1$ から
  $8$ まで全域に分布するので、次は語長の短い支持台弧型（語長 $1$ が
  $222$ 種）から層別して値の規則を読み取る。
  観測は同じ実行の中で assert へ固定した（核基底の順序は決定的なので
  縮約結果も再現する）。固定後の再実行でも一致（PASS）を確認した。

- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
