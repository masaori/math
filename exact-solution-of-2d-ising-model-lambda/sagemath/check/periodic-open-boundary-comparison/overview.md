# SageMath Check: 周期境界と開境界の境界評価

## 対象

**対象ラベル**: `claim_periodic_open_boundary_comparison`

- 実行日: 2026-08-15
- 結果: すべて通過（15 組）
- 帰属: 配位・辺・破れボンド数は有限集合と $\mathbb{N}$、評価点と分配多項式の値は
  $\mathbb{Q}_{>0}$ で厳密に計算した。浮動小数点・`RR`・`CC` は使わない。

## 何を確かめるか

$L\in\{1,2,3\}$、$t\in\{1/3,1/2,1,2,3\}$ の全組について、次を独立に検査する。

- 開境界正方形と周期境界正方形の配位が、同じ $L^2$ 頂点へのスピンの割当として一致する。
- 周期境界にだけある辺が、各向き $L$ 本ずつの合計 $2L$ 本である。
- 周期境界の破れボンド数が、開境界の破れボンド数と境界横断辺の破れ本数との和に等しい。
- 境界横断辺の破れ本数が $0$ 以上 $2L$ 以下である。
- $0<t\le1$ と $1\le t$ のそれぞれについて、本文の上下二つの不等式が成り立つ。

## 検査できないこと（黙って広げない）

有限標本検査は任意の $L$ や任意の正の実数 $t$ についての証明ではない。本文は、配位の
全単射、破れボンド数の分解、正の底の自然数冪の順序、有限和の順序から一般の場合を証明する。
Lean は配位の全単射の具体版（`PeriodicOpenComparison.lean`）まで。破れボンド数の分解、
実数評価の上下評価、必要十分版・導出版は未了である。
