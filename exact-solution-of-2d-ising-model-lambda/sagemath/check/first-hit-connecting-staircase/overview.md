# SageMath Check: 最初に当たる歩数で打ち切った接続階段

**対象ラベル**: `def_first_hit_connecting_staircase`, `claim_first_hit_connecting_staircase_meets_lifts_only_at_ends`

$L=1,2,3$ の非零巻き付きの頂点単純な閉じた非後退辺列について、横断座標が一周期の
最大水準 $K_{\max}$ に等しい持ち上げ点（商 $-2..2$ の窓）を基点に取り、分離条件
$u\,W_{\perp}>K_{\max}-K_{\min}$ を満たす最小の $u$ と $u+1$ の二通りで、
反復回数 $u$ の反復横断階段の最初の当たり歩数 $s_{\mathrm{hit}}$ を求める。
そのうえで、接続階段の頂点がすべて相異なること、$s\ge1$ の頂点が元の周期持ち上げと
交わらないこと、$s<s_{\mathrm{hit}}$ の頂点が移動後の持ち上げと交わらないこと、
$s_{\mathrm{hit}}$ の頂点が移動後の持ち上げに属することを検査する。
持ち上げへの所属判定は有限窓ではなく、周期並進ベクトルによる整数の割り算
（各代表点との差が周期並進ベクトルの整数倍か）で厳密に行う。

- 実行: `sage sagemath/check/first-hit-connecting-staircase/check.sage`
- 状態: PASS（2026-09-01）。非零巻き付きの頂点単純閉路 3,464 本、上端基点 37,680 個、
  接続階段の頂点 236,600 個、持ち上げ所属の厳密判定 510,640 件を検査した。
- 計算: 有限列挙と `ZZ` の除法・四則・順序だけ。浮動小数点は使わない。
