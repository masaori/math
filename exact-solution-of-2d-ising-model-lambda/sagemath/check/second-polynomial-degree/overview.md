# SageMath Check: もう 1 つの不定元の多項式と、その次数・モニック性

## 対象

**対象ラベル**: `def_second_polynomial_ring` / `def_second_constant_embedding` /
`def_second_degree_bound` / `def_second_monic` / `claim_second_degree_sum` /
`claim_second_degree_prod` / `claim_second_monic_prod` / `claim_second_monic_add_lower`
（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の定義 4 件
  （もう 1 つの不定元の多項式・定数として送る写像・次数が $n$ 以下の元の全体・モニックな次数 $n$ の元の全体）
  と主張 4 件（有限和・有限積の次数、モニックな元の有限積、モニックな元に低次の元を足すこと）
- 併せて使う定義: `def_constant_polynomial`（整数から定数多項式を与える写像 $\kappa$）

### 何を確定させるための検証か

本文は、特性多項式を書く場所として $\mathbb{Z}[x]$ を係数環とする $t$ の多項式環 $\mathbb{Z}[x][t]$ を
用意し、次数を写像ではなく上界の条件（$\mathcal{D}_n$）として定め、モニックな次数 $n$ の元の全体
$\mathcal{M}_n$ を定めた。そのうえで、次のセクションで特性多項式の次数を数えるために要る
4 つの性質を示している。この検証はその 4 つと、定義そのものを固定する。

1. `def_second_polynomial_ring`。本文が書いた 2 つの等式
   $\mathrm{cf}_k(f+g)=\mathrm{cf}_k(f)+\mathrm{cf}_k(g)$ と
   $\mathrm{cf}_k(fg)=\sum_{i=0}^{k}\mathrm{cf}_i(f)\,\mathrm{cf}_{k-i}(g)$ が、SageMath 自身の
   多項式環の和と積に対して成り立つこと。本文は 4 主張をこの 2 つの等式だけから導いているので、
   これは前提の確認である（畳み込みの向きの取り違えもここで検出される）。
2. `def_second_constant_embedding`。$\iota$ が和と積を保ち、$\iota(\kappa(0))$ が零元・
   $\iota(\kappa(1))$ が単位元であり、$\iota$ が単射であること。単射性を見るのは、本文が
   $\mathbb{Z}[x]$ の元と $\mathbb{Z}[x][t]$ の元を同じ記号で書かないと約束しているためである
   （$\iota$ を通す経路が情報を落としていないことの確認）。
3. `def_second_degree_bound` / `def_second_monic`。本文の述語（係数で書いたもの）が、SageMath 自身の
   `degree()` / `leading_coefficient()` による判定と一致すること。あわせて $\mathcal{M}_n$ の $n$ が
   一意であること（本文が定義の中で示していること）も見る。
4. `claim_second_degree_sum`。$\mathcal{D}_n$ の元の 2 項和・3 項和が $\mathcal{D}_n$ に属すること。
   空和（零元）が $\mathcal{D}_n$ に属することも見る（帰納法の出発点）。
5. `claim_second_degree_prod`。$\mathcal{D}_m$ と $\mathcal{D}_n$ の元の積が $\mathcal{D}_{m+n}$ に
   属すること。空積（単位元）が $\mathcal{D}_0$ に属することも見る。
6. `claim_second_monic_prod`。$\mathcal{M}_m$ と $\mathcal{M}_n$ の元の積が $\mathcal{M}_{m+n}$ に
   属すること。空積が $\mathcal{M}_0$ に属することも見る。
7. `claim_second_monic_add_lower`。$\mathcal{M}_n$ の元に $\mathcal{D}_{n'}$（$n'<n$）の元を
   足すと $\mathcal{M}_n$ に属すること。

3 を置いたのは、4〜7 だけでは本文の述語が正しく上界を表しているかを確かめられないからである
（$k>n$ を $k\ge n$ と取り違えても、4〜7 の形の主張は通ってしまう）。Sage の `degree()` は
係数の台から計算されており、本文の「$k>n$ のすべての $k$ で係数が $0$」という述語とは
作り方が独立である。

境界も 2 つ見ている。**上界が一般には等号でないこと**（因子が零元のとき次数が落ちる）と、
**7 の仮定 $n'<n$ が空でないこと**（$n'=n$ では $t^2+t^2$ のように最高次の係数が変わり成り立たない）。
前者は 5 が上界の主張であることを、後者は 7 の仮定が余分でないことを検証側でも固定する。

### 走らせた範囲（打ち切りを隠さない）

係数は $\mathbb{Z}[x]$ の 6 元 $\{0,\ \kappa(1),\ \kappa(2),\ x,\ x+1,\ x^2-1\}$ に限る。

| 見るもの | 走らせた範囲 |
|---|---|
| 1（和と積の係数） | 係数 3 元・次数 2 以下の 27 個の全対 × $k=0,\dots,5$ |
| 2（$\iota$） | 係数 6 元の全対 |
| 3（述語と Sage の一致） | $n=0,1,2$ の $\mathcal{D}_n$（6・36・216 個）× 判定する次数 $n'=0,\dots,3$ |
| 4（有限和） | $n=0,1,2$。2 項は全対、3 項は係数 3 元に絞った集合の全 3 つ組 |
| 5（有限積） | $m,n=0,1,2$ の全対。3 項は係数 3 元に絞った集合の全 3 つ組 |
| 6（モニックな有限積） | $m,n=0,1,2$ の $\mathcal{M}$（1・6・36 個）の全対。3 項は係数 3 元 |
| 7（モニック + 低次） | $n=1,2,3$、$n'=0,\dots,n-1$ の全対 |

**これは標本である。** 係数環 $\mathbb{Z}[x]$ も次数も無限にあるので総当たりではない。
係数に $x^2-1$（既約でない元）と $\kappa(2)$（単元でない整数）を入れてあるのは、
主張が零因子の非存在や係数の可逆性に依存していないことを見るためである。

### 計算の厳密性

すべて `ZZ` / `ZZ[x]` / `ZZ[x][t]` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの章で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。

### 表現についての注意

不定元を $\lambda$ と呼ばないのは本文と同じ理由である（$\lambda$ は対数順序群 $\Lambda$ の元を
表す記号として固定してある）。加えて Python では `lambda` が予約語であり、検証側でも使えない。
$\mathrm{cf}_k$ は Sage の添字アクセス `f[k]` で実装し、$\mathcal{D}_n$ の判定は
$k=n+1,\dots,n+7$ の範囲で係数が $0$ であることを見る（扱う元の次数がこの範囲に収まるため。
係数の台が有限であることは Sage の多項式の表現そのものが保証している）。
