# 交差する二つの非可縮一周路を持つ鍵の局所符号反転対合

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`
- 住処: 有限集合、整数、有限積
- 実行: `sage sagemath/check/translation-crossing-cycles-local-involution/check.sage`
- 状態: PASS（2026-09-04。一辺三の実在する全 $1{,}442$ 鍵、全 $5{,}768$ 動辺配向で実行済み）

単純通過辺集合 $E$ を第 $0$ 行の水平非可縮一周路と第 $0$ 列の垂直非可縮一周路の和とした。
$E$ の巻き付き偶奇は $(1,1)$ であり、$E$ に含まれる水平一周路との交差文字は非自明である。
$D$ は $E$ の補集合の任意の部分集合を走らせた。

動辺集合を固定した各頂点の局所非後退全単射について、二本の像を交換して回転数を変えずに
完全対合できる局所方向型を全列挙した。この型は、二本の入方向と二本の出方向が同じ曲がり
二方向である四型に限る。実在する全ての動辺配向にはこの型の頂点がちょうど一つある。
従って、その頂点で二つの局所全単射を交換する操作は、動辺集合と四つのねじれ符号を保ち、
回転位相を保ったまま置換符号だけを反転する不動点のない対合になる。

局所全単射数の有限積により、対象となる置換は $10{,}570{,}752$ 個、対は
$5{,}285{,}376$ 組である。全置換を一件ずつ展開せず、対合する局所因子と残りの局所因子の
積として等号を固定した。浮動小数点は使っていない。

これは自由な対角軌道の代表鍵での相殺を与える一般構成の一つの閉じた場合である。
次に残るのは、任意の非自明文字の偶部分グラフで、同じ局所方向型の頂点が存在する条件を
決めるか、存在しない場合の別の局所対合を構成することである。
