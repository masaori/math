# SageMath Check: 六ビット条件の切断線幾何への引き戻し

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-17
- 結果: 成功。前段の「連結」は方向二本をつなぐ条件だけであり、1,036 入射のうち 385 入射は
  内部語の切断旗から復元した座標列を持たないことを確定した。651 入射は実現可能で、うち
  78 入射は一辺二・三の二通りの切断旗候補を持つが、誤った反対端点だけを返す入射は無かった。

## 何を確かめるか

二つの切断候補がともに方向上連結する 489 項について、各内部語を一辺二または一辺三のトーラスへ
座標として持ち上げる。語の各位置の切断旗と、隣り合う位置を結ぶ出方向の両方に一致する座標列だけを
幾何的に実現可能とする。先頭への入方向または末尾からの出方向へ一辺延長し、反対端点の切断旗を
復元できるかを全境界入射について判定する。

この判定により、方向上は連結していても座標上は実現できない入射が存在する。従って六ビットを
既存の全入射へそのまま幾何的に読み替えることはできない。次は幾何的に実現可能な入射だけで候補記述を
作り直し、選択衝突と必要な端点ビットを再計算する。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-selector-boundary-cut-geometry/check.sage
```
