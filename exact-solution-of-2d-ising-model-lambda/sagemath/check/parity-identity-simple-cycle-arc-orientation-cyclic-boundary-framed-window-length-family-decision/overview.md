# SageMath Check: 境界方向を共通基準にした未評価巡回窓長の一括判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、各実現可能な境界入射候補の
境界方向を上方向へ送る一意な回転を、巡回内部語の全ての連続窓へ共通に
作用させる。既に評価した窓長三より大きく、現有限データの最大内部語長
以下である窓長四から八を有限集合として列挙する。

各窓長について、候補ごとの順序付き窓の出現回数と相対端点 10 成分との
組が、二つの正準巡回支持の係数を決めるかを一括判定する。これは有限データ
上の判定であり、一般の辺長・一般の内部語についての主張ではない。各窓長の
係数衝突の証人は `certificate.json` に保存する。

プログラミングによる検証では、境界基準の順序付き窓は窓長四から八で
47,848、59,704、64,308、65,512、65,676 種へ増えたが、全窓長で
9,739 弧型の分割は 7,427 記述のままだった。端点だけの支持の 220 種、
語位置と端点の支持の 260 種の係数衝突も全て残った。各窓長の分割が
直前の分割を細分することと記述数が増えないことから、窓長三から八までの
分割は一致する。従って境界基準の局所窓頻度候補は有限範囲で成立しない。
