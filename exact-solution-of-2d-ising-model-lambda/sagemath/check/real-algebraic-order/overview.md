# SageMath Check: 実代数的数の順序

## 対象

**対象ラベル**: `claim_rationals_are_real_algebraic`, `claim_neg_one_not_square`,
`def_real_algebraic_order`

- 実行日: 2026-08-14
- 結果: 有限標本検査がすべて通過
- 帰属: `QQ`・`AA`・`QQbar` の厳密計算。浮動小数点を使わない。

## 何を確かめるか

モデル $R=\texttt{AA}$（Sage の実代数的数体）で、本文の 3 ブロックに対応する計算を
有限標本で確かめる。普遍量化された主張そのものの証明は本文の人手証明（と今後の Lean）が
担い、この検査だけからは導かない。

- 有理数の所属（`claim_rationals_are_real_algebraic`）: 有理数サンプル 8 点
  （零・正・負、整数・非整数）について、本文の証明の段どおりに
  「1 の加算の繰り返し（自然数の帰納）→ 加法逆元（整数）→ 乗法逆元と乗法（有理数）」で
  $q=k\cdot n^{-1}$ を `AA` の中に再構成し、`AA(q)`・`QQbar(q)` と同じ元であること
- $-1$ は非零元の平方でない（`claim_neg_one_not_square`）: 非零サンプル 7 点で
  $w\cdot w\ne-1$、あわせて $x^2+1$ が `AA` に根を持たないこと
- 順序の三分法（`def_real_algebraic_order`）: サンプル 8 点の全対 64 組について、
  $z:=b-a$ が「$z=0$」「$z=w^2$（$w\ne0$）」「$-z=w^2$（$w\ne0$）」のちょうど 1 つを
  満たすこと（厳密平方根で $w$ を構成）、および定義の $<_R$ がこのモデルで `AA` の
  組み込みの厳密順序と一致すること

## 範囲の注記（黙って狭めない）

サンプルは次数 2 以下の実代数的数に限る（`AA` の厳密比較・厳密平方根は次数が高いと
exactify の資源上限に当たるため。`real-closed-subfield` の検査と同じ理由）。
検査の内容自体は緩めていない。`AA`・`QQbar` の等号・順序比較は厳密であり、
数値近似を経由しない。
