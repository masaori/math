# SageMath Check: セクター多項式の値の双対関係

## 対象

**対象ラベル**: `claim_sector_value_duality`

- 実行日: 2026-08-14
- 結果: $L=1,2,3$ × 有理点 6 個 × 4 セクターすべて通過
- 帰属: 有限集合、`ZZ[x]`、`QQ` の厳密計算。浮動小数点を使わない。

## 何を確かめるか

主張 $H^{a,b}_L(q)=(1+q)^{2L^2}\cdot G^{a,b}_L(\mathrm{KW}(q))$
（`claim_sector_value_duality`。$q\in\mathbb{Q}_{(0,1)}$、$a,b\in\{0,1\}$）について、
証明の各段を一段ずつ確かめる。

- 準備: 各偶部分グラフ $A$ の指数 $2L^2-|A|$ と $|A|$ が自然数であること、
  $1+q\ne0$、$\mathrm{KW}(q)\in\mathbb{Q}_{(0,1)}$（前セクションとの整合）、
  $(1+q)\cdot\mathrm{KW}(q)=1-q$
- 主張の等式: $H^{a,b}_L$ と $G^{a,b}_L$ を偶部分グラフの数え上げで独立に構成し、
  $q$ と $\mathrm{KW}(q)$ での値を `QQ` で比較する
- 項単位の検査（式変形の中間 3 行に対応。$q=1/2$）: 各偶部分グラフの重みについて
  $(1-q)^{|A|}=((1+q)\cdot\mathrm{KW}(q))^{|A|}$、積の冪は冪の積、
  冪の指数法則 $(2L^2-|A|)+|A|=2L^2$ を一段ずつ確かめる

検査点は $q\in\{1/2,\ 1/3,\ 2/5,\ 3/7,\ 9/10,\ 1/40\}\subset\mathbb{Q}_{(0,1)}$ である。
`QQ` の等号・順序比較は厳密であり、数値近似を経由しない。
