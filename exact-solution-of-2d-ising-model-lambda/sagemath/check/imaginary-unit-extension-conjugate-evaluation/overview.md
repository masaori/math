# SageMath Check: 虚数単位を足した体の共役は多項式の値と入れ替わる

## 対象

**対象ラベル**: `claim_imaginary_unit_extension_conjugate_evaluation`

- 実行日: 2026-11-20
- 結果: 全検査通過（PASS 513）
- 帰属: 準備の恒等式は整係数多項式環 `ZZ[a,b,c,e,w]`（`ω·ω=-1` を使う段は差が `w*w+1` の倍数であること）、標本は `QQbar` の厳密な元。浮動小数点は使わない。
- 標本: $F=\mathbb{Q}(\sqrt2)$（$\overline{\mathbb{Q}}$ の実の正の元が正錐を与える）、$\omega=i$。係数と $z$ は $F$ の元六つの対から作り、次数四以下の多項式四十個を調べる。

## 何を確かめるか

- 準備 (二) 和の共役、(三) 積の共役、(四) 共役の共役の式鎖の各行（文字係数の恒等式として）。
- 標本ごとに、準備 (五) $\mathrm{cj}_\omega(z^k)=\mathrm{cj}_\omega(z)^k$、所属の三行の式鎖、主張の七行の式鎖の各等号。
- $\mathrm{cjp}_\omega(g)$ を $g$ に替えると等号が崩れる例（$g=(1+i)t+1$、$z=i$）。主張を弱めていないことの確認。

有限個の標本の検算であり、普遍量化された主張の証明ではない。
