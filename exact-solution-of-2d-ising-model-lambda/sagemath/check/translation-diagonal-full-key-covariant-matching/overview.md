# 一辺三の全辺鍵ファイバーの対角共変な位相反転完全マッチング

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限群作用、$\mathbb Q(\zeta_8)$、自然数
- 実行: `sage sagemath/check/translation-diagonal-full-key-covariant-matching/check.sage`
- 状態: PASS（2026-09-03。約 2 分 36 秒。全数値を等号 assert で固定して実行済み）

一辺三の全辺鍵ファイバー $75{,}776$ 置換を対角平行移動で軌道分解する。
固定置換 $80$ 個には前段で構成した位相ベクトルの直接対 $40$ 対を使う。
残る置換は大きさ $3$ の自由軌道に分け、位相ベクトルが反対の二軌道を
整列順に対にして、代表上の対を対角平行移動で軌道全体へ運ぶ。

検査では、全置換を一度ずつ覆うこと、各対が四つのスピン構造で位相を反転すること、
対の集合が対角平行移動で不変であること、四位相和が全て零になることを等号 assert で固定する。

結果として固定点は $80$ 個、自由軌道は $25{,}232$ 個だった。自由軌道の位相ベクトルは
$v_0=(1,-1,-1,1)$ と $-v_0$ の二値で、各 $12{,}616$ 軌道だった。固定点の直接対
$40$ 対と自由軌道の対 $12{,}616$ 組から、全置換を覆う $37{,}888$ 対を構成した。
全対は位相を反転し、対角平行移動で対の集合を保ち、四位相和は $(0,0,0,0)$ になった。

従って、一辺三の全辺鍵ファイバーでは、固定点の直接対と自由軌道の運搬を合成すれば
対角共変な位相反転完全マッチングが存在する。これは頂点組み替え候補だけに限定しない
相殺であり、一般の奇数辺長へ同じ軌道分解を持ち上げられるかが次の判定対象である。
