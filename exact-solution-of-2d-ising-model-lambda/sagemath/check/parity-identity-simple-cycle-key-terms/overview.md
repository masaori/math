# 単純閉路の鍵の四項を方向列統計の F_2 線型結合で解く

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

$E$ が単一の単純閉路（全頂点の次数が $2$ で辺連結成分が $1$）である鍵 $(D,E)$ の全て
（一辺二 $320$ 鍵・一辺三 $312$ 鍵）について、標準形配向での四項
（動辺数・頂点項・非共有端点対項・標的指数）を計算し、閉路の方向列から機械的に
読める統計（定数・$|E|$・水平辺数・垂直辺数・巻き付き偶奇二つとその積・角の個数の半分・
行 $0$ と列 $0$ の角の個数・$|D|$・選択文字対の項）の $\mathbb F_2$ 線型結合として
各項が書けるかを厳密な線型方程式で解いた。

- 一辺三（$D=\varnothing$）では四項の全てが書け、角の統計は不要で、per-key の明示式
  「動辺数 $=|E|$、頂点項 $=1+|E|+\varepsilon_{\mathrm h}\varepsilon_{\mathrm v}$、
  対項 $=1+|E|$、標的指数 $=|E|+\varepsilon_{\mathrm h}\varepsilon_{\mathrm v}$」
  （すべて mod $2$）が全 $312$ 鍵で成り立つ。
- 一辺二では動辺数（常に $0$）と標的指数（既知の閉形式）は書けるが、
  頂点項と非共有端点対項は候補統計の線型結合では書けない。$D$ が動くため、
  $|D|$ と選択文字対の項だけでは $D$ と閉路の相対配置の情報が足りない。

従って、単純閉路代表での恒等式の評価は、$D=\varnothing$ の側では方向列統計だけで
閉じる見込みがあり、$D\neq\varnothing$ の側では $D$ と閉路の相対配置を読む統計の
追加が要る。次は一般の辺長で $D$ に適合する単純閉路代表の存在条件を記述する。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-key-terms/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
