# SageMath Check: 接続階段の周期並進による単純閉路

**対象ラベル**: `def_periodic_lift_closure_cycle`, `claim_periodic_lift_closure_is_simple_cycle`

$L=1,2,3$ の非零巻き付きの頂点単純な閉じた非後退辺列について、周期数 $c=1,2$ の
それぞれで、最初の交点で打ち切った接続階段、移動後の周期持ち上げの $c$ 周期分、
接続階段の $c$ 周期並進の逆向き、元の周期持ち上げの $c$ 周期分の逆向きを本文の
定義どおりに合成する。合成列が閉じること、全ての連続差が単位格子ベクトルである
こと、終点を除く全頂点が二つずつ相異なることを `ZZ` 上で検査する。
