# SageMath Check: 接続階段の周期並進による単純閉路

**対象ラベル**: `def_periodic_lift_closure_cycle`, `claim_periodic_lift_closure_is_simple_cycle`

$L=1,2,3$ の非零巻き付きの頂点単純な閉じた非後退辺列について、最初の交点で
打ち切った接続階段、移動後の周期持ち上げの一周期分、接続階段の一周期並進の逆向き、
元の周期持ち上げの一周期分の逆向きを本文の定義どおりに合成する。合成列が閉じること、
全ての連続差が単位格子ベクトルであること、終点を除く全頂点が二つずつ相異なることを
`ZZ` 上で検査する。

- 実行: `sage sagemath/check/periodic-lift-closure-cycle/check.sage`
- 状態: PASS（2026-09-01）。非零巻き付きの頂点単純閉路 3,464 本、閉包 75,360 本、
  閉包の頂点 1,490,960 個を検査した。
- 計算: 有限全列挙と `ZZ` の除法・四則・順序だけ。浮動小数点は使わない。
