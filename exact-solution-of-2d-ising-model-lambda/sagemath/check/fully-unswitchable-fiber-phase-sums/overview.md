# SageMath Check: 三分類の部分和はファイバー単位では選択和に一致しない

**対象ラベル**: `claim_weighted_path_reversal_selection_orbit_sums`, `claim_fully_unswitchable_contacts_witness_doubled_edges`

一辺 $L=2$ の全ファイバー $(D,E)$ と四つのスピン構造 $(a,b)$ について、ファイバー位相和を
順序に依らない三分類（接触なし・切り替え可能対あり・全対切り替え不能）ごとの部分和
$S_Z, S_X, S_Y$ へ分け、選択和 $U$ と比較する。$D$ を縮約する帰納の設計を決めるための観察であり、
各部分和がファイバー単位で零（または $U$）になるなら固定ファイバー内の対合で足りるが、
ならないならファイバーを跨ぐ構成が必要になる。

- 実行: `sage sagemath/check/fully-unswitchable-fiber-phase-sums/check.sage`
- 状態: PASS（2026-09-02）
- 方法: 有限集合の数え上げと $\mathbb Q(\zeta_8)$ の等号だけ。浮動小数点は使わない。
- 結果: 全 $609$ ファイバー×四スピン構造の $2{,}436$ 組で $S_Z+S_X+S_Y=U$ は成立した
  （既知のファイバー一致の三分類分解）。一方、$S_X\ne0$ が $736$ 組、$S_Y\ne0$ が $648$ 組、
  $S_Z\ne U$ が $1{,}384$ 組あった。$S_Y\ne0$ の最初の例は $D=\{v(0,1)\}$、
  $E=\{h(0,1),h(1,1),v(0,0),v(1,1)\}$、$(a,b)=(0,0)$ で $S_Y=-2$ である。
- 帰結: 切り替え可能部分も全対切り替え不能な残余も、各部分を保つ固定ファイバー内の
  符号反転対合だけでは消えない。ただし既存の切り替え平滑化は $D,E$ を保つので、この観察だけから
  異なるファイバーを結ぶ縮約帰納の存在は従わない。別の縮約操作または和の関係を構成する必要がある。
