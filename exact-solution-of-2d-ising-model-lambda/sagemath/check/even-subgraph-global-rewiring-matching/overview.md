# 置換ごとに偶部分グラフを選ぶ大域的組み替えの完全マッチング

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、整数、$\mathbb{Q}(\zeta_8)$
- 実行: `sage sagemath/check/even-subgraph-global-rewiring-matching/check.sage`
- 状態: PASS（2026-09-03、非自明文字の 64 ファイバー・置換 5,248 個すべてを 2,624 対へ完全マッチング）

一辺 $L=2$ の巻き付き文字が非自明な各ファイバーで、偶部分グラフに沿う頂点組み替え候補のうち、
四スピン構造すべてで位相寄与を反転するものを辺とする二部グラフを作る。置換ごとに使う
偶部分グラフを変えてよいとき、このグラフに完全マッチングが存在するかを厳密に検査する。

完全マッチングがあれば候補を大域的な符号反転対合へまとめられる。存在しなければ、固定した
偶部分グラフだけでなく、置換ごとに選ぶこの候補族全体でも消滅の構成には足りない。

全 64 ファイバーで完全マッチングが存在した。従って一辺二では、固定した偶部分グラフに
対する一様作用は存在しなくても、置換ごとに使う偶部分グラフと頂点組み替えを選べば、
四スピン構造に共通する符号反転対合を構成できる。
