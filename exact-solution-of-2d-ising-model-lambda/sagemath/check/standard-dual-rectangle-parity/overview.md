# 偶数次数から得る標準双対路の長方形の辺偶奇

**対象ラベル**: `claim_standard_dual_rectangle_parity`

各頂点で四辺の通過和が偶数という仮定の下、長方形を一列ずつ延ばしたときの式を検査する。辺長二の全二値割当と、辺長三・四の固定乱数種による割当を調べる。仮定を満たす場合のみ判定し、閉歩道から仮定を導く部分は対象外とする。

- 実行: `sage sagemath/check/standard-dual-rectangle-parity/check.sage`
- 状態: PASS（2026-11-05。有限場合 18,473 件）
- 計算: 整数の有限和と二で割った余りだけを使用する。
