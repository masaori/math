# 代数的数の全体は自然数で列挙できる

**対象ラベル**: `claim_algebraic_numbers_enumeration`

本文の段は、整数対による有理係数多項式の可算性、各多項式の有限根集合、根集合による全体の被覆、自然数からの全射である。SageMath は六つの整係数多項式（有理係数多項式の部分集合）について、根の個数が次数以下であることと、根を有限列へ並べられることを厳密計算で確かめる。無限個の多項式への一般化は有限計算では検証しない。

実行: `sage sagemath/check/algebraic-numbers-enumeration/check.sage`

状態: 2026-11-17 実行成功。六つの整係数多項式について、根の有限性と有限列挙を厳密計算で確認した。
