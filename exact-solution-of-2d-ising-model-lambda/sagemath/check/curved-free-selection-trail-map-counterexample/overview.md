# 曲がり型なし配向の局所選択のトレイル台写像の反例

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

重み $2^{s(o)}$ の局所選択展開（曲がり型なし均衡配向 $o$ と直進型頂点の
部分集合 $S$ の対）を選択集合へ写す候補として、次のトレイル台写像を検査した。
$E$ の各辺を $o$ の向きに向け、次数 $2$ の頂点では一意の出辺へ、直進型頂点
では $S$ に属せば左折・属さなければ右折の出辺へつなぐと $E$ は閉トレイルへ
分割される。辞書式最小の辺を向き $0$ で通るトレイルの台の合併を
$C(o,S)$ とする。

一辺二の自明文字・選択非空の全 $369$ ファイバーで固定した事実:

- $C(o,S)$ は常に $E$ の $\mathbb F_2$ 巡回空間の元である（全 $768$ 対）。
- 直進型頂点を持たない階数 $2$ 以下の全 $368$ ファイバーでは全単射になる
  （$E$ はサイクルの直和で、トレイルは成分、$C$ は成分の向きの符号化）。
- 全辺・階数 $5$ のファイバーでは全単射に届かない。$S$ の元数が奇数だと
  $E$ 全体が $1$ 本のトレイルになり $C$ が空集合または $E$ へ潰れる
  （$8$ 対 $1$ の衝突が $2$ つ）。偶数なら $2$ 本に割れて像は相異なる。
  像は $18$ 個で $32$ に届かない。

従ってトレイル台の合併は左右選択の奇偶を保存せず、一般の全単射としては
採用できない。一般の構成は、選択の情報を辺集合へ落とす前に保つ別の対応を要する。

- 実行: `sage sagemath/check/curved-free-selection-trail-map-counterexample/check.sage`
- 状態: PASS（2026-09-04。反例の固定であり、候補写像の否定的結果の記録）
- 方法: 有限集合、$\mathbb F_2$、整数の厳密演算のみ。浮動小数点は使わない。
