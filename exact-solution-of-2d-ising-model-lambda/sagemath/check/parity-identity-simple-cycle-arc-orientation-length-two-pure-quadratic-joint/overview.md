# 語長二に純二次式を許し、語長一の局在形と語長三の固定項を保つ

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に限った有限存在判定。
語長一は切断旗を含む二成分の積だけ、語長二は相異なる二成分の積を全て許し、
語長三は切断旗を含む積に各語位置の上辺所属と左辺所属の積の和を加える。
各語長の係数は独立で、定数項と一次項は零。他の語長と閉路型の値は自由未知数。
語と端点対を別々に正準化する既存署名を保つ。実頂点の同定は追加しない。
一般命題と Lean 二版は未追加。整数・有限体・上流の円分体の厳密計算だけを使う。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-two-pure-quadratic-joint/check.sage
```

初回のみ `--record` を付け、解または左核の矛盾証拠を保存する。
通常実行は系を再構成し、階数と保存証拠を再判定する。
2026-09-06 初回のプログラミングによる検証: 終了コード 0 で通過。
12,220 行・13,238 未知数で、係数行列の階数は 11,826、拡大階数は 11,827 だった。
鍵の式 1,003 本と追加制約 2,094 本による左核の矛盾証拠を `certificate.json` に保存した。
その行を足すと左辺が零、右辺が一になる。証拠の台の最小性は主張しない。
保存証拠を含む全再実行も終了コード 0 で通過し、両階数と左核の矛盾を再現した。

LLM による検証: 非可解性は三語長の同時制約に対する結論であり、語長二単独の二次式を否定しない。
語長一の局在形と語長三の固定項を保つ限り、語長二の非切断項を全て許しても足りない。
次は語長三の固定項を保ち、語長一・二の両方に全ての純二次項を許した系を判定する。
