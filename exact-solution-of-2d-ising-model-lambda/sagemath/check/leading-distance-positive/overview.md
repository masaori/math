# SageMath Check: 先頭距離は正である

**対象ラベル**: `claim_leading_distance_positive`

一辺 $L=2$ の分配多項式を $\mathbb Z[x]$ で厳密に作り、その全 Fisher 零点を
`QQbar` で取る。$s^2=2$ の二根ごとに、各零点の臨界点への距離の二乗を
`AA` の二平方和として計算し、零でないことと正であることを確認する。さらに有限集合の最小値
$d_1(L)$ が零でなく正であることを確認する。二平方和が `AA` 内の零でない元の平方に書ける段は、
単純な厳密標本 $u=2/3,v=1/3$ で独立に確認する。
浮動小数点は使わない。

```sh
sage sagemath/check/leading-distance-positive/check.sage
```

**2026-08-18 実行: 16 個の零点と 2 個の先頭距離、および平方表示の厳密標本がすべて通過。**
