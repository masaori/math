# SageMath Check: 辺の行ごとの分割と、破れボンド数の行内・行間への分解

## 対象

**対象ラベル**: `claim_edge_row_partition`, `claim_broken_bond_row_decomposition`
（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「転送行列」の主張
  「辺の集合は行ごとに分割される」「破れボンド数は行内の破れと行間の破れに分かれる」
- 併せて使う定義: `def_lattice` / `def_configuration` / `def_broken_bond_count` /
  `def_row_configuration` / `def_row_restriction` /
  `def_intra_row_broken_count` / `def_inter_row_broken_count`

### 何を確定させるための検証か

1. 各行の辺の番号の集合 $E_{L,\mathrm{h},i}$ と $E_{L,\mathrm{v},i}$ について、番号付けの写像
   $j\mapsto iL+j+1$（縦向きは $L^2$ を足したもの）が $\{0,\dots,L-1\}$ からの全単射であること、
   本数が $L$ であること、
   異なる行どうしが互いに素であること、合併が $E_{L,\mathrm{h}}$ / $E_{L,\mathrm{v}}$ に一致すること、
   そして端点が番号から直接読める形（本文の 4 つめ）と一致することを確かめる。
   端点の比較相手は `def_lattice` の定義そのままの `endpoints` なので、作り方は独立である。
2. すべての配位について
   $b(\sigma)=\sum_i b_{\mathrm{h}}(\rho_i(\sigma))+\sum_i b_{\mathrm{v}}(\rho_i(\sigma),\rho_{i+1}(\sigma))$
   を確かめる。左辺は辺の番号を $1$ から $2L^2$ まで全部走って数えたもの、右辺は配位を各行へ
   制限してから行内・行間を別々に数えたものであり、両者の作り方は独立である。
3. 行配位の個数が $2^L$ であること、および配位の各行への制限がすべて行配位として現れること
   （$\rho_i$ の値が $R_L$ に入っていること）。

$L=1,2,3$ で全配位を総当たりする（配位の個数は $2$, $16$, $512$）。

### 計算の厳密性

すべて `ZZ` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの章で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。

```

```

$L=1$ は縮退した場合であり、横向きの辺も縦向きの辺も両端が同じ頂点になる。
このとき破れは起こらないので両辺とも $0$ になる。本文の主張はこの場合も含めて成り立つ。
$L=2$ では横向きの 2 本が同じ 2 点を結ぶが、辺を番号で区別しているので数え落としは起きない
（`def_lattice` の但し書きと同じ理由）。
