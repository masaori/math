# SageMath Check: 行列の冪の作用は、作用を反復したものである

## 対象

**対象ラベル**: `claim_qbar_action_pow`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の主張 1 件
- 併せて引く定義: `def_qbar_matrix_power`（代数的数を成分とする行列の冪）・
  `def_qbar_action_iterate`（作用の反復）・`def_qbar_matrix`・`def_qbar_vector`・
  `def_qbar_matrix_action`・`def_qbar_matrix_product`・`def_qbar_identity_matrix`

### 何を確定させるための検証か

シフト行列の固有値が 1 の $L$ 乗根であることは、固有ベクトルへ $U$ を $L$ 回作用させ、
$U^{L}=I$ で恒等作用へ戻すことで出る。そのためには「行列の冪の作用」と「作用の反復」が
同じものであることが要る。ここではその一歩だけを確かめる。

確かめるのは次の 7 で、そのうち 3・4 は人手証明の 2 つの鎖の段に 1 対 1 で対応する。

1. 添字集合。行配位の全体 $R_L$ が $2^{L}$ 個の元をもつこと。
2. 冪と作用の反復が定義どおりに作られていること（再帰の 2 式）。
3. 出発点（$k=0$）の鎖の 3 段（冪の定義・単位行列の作用・作用の反復の定義）。
4. 一歩（$k\to k+1$）の鎖の 4 段（冪の定義・積の作用・帰納法の仮定・作用の反復の定義）。
5. 主張そのもの。$A^{k}\cdot v=\mathrm{it}^{[k]}_{A}(v)$ が写像の等号として成り立つこと。
6. 主張が空虚でないこと。取っている $v$ は零ベクトルでなく、$A^{k}\cdot v$ の値は
   $k$ ごとに相異なる（反復が実際に動いている）。
7. 使っている性質。成分を非可換環（2 次上三角行列の環）に取っても主張が成り立つこと
   （証明が積の可換性を使っていないこと）。あわせて、冪の一歩を右から掛ける形
   （$A^{k+1}:=A^{k}A$）に変えても同じ行列になることを確かめた。同じ行列の冪どうしは
   成分が非可換でも可換なので、値は変わらない。**左から掛ける約束が効いているのは
   証明の形の側だけである**（一歩で外す因子が左になり、`claim_qbar_action_product` を
   そのまま当てられる）。

## 走らせた範囲

$L=1,2,3$、$k=0,\dots,4$（$R_L$ の全成分）。非可換環の側も同じ範囲。
$L\ge4$ や大きい $k$ を回していないのは、この計算が $L$ にも $k$ にも依存せず
新しい場合が現れないためである（帰納法の一歩は $k$ に依らない同じ 4 段であり、
$L$ は添字集合の大きさを変えるだけである）。

## 計算の厳密性

代数的数の全体は `QQbar`（厳密な代数的数の体）で表し、浮動小数点は使っていない。
非可換環の側は `MatrixSpace(QQ, 2, 2)` の元で、こちらも厳密である。
実数体・複素数体は使っていない。

## 実行

```sh
sage sagemath/check/qbar-action-pow/check.sage
```

## 結果

**2026-08-10 実行: すべて成立。**

```
L = 1 : A^k·v = it^[k](v) を k = 0,...,4 で確認（鎖の 3 段と 4 段も一致）
L = 2 : A^k·v = it^[k](v) を k = 0,...,4 で確認（鎖の 3 段と 4 段も一致）
L = 3 : A^k·v = it^[k](v) を k = 0,...,4 で確認（鎖の 3 段と 4 段も一致）
非可換環（2 次上三角行列）を成分に取っても A^k·v = it^[k](v) が成り立つ（可換性を使っていない）
右から掛ける再帰（A^{k+1} := A^k A）も同じ行列を与える（左から掛ける約束は値ではなく証明の形のため）
すべて成立。実数体・複素数体は使っていない（QQbar の厳密計算）。
```

### 記録

- 2026-08-22 に本文の側を一般化した。この節の線型代数は、行配位の全体ではなく
