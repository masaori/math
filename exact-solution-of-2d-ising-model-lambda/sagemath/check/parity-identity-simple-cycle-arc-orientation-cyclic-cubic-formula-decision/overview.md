# SageMath Check: 固定原始特徴の次数三以下ブール式の一括判定

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: 二つの正準係数について次数三以下の候補クラスは非可解
- 帰属: 有限集合と $\mathbb F_2$ 上の有限線形代数。浮動小数点を使わない。

## 何を確かめるか

絶対境界方向の四指示関数、相対端点十成分、境界基準の巡回三文字出現回数の偶奇を原始特徴として固定する。定数項、一次項、相異なる二特徴積、相異なる三特徴積を全て許した一つの有限線形系を作り、端点だけの支持係数と語位置・端点の支持係数を全ての実現可能な候補で同時に返す式が存在するかを判定する。

記述ごとの真理値表は原始特徴へ加えない。非可解でも、次数四や新しい原始特徴へ自動的に進まない。

## 結果

11,841 観測で現れた係数列は 460,111 本、そのうち三次列は 362,140 本だった。係数行列の階数は 11,584、二つの標的を加えた拡大行列の階数はいずれも 11,585 であり、両方とも非可解だった。それぞれ 16 観測からなる左核矛盾証拠を `certificate.json` に保存した。証拠は観測行の XOR が零、標的列の XOR が一であることをコード内で再計算する。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-cubic-formula-decision/check.sage
```
