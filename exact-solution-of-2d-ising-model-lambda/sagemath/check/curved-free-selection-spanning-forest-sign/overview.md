# 生成森座標を生の置換へ持ち上げる符号対応の反例

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

曲がり型なし均衡配向を誘導する一辺二の各置換から、直進型頂点での
左折・右折を読み取り、成分指示元を先頭に置いた Kruskal 基本閉路基底の
係数へ移した。得た巡回空間の元を辞書式最小の選択集合へ対称差で加えると、
生成森座標による選択集合への対応を生の置換へ持ち上げられる。

しかし、四つのねじれを含む符号比較 $74{,}496$ 件中 $35{,}712$ 件で、
置換の位相寄与と対応先の選択項の符号が異なった。従って生成森座標の
全単射は、生の置換ごとの符号保存対応としては使えない。一般の符号同定は、
局所遷移行列式の中で相殺を済ませた配向類の和を単位に組む必要がある。

- 実行: `sage sagemath/check/curved-free-selection-spanning-forest-sign/check.sage`
- 状態: PASS（2026-09-04。一辺二の厳密反例）
- 方法: 有限集合、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
