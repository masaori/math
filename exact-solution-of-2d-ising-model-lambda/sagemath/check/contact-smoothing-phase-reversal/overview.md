# SageMath Check: 接触平滑化による位相寄与の符号反転

**対象ラベル**: `claim_contact_smoothing_phase_reversal_iff`

切り替え可能な接触対で二つの像を交換した前後について、非後退置換一つの位相寄与
$\mathcal W^{a,b}_L(\varphi)$ を四つのスピン構造で直接計算する。二接続の回転数和の差が $0$
であることと位相寄与が符号反転することが同値であり、差が $\pm4$ なら位相寄与が不変で
あることを検査する。

- 実行: `sage sagemath/check/contact-smoothing-phase-reversal/check.sage`
- 状態: PASS（2026-09-02）
- 結果: 一辺 $L=2$ の切り替え可能接触対 $192{,}896$ 件と四つのスピン構造を検査した。
  回転差が $0$ の対は $140{,}416$ 件、$-4$ と $4$ の対は各 $26{,}240$ 件だった。
  標準接触対が切り替え可能な置換 $11{,}980$ 個の内訳は、回転差 $0$ が $4{,}748$ 個、
  $-4$ と $4$ が各 $3{,}616$ 個だった。

計算は円分体 $\mathbb Q(\zeta_8)$ と整数だけで行い、浮動小数点は使わない。
