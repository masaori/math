# 各成分の曲がり型なし均衡配向の全反転対（一般証明の核）

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

一般の辺長 $L$ のトーラス正方格子の偶部分グラフ $E$（各頂点の次数は $2$ か $4$）の
任意の連結成分 $K$ について、曲がり型なし均衡配向（次数 $4$ の頂点の入辺二本の軸が
一致する均衡配向）の集合は、空であるか、ある配向とその全反転のちょうど $2$ 元集合で
ある。証明は三つの核から成る。

- **局所決定性**（辺長非依存）: 頂点に接続する一本の辺の向きを与えると、その頂点の
  曲がり型なし均衡な局所状態は一意に決まる。次数 $2$ は入 $1$ 出 $1$ の均衡から。
  次数 $4$ では、辺 $e$ が出のとき入辺二本の軸が $e$ の軸だとすると $e$ 自身が入辺に
  なり矛盾するので、入辺は他軸の二本に限る。
- **全反転の保存**（辺長非依存）: 入と出の交換は曲がり型なし均衡性を保ち、次数 $4$ の
  二つの局所状態を互いに入れ替える。辺が一本でもあれば全反転は元の配向と異なる。
- **辺連結伝播**: $K$ は辺連結なので、固定した最小辺の向き $2$ 通りそれぞれから
  局所決定性で全辺の向きが一意に伝播する。従って高々 $2$ 個、非空なら全反転対で
  ちょうど $2$ 個である。

検算は、局所決定性と全反転の交換を局所状態の記号的列挙（軸列 $4$ 種・固定 $20$ 件）で、
伝播の帰納法を一辺二・一辺三の全偶部分グラフの相異なる成分（$29$ 個と $934$ 個）で
伝播結果と総当たり列挙の集合一致として固定した。

- 実行: `sage sagemath/check/curved-free-orientation-full-reversal-pair/check.sage`
- 状態: PASS（2026-09-04。局所核は記号的、伝播は一辺二・一辺三の全成分）
- 方法: 有限集合、$\mathbb F_2$、整数の厳密演算のみ。浮動小数点は使わない。
