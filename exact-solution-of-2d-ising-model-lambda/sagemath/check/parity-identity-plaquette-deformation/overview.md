# プラケット変形での頂点項と対項の同時変化は近傍で決まる

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

偶部分グラフを結ぶ基本の局所変形（プラケットとの対称差）について、
鍵 $(D,E)$ と変形後の鍵 $(D,E\triangle P)$ の標準形配向での
動辺数・頂点項（頂点局所量の積の符号指数）・非共有端点対項・標的指数の
四つの mod 2 変化を全鍵で計算した。変形の恒等式
「動辺数の変化＋頂点項の変化＋対項の変化＝標的指数の変化」は毎回成り立つ。

分類の結果:

- プラケットの切断旗（行・列が mod $L$ で巻き戻るか）と、プラケット近傍の
  局所配置（$E$ と $D$ の入り方）で分類すると、**頂点項と非共有端点対項の
  和の変化・動辺数の変化・標的指数の変化はすべて分類ごとに一定**（混在零。
  一辺二は $120$ 変形・$120$ 類、一辺三は $4{,}914$ 変形・$1{,}024$ 類）。
- 一辺三では、和は決まるのに**二項への割り方だけが近傍配置で決まらない**
  （頂点項と対項が個別に変わる混在類が $16$）。一辺二では $D$ の近傍配置まで
  含めれば割り方も決まる。

従って、前 tick で排除した「切断依存項だけの分離評価」に代わり、
二項の和を一つの局所量として扱えば、切断を横切る辺を動かす変形の効果は
プラケット近傍だけで決まる。切断に接する変形（一辺二 $90$、一辺三 $2{,}730$）も
すべてこの分類に従う。
