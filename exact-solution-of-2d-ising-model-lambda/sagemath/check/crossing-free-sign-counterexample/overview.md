# 横断数零だけでは回転位相符号が決まらない反例

**対象ラベル**: `claim_crossing_free_sign_counterexample`

- 実行: `sage sagemath/check/crossing-free-sign-counterexample/check.sage`
- 状態: PASS（2026-08-30）
- 使用する環: `ZZ` と有限集合だけ。浮動小数点は使わない。

一辺二のトーラス上の本文の六辺を定義どおりに構成し、辺の相異性、閉性、非後退性、
全十五添字対の非横断性、一歩の回転数、二つの切断線偶奇を独立に計算する。
その結果、横断数零・切断線偶奇 `(0,0)` にもかかわらず回転数は零で、回転位相符号は
単純閉路から予想される `-1` でなく `1` になることを厳密に検査する。
