# 境界頂点で切った弧による頂点項の分解

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

単純閉路 $E$ を $\partial D$ の頂点で切り、各弧について、辞書式最小の
選択 $C$ を含む頂点署名を閉路順に並べた有限列を記録する。向きを逆にした
列は同じ弧型とする。頂点項が弧型ごとの値の和として書けるかを、合同の
$\mathbb F_2$ 線型系で判定する。

一辺二・三の全 $7{,}085$ 鍵に現れる弧型は $6{,}421$ 種で、所属行列の
階数は $5{,}983$ だった。線型系は解を持ち、直接衝突も無い。一つの解の
支持台は $2{,}769$ 弧型である。従って頂点局所署名では不足していた閉路順序の
情報を弧の有限列として保持すれば、頂点項は弧型ごとの値の和へ分解できる。
ただしこれは弧の完全な署名列を使う存在確認であり、閉じた公式ではない。
次は弧の長さ・曲がり・端点の $D/C$ 配置・切断横断数へ署名を圧縮する。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-boundary-arc-decomposition/check.sage`
- 状態: PASS（2026-09-05。弧型 $6{,}421$ 種・階数 $5{,}983$、解あり。
  一つの解の支持台 $2{,}769$ 弧型）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
