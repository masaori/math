# SageMath Check: 台固定の集約でも三分類の部分和は消えない（全分解の実現は成立）

**対象ラベル**: `claim_fully_unswitchable_contacts_witness_doubled_edges`, `claim_weighted_path_reversal_selection_orbit_sums`

選択和の側は偶部分グラフ対 $(P,Q)$ の $P\cap Q=D$, $P\triangle Q=E$ による分類であり、
和集合 $P\cup Q=D\cup E$ はファイバーをまたいで共有される。そこで一辺 $L=2$ の全ファイバーを
台 $F=D\cup E$ で束ね、ファイバーは保たず台だけを保つ相殺の単位が成立するかを検査する。
あわせて、台の分解 $F=D\sqcup E$（$E$ は偶）のうち置換が一つも無い分解で選択和 $U$ が
零になるか（ファイバー単位の一致 $\mathcal K=\mathcal U$ が空のファイバーで破れないか）も確かめる。

- 実行: `sage sagemath/check/same-support-fiber-phase-sums/check.sage`
- 状態: PASS（2026-09-03。実行 5 分 24 秒）
- 方法: 有限集合の数え上げと $\mathbb Q(\zeta_8)$ の等号だけ。浮動小数点は使わない。
- 結果: 台は $104$ 個、四スピン構造で $416$ 組。**置換の無い分解は $0$ 組**であり、
  一辺二では互いに素な $D\sqcup E=F$（$E$ 偶）の全分解が非後退置換で実現される。
  一方、台で集約した三分類の部分和は $\Sigma S_X\ne0$ が $132$ 組、$\Sigma S_Y\ne0$ が $248$ 組、
  $\Sigma S_Z\ne\Sigma U$ が $380$ 組あった。$\Sigma S_Y\ne0$ の最初の例は
  台 $F=\{v(0,1),v(1,1)\}$、$(a,b)=(0,0)$ で $\Sigma S_Y=1$ である。
  各台で $\Sigma S_Z+\Sigma S_X+\Sigma S_Y=\Sigma U$（ファイバー一致の集約）は全 $416$ 組で成立した。
- 帰結: 固定ファイバー内でも台固定の集約でも、切り替え可能部分と全対切り替え不能な残余は
  単独では消えない。従って、分類（接触なし・切り替え可能・全対切り替え不能）を保つ符号反転対合は、
  固定ファイバーまたは台固定の相殺単位では存在しない。一般の $L$ の証明は三分類を混ぜた関係
  （ファイバー位相和の全体と選択和を直接結ぶ数え上げ）として構成する必要がある。
  空のファイバーが無いという正の観察は、ファイバー単位の一致を示す際に
  「置換が無い場合」の場合分けが一辺二では現れないことを示す。
