# 二つの符号付き数え上げは軌道の元数を重みとする和である

**対象ラベル**: `claim_weighted_path_reversal_selection_orbit_sums`
- 検証コード: `check.sage`
- 方法: 一辺 $L=2$ の全ファイバーと四つのスピン構造について、接触対の順序に依らない三分類で細分した経路反転軌道と選択補集合軌道の元数を重みとして足し、ファイバー位相和と選択和の定義による直接和にそれぞれ一致することを検査する。
- 浮動小数点: 使用しない（有限集合の元の個数、$\mathbb Z$ と $\mathbb Q(\zeta_8)$ の等号だけ）。
- 実行日: 2026-09-02
- 結果: 全 $609$ ファイバーと四つのスピン構造の $2{,}436$ 組で、二つの重み付き軌道和が定義による直接和に一致した。
- 状態: PASS（2026-09-02 実行）。
