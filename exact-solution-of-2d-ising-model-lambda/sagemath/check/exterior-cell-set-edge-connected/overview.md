# SageMath Check: 持ち上げ点が相異なる閉路の内側セル集合の補集合は辺連結である

**対象ラベル**: `claim_exterior_cell_set_edge_connected`

原点から始まる長さ $10$ 以下の、点が二つずつ相異なる閉じた非後退単位格子歩をすべて列挙する。
この点列は主張の一周期の持ち上げ点列そのものである。さらに $L=1,2,3$ のトーラスへ射影し、
$n_{\mathrm{ct}}>0$ となる歩が実在することを確認して、旧仮定では扱えなかった対象を検算に含める。
外接長方形内の各外側セルについて、同じ行を右へ進むと、外側セルだけを通って歩道沿いの外側帯または
外接長方形の外側へ到達することを検査する。あわせて、歩道沿いの外側帯と外接長方形の外側に共通セルがあり、
有限な検査窓内の外側セルが辺隣接で一つにつながることを幅優先探索で検査する。

- 実行: `sage sagemath/check/exterior-cell-set-edge-connected/check.sage`
- 状態: PASS（2026-09-01）。持ち上げ点相異の閉じた非後退歩道 704 本、外側セル 864 個、歩道沿いの外側帯への到達 432 件、外接長方形の外側への到達 432 件を検査した。射影後に $n_{\mathrm{ct}}>0$ となる歩は $L=1$: 704 本、$L=2$: 696 本、$L=3$: 592 本。
- 計算: 単位格子歩の有限列挙と `ZZ` の比較・加法・剰余・奇偶だけ。浮動小数点は使わない。
