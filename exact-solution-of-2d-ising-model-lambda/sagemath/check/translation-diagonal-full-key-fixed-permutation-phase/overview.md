# 全辺鍵の対角固定置換の位相対消滅条件

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限グラフ、$\mathbb Q(\zeta_8)$、自然数
- 実行: `sage sagemath/check/translation-diagonal-full-key-fixed-permutation-phase/check.sage`
- 状態: PASS（2026-09-03。約 1 分 24 秒。全数値を等号 assert で固定して再実行済み）

奇数辺長で対角平行移動 $(1,1)$（位数 $L$）に固定され選択文字が非自明な鍵は
全辺鍵 $(D,E)=(\varnothing,E_L)$ だけだった
（`translation-diagonal-fixed-nontrivial-character`）。この鍵のファイバー上に
対角部分群と可換な符号反転完全マッチングが存在するための必要条件を検査した。

群の元 $g$ が置換 $u$ を固定し、不変なマッチング $M$ が対 $\{u,v\}$ を含むなら、
$\{g\cdot u,g\cdot v\}=\{u,g\cdot v\}\in M$ で $u$ の属する対は一つなので
$g\cdot v=v$ である。従って固定置換は固定置換同士で対にされ、候補辺は四つの
スピン構造すべてで位相寄与を反転するから、固定置換の位相ベクトルの多重集合は
符号反転で不変でなければならない。

全辺鍵のファイバーは「各基底辺の向きを一つ選ぶ割当で全頂点の入次数・出次数が
$2$ になるもの（氷型配向）」と「各頂点での入辺 $2$ 本から出辺 $2$ 本への全単射」の
組と一対一に対応し、動く辺の逆向き辺は動かないので非後退条件は自動で満たされる。
対角固定置換は、配向が対角辺軌道上で一定で、対応が頂点軌道の代表から平行移動で
運ばれるものに限る。一辺二では全辺鍵のファイバー $288$ 個（氷型配向 $18$ 個
$\times 2^4$）を直接列挙し、固定置換 $24$ 個（不変氷型配向 $6$ 個 $\times 2^2$）が
構成法と一致することを検証した。一辺三の全辺鍵ファイバーの大きさは氷型配向
$148$ 個 $\times 2^9=75{,}776$ である。

奇数辺長の結果（不変氷型配向数、固定置換数、多重集合の符号反転不変性、四位相和）:

- $L=3$: $(10,\ 80,\ \text{成立},\ (0,0,0,0))$
- $L=5$: $(34,\ 1{,}088,\ \text{成立},\ (0,0,0,0))$
- $L=7$: $(130,\ 16{,}640,\ \text{成立},\ (0,0,0,0))$

従って、位相ベクトルの数え上げの水準では対角部分群の障害は現れない
（固定置換は符号反転の相手を常に同数持つ）。これは必要条件であり、固定置換同士を
実際に結ぶ位相反転候補辺が存在して不変な完全マッチングを与えるかは別途の検査である。
次は奇数辺長の固定置換の間の候補辺を構成し、固定置換だけの部分グラフに完全
マッチングがあるかを判定する。
