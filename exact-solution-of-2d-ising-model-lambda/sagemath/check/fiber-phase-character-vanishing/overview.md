# SageMath Check: 文字の三種別ごとの三分類部分和の個別消滅

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_fully_unswitchable_contacts_witness_doubled_edges`

一辺 $L=2$ の全ファイバー $(D,E)$ と四つのスピン構造 $(a,b)$ について、選択和の文字評価が
与える三種別（選択集合が空 / 文字が非自明 / 文字が自明）ごとに、ファイバー位相和の三分類の
部分和 $S_Z$（接触なし）・$S_X$（切り替え可能対あり）・$S_Y$（全対切り替え不能）が個別に
消えるかを数える。全組で $S_Z+S_X+S_Y=U$（既知のファイバー一致）と、空・非自明の種別で
$U=0$（文字評価）を assert する。

- 実行: `sage sagemath/check/fiber-phase-character-vanishing/check.sage`
- 状態: PASS（2026-09-03。実行 4 分 32 秒）
- 方法: $\mathbb Z$ と $\mathbb Q(\zeta_8)$ の等号だけ。浮動小数点は使わない。
- 結果: 全 $2{,}436$ 組の種別は、空 $768$ 組・非自明文字 $192$ 組・自明文字 $1{,}476$ 組。
  **空と非自明文字の全 $960$ 組で $S_Z,S_X,S_Y$ は全て個別に零**であり、非零の部分和は
  自明文字の組にしか現れない（$S_Z\ne0$ が $92$ 組、$S_X\ne0$ が $736$ 組、$S_Y\ne0$ が
  $648$ 組、$S_Z\ne U$ が $1{,}384$ 組）。従って一辺二では、文字による消滅
  （$\mathcal K=0$ となるべき組）は三分類の各部分ごとに成立しており、文字和の構成は
  部分ごとの符号反転構造として探してよい。自明文字の組では部分和は単独で $U$ に
  一致しないため、非零の値の同定は三分類を混ぜた全体で行う。
