# 直線合併を含まない成分は単一の単純閉路を辺数最小代表に持つ

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

固定した反転対 $D$ ごとのプラケット変形グラフで、直線ループの合併を含まない各成分から、
まず辺数が最小で、その中で辞書式最小の偶部分グラフ $E$ を選んだ。

- 一辺二の未被覆 $216$ 成分では、全ての代表が四辺からなる連結な単純閉路である。
  $|D|=0,1,2,3,4$ の全てが現れ、巻き付き偶奇も、$D=\varnothing$ の場合を除いて複数種が現れる。
- 一辺三の未被覆成分は一つで、その代表は巻き付き偶奇 $(1,1)$ の六辺単純閉路である。
  四項（動辺数・頂点項・非共有端点対項・標的指数）は $(0,0,1,1)$ になる。

従って、直線合併に足すべき第二の代表族は「$D$ と互いに素で、許される鍵をなす単一の
単純閉路」である。一辺二・三ではこの二族で全成分を覆う。一般の辺長へ進むには、
$D$ に適合する単純閉路代表の存在条件を記述し、その四項を閉路の方向列から評価する必要がある。

- 実行: `sage sagemath/check/parity-identity-minimal-standard-representatives/check.sage`
- 状態: PASS（2026-09-04）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
