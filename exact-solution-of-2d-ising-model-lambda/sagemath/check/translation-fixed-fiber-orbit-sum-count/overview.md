# 平行移動固定ファイバー鍵の軌道和による全数一致と個数

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、自然数
- 実行: `sage sagemath/check/translation-fixed-fiber-orbit-sum-count/check.sage`
- 状態: PASS（2026-09-03、約 17 秒）

ファイバー鍵は $(D,E)$（$D,E$ は基底辺集合の互いに素な部分集合で、$E$ は全頂点の
次数が偶数の偶部分グラフ）である。一辺 $2$ ではこの鍵は全部で $881$ 個あり、
各非零平行移動で固定される鍵の集合は、$D$ と $E$ をともにその平行移動の辺軌道の和とし
$E$ が偶部分グラフになる割当の集合と全数一致した。個数は軸方向 $(0,1),(1,0)$ で
各 $45$、対角 $(1,1)$ で $41$ である。可除条件（$2\mid|D|,|E|$）だけを満たす鍵は
各平行移動で $441$ 個あり、固定鍵はその真部分集合である。

一般の辺長では、軌道の割当（各軌道を $D$・$E$・どちらでもない、の三択）を列挙して
固定鍵を数えた。$(L,\text{shift})=(3,(1,1))$ で $189$、$(4,(1,1))$ で $881$、
$(5,(1,1))$ で $4{,}149$、$(5,(1,2))$ で $3{,}969$ である。同じ位数 $5$ でも方向で
個数が違うのは、$E$ 側の偶部分グラフ条件が軌道の幾何に依存するためである。
一辺 $3$ では偶部分集合 $1{,}024$ 個の大きさ分布から可除条件だけを満たす鍵を
二項係数で数えると $299{,}187$ 個で、固定鍵 $189$ 個より圧倒的に多い。

従って、辺数の可除条件による除外は固定ファイバーの同定には遠く、固定鍵の実体は
「軌道の割当で $E$ が偶になるもの」として直接列挙するのが正しい。任意の $L\ge 2$ と
非零平行移動について、一つの辺軌道 $O$ を取り $(D,E)=(O,\varnothing)$ とすれば、
$D\cap E=\varnothing$ かつ $E$ は偶部分グラフであり、この鍵は平行移動で固定される。
従って固定鍵は全ての辺長 $L\ge2$ で非自明に存在するので、
選択規則を一般の辺長へ持ち上げる際は、固定部分群が非自明な軌道での運搬条件
（代表マッチングの固定部分群不変性、`even-subgraph-orbit-transport-stabilizer-condition`）
を避けて通れない。次は、固定鍵のうち単一の偶部分グラフで覆えないものが実際に
現れるかを、小さい辺長の未被覆判定と突き合わせて調べる。
