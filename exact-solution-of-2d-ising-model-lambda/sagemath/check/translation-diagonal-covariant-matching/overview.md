# 対角平行移動部分群と可換な符号反転完全マッチング族

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、円分体 $\mathbb{Q}(\zeta_8)$ の等号
- 実行: `sage sagemath/check/translation-diagonal-covariant-matching/check.sage`
- 状態: PASS（2026-09-03。約 7 分。全数値を等号 assert で固定して再実行済み）

一辺 $L=2$ の一様被覆検査の対象（巻き付き文字が非自明で有効な偶部分グラフ $H$ を
持つ）全 $64$ ファイバー鍵の上で、対角平行移動部分群 $\{(0,0),(1,1)\}$ の作用は
自由である（各鍵の $(1,1)$ 像が自分と異なることを全数 assert。
translation-fixed-fiber-invariant-matching の対角固定鍵零と同じ事実）。
対角軌道は $32$ 個（各大きさ $2$）で、各代表に、四スピン構造すべてで位相寄与を
反転する全候補辺の完全マッチングを一つ構成し、$(1,1)$ で軌道のもう一方の鍵へ
運んだ。候補関係は非対称（候補が片側の置換からしか発見されないことがある）なので、
正負両側の置換から候補辺を集めて二部グラフを作る。

得られた $64$ 個の完全マッチング（対の総数 $2{,}624$、ファイバーの大きさの分布は
$8$ が $20$・$24$ が $8$・$32$ が $12$・$48$ が $16$・$288$ が $4$・$648$ が $4$）
について、次を等号 assert で固定した。

1. 各ファイバーの全置換をちょうど一度ずつ覆う。
2. 各対は移した先でも位相反転候補辺である（witness の偶部分グラフを $(1,1)$ で
   移したものが移動先でも有効で、発見元の置換の組み替え候補に相手が含まれ、
   四位相が全反転する）。
3. 族は対角部分群と可換である（各鍵のマッチングの $(1,1)$ 像が移動先の鍵の
   マッチングと一致。$64$ 比較すべて成立）。
4. **合成**: 各ファイバーで四つのねじれ位相和
   $\sum_{\varphi}\varepsilon_{a,b}(\varphi)$（$a,b\in\{0,1\}$）が、対ごとの相殺により
   全て零になる。マッチングが全置換を覆うので、巻き付き文字が非自明な全 $64$
   ファイバーの選択和への寄与は四スピン構造すべてで消える。

固定部分群が非自明な軸方向固定の $8$ 鍵（translation-fixed-fiber-invariant-matching
で軸部分群の不変マッチングが無いと確定したもの）も、対角部分群では自由軌道に
入るのでこの構成で覆われる。従って一辺二では、位相反転候補辺だけから作れる
共変族として対角部分群のものが実在し、選択和の文字評価に要る「巻き付き文字が
非自明なファイバーの寄与の相殺」は、この対角共変族の対消去で実現される。

一般の辺長への持ち上げでは、対角部分群に対応する部分群の固定鍵が零になるか
（一辺二に固有の偶然か）を確かめる必要がある。次はその判定を小さい辺長で行う。
