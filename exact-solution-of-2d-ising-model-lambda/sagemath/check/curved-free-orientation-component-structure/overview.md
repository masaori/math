# 曲がり型なし均衡配向の成分ごとの構造

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

一般の辺長で配向側の座標を列挙に頼らず取るための構造を、一辺二・一辺三の
トーラスの全偶部分グラフで固定した。

- 各連結成分の曲がり型なし均衡配向（次数 $4$ の頂点の入辺二本の軸が常に
  一致する均衡配向）は $0$ 個か $2$ 個で、$2$ 個のときは互いの全反転である。
  従って $E$ 全体では $0$ 個か $2^{c(E)}$ 個で、二つの配向の不一致辺集合は
  常に成分の辺集合の合併になる。
- 次数勘定の等式 $|E|-|V(E)|=n_4(E)$。従って巡回空間の階数
  $|E|-|V(E)|+c(E)$ は $c(E)+n_4(E)$ に分解し、成分の指示元 $c(E)$ 本は
  巡回空間の一次独立な元である。
- 一辺三で曲がり型なし配向を持たない非空偶部分グラフは $346$ 個で、既に
  固定した非自明文字の偶部分グラフの個数 $346$ に一致する（非自明文字が
  曲がり型頂点を強制する定理の逆向きは、一辺二・一辺三の全数では同値）。

これで配向側は「成分ごとの反転ビット」＝成分の指示元への展開として列挙に
頼らず座標化できる。残るのは直進型頂点の局所選択ビットから、巡回空間の
残り $n_4$ 次元の係数を取り出す規則である。

- 実行: `sage sagemath/check/curved-free-orientation-component-structure/check.sage`
- 状態: PASS（2026-09-04。一辺二の $32$ 個・一辺三の $1{,}024$ 個の全偶部分グラフ。
  一般の辺長は未証明）
- 方法: 有限集合、$\mathbb F_2$ の線型代数、整数の厳密演算のみ。浮動小数点は使わない。
