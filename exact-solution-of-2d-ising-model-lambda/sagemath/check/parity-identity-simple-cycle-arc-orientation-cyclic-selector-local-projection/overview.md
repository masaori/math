# SageMath Check: 有向切断候補の端点局所選択写像

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。内部の有向語を捨て、反転正規化前の向き、端点が語の
  先頭・末尾のどちらに合うか、端点の全所属・切断旗・端点順を残すと、
  614 個の局所記述が要求する切断候補に衝突は無かった。

## 何を確かめるか

二つの切断候補を分けた有向記述から内部語を取り除き、端点で読める局所情報だけへ
射影する。同じ語長・同じ端点対・同じ二候補の局所記述を持つ支持項が、常に同じ候補を
選ぶかを判定する。

全 781 支持項を局所記述でまとめ、同じ局所記述が常に同じ順位の候補を選ぶかを判定する。
これにより観測済みの支持上では 614 個の局所記述から切断位置を選ぶ写像が定まる。
一般語長の閉じた式ではないため、次は 614 個の有限表を端点ビットの述語へ圧縮する。

sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-selector-local-projection/check.sage
