# SageMath Check: 語長四の巡回不変な固定線型形式

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 通過。語位置の巡回移動で不変な非零の固定特徴線型形式は無く、巡回移動で閉じた固定形式の核も零次元だった。

## 何を確かめるか

全 $7{,}085$ 鍵、$11{,}208$ 未知数の可解な合同系を、特徴以外の列 $B$ と
$3{,}240$ 個の特徴列 $C$ に分ける。左核条件 $yB=0$ を満たす全ての $y$ から
$yC$ を作ると、解空間上で値が固定される特徴線型形式の空間が得られる。
この空間の次元は $491$ だった。

語位置四箇所の巡回移動は特徴を $1{,}212$ 軌道へ分け、軌道の大きさごとの個数は
$528,12,672$（大きさ $1,2,4$）だった。軌道和が張る巡回不変空間と固定形式空間の
共通部分は零次元である。また固定形式空間とその巡回移送を順に交差させた次元は
$491,6,0,0$ となり、四つの語位置へ一貫して運べる非零の固定形式も存在しない。
従って前回の $248$ 項の支持だけでなく、特徴係数だけの固定線型結合からも巡回的な核は抽出できない。
弧型係数も混ぜた共変関係はこの計算の対象外である。
