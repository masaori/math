# 重複隣接旗を加えた合同局所符号式の非存在

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二の全 $320$ 鍵と一辺三の対象 $6{,}765$ 鍵について、上下左右の
各スロットの $D/E$ 所属・切断隣接旗に、上下または左右の対向スロットが
同じ無向端点対を持つことを表す重複隣接旗二つを加えた。頂点項がこの
拡張署名の任意関数の頂点和で書けるかを、合同の $\mathbb F_2$ 線型系で
判定した。

重複隣接旗を加えると、一辺二と一辺三の署名は分離し、現れる署名は
$394$ 種、所属行列の階数は $323$ となる。しかし線型系に解は無い。
辺長ごとに分けると、一辺二は署名 $124$ 種・階数 $89$ で解を持つ一方、
一辺三は署名 $270$ 種・階数 $234$ で、それ単独でも解を持たない。
従って不足は一辺二の重複隣接を識別できないことではなく、一辺三の
$D\ne\varnothing$ を含む鍵の頂点項が、この頂点局所署名だけでは決まらない
ことにある。次は選択集合の局所所属を署名へ加え、閉路上で伝播する情報を
明示すれば解けるかを検査する。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-joint-duplicate-adjacency/check.sage`
- 状態: PASS（2026-09-05。合同系は署名 $394$・階数 $323$ で解なし。
  一辺二は解あり、一辺三は署名 $270$・階数 $234$ で解なし）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
