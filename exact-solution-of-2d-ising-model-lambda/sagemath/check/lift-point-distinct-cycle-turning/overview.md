# SageMath Check: 持ち上げ点が相異なる零巻き付き閉路の循環総回転数

**対象ラベル**: `claim_plane_simple_polygon_cyclic_turning`

一周期の持ち上げ点が二つずつ相異なる零巻き付きの閉じた非後退単位格子歩について、
循環総回転数が $\{+4,-4\}$ に属することを検査する（両方の値が実際に現れることも確認する）。
射影は各歩の方向を保つので、$L$ トーラスへ射影した辺列の循環総回転数は平面歩のそれに等しい。

- 実行: `sage sagemath/check/lift-point-distinct-cycle-turning/check.sage`
- 状態: PASS（2026-09-01）。長さ $10$ 以下の持ち上げ点相異の閉歩道 704 本を検査し、循環総回転数はすべて $\{+4,-4\}$ に属し、両方の値が現れた。これらを $L=1,2,3$ トーラスへ射影したとき、$n_{\mathrm{ct}}>0$ となる歩道（旧仮定 $n_{\mathrm{ct}}=0$ では扱えなかった対象）がそれぞれ 704、696、592 本存在することも確認した。
- 計算: 有限の数え上げと `ZZ` の四則・剰余だけ。浮動小数点は使わない。
