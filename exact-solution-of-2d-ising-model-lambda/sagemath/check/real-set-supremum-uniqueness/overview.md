# SageMath Check: 上限の一意性（記法 sup の正当化）

## 対象

**対象ラベル**: `claim_real_set_supremum_unique`

- 実行日: 2026-08-15
- 結果: 有限標本検査がすべて通過（合計 74 件）
- 帰属: すべて $\mathbb{Q}$ の厳密比較で行い、浮動小数点・ball 算術を使わない。

## 何を確かめるか

- 準備のモデル: 有限モデル（周囲集合 $A\supseteq S$。上限の述語の「任意の
  $M\in\mathbb{R}$」を「任意の $M\in A$」に置き換える）で、$u_1,u_2$ がともに
  上限なら最小性の適用で $u_1\le u_2$ かつ $u_2\le u_1$（厳密。$5$ 件）。
- 略記の展開: $a\le b$ ならば「$a<b$ または $a=b$」のちょうど一方（厳密。$36$ 件）。
- 三分律による除外: $a<b$ のとき $b<a$ も $a=b$ も成り立たない（厳密。$28$ 件）。
- 本体のモデル: 各有限モデルで上限の述語を満たす元はちょうど一つで、$\max(S)$ に
  等しい（厳密。$5$ 件）。

## 検査できないこと（黙って広げない）

**実数の部分集合一般についての普遍量化された主張そのものは有限標本では検査できない。**
上限の述語の「任意の $M\in\mathbb{R}$」は有限モデルでは周囲集合 $A$ への制限であり、
$\mathbb{R}$ 全体の量化の検査ではない。主張そのものの保証は本文の人手証明と Lean が担う。
