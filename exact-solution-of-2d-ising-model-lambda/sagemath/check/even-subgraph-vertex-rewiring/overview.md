# SageMath Check: 偶部分グラフに沿った頂点の入出接続の組み替え

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`

一辺 $L=2$ の各ファイバー $(D,E)$ のうち、$E$ に含まれる偶部分グラフ $H$ で巻き付き文字が
非自明（$\chi_E(H)=-1$）になる全 $13{,}568$ 組 $(\varphi,H)$ について、$H$ の外どうしの遷移を
保ち、$H$ 上の歩道の向き付き辺を全て逆向きへ差し替え、各頂点で残った到着と出発を
直ちに引き返さない任意の全単射で結び直す候補の族を全数で調べる。

- 実行: `sage sagemath/check/even-subgraph-vertex-rewiring/check.sage`
- 状態: PASS（2026-09-03）
- 方法: 有限集合・有限写像と $\mathbb Q(\zeta_8)$ の等号だけ。浮動小数点は使わない。
- 結果: 全組で各頂点の残った到着と出発の個数は釣り合い（釣り合わない組は $0$）、
  非後退置換になる結び直しが常に存在した（候補総数 $38{,}016$。候補が空の組も $0$）。
  しかし、四スピン構造すべてで位相寄与の比が文字 $-1$ になる候補を持つ組は
  $11{,}904$ に留まり、$1{,}664$ 組ではどの候補も位相比 $-1$ を実現しない。
  最初の例は $D=\varnothing$、$E=\{h(1,0),h(1,1),v(0,1),v(1,1)\}$、
  $H=\{h(1,0),h(1,1)\}$ である。従って、この局所的な組み替えの族だけでは、
  非自明文字のファイバー位相和を消す一様な文字作用は構成できない。
