# SageMath Check: 正準弧型支持の巡回軌道符号化

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。二つの正準弧型支持を、内部語の巡回・反転軌道の代表と、
  代表から元の切断位置へ戻す巡回移動量で損失なく符号化した。

## 何を確かめるか

端点対を固定し、弧の空でない内部語だけを巡回移動する。既に弧型が反転で
同一視されているため、巡回移動後にも反転正規形を取る。この軌道の辞書順最小元を
軌道代表とし、軌道代表から元の反転正規形へ戻る最小の巡回移動量を切断位置とする。

この「軌道代表と切断位置」の組から元の弧型を復元できることと、一つの支持の中では
異なる二項が同じ軌道へ落ちないことを、前段で復元した二つの正準弧型支持の全項で
確かめる。軌道代表の定義と復号は任意の空でない有限語に同じ式で適用できる。

## 結果

- 端点特徴代表の支持 462 項は 462 個の異なる巡回・反転軌道へ写った。
- 語位置・端点積代表の支持 616 項は 616 個の異なる巡回・反転軌道へ写った。
- 両支持が共有する軌道は 227 個だった。
- 支持に現れる語長は $1,2,3,5,6,7$ であり、語長 $4$ の弧型項は現れなかった。
- 語長 $3,5,6,7$ の各項の軌道サイズはそれぞれ語長に等しかった。語長 $1,2$ の
  各項は、反転同一視のため軌道サイズが $1$ だった。
- 軌道への射影は両支持上で単射だった。一方、切断位置は語長と端点特徴だけでは
  一意に決まらないため、一般語長の関係式には切断位置を選ぶ追加規則が必要である。
