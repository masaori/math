# SageMath Check: 切断候補の衝突を分ける内部語の向き奇偶

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。端点ビットで衝突する語長三の二語では、内部語の四つの向き座標の
  出現数が全て奇数だった。対応する語長五の二語ではこの条件が成り立たない。
  この一ビットを端点ビットへ加えると、観測済み支持の衝突は零になった。

## 何を確かめるか

内部語の各項が持つ四つの向きビットを、語位置全体で座標ごとに加え、その奇偶を取る。
この四ビットは語順の巡回移動と反転で変わらないため、巡回・反転軌道そのものから定まる。

前段の二つの衝突証拠では、語長三の側の奇偶はどちらも $(1,1,1,1)$ であり、語長五の側は
それぞれ $(0,1,1,0)$ と $(0,1,0,1)$ である。従って「四座標の出現数が全て奇数」という
一ビットは、語長を直接参照せずに二つの衝突を分離する。観測済み支持 781 項では、
この一ビットと端点ビットを合わせた入力に相反する候補順位は無い。

これは有限支持上の選択述語であり、一般語長の閉じた規則ではない。次はこの奇偶が
弧の端点境界と選択位置を結ぶ理由を、内部語の連結条件から導く。
