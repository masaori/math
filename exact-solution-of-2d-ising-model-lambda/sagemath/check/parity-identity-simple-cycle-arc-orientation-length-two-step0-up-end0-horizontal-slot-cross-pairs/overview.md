# SageMath Check: 語長二の先頭端点左右にまたがる所属向き交差二項

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-15
- 結果: 左側の `step0` 単一辺所属項と右側の `end0` 単一辺所属項を組む系、および左右を反転した系は、どちらも可解である。各系について保存した厳密解で全 7,085 鍵を復元した。
- 帰属: 一辺二・三の有限集合と有限次元の $\mathbb F_2$ 線型系。浮動小数点を使わない。

## 何を確かめるか

語長一の全純二次項と語長三の固定項を保つ。語長二では、直前の 160 項に加える候補を、先頭語位置 `step0` の上スロットと先頭端点 `end0` の左右スロットを結ぶ異軸両所属混合積のうち二項だけにする。

一方は、単一辺所属が `step0` 側にある左スロットの項と、単一辺所属が `end0` 側にある右スロットの項を組む。他方は左右を反転して組む。各交差二項だけを許した合同線型系を判定し、可解なら厳密解を、非可解なら左核の矛盾証拠を保存して再実行時に検査する。

これは一辺二・三の有限データに対する判定である。一般の辺長と全語長についての命題ではなく、Lean 二版の対象も追加しない。

## 結果

二つの系はいずれも 12,220 行・13,356 未知数で、係数行列と拡大係数行列の階数はともに 11,835 だった。保存した厳密解で全 7,085 鍵を復元した。

LLM による検証: 同じ端点スロットを使う二項族二つと、左右にまたがる交差二項族二つが全て可解なので、先頭端点の左右の選択は可解性を左右しない。単一辺所属が `step0` 側だけまたは `end0` 側だけの各 8 項族が非可解である既検査と合わせ、追加する二項は所属向きが異なることが必要で、この四項内ではその任意の組で十分である。この結論は一辺二・三の有限データに限り、一般の辺長と全語長は未判定で、一般命題と Lean 二版は追加しない。

sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-two-step0-up-end0-horizontal-slot-cross-pairs/check.sage
