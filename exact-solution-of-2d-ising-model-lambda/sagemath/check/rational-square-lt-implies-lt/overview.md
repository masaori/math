# SageMath Check: 非負有理数の平方の大小から大小

## 対象

**対象ラベル**: `claim_rational_square_lt_implies_lt`

- 実行日: 2026-08-13
- 結果: 通過（分子・分母 1..15 と 0 の非負有理数の組で、主張 10296 組・
  背理法の鎖 10440 組・全順序の同値 20736 組を厳密検査した）
- 帰属: `QQ` の厳密計算。浮動小数点は使わない。

## 何を確かめるか

主張は「任意の $p,q\in\mathbb{Q}$ について、$0\le p$ かつ $0\le q$ かつ
$p\cdot p<q\cdot q$ ならば $p<q$」。証明の組み立てを一行ずつ突き合わせる。

- 主張そのもの: $p\cdot p<q\cdot q$ を満たす標本の全点で $p<q$
- 背理法の鎖の各段（$q\le p$ を満たす標本の全点で検査する。
  主張の仮定と背理法の仮定は標本上で両立しないので、鎖の段は
  背理法の仮定側の標本で見る）:
  - $q\cdot q\le p\cdot q$（$q\le p$ の両辺へ $0\le q$ の $q$ を右から掛ける）
  - $p\cdot q\le p\cdot p$（$q\le p$ の両辺へ $0\le p$ の $p$ を左から掛ける）
  - $q\cdot q\le p\cdot p$（推移律）
  - このとき $p\cdot p<q\cdot q$ は成り立たない（成り立てば非反射性に反する）
- 全順序の段: $\lnot(q\le p)$ と $p<q$ の同値

主張そのものは全称なので有限の標本でしか見られないが、鎖の各段は該当する標本の
全点で成立する。`QQ` の順序判定は厳密である。
