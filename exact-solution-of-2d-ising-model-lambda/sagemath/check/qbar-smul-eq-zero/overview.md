# SageMath Check: 零でない列ベクトルのスカラー倍が零ベクトルならば、スカラーは 0 である

## 対象

**対象ラベル**: `claim_qbar_smul_eq_zero`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の主張 1 件
- 併せて引く定義: `def_algebraic_numbers`（$\overline{\mathbb{Q}}$ が体であること）・
  `def_qbar_vector`（列ベクトル $V_L$ は $R_L$ から $\overline{\mathbb{Q}}$ への写像）・
  `def_qbar_vector_smul`（スカラー倍 $z\odot v$）・`def_qbar_zero_vector`（零ベクトル $o_L$）・
  `def_row_configuration`（添字集合 $R_L$）

### 何を確定させるための検証か

シフト行列の固有値が 1 の $L$ 乗根であることを言う組み立てでは、
$(\mathrm{Ev}_{\xi}(U))^{L}$ を固有ベクトルへ作用させて $z^{L}\odot v=v$ の形を出し、
そこから $z^{L}=1$ を取り出す。その最後の一歩が本主張である
（$(z^{L}-1)\odot v=o_L$ かつ $v\ne o_L$ から $z^{L}-1=0$ を出す）。
固有ベクトルの定義に $v\ne o_L$ を課してあるのは、まさにこの段のためである。

確かめるのは次の 7 で、2 から 4 は人手証明の準備の段と 2 つの鎖に対応する。

1. 添字集合。行配位の全体 $R_L$ が $2^{L}$ 個の元をもつこと。
2. 準備の段。$v\ne o_L$ ならば $v(\tau_1)\ne o_L(\tau_1)=0$ を満たす $\tau_1$ が取れること。
3. 第 1 の鎖の 3 段。$z\,v(\tau_1)=(z\odot v)(\tau_1)=o_L(\tau_1)=0$。
4. 第 2 の鎖の 5 段。$1$ を掛ける → 逆元を差し込む → 結合則 → 第 1 の鎖の結果を代入 →
   零元との積、で $z=0$ が出ること。
5. 主張そのもの。$z\odot v=o_L$ かつ $v\ne o_L$ ならば $z=0$ であること。
6. 仮定 $v\ne o_L$ が外せないこと。$v=o_L$ のときは $z\ne0$ でも $z\odot v=o_L$ になること。
7. 主張が空虚でないこと。$z\ne0$ かつ $v\ne o_L$ のとき $z\odot v\ne o_L$ であること。

### 計算をどこで行っているか（$\overline{\mathbb{Q}}$ の扱い）

代数的数の全体は `QQbar`（厳密な代数的数の体）で表した。スカラーには $2$・$-1/3$・$\sqrt2$・
$\sqrt{-1}$ と $0$ を使い、列ベクトルは零ベクトル・1 か所だけ零でないもの（各点を 1 度ずつ）・
全成分が零でないもの・一部が零のものを、添字の順番から決まる形で作っている
（乱数を使っていないので実行するたび同じものになる）。
**浮動小数点は使っていない**。実数体にも複素数体にも入っていない。

## 走らせた範囲

- $L=1,2,3$（$R_L$ の元の個数はそれぞれ 2・4・8）、スカラー 5 個、列ベクトルは $2^{L}+3$ 個。

$L=4$ 以降を回していないのは、この主張が $L$ にも成分の値にも依存せず、
証明が「値の異なる点を 1 つ取ること」と「零でない元が逆元を持つこと」しか使っていないためである
（増やしても新しい場合は現れない）。
