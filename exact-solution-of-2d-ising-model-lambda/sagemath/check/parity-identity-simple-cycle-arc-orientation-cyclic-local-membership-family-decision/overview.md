# SageMath Check: 局所所属の述語族への集約

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-18
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、内部語の文字を方向名に依らない
局所所属の述語族へまとめる。各文字を、単一辺の局所向きが直進か曲がりか、
二重辺と切断旗の個数、単一辺・二重辺・切断旗の二重・三重交差の個数で分類する。
得られる 34 族の出現回数と相対端点 10 成分との組が、二つの正準巡回支持の
係数を決めるかを判定する。

プログラミングによる検証では 9,739 弧型が 5,753 記述へまとまったが、
端点だけの支持で 315 種、語位置と端点の支持で 388 種の記述が係数 0 と 1 の
両方を含んだ。従って、この方向名を捨てた 7 量だけでは係数を決められない。
次は、個数へ潰したため失われたスロットの相対配置を述語族へ加える。

これは有限データ上の反証であり、一般の辺長・全語長についての主張ではない。
衝突の証人と 34 族の一覧は `certificate.json` に保存する。
