# SageMath Check: 語長四候補を反証する五鍵の特徴比較

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 範囲: 位置ビット閉式の語長四候補を反証した左核の五鍵
- 内容: 五鍵で相殺せず残る語長四弧型と、候補が落とした特徴を比較する
- 帰属: 有限集合と $\mathbb F_2$。浮動小数点を使わない

## 結果

2026-09-15 に実行した。鍵位置 634、654、670、696、698 の式を足すと、自由未知数として
残した 7,968 弧型はすべて偶数回現れて消え、固定した語長四弧型は二種類だけが奇数回残る。
二種類は両端点の完全署名が同じで、位置ビット閉式の値もともに零だが、五鍵の右辺の和は一である。

二種類は、先頭内部頂点の横向き単辺に対して二重辺が上にあるか下にあるかを区別する。
交差所属積 `step0_e_left*step0_d_up` は二種類で一、零となり、保存した五鍵の左核証拠との積は一である。
したがって、既存候補が落とした特徴には、同じ内部頂点における**異なる軸の単辺所属と二重辺所属の
相対配置**が含まれる。これは端点の切断旗と内部語位置の切断旗だけからは復元できない。

ただし、この一項だけを 7,085 鍵全体へ加えた系は階数 6,303、拡大階数 6,304 で非可解である。
この項は今回の五鍵証拠を除くが、閉式を完成させる十分条件ではなく、別の独立な障害が残る。
一般の辺長・全語長についての命題ではなく、一般命題と Lean 二版は未追加である。
