# SageMath Check: 非圧縮端点所属による切断候補の識別可能性

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。端点を語の境界に置く二候補を、軌道代表と端点の未圧縮な
  選択集合所属だけで分ける規則は成立しないことを確定した。

## 何を確かめるか

語長二以上の支持 781 項について、前段の二つの切断候補ごとに軌道代表を
復号し、その先頭・末尾へ整合する端点の選択集合所属を付加する。これを
候補の有限記述とする。

二候補の有限記述が同じになる項は 162 項あった。異なる 619 項でも、実際の
切断位置が辞書順最小の記述を選ぶものは 281 項、最大を選ぶものは 338 項に
分かれた。従って、端点の選択集合所属を圧縮前の形へ戻しても、それと
巡回・反転軌道代表だけでは二候補を一意に分けられない。

一方、二つの正準支持で重複する軌道をまとめた 620 件の有限要件には矛盾が
無い。次は、反転同一視の前の有向境界情報を一つ加え、162 件の同値候補を
先に分離する。
