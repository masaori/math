# SageMath Check: 有限内部語の一般境界延長規則

## 対象

**対象ラベル**: `claim_cut_flag_congruence_start_recovery`、
`claim_cut_flag_two_coordinate_boundary_completeness`、
`claim_cut_flag_realizable_candidate_selection`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての証明ではない。
- 実行日: 2026-09-18
- 結果: 辺長二から四、語長一から四の非後戻り内部語について、方向列の累積変位と各頂点の
  切断旗が課す始点座標の合同条件を 13,920 系で解き、始点を全列挙する旧規則と完全に一致した。
  復元した行始点集合と列始点集合の直積が全座標列を尽くすことも 13,920 系で一致した。
  27,840 件の境界延長と、前段の一辺二・三の 1,036 境界入射に対する従来の判定も完全に一致した。
  復元した反対端点旗への所属で濾過すると、実現可能な 651 入射を残し、実現不能な 385 入射を除いた。

## 何を確かめるか

辺長、空でない有限内部語、内部語を順に通る向きを入力とする。方向列から行・列の累積変位を作る。
各頂点で「座標が $0$」「座標が $L-1$」という正の切断旗は始点剰余類の合同式を、負の切断旗は
対応する剰余類の除外条件を与える。行と列で独立に合同条件を解いて始点を復元し、その列を先頭または
末尾から一辺延長して反対端点の切断旗を返す。この規則は始点の全列挙、語長、観測済み支持に依存しない。

有限全探索では、合同条件による復元結果が始点の全列挙と一致し、実際の座標路から作った全ての内部語で
元の座標列が候補に含まれ、両端の一辺延長が返す切断旗も実際の反対端点と一致することを確かめる。
さらに、復元された行始点と列始点の直積から作る座標列の集合が、全列挙で得た座標列の集合と一致することを
各合同系で確かめる。従って二次元座標列と境界延長候補の完全性も同じ有限検算の対象である。
一般の辺長と語長に対する命題と Lean 二版は `claim_cut_flag_congruence_start_recovery` に置き、
`claim_cut_flag_two_coordinate_boundary_completeness` が行列の独立適用を述べる。この有限全探索は
それらの具体例と実装経路を厳密整数計算で検算する。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-selector-general-boundary-extension/check.sage
```
