# SageMath Check: 有限内部語の一般境界延長規則

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての証明ではない。
- 実行日: 2026-09-17
- 結果: 辺長二から四、語長一から四の非後戻り内部語について、座標持ち上げと境界延長の規則を
  13,920 本の座標路・27,840 件の境界延長で全探索した。前段の一辺二・三の 1,036 境界入射に
  ついて、従来の判定と完全に一致した。

## 何を確かめるか

辺長、空でない有限内部語、内部語を順に通る向きを入力とする。最初のトーラス頂点を有限個全て調べ、
内部の出方向に沿って座標列を作り、各位置の切断旗と一致する列だけを残す。その列を先頭または末尾から
一辺延長し、反対端点の切断旗を返す。この規則は語長や一辺二・三の観測済み支持に依存しない。

有限全探索では、実際の座標路から作った全ての内部語について元の座標列が規則の候補に含まれ、両端の
一辺延長が返す切断旗も実際の反対端点と一致することを確かめる。これは一般証明ではなく、一般証明へ
移す対象を「有限語の座標持ち上げと一辺延長」という一つの規則へ固定する検算である。
