# 経路反転で標準接触対に依存する分類は保たれない

**対象ラベル**: `claim_path_reversal_contact_pair_preservation`, `def_standard_turning_difference_subsets`, `def_unswitchable_standard_pair_subset`
- 検証コード: `check.sage`
- 方法: 一辺 $L=2$ の全非後退置換を、接触の無い部分・位相反転部分・標準対の回転差が $-4,4$ の二部分・残余へ分類し、経路反転の前後の分類を全数比較する。
- 浮動小数点: 使用しない。
- 実行日: 2026-09-02
- 結果: 接触の無い $49$ 個は全て同じ部分に留まった。一方、残余から位相反転部分へ移るものが $1{,}416$ 個、残余から回転差 $-4$ と $4$ へ移るものがそれぞれ $384$ 個と $520$ 個、位相反転部分から回転差 $-4$ へ移るものが $136$ 個、回転差 $-4$ から $4$ へ移るものが $1{,}548$ 個あった。逆向きの遷移数も経路反転の対合性により全て一致した。
- 帰結: 接触対全体と各対の切り替え可能性は経路反転で保たれるが、固定した辞書式順序の最小元はその全単射で保たれない。したがって標準接触対に依存する四部分をそのまま経路反転軌道の重みに使う経路は採用しない。次は接触対の順序に依らない分類を構成する。
- 状態: PASS（2026-09-02 実行）。
