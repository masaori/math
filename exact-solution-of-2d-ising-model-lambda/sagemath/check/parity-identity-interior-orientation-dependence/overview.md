# 内部合成偶奇の配向依存（反例）

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

偶奇恒等式の左辺を動辺数・内部辺対・切断線辺対・局所位相へ分けたとき、
内部側の合成偶奇（動辺数＋内部辺対の反転和＋局所位相）が鍵 $(D,E)$ だけで
決まるなら、一般証明は内部と切断線を独立に扱えた。本検算はそれが成立しない
ことを反例で固定する。一辺二で $8$ 鍵、一辺三（$D=\varnothing$ の自明文字）で
$21$ 鍵は、同じ鍵の曲がり型なし均衡配向の間で値が異なる。値が一定の鍵に
限っても、$E$ の巻き付き偶奇と切断線に触れる辺数の偶奇・その二項係数の偶奇が
全て同じで値が異なる鍵の組が存在する。従って残る一般証明は、内部寄与を
配向と独立な不変量として合成するのではなく、成分反転で内部側の変化と
切断線側の変化が相殺することを示す形で組む。

- 実行: `sage sagemath/check/parity-identity-interior-orientation-dependence/check.sage`
- 状態: PASS（2026-09-04。一辺二の配向依存 $8$ 鍵・統計衝突あり、
  一辺三の配向依存 $21$ 鍵・統計衝突あり）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
