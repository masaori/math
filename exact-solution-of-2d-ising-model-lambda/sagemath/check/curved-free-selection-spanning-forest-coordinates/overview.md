# 成分指示元と生成森による局所選択座標

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

有限偶グラフ $E$ の各連結成分の辺指示元を先頭に置く。辺の固定順序に従う
Kruskal 森を作り、非森辺が定める基本閉路を順に走査して、階数を増やすものだけを
加える。基本閉路は巡回空間の基底なので、この操作は成分指示元を保った基底拡張を
与える。次数が二か四なら巡回階数は $c(E)+n_4(E)$ であるから、追加される基底元は
ちょうど $n_4(E)$ 本である。これらを次数四頂点の固定順序と対応させれば、各頂点の
局所選択ビットが残りの基底係数になる。巡回空間の全元を先に列挙する必要はない。

一辺二・一辺三で、曲がり型なし配向を持つ非空偶部分グラフの全てについて、基底の
階数、各基底元の偶次数性、成分配向ビットと局所選択ビットから全係数列への全単射を
検査した。一辺二は $23$ グラフ・$80$ 係数列、一辺三は $677$ グラフ・$3{,}136$
係数列である。一般の有限偶グラフに対する基底拡張規則は線型代数から従うが、各成分の
曲がり型なし配向が常に全反転対になることと、符号が選択和と一致することは一般の
辺長ではまだ証明していない。

- 実行: `sage sagemath/check/curved-free-selection-spanning-forest-coordinates/check.sage`
- 状態: PASS（2026-09-04。一辺二・一辺三の有限確認）
- 方法: 有限集合、$\mathbb F_2$、整数の厳密演算のみ。浮動小数点は使わない。
