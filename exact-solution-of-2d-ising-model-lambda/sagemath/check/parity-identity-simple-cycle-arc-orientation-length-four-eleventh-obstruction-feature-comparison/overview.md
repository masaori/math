# SageMath Check: 十特徴追加後に残る語長四障害の特徴比較

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 範囲: 位置ビット閉式へ先行する十の障害を除く特徴を加えた有限合同系
- 内容: 次の左核矛盾証拠と、そこで相殺しない語長四弧型の特徴を比較する
- 帰属: 有限集合と $\mathbb F_2$。浮動小数点を使わない

## 結果

2026-09-15 に実行した。先行する十特徴を加えた系から、35 鍵を台に持つ次の
左核矛盾証拠を取り出した。35 行を足すと、自由未知数として残した 7,968 弧型と
先行十特徴は相殺し、固定済みの語長四弧型 26 種だけが奇数回残る。候補値の和は零、
鍵の右辺の和は一なので、これは先行する十の証拠とは独立な障害である。

26 種上で一次特徴と二特徴積を全数比較すると、相殺しない特徴は 1,049 個あり、
そのうち一次特徴は 16 個だった。先頭語位置の右側での倍化辺所属 `step0_d_right` は
証拠との積が一になる。この列も加えた全 7,085 鍵の系は階数 6,313、拡大階数 6,314
でなお非可解だった。したがって、この特徴は今回の証拠を除くが、閉式を完成させる
十分条件ではなく、さらに独立な障害が残る。一般の辺長・全語長についての命題ではなく、
一般命題と Lean 二版は未追加である。
