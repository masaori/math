# SageMath Check: 切断候補の端点ビットへ加える語長三の指示ビット

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と整数の厳密演算。浮動小数点を使わない。
- 一般の辺長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 成功。端点ビットで衝突する二つの入力はいずれも語長三と語長五を
  区別する必要があり、語長三の指示ビットを加えると観測済み支持の衝突は零になった。

## 何を確かめるか

前段で得た端点ビットの二つの衝突証拠を比較する。どちらも同じ端点ビットに対して
語長三と語長五が反対の候補順位を要求する。従って語長の奇偶は両者を区別できず、
端点ビットだけを使う規則へ加える語長述語は、少なくとも語長三と語長五を分離しなければならない。

観測済み支持では、一ビットの述語「語長が三である」を端点ビットへ加えると、全 781 項の
入力 612 種に相反する要求は無い。これは有限支持上の必要な分離と十分な一ビットを述べるだけであり、
一般語長の閉じた選択規則を与えない。次は語長三と語長五の内部語を比較し、この指示ビットを
語長そのものではなく巡回語の構造から導く述語を探す。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-selector-length-three-indicator/check.sage
```
