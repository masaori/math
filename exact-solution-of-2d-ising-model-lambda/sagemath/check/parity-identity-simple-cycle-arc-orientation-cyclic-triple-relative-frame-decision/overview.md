# SageMath Check: 連続三文字の局所基準の回転関係

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-18
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、巡回内部語の連続三文字が持つ
単一辺・二重辺・切断旗の四スロット所属へ同じ四回転を作用させる。
三文字の軌道代表は絶対方向名を捨てる一方、三文字間の局所基準の
相対回転を保つ。この三文字族の巡回出現回数と相対端点 10 成分との組が、
二つの正準巡回支持の係数を決めるかを判定する。

これは有限データ上の判定であり、一般の辺長・全語長についての主張ではない。
衝突が残る場合の証人は `certificate.json` に保存する。

プログラミングによる検証では、観測された連続三文字は四回転の同時作用で
7,253 三文字族へまとまった。しかし、相対端点 10 成分との組で 9,739 弧型は
7,427 記述へ分かれ、端点だけの支持で 220 種、語位置と端点の支持で 260 種の
記述が係数 0 と 1 の両方を含んだ。これは隣接二文字の場合と同じ分割数・
衝突数である。三文字族の出現回数から、先頭二文字が一致する族を足すことで
隣接二文字族の出現回数を復元できるため、三文字の記述は隣接二文字の記述を
細分する。細分後の記述数が変わらないので、この有限範囲では両者の分割は
一致し、三文字化は係数決定に必要な情報を増やさない。次は連続四文字へ
同じ四回転を作用させた巡回窓を判定する。
