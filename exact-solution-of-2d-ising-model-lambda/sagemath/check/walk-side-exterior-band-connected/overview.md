# SageMath Check: 頂点単純閉路の歩道沿いの外側帯は空でなく辺連結である

**対象ラベル**: `claim_walk_side_exterior_band_edge_connected`

原点から始まる長さ $10$ 以下の頂点単純な閉じた非後退単位格子歩をすべて列挙する。
右半直線と縦辺の交差数が偶数である外側セルのうち訪問頂点を四隅に持つもの（歩道沿いの外側帯）を作り、次を検査する。

- 各訪問頂点の外側セル集合 $A'_j$ が空でない。
- 歩の各辺を挟む二セルのうちちょうど一方が外側で、隣り合う訪問頂点の $A'_j\cap A'_{j+1}$ に入る（橋）。
- 帯 $\mathcal O(\gamma)=\bigcup_j A'_j$ が空でなく、辺隣接による幅優先探索が帯全体に到達する。

- 実行: `sage sagemath/check/walk-side-exterior-band-connected/check.sage`
- 状態: PASS（2026-08-31。頂点単純な閉じた非後退歩道 704 本・橋 6,672 箇所・外側帯セル延べ 9,488 個）
- 計算: 単位格子歩の有限列挙と `ZZ` の比較・加法・奇偶だけ。浮動小数点は使わない。
