# 曲がり型なし配向類の局所行列式和と選択符号の同定

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

自明文字で選択集合が非空な鍵 $(D,E)$ について、曲がり型なし均衡配向を
置換の列挙に頼らず局所決定性の伝播で構成し、各配向類の位相和を分解済みの
局所遷移行列式の積の公式で計算した。

- 構成した配向は成分ごとの向き $2^{c(E)}$ 個を尽くし、一辺二では置換
  ファイバーが誘導する曲がり型なし配向の集合に一致する。
- 選択和の各項 $w(D\cup C)\,w(D\cup(E\setminus C))$ は全て同じ符号を持つ。
- 全ての曲がり型なし配向類の局所行列式和は、四つのねじれそれぞれで
  共通符号 $\times\,2^{n_4(E)}$ という同一の値になる（成分反転で不変）。

一辺二は全 $369$ ファイバー鍵（値の検査 $2{,}952$ 件）、一辺三は $D=\varnothing$
の自明文字 $677$ 鍵（選択項 $12{,}544$ 項、値の検査 $6{,}088$ 件）の全数で
検査した。一辺三では、非空偶部分グラフで曲がり型なし配向が存在することと
文字が自明なことの同値も全数で照合した。

- 実行: `sage sagemath/check/curved-free-class-sum-selection-sign/check.sage`
- 状態: PASS（2026-09-04。一辺二の全鍵と一辺三の $D=\varnothing$ 鍵の全数）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
