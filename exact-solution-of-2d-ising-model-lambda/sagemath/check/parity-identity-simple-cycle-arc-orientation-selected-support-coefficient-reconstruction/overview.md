# SageMath Check: 実現可能な最小切断による支持係数の再構成

## 対象

**対象ラベル**: `claim_selected_support_coefficient_reconstruction`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての検算ではない。
- 実行日: 2026-09-18
- 結果: 成功。二つの正準巡回支持のうち、方向上連結する二候補を持つ 489 項を、巡回・反転軌道上の係数と、有限合同条件が残す実現可能候補の最小元から損失なく再構成した。

## 何を確かめるか

端点特徴代表の支持 462 項と語位置・端点積代表の支持 616 項から、方向上連結する切断候補が二つある 489 項を取り出す。弧型から巡回・反転軌道と切断位置を取り出し、各軌道で座標上実現可能な切断候補を列挙して、保存済み切断位置がその最小元であることを確かめる。

各軌道の係数を切断候補上の係数の $\mathbb F_2$ 和として作り、最小候補へだけその係数を戻す。復元後の全候補係数が保存済み支持の係数と一致することを検査する。二支持全体から軌道への射影の単射性は、先行する「正準弧型支持の巡回軌道符号化」の検算が担う。

## 実行方法

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-selected-support-coefficient-reconstruction/check.sage
```
