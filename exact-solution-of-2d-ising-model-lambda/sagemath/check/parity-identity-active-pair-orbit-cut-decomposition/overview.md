# 動辺対の軌道項と座標切断横断項への分解

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

標準形配向の動辺集合に含まれる非共有端点の有向辺対を、二辺の同時平行移動軌道ごとにまとめた。
各軌道の辞書式最小の辺対を代表とすると、動辺対に制限した寄与の和は

\[
  (\text{代表の寄与})(\text{動辺対の個数})
  +(\text{終点二つの座標切断横断数})
  +(\text{始点二つの座標切断横断数})
  \pmod 2
\]

に等しい。後ろ二項は、二点を同時に平行移動したときに mod $L$ の座標切断を片方だけが横切り、
辞書式順序が反転する回数である。従って、前回得た全軌道の偶奇を、一般の鍵の動辺集合へ
制限したときに必要な補正は座標切断の横断数だけで書ける。

- 一辺二: 自明文字で選択非空の $369$ 鍵、動辺対 $2{,}952$、動辺が当たる軌道延べ
  $2{,}154$。切断補正が奇の軌道・鍵の組は $0$。
- 一辺三: $D=\varnothing$ の自明文字 $677$ 鍵、動辺対 $14{,}472$、動辺が当たる軌道延べ
  $11{,}175$。切断補正が奇の軌道・鍵の組は $3{,}374$。

一辺三では補正が実際に非零なので、軌道代表の寄与だけでは動辺対和を復元できない。

- 方法: 有限集合と $\mathbb F_2$ の厳密演算のみ。浮動小数点は使わない。
