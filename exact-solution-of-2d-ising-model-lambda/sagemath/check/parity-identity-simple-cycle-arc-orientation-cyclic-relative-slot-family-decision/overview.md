# SageMath Check: 単一辺を基準にした相対スロット配置

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-18
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、内部語の各文字が持つ単一辺・二重辺・
切断旗の四スロット所属を、正方形の四つの回転で同時に移す。上・下・左・右という
絶対方向名を捨てる一方、鏡映は使わず、弧の向きが区別する時計回り・反時計回りと、
単一辺の局所向きに対する二重辺・切断旗の相対配置を保った
軌道代表を局所族とする。この局所族の出現回数と相対端点 10 成分との組が、二つの
正準巡回支持の係数を決めるかを判定する。

これは有限データ上の判定であり、一般の辺長・全語長についての主張ではない。
局所族の一覧と、衝突が残る場合の証人は `certificate.json` に保存する。

プログラミングによる検証では 216 文字が 55 局所族へまとまり、相対端点 10 成分との
組で 9,739 弧型は 6,021 記述へまとまった。しかし、端点だけの支持で 312 種、
語位置と端点の支持で 381 種の記述が係数 0 と 1 の両方を含んだ。従って、各文字の
相対スロット配置の出現回数だけでは両係数を決められない。個々の文字内の配置は
保っているため、次は隣接する文字間で局所基準の回転がどう移るかを加える。
