# SageMath Check: 持ち上げ点と境界頂点の全単射

**対象ラベル**: `claim_plane_simple_polygon_cyclic_turning`

本文の証明の段落「一周期の持ち上げ点と境界頂点を対応させる」の三つの事実を検査する。
一周期の持ち上げ点が二つずつ相異なる零巻き付きの閉じた非後退単位格子歩について、
(a) 各歩の単位辺の通過回数はちょうど 1 で内側セル集合の境界辺であること、
(b) 内側セル集合の各境界辺（縦辺は横に隣り合う二セル、横辺は上下に隣り合う二セルが共有する）の通過回数は奇数であること、
(c) $k\mapsto P_k(\gamma)$ が $\{0,\ldots,m-1\}$ から境界頂点集合への全単射であること。
内側セルは右半直線との交差奇偶で定める。

- 実行: `sage sagemath/check/plane-simple-polygon-lift-point-boundary-vertex-bijection/check.sage`
- 状態: PASS（2026-11-27）。長さ $10$ 以下の持ち上げ点相異の閉歩道 704 本で、歩の単位辺 6672 件、境界辺 6672 件、境界頂点 6672 件を検査した。実行環境に SageMath が無いため、`ZZ` を Python の `int` に置き換えて同じコードを実行した。
- 計算: 有限の数え上げと `ZZ` の四則・剰余だけ。浮動小数点は使わない。
