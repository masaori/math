# SageMath Check: 代数的数の有限積が 0 ならば、0 である因子がある

## 対象

**対象ラベル**: `claim_qbar_prod_eq_zero`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の主張 1 件
- 併せて引く定義: `def_algebraic_numbers`（代数的数の全体 $\overline{\mathbb{Q}}$）

### 何を確定させるための検証か

シフト行列の特性多項式は軌道ごとの因子の積であり（`claim_shift_char_orbit_factorization`）、
その値は因子の値の積である（`claim_second_evaluation_prod`）。値が 0 であることから
「値が 0 である因子が 1 つある」を出すのがこの主張であり、次のセクション
（特性多項式の値を 0 にする代数的数が 1 の $L$ 乗根であること）が引く形そのものである。

確かめるのは次の 6 で、人手証明の段に 1 対 1 で対応する。

1. 帰納法の出発点。空の積は $\overline{\mathbb{Q}}$ の単位元 $1$ であり $1\ne0$ である
   （したがって空の $s$ は仮定を満たさない）。
2. 帰納法の一歩の第 1 の鎖。$\prod_{i\in s\cup\{a\}}c_i=c_a\cdot\prod_{i\in s}c_i$。
3. 帰納法の一歩の第 2 の鎖（$c_a\ne0$ の場合）。5 段の各段が成り立つこと
   （$1$ を掛ける・逆元を差し込む・結合則・仮定を代入・零元との積）。
4. 主張そのもの。族の全部分集合 $s$ について、積が 0 ならば 0 である因子があること。
5. 主張が空虚でないこと。積が 0 になる $s$ と、ならない $s$ の両方が実際にあること。
   加えて応用の形（因子を軌道ごとの因子の値 $z^{\lvert O\rvert}-1$ に取ったもの）でも
   0 になる因子が取れ、その指数について $z^{\lvert O\rvert}=1$ であること。
6. 仮定が外せないこと。零因子を持つ環 $\mathbb{Z}/6\mathbb{Z}$ では同じ言明が破れること
   （$2\cdot3=0$ だが $2$ も $3$ も 0 でない）。すなわちこの主張は
   $\overline{\mathbb{Q}}$ が体であることを使っている。

### 計算をどこで行っているか（$\overline{\mathbb{Q}}$ の扱い）

代数的数の全体は SageMath の `QQbar`（厳密な代数的数の体）で表した。
**浮動小数点は使っていない**（`ZZ` / `QQ` / `QQbar` の厳密計算だけ）。
実数体にも複素数体にも入っていない。

## 走らせた範囲

因子の族は 5 個の代数的数からなるものを 2 つ（0 を含むものと含まないもの）用意し、
その全 32 部分集合を $s$ として走らせた（合計 64 組）。
一歩の鎖は、その各 $s$ と $s$ に属さない $a$ の全組み合わせ（160 組・うち $c_a\ne0$ が 144 組）。
応用の形は軌道の元の個数の組 6 通り（$L=1,\dots,6$ に実際に現れる形）と
$z$ 6 個（$1$・$-1$・1 の 3 乗根・1 の 6 乗根・$2$・$\sqrt2$）。
本文の主張は任意の $s$ と任意の族についてのものなので、有限個で確かめたことは証明ではない。
