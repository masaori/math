# SageMath Check: 境界方向を共通基準にした隣接二文字の出現回数

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、各実現可能な境界入射候補の
境界方向を上方向へ送る一意な正方形回転を選ぶ。その同じ回転を巡回内部語の
隣接二文字へ作用させ、順序付き二文字の出現回数と、その候補の相対端点
10 成分を対応づける。

候補ごとの対応を失わないこの記述が、二つの正準巡回支持の係数を
有限全データ上で決めるかを判定する。これは一般の辺長・一般の内部語に
ついての主張ではない。衝突が残る場合は、その証人を `certificate.json` に保存する。

プログラミングによる検証では、境界方向の共通基準で表した順序付き隣接二文字は
7,856 種だった。相対端点 10 成分との組により 9,739 弧型は 7,427 記述へ分かれたが、
端点だけの支持では 220 種、語位置と端点の支持では 260 種の記述に係数 0 と 1 が
混在した。この分割と衝突数は、各隣接窓を独立に回転同値でまとめた既存判定と一致する。
従って、有限範囲では境界方向を共通基準にしても隣接二文字の出現回数は両係数を
決めず、次は同じ境界基準で連続三文字の順序を保った出現回数を判定する。
