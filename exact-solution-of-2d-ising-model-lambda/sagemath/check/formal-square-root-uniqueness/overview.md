# 定数項一の形式的平方根は一意である

検算対象は、対象ラベルに添付したノート「旧主張：定数項一の形式的平方根の一意性」です。
本文の多項式平方根の一意性の検算ではありません。有限標本・有限打切りの計算は、
無限列全体の可算性を保証しません。旧検算コードは参照用に保持しています。

**対象ラベル**: `claim_qbar_polynomial_square_root_unique`
- 実行: `sage sagemath/check/formal-square-root-uniqueness/check.sage`
- 状態: PASS（2026-10-24、44 件を再実行）

係数を `QQbar` に固定し、定数項が一の有限多項式を形式的冪級数の有限標本として使う。保存した旧証明の
因数分解、同じ平方を持つこと、定数項一の分岐では一致することを厳密計算する。反対分岐
`T=-S` は平方が同じでも定数項が負一になり、仮定から外れることも検査する。浮動小数点は使わない。
