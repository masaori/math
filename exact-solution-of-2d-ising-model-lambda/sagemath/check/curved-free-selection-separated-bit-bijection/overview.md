# 曲がり型なし配向と局所選択の分離ビット全単射

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

前のトレイル台写像が情報を失う唯一の全辺ファイバーについて、配向と局所選択を
別々のビットとして保つ対応を構成した。一辺二の全辺ファイバーでは、曲がり型なし
均衡配向の辞書式順位が一ビット、四つの直進型頂点の選択が四ビットを与える。
$E$ の $\mathbb F_2$ 巡回空間から辞書式に決めた五元の基底へこの五ビットを係数として
渡し、辞書式最小の選択集合との対称差を取る。

一辺二の自明文字・選択非空の全 $369$ ファイバーで固定した事実:

- 直進型頂点を持たない $368$ ファイバーでは、前のトレイル台写像が選択集合への
  全単射になる。
- 全辺ファイバーでは、配向一ビットと局所選択四ビットを巡回空間の五つの基底係数へ
  分けて渡す対応が、全 $32$ 対を相異なる選択集合へ写す。
- 合計 $768$ 対の像は各ファイバーの選択集合をちょうど一度ずつ尽くす。

これで一辺二では全単射が構成できた。ただし全辺ファイバーでの座標化は有限列挙の
辞書式順序に依存する。一般の辺長では、配向差と局所選択ビットから基底係数を
列挙に頼らず取り出す規則が必要である。

- 実行: `sage sagemath/check/curved-free-selection-separated-bit-bijection/check.sage`
- 状態: PASS（2026-09-04。一辺二の有限構成。一般の辺長は未証明）
- 方法: 有限集合、$\mathbb F_2$、整数の厳密演算のみ。浮動小数点は使わない。
