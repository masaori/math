# SageMath Check: 正錐の元を係数とする平方和は前錐をなす

## 対象

**対象ラベル**: `def_positive_weighted_square_sums`, `claim_positive_weighted_square_sums_is_precone`

- 実行日: 2026-11-17
- 結果: 全検査通過（二つのモデルで無作為の族 200 組ずつ、多項式環の恒等式 16 通り）
- 帰属: `QQ` の厳密計算。浮動小数点を使わない。

## 何を確かめるか

本文の証明の段を、行ごとに次で確かめる。普遍量化された主張の証明ではない。

- 単位元の所属の段: $1\ne0$、$(-1)\cdot(-1)=1$、二つのモデルで $1\in C_F$。
- 和の段: $z_1+z_2$ が、添字集合を交わらない和 $K$ に取った $e,v$ の平方和に等しいこと。
- 積の段: $z_1\cdot z_2$ が二重和に等しく、それが直積 $I\times J$ 上の $e',v'$ の平方和に等しいこと。$e'$ の値が $C_F$ に入ること。
- 平方の条件と正錐の包含の段: 一元集合上の和で $y_0\cdot y_0$ と $c_0$ が表せること。空の和が零元であること。
- 和と積の式変形を、多項式環 $\mathbb Q[c,y,d,w]$ の恒等式として、添字の大きさ $0$〜$3$ の全 16 通りで確かめる。

モデルは次の二つ。$Q_s$ の元 $a+bs$（$s\cdot s=2$）を有理数の組 $(a,b)$ で表す。

- モデル A: $F=\mathbb Q\subseteq E=Q_s$、$C_F=\mathbb Q_{>0}$。
- モデル B: $F=E=Q_s$、$C_F=P_s$（`def_quadratic_positive_cone` の三つの有理条件）。
