# 対角平行移動固定鍵の非自明な選択文字

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限グラフ、$\mathbb F_2$、自然数
- 実行: `sage sagemath/check/translation-diagonal-fixed-nontrivial-character/check.sage`
- 状態: PASS（2026-09-03。約 7 秒。全数値を等号 assert で固定して再実行済み）

一辺 $L$ の対角平行移動 $(1,1)$ で固定されるファイバー鍵 $(D,E)$ は、$D$ と
$E$ がともに対角平行移動の辺軌道の和で、互いに素、かつ $E$ が偶部分グラフで
あるものに限る。各辺軌道の長さは $L$、軌道数は $2L$ である。

$E$ の中の偶部分グラフ $H$ に対する選択文字
$\langle E,H\rangle=\epsilon_{\mathrm h}(E)\epsilon_{\mathrm v}(H)
+\epsilon_{\mathrm v}(E)\epsilon_{\mathrm h}(H)\pmod2$ が非自明かを、$E$ が作る
有限グラフの基本閉路上で判定する。具体的には、各辺へ文字の係数を置き、それが
頂点ポテンシャルの差として書けるかを全成分で調べる。書けないことと、文字値が
$1$ になる閉路 $H\subseteq E$ が存在することは同値である。

各 $E$ に対して、$D$ は $E$ に使わなかった辺軌道の任意の和なので、該当する
固定鍵の個数は $2^{2L-r(E)}$（$r(E)$ は $E$ に使った辺軌道数）を足して数える。
一辺二から八までの結果は次のとおりだった。括弧内は
「対角固定鍵の総数、文字が非自明な $E$ の個数、非自明文字を持つ対角固定鍵の個数」である。

- $L=2$: $(41,0,0)$
- $L=3$: $(189,1,1)$
- $L=4$: $(881,0,0)$
- $L=5$: $(4{,}149,1,1)$
- $L=6$: $(19{,}721,0,0)$
- $L=7$: $(94{,}509,1,1)$
- $L=8$: $(456{,}161,0,0)$

奇数辺長で該当する $E$ は全基底辺集合だけであり、その補集合に置ける $D$ は空集合だけなので、
該当する鍵も $(D,E)=(\varnothing,E_L)$ の一つだけである。偶数辺長では該当する $E$ が無い。
従って一辺二の対角部分群の自由作用は、少なくとも一辺三では既に破れる。一方で障害は
一辺二から八の観察では奇数辺長の一鍵へ集中しており、偶数辺長では対角固定鍵があっても
選択文字が非自明な検査対象には入らない。次は奇数辺長の全辺鍵で、候補辺に対角部分群不変な
完全マッチングが存在する条件を調べる。
