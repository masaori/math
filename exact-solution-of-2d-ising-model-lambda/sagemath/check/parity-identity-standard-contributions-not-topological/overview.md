# 標準形の四寄与は位相三量だけでは決まらない

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

各辺連結成分の最小辺の向きを 0 に固定した標準形でも、動辺数・内部辺対・
切断線辺対・局所位相の四寄与は、巻き付き偶奇二つと交差対だけから個別には
決まらない。同じ三つ組に複数の四寄与の組が属する反例を、一辺二と一辺三の
有限系で固定した。一方、四寄与の総和は全件で標的の位相式に一致する。

従って一般証明では、四寄与を位相三量から別々に復元するのではなく、追加の
幾何的統計を導入して途中で相殺する必要がある。

- 実行: `sage sagemath/check/parity-identity-standard-contributions-not-topological/check.sage`
- 状態: PASS（2026-09-04。同じ位相三量で複数の四寄与を持つ類は一辺二 7 類・一辺三 4 類。四寄与の異なる組は一辺二 8 種類・一辺三 12 種類）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。
  浮動小数点は使わない。
