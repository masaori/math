# 語長一の局在形と語長三の固定非切断項を両立させる

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に限った有限存在判定。
前回の語長一・二・三の同時制約から語長二の制約だけを外す。
語長一の弧型値は切断旗を含む二次単項式だけの和とし、語長三ではそれに
各語位置の上辺所属と左辺所属の積の和を加える。
各語長に別々の係数を許す。語長二を含む他の語長と閉路型の値は自由未知数のままである。
定数項・一次項・他の非切断項は零。語と端点対を別々に正準化し、実頂点の同定を追加しない。
一般の辺長の命題と Lean 二版は未追加。整数・有限体・上流の円分体だけで計算する。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-one-three-fixed-interior/check.sage
```

初回は `--record` を付けて証拠を保存し、通常実行で保存した証拠を再判定する。
2026-09-06 初回のプログラミングによる検証: 終了コード 0 で通過。
10,378 行・11,698 未知数で係数行列と拡大係数行列の階数はともに 10,011。
解を `certificate.json` へ保存し、全 7,085 鍵の値を復元した。
この一解の切断旗を含む積は語長一で 122 項、語長三で 242 項だった。
項数の最小性と係数の一意性は主張しない。保存した証拠を読む再実行も終了コード 0 で通過し、両階数と全鍵の復元を再現した。

LLM による検証: 構成の指定語長は一・三だけで、右辺は一で零、三で固定語位置和である。
従って語長一の局在制約だけは、語長三の固定項と両立する。
前回の三語長同時系の非可解性と合わせ、そこから語長二の局在条件を外せば矛盾が解消する。
語長二の局在形と語長三の固定項だけが両立するかは未判定で、次に切り分ける。
