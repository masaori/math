# 多重通過頂点の横断数

**対象ラベル**: `claim_vertex_crossing_number_factorization`
- 実行: `sage sagemath/check/vertex-crossing-factorization/check.sage`
- 状態: PASS（2026-08-30、閉じた非後退辺列 1,064 件）
- 使用する環: `ZZ` と有限集合だけ。浮動小数点は使わない。

$L=1,2,3$・辺 1〜5 本の全閉じた非後退辺列について、各格子頂点での横断対の個数
$c_v(\gamma)$（横断の定義 `def_index_pair_crossing` から独立に数える）が、
その頂点での軸 0 の直進通過数と軸 1 の直進通過数の積に等しいことを検査する。
同じ頂点を三回以上直進通過する標本が含まれることも確認する。

2026-08-30 レビュー修正: 当初の検算は横断対を直積 $H\times V$ から構成していて
左辺が横断の定義から計算されていなかった（ほぼ恒真）。左辺を横断述語で
独立に数える形へ強化した。
