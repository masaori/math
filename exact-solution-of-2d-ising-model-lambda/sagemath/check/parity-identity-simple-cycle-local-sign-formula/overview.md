# 単純閉路鍵の頂点項の閉じた局所式（次数 3 の単項式和）

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二の単純閉路鍵の頂点項は局所署名の指示関数 $46$ 種の和で書けることまで
固定済みだが、指示関数の一覧は列挙に依存して一般の辺長へ持ち上がらない。
そこで署名の成分——各頂点の上下左右のスロットの $D$ 所属 $d_s$・$E$ 所属
$e_s$ と切断隣接旗 $4$ つ——を $\mathbb F_2$ 変数とみなし、次数 $k$ 以下の
単項式全体を特徴量として頂点項の頂点和表示を解いた。

次数 $1$・$2$ では（切断旗を入れても）解が無く、次数 $3$ で初めて解ける。
核ベクトルで支持台を貪欲に縮めた表示は $16$ 項で、次数 $3$ の項は全て
上スロット・下スロット・左スロットの所属変数一つずつの積である。切断旗は
$e_{\mathrm{up}}\cdot\mathrm{row0}$ と $e_{\mathrm{left}}\cdot\mathrm{col0}$
の二項にだけ現れる。一辺二では動辺数が常に偶数なので、非共有端点対項は
標的指数とこの局所式の和で決まる。

これは一辺二の全 $320$ 鍵での固定であり、同じ式が一般の辺長で成り立つかは
未検証である。次数 $3$ が必要という下界は、頂点項が二スロットの相関では
書けず三スロットの相関を要することを言っている。

- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
