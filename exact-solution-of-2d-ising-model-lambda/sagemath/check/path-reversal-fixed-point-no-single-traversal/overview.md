# 経路反転の不動点は単純通過辺を持たない

**対象ラベル**: `claim_path_reversal_fixed_point_no_single_traversal`
- 検証コード: `check.sage`
- 方法: 一辺 $L=2$ の全非後退置換について、経路反転の不動点では単純通過の辺集合が空であることを検査する。さらに単純通過辺集合が非空な全ファイバーと四つのスピン構造・両符号について、経路反転が不動点を持たないことと、符号別の経路反転軌道の元の個数が全て二であることを検査する。
- 浮動小数点: 使用しない（有限集合の元の比較と $\mathbb Q(\zeta_8)$ の等号だけ）。
- 実行日: 2026-09-02
- 結果: 非後退置換 $30{,}784$ 個のうち経路反転の不動点は $152$ 個で、全て単純通過の辺集合が空だった。単純通過辺集合が非空な $505$ ファイバー×四スピン構造・両符号の経路反転軌道 $40{,}768$ 個は全て二元だった。
- 状態: PASS（2026-09-02 実行）。
