# SageMath Check: 巡回窓の多重集合による二軌道係数の判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

辺長二・三から得た有限合同系の全弧型について、前段の相対端点 10 成分に
内部語の長さ $k$ の巡回窓の多重集合を加える。窓の開始位置を忘れて巡回移動に
不変とし、語の反転前後で辞書式最小を取って反転にも不変とする。二つの正準巡回
支持の係数をともに決める最小の共通窓長を有限範囲で判定する。

これは一般の辺長についての係数式ではなく、内部語から残す巡回不変量を窓長で
段階化した候補族の有限判定である。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-cyclic-window-profile-coefficient-decision/check.sage
```

プログラミングによる検証では、内部語を捨てた相対端点 10 成分だけの記述には
端点だけの支持で 238 種、語位置・端点の支持で 305 種の係数衝突が残った。
長さ 1 の巡回窓の多重集合、すなわち内部語の各文字の出現回数を加えると、
9,739 弧型は 9,735 記述へ分かれ、どちらの支持にも係数衝突は残らなかった。
従ってこの巡回窓候補族では、両係数を決める最小の共通窓長は 1 である。
