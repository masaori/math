# SageMath Check: 語長四の弧型係数を含む巡回共変な固定線型関係

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 通過。巡回不変な固定関係を弧型係数だけの関係で割った商空間は 339 次元だった。

## 何を確かめるか

全 $7{,}085$ 鍵、$11{,}208$ 未知数の可解な合同系の行空間から、自由な弧型係数と
$3{,}240$ 個の特徴係数だけに台を持つ固定線型関係を全て取る。語位置四箇所の巡回移動は
特徴係数へ作用し、弧型係数は固定する。この作用で不変な関係を求め、弧型係数だけの関係を除いた商空間の次元で
特徴係数を本質的に混ぜる関係の有無を判定する。

自由な弧型係数は $7{,}609$ 個、閉路型係数は $359$ 個である。閉路型係数を零にする
制約の階数は $359$ で、弧型係数と特徴係数だけに台を持つ固定関係は $6{,}434$ 次元だった。
このうち特徴係数を全て零にした弧型係数だけの関係は $4{,}876$ 次元である。

特徴係数を一語位置だけ巡回移動した差も零にする制約の階数は $1{,}578$ で、巡回不変な
固定関係は $5{,}215$ 次元だった。従って弧型係数だけの関係を除いた商空間は $339$ 次元である。
特徴係数だけでは巡回不変な固定関係が零次元だった前回の結果と合わせると、この $339$ 次元は
いずれも弧型係数と特徴係数を本質的に混ぜる。一般の語長へ運べる式はまだ同定していない。
