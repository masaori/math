# SageMath Check: 完全に切り替え不能な残余の各接触が指す反転対の辺

**対象ラベル**: `claim_fully_unswitchable_contacts_witness_doubled_edges`

一辺 $L=2$ の全非後退置換から、標準接触対が切り替え不能な残余を取り出す。
残余を、別の切り替え可能な接触対を持つ置換と、全接触対が切り替え不能な置換へ分類する。
後者の各接触対について、像が他方自身になる障害は起こらず、反転像による障害が
接触対の少なくとも一方の台の辺を $D(\varphi)$ に入れることを厳密に検査する。

- 実行: `sage sagemath/check/fully-unswitchable-contacts-witness-doubled-edges/check.sage`
- 状態: PASS（2026-09-02）
- 結果: 一辺 $L=2$ の残余を、別の切り替え可能な接触対を持つ $17{,}925$ 個と、
  全接触対が切り替え不能な $830$ 個へ分類した。後者の全接触対について、
  接触対 $5{,}216$ 件のそれぞれに対応する反転対の辺が存在することを確認した。

計算は有限集合の等号と部分集合の所属だけで行い、浮動小数点は使わない。
