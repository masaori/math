# 衝突森の各成分に接する残りの候補辺の配置

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、$\mathbb{Q}(\zeta_8)$
- 実行: `sage sagemath/check/even-subgraph-orbit-collision-forest-context/check.sage`
- 状態: PASS（2026-09-03、成分 $176$ 個・残候補対 $5{,}120$ 本）

一辺 $L=2$ の共変な全候補集合で、一意な一頂点候補の選択辺 $1{,}280$ 本が作る森
（長さ $4$ の道 $32$ 個と、中心から四本の長さ $2$ の腕が出る木 $144$ 個）について、
各中心の候補元としての性質と、森の頂点に接する残りの候補辺
（全 $6{,}400$ 本の無向対から選択辺を除いた $5{,}120$ 本）の行き先を全数検査する。

全 $176$ 中心は位相反転候補を一本も持たない置換である（候補零本）。残りの候補対は
どの成分の内部にも一本も残らず、成分に接するものは全て成分の外へ出る。行き先の内訳は、
成分から森の外の頂点へ出るものが一頂点変更 $1{,}504$ 本・二頂点変更の分裂 $1{,}280$ 本・
合併 $512$ 本、異なる二成分を結ぶものが二頂点変更の分裂 $640$ 本、森に触れないものが
一頂点変更 $32$ 本・二頂点変更の分裂 $640$ 本・合併 $512$ 本である。

成分ごとの外へ出る残候補は道が $8$ 本、木が $30$ 本で一定である。各中心には成分の
外の頂点から候補辺がちょうど $2$ 本入る（同じ成分からは零本）。従って奇数頂点の
各成分を対で覆うには、成分間または森の外の置換と対にする辺が必ず要り、中心の対は
外から入るちょうど $2$ 本のどちらかから選ぶことになる。次はこの外部辺の相手
（森の外の置換・別の成分の頂点）の配置から、平行移動と可換な無向対の選択規則を探す。
