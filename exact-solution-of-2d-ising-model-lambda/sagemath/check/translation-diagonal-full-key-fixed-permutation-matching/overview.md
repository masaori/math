# 一辺三の全辺鍵における対角固定置換の候補グラフ

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限二部グラフ、$\mathbb Q(\zeta_8)$、自然数
- 実行: `sage sagemath/check/translation-diagonal-full-key-fixed-permutation-matching/check.sage`
- 状態: PASS（2026-09-03。全数値を等号 assert で固定して再実行済み）

奇数辺長で最初に現れる全辺鍵 $(D,E)=(\varnothing,E_3)$ の対角固定置換
$80$ 個について、偶部分グラフ $H$ に沿う頂点組み替えで互いに移り、$H$ の
巻き付き文字が非自明で、四つのスピン構造の位相寄与が全て反転する二置換を
候補辺で結んだ。

二置換の動く向き付き辺集合の差から $H$ は一意に決まる。$H$ 外から $H$ 外への
遷移が保たれていれば、残る遷移は各頂点で自由な到着と出発を結ぶ全単射である。
候補置換は既に非後退置換なので、この条件は前段の頂点組み替え候補の定義と一致する。

正位相側・負位相側は各 $40$ 頂点で、向き付き候補は $416$ 本、重複を除いた
二部グラフの辺は $368$ 本だった。両側とも孤立点は無いが、最大マッチングは
$16$ 対で $32$ 頂点しか覆わない。さらに未対応の正側頂点から交互路で到達する
正側集合 $S$ とその近傍 $N(S)$ を構成し、$|N(S)|<|S|$ を assert した。
実際には $|S|=32$、$|N(S)|=8$ である。
従って Hall の必要条件により、この候補グラフには完全マッチングが存在しない。

これは一辺三で既に、対角固定置換を前段の頂点組み替え候補だけで対にする方針が
失敗することを示す。位相ベクトルの多重集合が符号反転不変であるという必要条件は
十分ではない。次は Hall 障害を担う固定置換の局所形を分類し、候補族を拡張すべきか、
別の相殺構造へ移るべきかを判定する。
