# 閉歩道の端点偶奇は頂点の四辺の通過偶奇である

**対象ラベル**: `claim_closed_walk_four_edge_parity`

頂点の四つの辺位置の通過回数と、向き付き辺の始点・終点の個数を一行ずつ照合し、閉歩道の偶奇と、各辺の通過偶奇の和を検査する。一辺一から三、長さ一から四の閉じた歩道を列挙する。非後退性はこの論法では使用しない。

- 実行: `sage sagemath/check/closed-walk-four-edge-parity/check.sage`
- 状態: PASS（2026-11-05。頂点ごとの閉歩道 2,616 件）
- 計算: 整数の有限和と二で割った余りだけを使用する。
