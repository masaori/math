# 非自明文字鍵の曲がり型頂点による局所符号反転対合

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`
- 住処: 有限集合、整数、有限積
- 実行: `sage sagemath/check/translation-nontrivial-key-curved-vertex-involution/check.sage`
- 状態: PASS（2026-09-04。一辺三の非自明文字の偶部分グラフ全 $346$ 個、
  均衡配向全 $2{,}956$ 個、$D=\varnothing$ の置換全 $115{,}688$ 個で実行済み）

三段で検査した。

1. **記号的な局所分類。** 二本の像の交換で回転数を変えずに完全対合できる局所方向型は
   「二本の入方向と二本の出方向が同じ曲がり二方向」の四型に限る（前 tick の再確認）。
   さらに反転対辺は同じ頂点へ入方向 $d$ と出方向 $d+2$ を同時に与えるが、曲がり二方向の
   対 $\{c,c+1\}$ は $d$ と $d+2$ を同時に含めない。従って曲がり型頂点は
   「$E$ の次数 $4$ 頂点で、$E$ の配向が曲がり型のもの」に限り、**$D$ に依存しない**。

2. **存在の全数検査。** 一辺三の偶部分グラフ $1{,}024$ 個のうち非自明文字を持つ全
   $346$ 個について、$E$ の均衡配向（各頂点で入次数=出次数）を全列挙すると合計
   $2{,}956$ 個で、その**すべて**に曲がり型の次数 $4$ 頂点が少なくとも一つある。
   ファイバーの各置換の単純通過部分は $E$ の均衡配向を誘導するので、任意の $D$ に
   ついてファイバーの全置換が曲がり型頂点を持つ。

3. **対合の直接検証。** $D=\varnothing$ の全ファイバー（置換合計 $115{,}688$ 個）と、
   辞書式最小の非自明文字 $E$（第 $0$ 行と第 $0$ 列の交差一周路）に閉路状の反転対
   $D$（第 $1$ 行・第 $1$ 列・その和）を付けた鍵の全ファイバー（置換合計 $696$ 個）で、
   辞書式最小の曲がり型頂点の二つの局所全単射を交換する写像が、動辺集合・総回転数を
   保ち、巡回数の偶奇だけを反転する不動点のない対合であることを一件ずつ展開して
   確かめた。曲がり型頂点の集合は動辺集合だけで決まり交換で保たれるので、辞書式最小の
   選択は交換の前後で一致し、対合が閉じる。同じ $E$ の全ての
   $D\subseteq E^{\mathsf c}$（$4{,}096$ 個）でも曲がり型頂点の集合は $E$ の配向だけで
   決まり、有効な動辺集合は前 tick と同じ $5{,}768$ 個、その局所全単射数の積は全て
   偶数（曲がり型頂点の因子 $2$ を含む）だった。一辺だけの反転対は孤立端で非後退
   全単射が無く、ファイバーは空である。

従って一辺三では、**全ての**非自明文字鍵 $(D,E)$ のファイバーが符号反転対へ分かれ、
四つのねじれ全てで $\mathcal K^{a,b}_3(D,E)=0$ が直接従う。前 tick までの
「軌道代表で構成して自由作用で運ぶ」段取りは一辺三では不要になった（対合が最初から
対角平行移動と可換な形で全鍵に定まるため）。文字評価による
$\mathcal U^{a,b}_3(D,E)=0$ と合わせ、一辺三の非自明文字鍵は平方恒等式の両側で消える。
検査は有限集合と整数の等号だけで行い、浮動小数点は使っていない。

残る一般化は、任意の辺長で「非自明文字の偶部分グラフの全ての均衡配向に曲がり型の
次数 $4$ 頂点が存在する」ことの証明である。次数 $4$ 頂点で曲がり型にならない配置は
「水平二辺が入り垂直二辺が出る（またはその逆）」の交差二型に限るので、これを排除する
一般論法（非自明文字が強いる交差頂点の存在と、その配向の分類）を探す。
