# SageMath Check: 有理数の平方は二にならない

## 対象

**対象ラベル**: `claim_no_rational_square_two`

- 実行日: 2026-08-13
- 結果: 通過（分子・分母 1..40 の正負 3200 個の有理数で $q\cdot q\ne2$ と証明の鎖を厳密検査した）
- 帰属: `QQ` / `ZZ` の厳密計算。浮動小数点は使わない。

## 何を確かめるか

主張は「任意の $q\in\mathbb{Q}$ について $q\cdot q\ne2$」。証明の組み立てを一行ずつ突き合わせる。

- 準備: $q<0$ の場合の $r:=-q$ について $r>0$ と $r\cdot r=q\cdot q$
- 鎖の先頭: $1=v_2(2)-v_2(1)=w_2(2)$（$2=2^1$、$1$ は空積）
- 鎖の中段: $w_2(r\cdot r)=w_2(r)+w_2(r)$（対数の加法性 `claim_log_additive` の $p=2$ 成分）
- 矛盾の段: 整数 $m$ について $m+m\ne1$（$m\ge1$ なら $m+m\ge2$、$m\le0$ なら $m+m\le0$）

主張そのものは全称否定なので有限の標本でしか見られないが、鎖の各段は標本の全点で成立し、
矛盾の段（$m+m\ne1$）は範囲内の全整数で検査した。`QQ`・`ZZ` の等号判定は厳密である。
