# 全辺鍵の局所対応交換による符号反転対合

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限置換、整数
- 実行: `sage sagemath/check/translation-full-key-local-pairing-involution/check.sage`
- 状態: PASS（2026-09-03。一辺三の全 $75{,}776$ 置換で実行済み）

奇数辺長の全辺鍵ファイバーでは、各氷型配向に曲がり型頂点が少なくとも一つある。
全頂点が直線型なら、各頂点は水平二辺が入る型または垂直二辺が入る型で、隣接するたびに
型が反転する。しかし奇数個の頂点を巡回して出発点へ戻ると型が反転したままになり矛盾する。

辞書式最小の曲がり型頂点で、入辺二本から出辺二本への対応を交換する。この操作は配向を
変えないので同じ頂点を再び選び、不動点のない対合になる。二像の交換は置換の巡回数の
偶奇を反転する。一方、曲がり型の四つの局所方向配置では二対応の四半回転和が等しいため、
総回転数は変わらない。従って
$\varepsilon(\varphi)=(-1)^{c(\varphi)+T(\varphi)}$ は必ず反転する。

検査では六つの局所入方向集合を全数で調べ、四つの曲がり型で局所四半回転和の差が零、
二つの直線型でだけ差が正負四になることを等号で固定する。さらに一辺三の全 $75{,}776$
置換について、曲がり型頂点の存在、選択頂点の保存、対合性、不動点なし、ファイバー保存、
$\varepsilon$ の反転を検査する。
