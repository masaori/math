# 閉歩道の各頂点に接する端点数は偶数である

**対象ラベル**: `claim_closed_walk_incidence_even`

閉じた辺列の終点列を始点列の巡回移動として作り、各頂点の始点数と終点数の一致、および端点数の偶奇を行別に検査する。頂点数一から四、辺数一から六を全列挙する。非後退条件はこの論法では使わない。

- 実行: `sage sagemath/check/closed-walk-incidence-even/check.sage`
- 状態: PASS（2026-11-05。有限場合 25,374 件）
- 計算: 整数の有限和と二で割った余りだけを使用する。
