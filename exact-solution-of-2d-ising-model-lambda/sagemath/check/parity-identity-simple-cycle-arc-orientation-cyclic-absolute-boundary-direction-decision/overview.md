# SageMath Check: 絶対境界方向を戻した候補記述の係数判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、境界方向を上方向へ正規化した
巡回三文字頻度と相対端点 10 成分からなる従来の候補記述へ、候補ごとの
正規化前の絶対境界方向を戻す。この追加情報だけで、端点だけの支持と
語位置と端点の支持の二つの正準係数がそれぞれ一意に決まるかを判定する。
これは有限データ上の判定であり、一般の辺長についての主張ではない。

プログラミングによる検証では、絶対境界方向を戻すと記述数は 7,427 から
9,735 へ増え、端点だけの支持に残っていた 220 種と、語位置と端点の支持に
残っていた 260 種の係数衝突はいずれも 0 になった。したがって現有限データ
では、境界方向の正規化で落としていた絶対方向を戻すだけで両係数が決まる。
