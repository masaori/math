# 語長三の相異なる二成分の積だけによる存在判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に対し、語長三の弧型 2,044 種の値を、68 特徴ビットの
相異なる二成分の積 2,278 個だけの和で表せるか判定する。係数は有限体 $\mathbb F_2$ の元。
定数項・一次項は零に固定する。平方は零一ビット上で一次項と一致するため含めない。
他の語長と閉路型の値は自由未知数として残す。連立系は 9,129 行・12,376 未知数である。

LLM による検証: 変更する条件は定数項と一次項の零固定だけであり、切断旗を含まない
二次項は許す。結果の射程は列挙した有限集合だけで、一般命題と Lean 二版は未追加。
整数・有限体と上流の円分体の厳密演算だけを使い、浮動小数点は使わない。


初回の起動はリポジトリ直下から相対パスを指定したため、対象ファイル不在で終了コード 2 になった。
数学の計算は開始していない。プロジェクト直下から同じ SageMath コマンドを再起動した。

係数行列と拡大係数行列の階数はともに 8,828 で、系は可解だった。
各弧型を二次項だけの式で評価し、全 7,085 鍵の値を復元するプログラミングによる検証が通過した。
得た一解は二次項 109 個（切断旗を含む積 67 個・含まない積 42 個）を持つ。
この項数は一解の観測であり、最小項数や個々の係数の不可欠性は主張しない。

従って定数項と一次項を残す必要はない。一方、前回の局在系の非可解性と合わせると、
切断旗を含まない二次項を全て除くことはできない。次はそれらの項を特徴の種類ごとに
零固定し、どの種類を残す必要があるかを解空間で切り分ける。

階数を固定した全再実行でも、両階数 8,828 と全 7,085 鍵の復元、同じ一解の項数を再現した。
