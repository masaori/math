# SageMath Check: 境界方向を共通基準にした連続三文字の出現回数

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: PASS
- 帰属: 有限集合と $\mathbb F_2$ 上の係数。浮動小数点を使わない。

## 何を確かめるか

一辺二・三から得た 9,739 弧型について、各実現可能な境界入射候補の
境界方向を上方向へ送る一意な正方形回転を選ぶ。その同じ回転を巡回内部語の
連続三文字へ作用させ、順序付き三文字の出現回数と、その候補の相対端点
10 成分を対応づける。

候補ごとの対応を失わないこの記述が、二つの正準巡回支持の係数を
有限全データ上で決めるかを判定する。これは一般の辺長・一般の内部語に
ついての主張ではない。衝突が残る場合は、その証人を `certificate.json` に保存する。

プログラミングによる検証では、境界方向の共通基準で表した順序付き連続三文字は
29,012 種だった。相対端点 10 成分との組により 9,739 弧型は 7,427 記述へ分かれたが、
端点だけの支持では 220 種、語位置と端点の支持では 260 種の記述に係数 0 と 1 が
混在した。この分割と衝突数は同じ境界基準の隣接二文字と一致する。連続三文字の
出現回数から先頭二文字が一致する三文字を足せば隣接二文字の出現回数を復元できるため、
三文字記述は二文字記述を細分する。記述数が同じなので有限範囲では両分割は一致する。
連続する窓長二・三で分割と衝突集合が変わらないため、次は実在する未評価の窓長
四から八を一括判定する。
