# 語長三の局在を要求しない二次式の存在判定

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に対し、語長三の弧型 2,044 種の値を、68 特徴ビットの
定数項・一次項・全ての相異なる二成分の積で書けるかを判定する。他の語長と閉路型の
値は自由未知数のまま残す。二次項は 2,278 個、係数は定数項を含め 2,347 個で、
連立系は 9,129 行・12,445 未知数となる。特徴は零または一なので平方は一次項と一致し、
この候補は次数二以下の全ての多項式を含む。

前回は定数項・一次項・切断旗を含まない二次項を零に固定して非可解となった。
今回はその零固定を全て外し、局在条件だけが障害だったかを切り分ける。

| ファイル | プログラミングによる検証の内容 | 状態 |
| --- | --- | --- |
| `check.sage` | 上流の方程式と追加行を照合し、階数で可解性を判定する。可解なら全鍵の値を復元し、非可解なら左核による矛盾証拠を照合する | PASS（2026-09-05、初回）。観測した階数を固定する assertion の追加後は全再実行していない |

係数行列と拡大係数行列の階数はともに 8,828 で、系は可解だった。
得た解について行列の残差が零であることに加え、各鍵の弧を再生成し、二次式と自由な
弧型の値から全 7,085 鍵の頂点項を復元するプログラミングによる検証が通過した。

従って語長三の障害は次数二そのものではなく、前回課した「定数項・一次項・切断旗を
含まない二次項を全て零にする」条件にある。どの種類の項を追加すれば足りるかは
まだ切り分けていない。次は定数項・一次項を零に固定し、全ての二次項だけで可解かを判定する。
まず今回の観測を固定した `check.sage` を再実行する。

LLM による検証: 既存の特徴抽出と二次特徴の構成、値と係数を同時に未知数とする
連立系を読み、局在条件を外し、語長三以外の値に制約を加えていないことを確認した。
結果の射程は列挙した有限集合だけである。一般命題の本文と Lean 二版は未追加。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-three-quadratic-existence/check.sage
```
