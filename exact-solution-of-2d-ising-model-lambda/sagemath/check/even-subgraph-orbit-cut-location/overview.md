# 二候補の切断・接合位置による区別

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像
- 実行: `sage sagemath/check/even-subgraph-orbit-cut-location/check.sage`
- 状態: PASS（2026-09-03、覆えない 16 ファイバーの二候補を持つ置換 1,984 個）

候補を二本持つ 1,984 置換について、二候補が変更する頂点集合を比較すると、1,792 個では
異なり、192 個だけが一致した。従って粗い軌道形では区別できなかった 1,056 個を含む候補の
大部分は、切断・接合する頂点の位置まで見れば区別できる。

残る 192 個では、変更する向き付き到着辺の集合、基底辺の多重集合、元の動く向き付き辺集合へ
引き戻した変更後続の対応まで二候補で全て一致した。すなわち、この比較で捉える局所操作としては
二候補を区別できず、像側の向きを元側へ戻す前にだけ違いが残る。次は、位置が異なる二候補から
平行移動や回転に依存せず一方を選び、その選択が候補辺の両端で一致する規則を調べる。
計算は有限集合と有限写像の等号だけで完結し、浮動小数点は使わない。
