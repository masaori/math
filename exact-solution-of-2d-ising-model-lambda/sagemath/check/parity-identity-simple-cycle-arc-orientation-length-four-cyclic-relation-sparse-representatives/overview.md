# SageMath Check: 語長四の巡回不変な混合関係の疎な代表

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 帰属: 有限集合と $\mathbb F_2$ の厳密演算。浮動小数点を使わない。
- 一般の辺長・全語長についての命題ではない。
- 実行日: 2026-09-16
- 結果: 通過。端点だけの 144 次元部分空間では、既約階段基底の総重み 663 を
  決定的な基底行加算で 521 へ減らし、疎化基底内の最小代表は
  `end0_c_down*end0_wrap_col0 + end0_c_right*end0_wrap_col0` の二軌道だった。
  語位置・端点積だけの 115 次元部分空間では総重み 334 を 316 へ減らし、
  最小代表は `step0_wrap_col0*end0_wrap_col0` の一軌道だった。この一軌道は
  四つの語位置へ巡回移送した四特徴の和を表す。

## 何を確かめるか

語長四の巡回不変な混合関係商のうち、端点特徴だけに支持を持つ 144 次元と、
語位置・端点積だけに支持を持つ 115 次元について、巡回軌道座標上の既約階段基底を作る。
各基底を、基底性を保つ行加算のうち Hamming 重みが真に減るものだけで決定的に疎化し、
それぞれの疎化基底内で支持が最小の代表を保存する。

ここでいう最小は、**この決定的に疎化した基底の行の中での最小**である。
部分空間の全非零元を列挙した最小距離の主張ではない。各代表が元の 339 次元商空間に属し、
疎化後の行が対象部分空間全体を張ることを $\mathbb F_2$ 上で厳密に確かめる。
