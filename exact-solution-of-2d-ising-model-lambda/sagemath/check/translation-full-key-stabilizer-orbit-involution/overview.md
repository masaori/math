# 全辺鍵の部分群固定集合上の一括交換対合と層均衡

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限置換、整数
- 実行: `sage sagemath/check/translation-full-key-stabilizer-orbit-involution/check.sage`
- 状態: PASS（2026-09-04。一辺三の全 $75{,}776$ 置換と一辺五の固定層 $1{,}088$ 置換で実行済み）

奇数辺長 $L$ の全辺鍵ファイバーへの対角平行移動群 $\mathbb Z_L$ の作用について、
約数 $d\mid L$ ごとに位数 $d$ の部分群 $H_d$ を固定し、$H_d$-固定集合 $F_d$ の上で
辞書式最小の曲がり型頂点の $H_d$-軌道（大きさちょうど $d$。対角平行移動は頂点に自由に
作用する）の全頂点で入辺二本から出辺二本への対応を一括交換する。交換する頂点集合が
$H_d$-不変なので $F_d$ は $F_d$ へ移り、配向・曲がり型集合・選択軌道が保存されて
不動点のない対合になる。相異なる頂点の互換 $d$ 個の合成なので巡回数の偶奇が $d$ 回
反転し、$d$ が奇数だから $\varepsilon=(-1)^{c+T}$ は反転する。従って各 $d\mid L$ で
$\sum_{\varphi\in F_d}\varepsilon(\varphi)=0$ であり、正確な安定化群位数の層
$E_d=F_d\setminus\bigcup_{d<d'\mid L}F_{d'}$ でも約数束の Möbius 反転で均衡する。
$\varepsilon$ は平行移動不変なので各軌道サイズの層で正負の軌道が同数になり、正確な
安定化群が等しい反対符号の代表を対にして $g\cdot r\mapsto g\cdot r'$ と運べば、
ファイバー全体を一回被覆する対角共変な符号反転完全マッチングが一般の奇数辺長で得られる。

**置換ごとに自分の安定化群 $\mathrm{Stab}(\varphi)$ の軌道を交換する操作は対合にならない。**
一辺三では $80$ 個の置換（固定置換の単頂点交換像）で安定化群が保存されず壊れる。
部分群 $H_d$ を先に固定して $F_d$ 上で閉じることが構成の要である。

検査では、一辺三の $F_3$（$80$ 置換）と一辺五の $F_5$（$1{,}088$ 置換）で一括交換の
対合性・ファイバー保存・$H_d$-固定性の保存・$\varepsilon$ 反転を固定し（$F_1$ の
単頂点交換は読み込み元 `translation-full-key-local-pairing-involution` で固定済み）、
一辺三の正確な層の均衡（位数 $1$ で各 $37{,}848$、位数 $3$ で各 $40$）、安定化群が
壊れる反例の個数 $80$、層均衡から運んだ $37{,}888$ 対のマッチングの一回被覆・
対角共変性・符号反転を等号 assert で固定する。浮動小数点は使わない。
