# 単純閉路鍵の一辺二・一辺三合同の局所符号式の非存在

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二の全 $320$ 鍵と、一辺三の自明文字を持つ単純閉路の $D=\varnothing$ 鍵
$312$ 件・選択集合が非空で $1\le|D|\le2$ の鍵 $6{,}453$ 件（計 $7{,}085$ 鍵）を
一つの $\mathbb F_2$ 線型系に載せ、頂点項を頂点署名（上下左右のスロットの
$D/E$ 所属と切断隣接旗の $12$ 変数）の関数の頂点和で書けるかを三段で判定した。

1. 直接衝突: 奇数回現れる署名の集合が等しい鍵対は一組だけあり、頂点項も
   一致した（相異なる奇署名集合は $7{,}084$ 種、衝突 $0$ 件）。
2. 存在: 現れる署名は $274$ 種、所属行列の階数は $246$ で、署名ごとの値を
   自由に選んでも線型系に解が無い。
3. 従って、単項式特徴の次数によらず、両辺長を同時に満たす局所式は
   この署名変数の範囲には存在しない。

一辺二の延長反例（`parity-identity-simple-cycle-local-sign-formula-extension`）
は「一辺二で解いた特定の式が延長できない」ことしか言っていなかったが、
本検査はそれを「署名の任意関数でも不可能」へ強めた。頂点署名は基底辺の
所属しか見ないため、一辺二で上下（左右）のスロットが同じ基底辺を指す
重複隣接の情報が落ちており、これが辺長を跨ぐ障害になっている。次は署名に
重複隣接旗（同一基底辺を指すスロット対の印）か辺長依存の変数を加えて解く。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-joint-local-sign-formula/check.sage`
- 状態: PASS（2026-09-05。衝突 $0$、署名 $274$・階数 $246$ で解なし）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
