# 語長一・二の局在を保った語長三への延長

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

プログラミングによる検証の対象は既存の 7,085 鍵である。一辺二の単純閉路鍵 320 件と、
一辺三の自明文字を持つ単純閉路について、反転対が空の 312 件および
反転対の辺数が一・二で選択集合が非空の 6,453 件を合同の線型系へ載せる。

語長一・二の局在拘束を保ち、語長三の弧型の値にも、定数項・一次項を持たず、
切断旗を含む二次単項式だけの和という同じ形を要求する。
零に固定する係数は未知数から除く。指定していない語長と閉路型の値は自由に残す。
一般の辺長、全語長、閉路型への同じ公式の存在を判定するものではない。

従って、この有限データ上で語長一・二・三を同時にこの形で書く解は存在しない。
語長三だけの局在が不可能なのか、三語長を同時に拘束することが障害なのかは未判定である。
次は語長三だけへ局在を課して両者を区別する。
- 可解なら、解の残差と、行列を用いない全鍵の頂点項の再構成を確かめる。
  非可解なら、左核に属して右辺との積が一となる不存在の証拠を確かめる。
- 四層の状態: 有限探索の検算。一般命題の本文と Lean 二版は未追加。
- 整数と $\mathbb F_2$、上流の $\mathbb Q(\zeta_8)$ の厳密計算だけを用い、浮動小数点は用いない。

LLM による検証: 零固定係数を除く構成と、係数行列との積が零・右辺との積が一という矛盾証拠を読み、結論が三語長の同時拘束の不存在に限られることを確認した。
