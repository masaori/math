# 一辺三の全辺鍵における Hall 障害の局所形と直接対

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限二部グラフ、$\mathbb Q(\zeta_8)$、自然数
- 実行: `sage sagemath/check/translation-diagonal-full-key-hall-structure/check.sage`
- 状態: PASS（2026-09-03。全数値を等号 assert で固定して実行済み）

前段で固定した Hall 障害（$|S|=32$、$|N(S)|=8$）の由来を、固定置換 $80$ 個の
不変氷型配向（$10$ 個、各 $8$ 置換）と位相ベクトルの分類で特定した。

- 各配向の $8$ 置換は正負位相にちょうど $4{+}4$ で分かれる。
- 候補辺が使える偶部分グラフ $H$（対角不変・巻き付き文字非自明）は
  $8$ 個で全て $9$ 辺であり、$8$ 個とも実際に使われている
  （辺数の内訳は $44$ 本が $6$ 個、$52$ 本が $2$ 個）。従って
  「$H$ に沿う頂点組み替え」の候補族はこれ以上拡張できない。
- 配向水準の候補グラフは、次数 $8$ の枢軸配向 $2$ 個と次数 $2$ の周辺配向
  $8$ 個からなる二重星形で、Hall 集合 $S$ は周辺 $8$ 配向の正側全員
  （各 $4$ 個）、$N(S)$ は枢軸 $2$ 配向の負側全員（各 $4$ 個）と一致する。
  障害は候補機構の配向水準の集中に由来する。

一方、位相ベクトルは二値 $\{v_0,-v_0\}$（$v_0=(1,-1,-1,1)$、各 $40$ 個）に
退化しており、正側は全員 $v_0$、負側は全員 $-v_0$ を持つ。従って正側と負側の
**任意の全単射**が四つのスピン構造すべてで位相を反転する対を与える。固定点上では
どの全単射も対角平行移動と自明に可換である（両端が固定点なので、平行移動で対を
運んでも同じ対に戻る）。整列順の全単射 $40$ 対を構成し、全対の位相反転を
assert で検証した。

結論: Hall 障害は「前段の頂点組み替え候補」という局所機構の失敗であって、
相殺構造そのものの失敗ではない。候補族の拡張は不可能（使える $H$ は全て使用済み）
だが不要であり、固定置換は位相ベクトルの直接対で相殺できる。次は、この直接対を
非固定軌道の運搬マッチングと合成して、一辺三の全辺鍵ファイバー全体に対角共変な
符号反転完全マッチングが存在するかを判定する。
