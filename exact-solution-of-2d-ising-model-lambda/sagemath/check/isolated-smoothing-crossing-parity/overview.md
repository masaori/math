# 孤立した横断の平滑化による横断数の更新

**対象ラベル**: `claim_isolated_smoothing_crossing_number_update`
- 実行: `sage sagemath/check/isolated-smoothing-crossing-parity/check.sage`
- 状態: PASS（2026-08-30、孤立横断の有限局所データ 115,400 件）
- 使用する環: `ZZ` と有限集合だけ。浮動小数点は使わない。

方向番号四つからなる全ての非後退通過について、選択した二通過だけが共通頂点を通り、
その二通過が横断する局所データを列挙する。二つの出方向を交換すると両方が曲がること、
選択した対以外の横断判定は変わらないこと、横断数がちょうど一つ減って偶奇が反転することを検査する。
