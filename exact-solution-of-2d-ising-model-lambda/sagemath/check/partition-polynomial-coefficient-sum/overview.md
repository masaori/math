# SageMath Check: 多重度の総和は配位の総数に等しい

## 対象

**対象ラベル**: `claim_coefficient_sum` （structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の主張「多重度の総和は配位の総数に等しい」
- 併せて使う定義: `def_lattice` / `def_configuration` / `def_broken_bond_count` /
  `def_multiplicity` / `def_partition_polynomial`

### 何を確定させるための検証か

本文の証明は「配位全体を破れボンド数の値ごとに類別し、各類の元の個数を足すと全体の個数になる」
という有限集合の数え上げだけからなる。この検証は、その各段を小さい格子で実際に数え上げて固定する。

1. 全配位を（$L$ が小さいので）総当たりで生成し、各配位の破れボンド数 $b(\sigma)$ を数える。
2. 多重度 $\Omega_L(m)$ を数え、分配多項式 $Z_L=\sum_{\sigma\in\Sigma_L}x^{b(\sigma)} \in \mathbb{Z}[x]$ を
   本文の定義そのまま（配位ごとに単項式を足し上げて）作る。
3. 係数の総和 $\sum_m \Omega_L(m)$ と $2^{L^2}$ が一致することを確かめる
   （本文の第 2・第 3 の等号に対応）。
4. 同じことを $Z_L(1)$ の評価としても確かめる（多項式の $1$ での値が係数和に等しいこと）。
5. 有理点 $x=1/2$ での値を素因数分解し、$\Phi_L=\log Z_L(1/2)$ が対数順序群 $\Lambda$ の元
   （素数の指数ベクトル）として書けることを確かめる。章「有限系の自由エントロピー」への橋渡し。

### 計算の厳密性

すべて `ZZ` / `QQ` / `ZZ['x']` の厳密計算で行う。**浮動小数点は使わない。**
本文がこの章で $\mathbb{R}$ へ脱出していないので、検証側にも脱出を持ち込まない。

### この検証が本文を直させた点（記録を消さない）

最初に書いた本文は辺集合 $E_L$ を「2 元集合の集合」として定義していた。この定義だと
周期境界の $L\le2$ で異なる辺が同じ頂点対を指すため $|E_L|=2L^2$ が成り立たず
（$L=1$ では自己ループ、$L=2$ では同じ 2 点を結ぶ辺が 2 本）、主張が小さい $L$ で崩れる。
検証がこれを検出したので、**本文の側**を「辺の番号の集合と端点写像 $\partial_0,\partial_1$」の定義へ直した。
検証を主張に合わせて緩めてはいない。

その後さらに 2 度、本文の定義を直している（いずれも本文の側を直した）。

- 辺の添字集合を $E_L=V_L\times\{\mathrm{h},\mathrm{v}\}$（頂点との直積）から、
  横向き $E_{L,\mathrm{h}}=\{1,\dots,L^2\}$ と縦向き $E_{L,\mathrm{v}}=\{L^2+1,\dots,2L^2\}$ という
  番号の集合へ変えた。辺の番号の集合の定義に頂点集合を混ぜないため。
- 2026-08-08 のレビューで、頂点 $(i,j)$ の第 1 成分を行番号・第 2 成分を列番号と本文で宣言し、
  横向きの辺が同じ行の中を結ぶ（列番号だけが 1 ずれる）ように端点写像を直した。
  それ以前は「横向き」と名付けた辺が行番号をずらしており、名前と実体が食い違っていた。
  数え上げの結果（$Z_L$、係数の総和）はこの入れ替えで変わらない。
