# 並べ替え反転に寄与する辺対の非局所性

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

標準形配向について、終点順序と始点順序の反転指示値の和が $1$ になる
有向辺対を全て取り出し、二辺が端点を共有するかを調べた。寄与する辺対には
端点を共有しないものが、一辺二で $868$ 対、一辺三で $5{,}340$ 対現れる。
従って、寄与する切断線対と内部対を直接対応させる規則は、同じ頂点に接する
辺だけを対象にはできず、離れた辺対も扱う必要がある。
