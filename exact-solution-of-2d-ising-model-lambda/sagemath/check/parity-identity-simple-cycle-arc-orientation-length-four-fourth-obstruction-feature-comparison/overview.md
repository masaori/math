# SageMath Check: 三特徴追加後に残る語長四障害の特徴比較

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 範囲: 位置ビット閉式へ先行する三つの障害を除く特徴を加えた有限合同系
- 内容: 第四の左核矛盾証拠と、そこで相殺しない語長四弧型の特徴を比較する
- 帰属: 有限集合と $\mathbb F_2$。浮動小数点を使わない

## 結果

2026-09-15 に実行した。最初の交差所属積 `step0_e_left*step0_d_up`、先頭語位置の
上辺所属 `step0_e_up`、最初の語位置の列切断旗 `step0_wrap_col0` を加えた系から、
28 鍵を台に持つ第四の左核矛盾証拠を取り出した。28 行を足すと、自由未知数として
残した 7,968 弧型と先行三特徴は相殺し、固定済みの語長四弧型 16 種だけが奇数回残る。
候補値の和は零だが鍵の右辺の和は一なので、これは先行する三つの証拠とは独立な障害である。

16 種上で一次特徴と二特徴積を全数比較すると、相殺しない特徴は 828 個あり、そのうち
一次特徴は 15 個だった。最初の語位置の反対側の列切断旗 `step0_wrap_collast` は証拠との
積が一になる。この列も加えた全 7,085 鍵の系は階数 6,306、拡大階数 6,307 でなお非可解だった。
したがって、四つ目の特徴は第四証拠を除くが、閉式を完成させる十分条件ではなく、
さらに独立な障害が残る。一般の辺長・全語長についての命題ではなく、一般命題と Lean 二版は未追加である。
