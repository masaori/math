# 均衡配向の局所行列式の型分類（辺長によらない全局所配置）

**対象ラベル**: `claim_selection_sum_character_evaluation`,
`claim_kac_ward_determinant_fiber_stratified_phase_sum`

頂点の局所遷移行列の成分は、入る動辺の方向と出る動辺の方向の差
（四半回転数の $\zeta_8$ 冪）だけで決まり、継ぎ目のねじれ符号は
列全体への $\pm1$ 倍として掛かる。従って局所行列式の絶対値の分類は
辺長・頂点の位置・スピン構造に依存しない。一つの頂点のまわりの
四つの枠（東・北・西・南の基底辺）に「無し・二重辺・単純入・単純出」を
割り当てた釣り合い（入と出が同数の）非空局所配置は全部で $69$ 件あり、
その全てで次を厳密検査した。

- 四枠すべてが単純辺で入方向が隣り合う**曲がり型**（$4$ 件）: 行列式は零。
- 四枠すべてが単純辺で入方向が向かい合う**直進型**（$2$ 件）: 行列式は
  $\pm2\zeta_8^2$（絶対値 $2$）。
- 単純辺が無く二重辺が奇数本（一本または三本。$8$ 件）: 行列式は零。
  ただしこの配置はその頂点で単純次数が零なので、選択集合が非空な鍵では
  二重次数の偶数性に反して実現しない。
- それ以外（$55$ 件）: 行列式は $\pm\zeta_8^t$（絶対値 $1$）。
- 列を任意の符号列 $\varepsilon$ で倍率すると行列式はちょうど
  $\prod\varepsilon$ 倍になる（$320$ 件）。継ぎ目符号の作用はこの形なので、
  上の分類は四つのねじれ全てで成り立つ。

一辺二で確認済みの局所行列式分解（`trivial-character-orientation-local-factor`）
と合わせると、**任意の辺長**の選択非空・自明文字の鍵の均衡配向類について、
位相和が零になるのは曲がり型の次数 $4$ 頂点を持つ類にちょうど限られ、
持たない類の位相和の絶対値は $2^{s(o)}$（$s(o)$ は直進型の次数 $4$ 頂点数）である。

- 状態: PASS（2026-09-04）
- 方法: 有限集合、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
