# 単一の偶部分グラフで覆えないファイバーの構造

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、整数、$\mathbb{Q}(\zeta_8)$
- 実行: `sage sagemath/check/even-subgraph-uncovered-fiber-structure/check.sage`
- 状態: PASS（2026-09-03、単一の偶部分グラフで覆えない 16 ファイバーの 2,816 置換）

置換ごとに偶部分グラフを変える頂点組み替え候補の二部グラフを、置換の軌道長の多重集合を
保つ辺へ制限した。該当する辺は一つもなく、16 ファイバーのいずれでも完全マッチングは
残らなかった。接触対が属する二軌道の長さの組と、切り替え可能接触対が属する二軌道の長さの組を
さらに固定しても同じである。

従って、検査した候補族による大域対応は軌道分解を保存する規則にはできない。接触対の配置を
同じ軌道長の組の間で保存する規則にもできない。次は、対応が軌道をどのように分裂・合併するかを
調べる必要がある。
