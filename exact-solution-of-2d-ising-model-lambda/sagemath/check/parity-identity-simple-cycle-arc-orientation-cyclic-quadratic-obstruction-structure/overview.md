# SageMath Check: 二つの次数二以下矛盾証拠が共有する構造

## 対象

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

- 実行日: 2026-09-20
- 結果: 二つの左核矛盾証拠は同じ三次相互作用で同時に破れる
- 帰属: 有限集合と $\mathbb F_2$ 上の有限線形代数。浮動小数点を使わない。

## 何を確かめるか

絶対境界方向つき次数二以下ブール式の判定で保存した、二つの正準係数に対する左核矛盾証拠を読む。各証拠について、定数・一次・相異なる二特徴積がすべて偶数回現れ、標的値だけが奇数回現れることを再検算する。

次に、原始特徴を変えず、相異なる三特徴積が各証拠上で奇数回現れる列を列挙する。二証拠に共通する列を、絶対境界方向・相対端点・境界基準の巡回三文字頻度の偶奇という三種類で分類する。

## 結果

実行結果は `certificate.json` に保存する。二証拠に共通して奇数回現れる三次列が存在するため、保存済みの二つの次数二以下矛盾証拠は、同じ三次相互作用によって同時に破れる。

これは三次式の存在証明ではない。共通三次列を一本加えるのではなく、同じ原始特徴からなる相異なる三特徴積を全て含む「次数三以下」の候補クラスを、二係数について一つの有限線形系で一括判定する。非可解でも、次数四や新しい原始特徴を自動的に一項ずつ追加しない。
