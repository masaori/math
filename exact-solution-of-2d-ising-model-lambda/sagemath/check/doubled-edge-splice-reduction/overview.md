# SageMath Check: 反転対の二方向を巡回から抜く縮約候補は非後退性を保たない

**対象ラベル**: `claim_fully_unswitchable_contacts_witness_doubled_edges`

完全切り替え不能な残余の接触が指す反転対の辺について、その二方向を置換の巡回から同時に抜き、
二方向を固定点へ戻す最も直接的な縮約候補を調べる。各方向の直前の辺は、抜いた方向の直後の辺へ
直接つなぐ。この操作が置換性・非後退性を保つか、反転対の辺集合 $D$ だけを一辺減らして
単純通過の辺集合 $E$ を保つかを、一辺二の有限集合で厳密に検査する。

- 実行: `sage sagemath/check/doubled-edge-splice-reduction/check.sage`
- 状態: PASS（2026-09-02）
- 方法: 有限集合・有限写像の等号と所属判定だけ。浮動小数点は使わない。
- 結果: 完全切り替え不能な残余について、同じ置換と同じ反転対の重複を除いた $2{,}912$ 件を
  検査した。縮約後は全件で置換だったが、非後退置換だったのは $32$ 件だけであり、$D$ だけを
  一辺減らして $E$ を保つものは一件も無かった。非後退になった最初の例でも、元の二つの反転対が
  ともに消えて $D=\varnothing$ となった。
- 帰結: 反転対の二方向を巡回から単に抜く操作は、$|D|$ に関する一段の縮約には使えない。
  切り替え平滑化は $D,E$ を保ち、この直接除去は非後退性または他の反転対を壊すため、別の局所操作か、
  個々の置換ではなくファイバー位相和どうしを結ぶ関係が必要である。
