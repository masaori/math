# 全位相反転候補辺集合の平行移動共変性と局所形

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像、$\mathbb{Q}(\zeta_8)$
- 実行: `sage sagemath/check/even-subgraph-orbit-all-phase-edges/check.sage`
- 状態: PASS（2026-09-03、覆えない $16$ ファイバーと非自明な平行移動の全 $48$ 組）

一辺 $L=2$ の単一の偶部分グラフでは覆えない $16$ ファイバーについて、各偶部分グラフで
最初に見つかった候補だけを残す縮約を行わず、四つのスピン構造で位相を反転する候補辺を
全て集める。全候補辺集合が平行移動と可換であることを $16\times3=48$ 組で検査し、
候補元ごとの候補数、変更後続数、一頂点・二頂点への局在、軌道の分裂・合併を数え直す。
計算は有限集合・有限写像と $\mathbb{Q}(\zeta_8)$ の等号だけで完結し、浮動小数点は使わない。

全候補辺集合は全 $48$ 組で平行移動と可換だった。位相反転候補を持つ置換は $2{,}624$ 個、
異なる候補辺は $6{,}400$ 本であり、候補数の分布は $1$ 本が $640$ 個、$2$ 本が $768$ 個、
$3$ 本が $640$ 個、$4$ 本が $576$ 個だった。変更後続数は $2$ 本が $2{,}816$ 候補、
$4$ 本が $3{,}584$ 候補で、前者は一頂点、後者は二頂点に二本ずつ局在する。
軌道変化は一軌道の二分裂が $5{,}376$ 本、二軌道の合併が $1{,}024$ 本だった。

縮約集合でも一頂点変更 $2{,}816$ 本は全て残っていたが、二頂点変更は $1{,}792$ 本から
$3{,}584$ 本へ、合併は $512$ 本から $1{,}024$ 本へ増えた。従って最初の候補だけを残す縮約は、
二頂点変更と合併の候補を半分落としていた。以後の候補選択規則はこの共変な全候補集合の上で調べる。
