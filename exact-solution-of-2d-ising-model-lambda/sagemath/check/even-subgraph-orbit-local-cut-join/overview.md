# 軌道の分裂・合併で変わる後続遷移は一つまたは二つの頂点に局在する

**対象ラベル**: `claim_selection_even_subgraph_action_character`,
`claim_selection_sum_character_evaluation`
- 住処: 有限集合、有限写像
- 実行: `sage sagemath/check/even-subgraph-orbit-local-cut-join/check.sage`
- 状態: PASS（2026-09-03、覆えない 16 ファイバーの候補辺 4,608 本）

像の置換を元の置換の動く向き付き辺集合へ引き戻し、二つの置換で後続辺が異なる
向き付き辺と、その終点である頂点を全数分類した。全 4,608 候補辺のうち 2,816 本は
一つの頂点で二本の後続遷移を変更し、1,792 本は二つの頂点でそれぞれ二本の後続遷移を
変更する。それ以外の頂点から出る遷移は変わらない。

元の一軌道の中だけで変更する 4,096 本が二分裂を、異なる二軌道にまたがる変更を含む
512 本が合併を起こす。従って一般の辺長へ持ち上げる候補は、一つまたは二つの頂点で
二本ずつの後続遷移を変更する局所操作として探せる。計算は有限集合と有限写像の等号だけで完結し、
浮動小数点は使わない。
