# 単純閉路と反転対の相対配置による二項の表示

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二の単純閉路鍵について、各頂点に接する上下左右の基底辺が反転対 $D$ と
単純閉路 $E$ のどちらに属するか、およびその頂点が切断に隣接するかを局所署名
として記録する。各署名を持つ頂点数の偶奇を相対配置統計とし、頂点項がその
$\mathbb F_2$ 線型結合で書けるかを厳密な線型方程式で判定する。

全 $320$ 鍵に現れる局所署名は $124$ 種、統計行列の階数は $89$ だった。
頂点項はこの統計行列の像に属し、SageMath が返した一つの表示は $46$ 種の
局所署名の個数の偶奇の和である。従って、一辺二では動辺数が常に偶数であることから、
非共有端点対項も「標的指数＋頂点項」として同じ統計と既知の標的指数で決まる。

これは有限列挙による表示の存在確認であり、$46$ 種の一覧を一般の辺長へ持ち上げられる
閉じた局所規則へ縮約したものではない。次は、選ばれた署名の共通条件を取り出し、
列挙に依らない頂点ごとの符号公式へまとめる。

- 実行: `sage sagemath/check/parity-identity-simple-cycle-relative-configuration/check.sage`
- 状態: PASS（2026-09-05）
- 方法: 有限集合、$\mathbb F_2$、整数、$\mathbb Q(\zeta_8)$ の厳密演算のみ。浮動小数点は使わない。
