# SageMath Check: 代数的数における値を取る写像は、有限積を有限積へ写す

## 対象

**対象ラベル**: `claim_second_evaluation_prod`（structured-latex 側の安定識別子）

- 本文: `structured-latex/content/main-text.ts` の章「固有値の代数性」の主張 1 件
- 併せて引く定義: `def_second_evaluation`
  （$\mathbb{Z}[x][t]$ の元の代数的数における値 $\mathrm{ev}_{\xi,z}$）

### 何を確定させるための検証か

シフト行列の特性多項式は軌道ごとの因子の積である
（`claim_shift_char_orbit_factorization`）。その値を 0 にする代数的数を扱うには、
まず積の値が値の積であることが要る。これはその一歩であり、次のセクション
（積の値を 0 にする代数的数が 1 の $L$ 乗根であること）が引く形そのものである。

確かめるのは次の 6 で、人手証明の段に 1 対 1 で対応する。

1. 帰納法の出発点。$s$ が空のとき $\mathrm{ev}_{\xi,z}(1)=1$
   （左辺は $\mathbb{Z}[x][t]$ の単位元の値、右辺は $\overline{\mathbb{Q}}$ の単位元）。
2. 帰納法の一歩の第 2 段。$\mathrm{ev}_{\xi,z}$ が積を保つこと。
3. 主張そのもの。族の全部分集合 $s$ について両辺が一致すること。
4. 応用の形。因子を軌道ごとの因子 $t^{m}+\iota(-\kappa(1))$ に取ったときにも成り立つこと。
5. 主張が空虚でないこと。両辺の値が $1$ でも $0$ でもない組が実際にあること。
6. 和を保つことを使っていないことの裏取り。和を保たないが単位元と積を保つ写像
   （$f\mapsto\mathrm{ev}_{\xi,z}(f)^2$）でも同じ結論が出ること。

### 計算をどこで行っているか（$\overline{\mathbb{Q}}$ の扱い）

代数的数の全体は SageMath の `QQbar`（厳密な代数的数の体）で表した。
**浮動小数点は使っていない**（`ZZ` / `QQ` / `QQbar` の厳密計算だけ）。
実数体にも複素数体にも入っていない。

## 走らせた範囲

因子の族は 5 個の $\mathbb{Z}[x][t]$ の元からなり、その全 32 部分集合を $s$ として走らせた。
応用の形は $m=0,\dots,4$ の 5 個の因子の全 32 部分集合。
$\xi$ は 4 個（$0$・$1$・$-3/2$・$\sqrt2$）、$z$ は 4 個（$0$・$2$・$-1/3$・$\sqrt2$）。
本文の主張は任意の $s,f,\xi,z$ についてのものなので、有限個で確かめたことは証明ではない。
