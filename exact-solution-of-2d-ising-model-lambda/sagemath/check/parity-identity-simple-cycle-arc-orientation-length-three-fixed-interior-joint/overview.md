# 語長一・二の局在形と語長三の固定非切断項を両立させる

**対象ラベル**: `claim_kac_ward_determinant_fiber_stratified_phase_sum`

一辺二・三の既存 7,085 鍵に限った有限存在判定。語長 $n\in\{1,2,3\}$ の弧型
$\tau$ の特徴ビットを $b_i(\tau)\in\mathbb F_2$、少なくとも一方が切断旗である
相異なる添字対の集合を $W_n$ とする。各語長に別々の係数 $\alpha^{(n)}_{ij}\in\mathbb F_2$ を許し、

$$
x_\tau=\begin{cases}0&n=1,2,\\
\sum_{k=0}^{2}b_{12k}(\tau)b_{12k+2}(\tau)&n=3
\end{cases}
+\sum_{(i,j)\in W_n}\alpha^{(n)}_{ij}b_i(\tau)b_j(\tau)
$$

を同時に課す。語位置の方向順は上・下・左・右。定数項・一次項・他の非切断項は零。
語と端点対は別々に正準化し、実頂点の同定を追加しない。他の語長と閉路型は自由未知数を保つ。
行列の各行と許可積をビット位置から独立照合し、階数、解または左核の矛盾証拠を判定する。
一般の辺長の命題と Lean 二版は未追加。整数・有限体・上流の円分体だけで計算する。

```sh
sage sagemath/check/parity-identity-simple-cycle-arc-orientation-length-three-fixed-interior-joint/check.sage
```

初回は `--record` を付けて証拠を保存し、通常実行で保存した証拠を独立に再判定する。
2026-09-06 初回のプログラミングによる検証: 終了コード 0 で通過。
12,220 行・12,458 未知数、係数行列の階数 11,612・拡大階数 11,613 で非可解だった。
`certificate.json` の左核の台は鍵の式 947 本と追加制約 1,942 本
（語長一 466 本・二 692 本・三 784 本）。和の左辺は零、右辺は一である。
台の最小性、各語長の制約を単独で加えた場合の非可解性は主張しない。
語長三単独の固定式と、語長一・二の局在式がそれぞれ可解でも、単一の弧型値を共有して
同時に成立するとは限らなかった。一般の辺長へのこの組合せの候補は採用しない。
LLM による検証: 構成は語長一・二の右辺を零、三だけを指定の語位置和とし、表示式に対応する。
保存した証拠を読む通常実行も終了コード 0 で通過し、両階数と再計算・保存の両証拠を再現した。
次は語長二の制約を外し、語長一の局在形と語長三の固定非切断項だけの両立を判定する。
