## セクション台帳

`status` は四層のどこまで済んだかを表す（`todo` / `記述まで` / `記述と SageMath まで` /
`Lean 具体版まで` / `done`）。**`done` は四層すべてを満たしたときだけ書く。**
tick は**最初の未完了セクションの、足りない層**を 1 つ進める（runbook「1 tick の実行手順」）。
