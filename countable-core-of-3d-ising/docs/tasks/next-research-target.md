# 第二の有理点へ向けた有限箱の継ぎ目評価

READMEの未達は、一とは異なる正の有理点で極限量の存在を模型固有に閉じることにある。
一般列の必要条件やcityの対分け補題を追加することでは、この未達は閉じない。
次は点を `q=2`、自由境界の立方箱と本文の分配多項式に固定し、箱の結合という模型固有の入力を使う。

最初に、辺の因子が不一致なら `q`、一致なら一という本文の定義を照合する。
一辺 `2n` の箱を一辺 `n` の八箱へ分けるとき、継ぎ目の辺数が `12n²` であることと、
各有限配位の制限・結合が全単射を与えることを用いる。候補は
`P_n(2)^8 ≤ P_(2n)(2) ≤ 2^(12n²) P_n(2)^8` という有理数の有限不等式である。
本文の変数・境界条件が違えば同式を流用せず、不一致を対象の否定結果として記録する。

この評価を採用する前に、本文の極限量の存在条件へ何を渡せるかを明示する。
実数値の自由エネルギーの収束だけへ脱出して、可算側の極限量の存在を得たと書いてはならない。
有限箱の評価から可算側の存在条件への接続が欠けるなら、欠ける条件を具体化して今回の候補評価を閉じる。
未証明の接続の周辺へ新しい補題列を無期限に追加しない。

完了条件は、定義への適合、有限箱の候補評価の採否、存在条件へ渡せるものと残る不足をそろえること。
プログラミングによる検証は、まず `n=1` の全配位と本文の有限和による境界因子の照合を担う。
全 `n` の主張は一般証明を別に要する。LLMによる検証は、この評価が模型固有の不足へ寄与するかを判断する。
新しい定理の成立・第二点の存在の確定はまだない。状態は未着手。
