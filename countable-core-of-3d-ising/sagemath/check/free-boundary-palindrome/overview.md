# SageMath Check: 多重度の回文性（帰無モデル）

**対象ラベル**: `claim_palindrome`

本文の証明の各段を、小さい箱の全数列挙で一段ずつ確かめる。すべて `ZZ` と有限集合の
列挙による厳密計算であり、浮動小数点は使わない。

| 確かめた段 | 本文のラベル | 方法 |
| --- | --- | --- |
| 辺の両端の座標和の偶奇が異なる | `claim_edge_endpoints_parity` | $L=1,\dots,4$ の全辺 |
| 奇数側反転が対合（$T(T\sigma)=\sigma$） | `claim_odd_flip_involution` | $L=1,2$ の全配位 |
| 各辺の破れの反転（$(T\sigma)(u)\ne(T\sigma)(v)\Leftrightarrow\sigma(u)=\sigma(v)$） | `claim_odd_flip_reverses_edges` | $L=2$ の全配位 × 全 12 辺 |
| 破れ数の補数（$m(T\sigma)=\#E_L-m(\sigma)$） | `claim_broken_complement` | $L=2$ の全配位 |
| 多重度の回文性（自由境界の $\Omega_L(m)=\Omega_L(\#E_L-m)$） | `claim_palindrome` | 下記 |

回文性そのものは三通りで確認した。

- $L=1$（$\#E_1=0$、辺の無い縮退した場合）：全数列挙。
- $L=2$（$\#E_2=12$、配位 $2^8$）：全数列挙。層ごとの転送による数え上げとも一致。
- $L=3$（$\#E_3=54$、配位 $2^{27}$）：全数列挙では届かないので、層ごとの転送
  （固定した第 3 座標の面配位 $2^9$ 通りを状態にし、層内破れと層間破れを分けて足す
  独立な第二の方法）で多重度を厳密に数え、回文であることを確認した。
  この方法は $L=2$ で全数列挙と一致することを併せて検査してある。

箱の選び方：$L=1$ が台の縮退（辺なし）、$L=2$ が偶奇両側の点を持つ最小の一般の場合、
$L=3$ が奇数辺長（奇数辺長でも自由境界なら回文が保たれることの確認。周期境界の奇数周期で
崩れるのとは別の族である）を覆う。

```sh
sage sagemath/check/free-boundary-palindrome/check.sage
```
