# SageMath Check: 同じ分配多項式は異なる二点データを区別しない

**対象ラベル**: `claim_same_partition_different_pair_data`

本文の証明の各段を、自由境界の一辺 $L=2$ の箱（頂点 8、内部辺 12）の全 $2^8$ 配位の
有限列挙で確認する。標識点対は隣接対 $(a,b)=((0,0,0),(1,0,0))$ と
対角対 $(a,c)=((0,0,0),(1,1,1))$ である。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 標識は頂点・辺・配位・破れ数を変えず、分配多項式は共通 | 各破れ数で一致配位数と不一致配位数の和が標識に依らず多重度に一致することと、$Z_2(1)=2^8$ の校正 | PASS |
| 破れ数 4 の配位の分割（本文の表の四つの整数） | $(a,b)$ は一致 20・不一致 10、$(a,c)$ は一致 12・不一致 18 | PASS |
| 符号付き多項式の四次係数が $10$ と $-6$ で、二つの多項式は等しくない | $P_{2;u,v}(X)\in\mathbb Z[X]$ を有限和で作り係数を厳密比較 | PASS |

すべて `ZZ`・`ZZ[X]` と有限集合の厳密計算であり、浮動小数点、実対数、指数関数、
無限和は使わない。
