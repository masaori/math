# SageMath Check: 共終な添字での交差べき等式は箱サイズ極限の一致に十分である

**対象ラベル**: `claim_cofinal_cross_power_equality_is_sufficient_for_limit_quantity`,
`claim_cofinal_equal_positive_real_sequences_share_limit`,
`remark_cofinal_agreement_does_not_give_existence`

交差べき等式を「ある添字以降のすべて」から「共終な添字」（成り立たない添字がいくらでも
大きいところに残ってよい）へさらに弱めても、乗根列の一致する添字が共終になる可算側の
合成を、正の有理数乗根を持つ有限列で本文と同順に確認する。あわせて、共終な一致だけからは
箱サイズ極限の存在が導けないことを述べる注意の反例を、有限の場合分けで確認する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 交差べき等式が成り立つ添字が共終であること | 各 $L_1$ について $L\ge L_1$ の証人を検査範囲内で探索 | PASS |
| 尾部版の仮定は満たさないこと（どの $L_0$ 以降にも破れる添字が残る） | 各 $L_0$ について反例添字を探索 | PASS |
| 成り立つ各添字で一箱ごとの乗根一致を得る段 | 乗根を特徴づける有限べきと `QQ` の厳密比較 | PASS |
| 乗根列の一致する添字も共終になる段 | 各 $L_1$ について一致する証人を探索 | PASS |
| 共終な一致から極限値の一致を導く段が使う不等式 | 有理な候補値の組ごとに三角不等式を `QQ` で厳密比較 | PASS |
| 矛盾の取り方が空でないこと（等号が達成される場合がある） | 候補値を一致値に取ったときの差の和を `QQ` で厳密評価 | PASS |
| 注意の反例（共終に一致するが箱サイズ極限を持たない列） | 有理な候補値と各 $N$ について奇数側・偶数側を同時に近づけられないことを厳密比較 | PASS |

極限の存在と値の一致そのものは、箱の大きさの極限を使う実数側の言明なので有限検査の
対象外である。浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
