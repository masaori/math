# SageMath Check: 大きさによる切り詰めは値の衝突を持つ

**対象ラベル**: `claim_magnitude_truncation_has_a_value_collision`

素指数データ（`def_positive_rational_prime_exponent_data`）を高さ $N$ で頭打ちにする写像
$\pi_N(a)=(\min\{v_p(a),N\})_p$ が値の衝突を持つこと、すなわち $u\ne w$ かつ
$\pi_N(u)=\pi_N(w)$ を満たす正の有理数 $u,w$ が存在することを、本文と同じ証人
$u=2^{N}$、$w=2^{N+1}$ で確認する。高さ $N$ の取り方を変えても同じ形の証人が作れることを、
いくつかの高さについて追う。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 証人 $u=2^{N}$、$w=2^{N+1}$ が正の有理数であること | `QQ` での正値判定と整数への一致 | PASS |
| 素数 $2$ での素指数が $N$ と $N+1$ で異なること | `QQ` の付値を厳密比較 | PASS |
| 素数 $2$ での成分が切り詰めると一致すること | $\min$ を `ZZ` で厳密評価 | PASS |
| $2$ 以外の素数で素指数も切り詰めた成分もともに $0$ であること | `QQ` の付値と $\min$ を厳密比較 | PASS |
| 検査した範囲のすべての素数で像が一致すること | 有限タプルの厳密比較 | PASS |
| $u\ne w$ であること | $w-u=2^{N}\ge2>0$ を `QQ` で厳密比較 | PASS |
| 切り詰めで落ちる情報の所在（切り詰める前の素数 $2$ での素指数の差が $1$） | `ZZ` の差を厳密比較 | PASS |
| 対偶の側（切り詰めない素指数データそのものはこの証人では衝突しない） | 有限タプルの非一致を厳密判定 | PASS |

無限積の成分のうち検査するのは $50$ 未満の素数の有限個だけである。本文の証明は
「素数 $2$ での成分」と「$2$ 以外の素数での成分」の二つに分けており、後者の論証は
$p\ne2$ にしか依らないので、有限個の標本で追えば足りる。

この主張は有限側だけで閉じており、箱の大きさの極限を使わない。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
