# SageMath Check: 極限量は有限箱の列だけの関数である

**対象ラベル**: `claim_limit_quantity_depends_only_on_finite_box_sequence`

証明の可算側の段（有限箱の列の一致から、素指数データによる正の有理数の一意な復元を経て、
有限箱の等式 $Z_L(q)=Z_L(q')$ と $\#V_L$ の一致に至るまで）を、箱の辺 $L=1,2$ と、
列が一致する有理点の対 3 組（同じ有理数の異なる表示）で、$\mathbb Q$ の厳密計算で確認する。
続く段（$\#V_L$ 乗根の底と指数の一致、同一実数列の極限の一意性）は実数の話なので検査対象外。

| 確かめた段 | 方法 | ステータス |

| 素指数データから正の有理数が $\prod_p p^{e_p}$ として一意に復元される | 復元した `QQ` の値と $Z_L(q)$ を比較 | PASS |
| したがって $Z_L(q)=Z_L(q')$（可算側の等式） | `QQ` の等式 | PASS |
| 第 1 成分 $\#V_L$ が一致する（乗根の指数の一致） | 整数の等式 | PASS |

浮動小数点、実対数、指数関数、無限和、極限は使わない。
