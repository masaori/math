# SageMath Check: 有限個の素数への切り詰めは値の衝突を持つ

**対象ラベル**: `claim_finite_prime_truncation_has_a_value_collision`

素指数データ（`def_positive_rational_prime_exponent_data`）を、素数からなる有限集合 $P$ での
指数だけへ切り詰める写像 $\pi_P$ が値の衝突を持つこと、すなわち $u\ne w$ かつ
$\pi_P(u)=\pi_P(w)$ を満たす正の有理数 $u,w$ が存在することを、本文と同じ証人 $u=1$、$w=r$ で確認する。
$P$ の取り方を変えても同じ形の証人が作れることを、いくつかの有限集合について追う。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| $P$ に属さない素数 $r$ が取れること | 最小の証人を素数判定で構成し $r\notin P$ を確認 | PASS |
| $P$ のすべての素数で $u=1$ の素指数が $0$ であること | `QQ` の付値を厳密比較 | PASS |
| $P$ のすべての素数で $w=r$ の素指数が $0$ であること | $p\ne r$ を確認したうえで `QQ` の付値を厳密比較 | PASS |
| 切り詰めた像が一致すること | 有限タプルの厳密比較 | PASS |
| $u\ne w$ であること | $r\ge2$ から $w-u\ge1>0$ を `QQ` で厳密比較 | PASS |
| 切り詰めで落ちる情報の所在（$r$ での素指数は一致しない） | `QQ` の付値を厳密比較 | PASS |

この主張は有限側だけで閉じており、箱の大きさの極限を使わない。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
