# SageMath Check: 点数乗表示の底の分母の素因子は、有理点の分母の素因子に限られる

**対象ラベル**: `claim_rational_power_base_denominator_primes`

互いに素な正の自然数 $a,b$ で $q=a/b$ と書き、有限箱の値を整数の商
$Z_L(q)=P_L/b^{\#E_L}$（$P_L=\sum_m\Omega_L(m)a^mb^{\#E_L-m}$）として表したうえで、
本文の証明の各段を `ZZ`/`QQ` の厳密計算で追う。$\Omega_L(m)$ は自由境界の立方箱の
全配位を総当たりして数え上げる（$L=1,2$。$L=3$ は $2^{27}$ 配位になるため含めない）。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| $Z_L(q)=P_L/b^{\#E_L}$ が `QQ` の等式であること、$P_L>0$ であること | 有理点 6 点で代入と有限和を厳密比較 | PASS |
| $p\nmid b$ のとき $v_p(Z_L(q))=v_p(P_L)\ge0$ であること | `QQ` の付値を素数 6 個で厳密比較 | PASS |
| 点数乗表示から $\#V_L\,v_p(c)=v_p(Z_L(q))$ と $v_p(c)\ge0$ が出ること | 表示が実際に成り立つ有理点 $1$（$Z_L(1)=2^{\#V_L}$、$c=2$）で厳密比較 | PASS |
| 既約分数 $c=u/v$ で $v_p(v)=0$ になること | `QQ` の分子分母を取り互いに素性と付値を厳密比較 | PASS |
| 分子の側は同じ論法では出ないこと | $a$ も $b$ も割らない素数が $P_2$ を割る実例を有理点 6 点すべてで提示 | PASS |

$\#E_L=3L^2(L-1)$、$\#V_L=L^3$ も箱の構成から確認している。

この主張は有限側だけで閉じており、箱の大きさの極限を使わない。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
