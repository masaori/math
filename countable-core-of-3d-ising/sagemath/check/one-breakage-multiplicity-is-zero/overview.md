# SageMath Check: 破れ数がちょうど 1 の配位数

**対象ラベル**: `claim_one_breakage_multiplicity_is_zero`

本文の三段を、辺の構成と配位の有限列挙により `ZZ` の厳密計算で確認する。

| 確かめた段 | ステータス |
| --- | --- |
| 各辺について同じ面をなす三本の辺が辺の集合に属し、始点が構成した点と一致すること | PASS |
| 破れ数がちょうど 1 の配位が存在しないこと | PASS |
| 多重度が正になる破れ数の並びに 1 が現れないこと | PASS |

段 1 は箱の一辺を 2, 3, 4 に固定して全ての辺で構成を確かめる。
段 2 と段 3 は配位を全て並べるので箱の一辺を 2 に固定する。
箱の大きさの極限、浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
