# SageMath Check: 素指数の符号だけを見る粗視化は箱サイズ極限の一致に十分でない

**対象ラベル**: `claim_sign_of_prime_exponents_is_not_sufficient_for_limit_quantity`

素指数データ（`def_positive_rational_prime_exponent_data`）を、どの素数がどちら向きに現れるか
という符号 $\operatorname{sgn}(v_p(\cdot))$ だけへ潰す粗視化が、箱サイズ極限に対して十分でない
ことを示す反例を、本文と同じ列 $A(L)=2$、$B(L)=4$、$M(L)=1$ で確認する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| $\operatorname{sgn}$ が本文の定義どおりであること | `ZZ` の順序比較を有限個の代表で確認 | PASS |
| 素数 $2$ での素指数が $1$ と $2$ で一致しないこと（符号へ潰して落ちる情報の所在） | `QQ` の付値を厳密比較 | PASS |
| 素数 $2$ での素指数の符号が一致すること | `ZZ` の符号を厳密比較 | PASS |
| $2$ 以外の素数では素指数も符号もともに $0$ であること | `QQ` の付値と `ZZ` の符号を厳密比較 | PASS |
| $a$ が定数列で候補値 $2$ との差が $0$ であること | 各添字で `QQ` の厳密比較 | PASS |
| $b$ が定数列で候補値 $4$ との差が $0$ であること | 各添字で `QQ` の厳密比較 | PASS |
| 二つの候補値を同時に近づけられないこと | 有理な候補値ごとに幅 $1/2$ での両立不能を厳密比較 | PASS |
| 符号への粗視化が高さ $N\ge2$ での切り詰めより粗いこと | `ZZ` の最小値と符号を厳密比較 | PASS |

極限の存在と値そのものは箱の大きさの極限を使う実数側の言明なので有限検査の対象外である。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
