# SageMath Check: 交差べき等式は正の乗根の一致を決める

**対象ラベル**: `claim_cross_power_equality_implies_root_equality`

証明の可算側の段を、乗根が正有理数に取れる三例（$A=8,N=3,B=4,M=2$ など整数・分数の両方）で
証明と同じ順に確認する。乗根の一意性そのもの（正の実数上で正の自然数乗が単射であること）は
実数側の言明なので、正有理数の有限標本での単射性の確認に代える。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 仮定 $A^M=B^N$ が有限算術で判定できる | `QQ` の厳密比較 | PASS |
| $x^{NM}=(x^N)^M=A^M=B^N=(y^M)^N=y^{MN}=y^{NM}$ の各行 | 乗根が正有理数の例で `QQ` の厳密比較 | PASS |
| 正の自然数乗の単射性（有限標本） | 正有理数 $x\ne y$ と $k\in\{1,2,3,6\}$ で $x^k\ne y^k$ | PASS |
| 交差べき等式が成り立たない負例は仮定の段で検出される | `QQ` の厳密比較 | PASS |

正の実数乗根の一意性の一般形は実数側の段であり、SageMath の有限検査対象外である。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
