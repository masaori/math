# SageMath Check: 値の衝突を持つ粗視化は箱サイズ極限の一致に十分でない

**対象ラベル**: `claim_colliding_coarse_graining_is_not_sufficient_for_limit_quantity`

正の有理数の上の粗視化 $\pi$ が値の衝突（$u\ne w$ かつ $\pi(u)=\pi(w)$）を持つとき、
その二つの値をそのまま定数列に取れば反例になる、という本文の構成を、衝突を持つ粗視化の
具体例 5 つについて確かめる。本文の主張は $\pi$ の作り方に何の仮定も置かないので、
検査も 5 例の内訳（有限個の素数へ切り詰める向き・値の大きさで切り詰める向き・
符号だけを残す向き・分子と分母の偶奇・一点へ潰す）に依存しない形で書いてある。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 各例が実際に値の衝突を持つこと | `QQ` の厳密比較で $u\ne w$ と $\pi(u)=\pi(w)$ を確認 | PASS |
| 構成した三つの列が主張の要求する集合に属すること | `QQ_{>0}` と `ZZ_{\ge1}` の帰属を各添字で確認 | PASS |
| すべての添字で粗視化の値が一致すること | 各添字で $\pi(A(L))=\pi(B(L))$ を厳密比較 | PASS |
| $M(L)=1$ なので乗根を取らずに $a(L)=u$、$b(L)=w$ となること | `QQ` の中で $a^{M}=A$、$b^{M}=B$ を厳密比較 | PASS |
| 二つの列が定数列で候補値との差が $0$ であること | 各添字で `QQ` の厳密比較 | PASS |
| 二つの候補値を同時に近づけられないこと | 幅 $|u-w|/2$ での両立不能を `QQ` で厳密比較 | PASS |
| 衝突を持たない粗視化ではこの構成が作れないこと（対偶の側） | 恒等写像の単射性を有限個の代表で確認 | PASS |

極限の存在と値そのものは箱の大きさの極限を使う実数側の言明なので有限検査の対象外である。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
