**対象ラベル**: `claim_tail_cross_power_equality_is_sufficient_for_limit_quantity`

交差べき等式をある添字 $L_0$ 以降だけに弱めても、$L_0$ 以降の乗根列の項別一致が
得られる（$L_0$ 未満での不一致を許す）可算側の合成を、正の有理数乗根を持つ有限列で
本文と同順に確認する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| $L_0$ 未満（$L=1$）では交差べき等式を仮定しないこと（実際に成り立たず乗根も不一致） | `QQ` 上の有限べきの厳密比較 | PASS |

| $L\ge L_0$ の各添字で一箱ごとの乗根一致を得る段 | 乗根を特徴づける有限べきと `QQ` の厳密比較 | PASS |
| $L\ge L_0$ の項だけを束ねると項別一致になる段 | 尾部（$L\ge L_0$）の有限列を要素ごとに比較 | PASS |

有限検査の対象外である。浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
