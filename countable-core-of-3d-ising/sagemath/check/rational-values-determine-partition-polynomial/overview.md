# SageMath Check: 有理点の値が分配多項式を決めること

**対象ラベル**: `claim_rational_values_determine_partition_polynomial`

本文の証明の各段を、自由境界の一辺 $L=1,2$ の分配多項式について確認する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 係数の非負性と正の定数項から、正の有理点での値が正の有理数になる | 相異なる $\#E_L+1$ 点 $1,2,\ldots,\#E_L+1$ への代入 | PASS |
| 素指数データが正の有理数を一意に復元する | 分子・分母の素因数分解から有限台の整数列を作り、積で復元 | PASS |
| 復元した値は元の分配多項式の値に一致する | 全ての評価点で厳密比較 | PASS |
| 次数以下の多項式は相異なる次数 $+1$ 点での値から一意に決まる | $\mathbb Q[X]$ 上の補間後、差が全評価点で零かつ零多項式であることを確認 | PASS |

すべて `ZZ`・`ZZ[X]`・`QQ`・`QQ[X]` と有限集合の厳密計算であり、浮動小数点、実対数、
指数関数、無限和は使わない。$L=1$ は次数 $0$ の端の場合、$L=2$ は次数 $12$ の非自明な場合である。
