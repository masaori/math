# SageMath Check: 尾部一致は極限量に対して十分である

**対象ラベル**: `claim_tail_agreement_is_sufficient_for_limit_quantity`

証明の可算側の段を、証拠 $N=2$ を持つ有限接頭部の異なる二列について確認する。$L=1$ の項は人工的な有限箱データとして異ならせ、$L=2$ では実際の分配多項式評価を用いて、有限箱の列の項、分配多項式値、有限箱量を特徴づける有限べきの等式が順に一致することを検査する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| 有限接頭部の相違は許し、$L\ge N$ で列の項が一致する | $\mathbb N\times\Lambda$ を点数と素指数データの組として厳密比較 | PASS |
| 素指数データの一致から $Z_L(q)=Z_L(q')$ が従う | `QQ` の正値と素因数分解を厳密比較 | PASS |
| 有限箱量 $a_L(q),a_L(q')$ を特徴づける有限べきの等式が一致する | $Z_L(q)^{\#V_L}=Z_L(q')^{\#V_L}$ を `QQ` 上で厳密比較 | PASS |

極限量への最終段は箱の大きさの極限と収束の定義であり、SageMath の有限検査対象外である。浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。

```sh
sage sagemath/check/tail-agreement-is-sufficient-for-limit-quantity/check.sage
```

**2026-08-18 実行: すべて通過。**

初回実行では、辺のない $L=1$ の実際の分配多項式を異なる評価点で評価すれば先頭項を異ならせられると誤認し、失敗した。実際には $Z_1=2$ で評価点に依らない。尾部一致の定義の有限検査と、実際の分配多項式による証明各段の検査を分離して修正した。
