# SageMath Check: 符号への潰しは値の衝突を持つ

**対象ラベル**: `claim_sign_collapse_has_a_value_collision`

素指数データ（`def_positive_rational_prime_exponent_data`）の各成分を符号だけへ潰す写像
$\pi_{\operatorname{sgn}}$ が値の衝突を持つこと、すなわち $u\ne w$ かつ
$\pi_{\operatorname{sgn}}(u)=\pi_{\operatorname{sgn}}(w)$ を満たす正の有理数 $u,w$ が存在することを、
本文と同じ証人 $u=2$、$w=4$ で確認する。

| 確かめた段 | 方法 | ステータス |
| --- | --- | --- |
| $u=2$、$w=4$ が正の有理数であること | `QQ` の正値判定 | PASS |
| 素数 $2$ での素指数が $1$ と $2$ で異なること | `QQ` の付値を厳密比較 | PASS |
| 素数 $2$ での符号がともに $1$ であること | `ZZ` の順序比較 | PASS |
| $2$ 以外の素数では素指数も符号もともに $0$ であること | `QQ` の付値と `ZZ` の順序を厳密比較 | PASS |
| 検査した範囲のすべての素数で像が一致すること | 有限タプルの厳密比較 | PASS |
| $u\ne w$ であること | $w-u=2>0$ を `QQ` で厳密比較 | PASS |
| 潰す前の素指数データはこの証人を区別すること | 有限タプルの非一致を厳密判定 | PASS |

無限積の成分のうち検査するのは $50$ 未満の素数だけである。本文の証明は
「素数 $2$ での成分」と「$2$ 以外の素数での成分」に分かれ、後者の計算は $p\ne2$ にしか
依存しないため、有限個の標本でも本文と同じ一行ごとの計算を追える。

この主張は有限側だけで閉じており、箱の大きさの極限を使わない。
浮動小数点、実対数、指数関数、無限和、級数、積分、微分は使わない。
