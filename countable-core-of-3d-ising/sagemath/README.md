# SageMath 検証（式変形と数え上げの厳密な裏取り）

規約の正本は [docs/context/証明の書き方.md](../../docs/context/証明の書き方.md) の
「SageMath 検証」である。ここにはこのプロジェクト固有の運用だけを書く。

## 置き方

```text
sagemath/
├── _shared/defs.sage          # 共通定義（格子・辺・配位・分配多項式・分離集合）
├── check/<対象名>/
│   ├── check.sage             # 検証コード（1 対象 1 ディレクトリ。連番は付けない）
│   └── overview.md            # 対象ラベル・何を確かめたか・結果・実行日
└── tools/verify-check-linkage.ts  # 対象ラベルが本文に実在することの機械検査
```

- `overview.md` の先頭に **`**対象ラベル**: \`<ラベル>\`` の行**を置く。
  ラベルは構造化テキスト側のブロックのラベルであり、ファイルパスに依存させない。
- 対象名は内容が分かる名前にする（`minimal-separating-set-is-edge-boundary` など）。連番を付けない。

## このプロジェクト固有の注意（立場）

- **厳密計算だけを使う。** `ZZ` / `QQ` / `Finset` 相当の有限集合の全数列挙で行う。
  **浮動小数点（`RR` / `CC` / `float`）を使わない。** 本文の立場（箱の大きさの極限以外は
  非可算へ出ない）に合わせるためであり、精度の都合ではない。
- 数え上げは**小さい箱で全数列挙**して確かめる。箱の大きさは検証時間ではなく
  「主張のどの場合分けを網羅したか」で選び、`overview.md` に書く。
- **検証が失敗したら本文を直す。** 検証を主張に合わせて緩めない。失敗の記録も消さない。

## 実行

```sh
sage sagemath/check/<対象名>/check.sage
node sagemath/tools/verify-check-linkage.ts
```
