## なぜ退避したか

プロジェクトの最初のゴール設定が**可算コアの同定**（有限格子の可算データの上で、
極限で効く部分と極限で潰れる部分を分離すること）に確定したため、本文はそのゴールの内容だけで
構成することにした。ここに置いた章は、当初本体に据えていた別の枠組みに属する。

降格の理由は、**有限の証拠と模型を結ぶ健全性の橋が無いこと**である。
有限の箱ごとの主張の族から、許される唯一の脱出（箱の大きさの極限）を 1 回だけ使って
無限体積の言明へ渡す定理を自分で作らない限り、証拠が捉える有理数の集合は模型の相転移と
結びついていない。橋が架かるまで本体へ戻さない。

**捨てていないのは規約による**（[docs/context/証明の書き方.md](../../../docs/context/証明の書き方.md)
の「採用しなかった経路は捨てない。採用しなかった理由を明記する」）。

## 既知の欠陥（戻すなら先に直すもの）

1. **観測点が箱の角にある。** 箱を $\{0,\dots,L-1\}^3$、原点を $(0,0,0)$ と置いたため、
   観測点が三方向で境界に接している。境界の影響が支配的で、バルクの量になっていない。
2. **証拠の定義が有限の検査になっていない。** 「すべての箱とすべての面積について
   数え上げが $C^n$ 以下」という無限個の主張を含む。数え上げの上界は具体的な定数を持つ
   一度きりの定理として分離し、証拠は有理数の不等式だけにする必要がある。
3. **上界が低温側を特徴づけない。** 原点が負である割合の上界を $1/2$ 以下としたが、
   高温側でも極限は $1/2$ になる。有理数の隔たり $\delta>0$ を伴う $1/2-\delta$ 以下が要る。
4. **未証明の主張が 2 つ残っている。** 極小分離集合の個数の指数上界と、
   Peierls の反転写像による上界。
5. **辺を頂点の 2 元集合として定義している。** 規約は「辺は番号の集合、格子の形は
   端点写像だけが担う」であり、数え上げの議論で頂点の構造が暗黙に混ざる。
