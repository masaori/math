## 1. `check_joint_eigenspace_decomposition` (4) の二項展開・二項定理は不要

**該当箇所**: `evenEigen_005_claim_check_joint_eigenspace_decomposition` の proof Step 4。

本文は `Q̌_ε = (∏_{μ∈T} ň_μ) ∏_{μ∉T}(I - ň_μ)` の第 2 の積を
`∑_{S ⊆ 𝓜̌∖T} (-1)^{|S|} ∏_{μ∈S} ň_μ` と展開し、
`trace_of_check_number_operator_product` と二項定理
`∑_j C(M-|T|, j)(-1)^j 2^{-j} = (1 - 1/2)^{M-|T|}` を使って `tr(Q̌_ε) = 1` を出している。

**一次情報**: `lean/Ising2D/Abstract/JointEigenspace.lean` の
`Ising2D.Abstract.two_pow_smul_tau_projOn`（章 009 の形式化で既に存在）は、
二項展開も二項定理も使わずに `2^{|s|} τ(Q_T) = τ(1)` を証明している。
効いているのは

  「**どちらの因子（`ň_j` でも `I - ň_j` でも）についても** `2 τ(R_j X) = τ(X)`」

という 1 段の帰納法だけで、`I - ň_j` の場合はその差として自動的に出る。
章 017 の `Ising2D.CheckFermiSetup.trace_Qproj`
（`lean/Ising2D/Part017/Claim005_CheckJointEigenspace.lean`）はこの補題の特殊化であり、
`|𝓜̌| = M` を代入して `tr(Q̌_ε) = 2^{M-M} = 1` を得ている。

これは章 009 について既に記録済み（`003_ch009_未定義記号と暗黙の仮定.md` の
「誤りではないが冗長と分かった箇所」）の指摘が、そのまま章 017 にも当てはまるということである。

## 2. `max_eigenvalue_of_V_plus_simple` (3) に直和分解 (5) は不要

**該当箇所**: `evenEigen_011_theorem_max_eigenvalue_of_V_plus_simple` の proof (3)。

本文は

> 各項 `(Λ̌_ε - Λ̌_max) Q̌_ε x` は `im Q̌_ε` に属し、
> `check_joint_eigenspace_decomposition` (5) より和は直和だから、各項が `0` でなければならない。

と、**直和分解 (5) を根拠に使っている**。

**一次情報**: `lean/Ising2D/Abstract/SimpleEigenvalue.lean` の
`Ising2D.Abstract.eq_proj_of_eigen` は、直和分解を一切使わずに同じ結論を出している。
仮定は次の 4 つだけである。

1. 台が環であり、その環が加群へ作用すること（作用の 5 法則）、
2. `∑_ε Q̌_ε = 1`（原文 (2)）、
3. `Q̌_ε V^{(+)} = Λ̌_ε Q̌_ε`（原文 (1) の左右を入れ替えた形）、
4. `ε ≠ (1,…,1) ⇒ Λ̌_ε ≠ Λ̌_max`（原文 (2)）。

証明は、固有方程式 `V^{(+)}x = Λ̌_max x` の**両辺に左から `Q̌_{ε'}` を掛ける**だけである:

    Λ̌_{ε'} (Q̌_{ε'} x) = (Q̌_{ε'} V^{(+)}) x = Q̌_{ε'} (V^{(+)} x) = Λ̌_max (Q̌_{ε'} x)

から `(Λ̌_{ε'} - Λ̌_max)(Q̌_{ε'} x) = 0`、したがって `ε' ≠ (1,…,1)` なら `Q̌_{ε'} x = 0`。
あとは `x = ∑_ε Q̌_ε x = Q̌_{(1,…,1)} x`。

**射影の性質（`Q̌^2 = Q̌`、`Q̌_ε Q̌_{ε'} = 0`）も、有限次元性も使っていない。**
つまり (3) の証明で (5) を引くのは冗長であり、(1)(2) だけで足りる。

（なお `dim im Q̌_{(1,…,1)} = 1` という結論そのものには (4) が必要である。
不要なのは (5) の**直和性**の部分だけである。）

## 2'. 関連: 本文は `V^{(+)} Q̌_ε = Λ̌_ε Q̌_ε` と `Q̌_ε V^{(+)} = Λ̌_ε Q̌_ε` を区別していない

上の証明が実際に使うのは**左からの形** `Q̌_ε V^{(+)} = Λ̌_ε Q̌_ε` である。
本文が述べているのは `eigenvalues_of_V_plus` (1) の `V^{(+)} Q̌_ε = Λ̌_ε Q̌_ε` だけで、
両者が同じであることは `X̌` と `Q̌_ε` が可換であることによる（本文は明示していない）。

`Ising2D.CheckFermiSetup.Qproj_mul_Vprime` / `Ising2D.Qproj_mul_VPlus` として明示的に用意した。

## 3. `V_plus_is_positive_definite` の `(V^{(+)})^{-1}` の正定値性は章 009 に対応物が無い

## 4. 章 009 の `𝓘` の同定が本章では無条件に決まること（本文の主張は正しい）

本文 `def_check_number_operator` は「009 章の `𝓘` と違い、ここでは `μ ∈ 𝓜̌` が例外なく走る」
と述べている。**これは形式化でも確認できた。**

章 009 の Lean 側 `Ising2D.FermiSetup`
（`lean/Ising2D/Part009/Definition004_NumberOperator.lean`）は、
添字集合について `I : Finset ℤ`, `hIlow`, `hIhigh`, `hgam : ∀ μ ∈ I, γ_2(θ_μ) ≠ 0`
の 4 つを**仮定として受け取る**構造になっていた（`γ_2(θ_μ) = 0` になる `μ` の同定は
章 008 の内容なので依存を切ってあった）。

章 017 の `Ising2D.CheckFermiSetup` にはこれらの場が**一切無い**。
添字集合は `Ising2D.CheckIdx M := {μ : ℤ // μ ∈ Finset.Icc 1 M}` として確定しており、
`Ising2D.CheckIdx.card : Fintype.card (CheckIdx M) = M` が無条件に成り立つ。
これが `tr(Q̌_ε) = 1`（`Ising2D.CheckFermiSetup.trace_Qproj`）と
`tr(V̌')` の前因子の消失（`Ising2D.CheckFermiSetup.trace_Vprime`）の直接の根拠である。
