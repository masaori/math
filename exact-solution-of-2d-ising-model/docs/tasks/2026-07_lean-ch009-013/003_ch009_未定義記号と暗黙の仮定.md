## (1) `number_operator_idempotent` の証明中で未定義の記号 `\mathcal{M}` を使っている

- 場所: `eigenvalues_of_V_005_claim_number_operator_idempotent` の proof、(1) の末尾
  「（`μ ∈ \mathcal{I}` なので `-μ ∈ \mathcal{M}` かつ `γ_2(θ_{-μ}) ≠ 0` であり…）」
- 問題: `\mathcal{M}` は 009 章のどこでも定義されていない。定義は 008 章
  （`content/008_TV1_hatZ_hatY_part2.ts` の `def_Vprime`）の
  `\mathcal{M} := \{-M,\dots,-1,1,\dots,M\}` にある。009 章は `\mathcal{I}` しか導入していない。
- 影響: 主張の正しさには影響しない（`-μ ∈ \mathcal{M}` は `μ ∈ \{1,…,M\}` から従う）。
  読者が 009 章だけを読むと意味が取れない。
- 一次情報: 009 章の本文を `\mathcal{M}` で検索すると、この 1 箇所しかヒットしない。
  定義ブロックは存在しない。

## (2) 平方根の分枝の整合が 009 章でも必要だが、本章はそれに触れていない

- 場所: `def_number_operator`（`n_μ := ψ_μ^† ψ_{-μ}`）と、それを使う
  `number_operator_idempotent` / `number_operators_commute`
- 問題: `ψ_μ^†`, `ψ_{-μ}` の定義には `t_μ = √(γ_2(θ_μ)γ_2(-θ_μ))` の**分枝の選択**が要る。
  008 章 `anticommutator_of_psi` について既に指摘済みの穴
  （`lean/Ising2D/Part008/Definition030_Fermi.lean` 冒頭、および `lean/README.md` の
  「形式化の過程で見つかった原文の問題」表）と同じ問題が 009 章にも波及する。
  009 章は `anticommutator_of_psi` を添字対 `(μ, -μ)`, `(μ, -ν)`, `(-μ, ν)` に適用しており、
  そのすべてで「`M ∣ (第1添字 + 第2添字)` のときに分枝が一致していること」が要る。
- Lean 側の扱い: 分枝関数 `t : ℤ → ℂ` と整合条件
  `hbr : ∀ a b, (M:ℤ) ∣ (a+b) → t b = t a` を `Ising2D.FermiSetup` の仮定として明示した
  （`lean/Ising2D/Part009/Definition004_NumberOperator.lean`）。
- 一次情報: 逆分枝では `[ψ_μ^†, ψ_ν^†]₊ = I ≠ 0` になることが
  `Ising2D.acomm_psiDag_psiDag_of_opposite_branch` として既に証明されている。
  したがってこの仮定は**省略できない**。

## (3) `constant_c_value` Step 3 の `V^{-1} = c^{-1} V'^{-1}` に根拠が書かれていない

- 場所: `eigenvalues_of_V_017_claim_constant_c_value` の proof Step 3
  「`V = cV'` から `V^{-1} = c^{-1}V'^{-1}` であり」
- 問題: これは「逆元の一意性」を使っている。`V` の可逆性は `V_is_positive_definite` Step 4、
  `V'` の可逆性は `trace_of_Vprime` Step 1 に書かれているので**埋まる**が、
  本文にはその接続が書かれていない。
- Lean 側の扱い: `V^{-1}` を明示的に構成し（`Ising2D.VmatInv`）、
  `VmatInv * Vmat = 1` と `Vmat * (c⁻¹ • V'^{-1}) = 1` から逆元の一意性で
  `VmatInv = c⁻¹ • V'^{-1}` を導いた（`lean/Ising2D/Part009/Claim017_ConstantC.lean`）。

## 参考: 誤りではないが冗長と分かった箇所

以下は**誤りではない**。形式化してみると不要と分かった経路なので、記録だけ残す。

- `sign_flip_conjugation` の Step 3・Step 4（`σ^z_m σ^z_{m+1}` と `G` への書き換え、
  および `M` の偶奇による場合分け）は不要。
  `U Z_m U^{-1} = -Z_m`, `U Y_m U^{-1} = +Y_m` が **`m` によらず**成り立ち、
  `H_1^{(±)}` が `Y_m Z_{m+1}` の、`H_2` が `Z_m Y_m` の和であることから直ちに従う
  （`Ising2D.Uflip_conj_Z` / `Uflip_conj_Y` / `Uflip_conj_H1` / `Uflip_conj_H2`）。
- 同じ理由で `iH_is_real_symmetric` の Step 0〜2（`Z_mY_m = -iσ^x_m` などの書き換え）も、
  「実対称である」という**結論だけ**を得るには不要。
  `Z_m^⊤ = Z_m`, `Y_m^⊤ = -Y_m`, `Z_m^* = Z_m`, `Y_m^* = Y_m` と
  `[Z_μ, Y_ν]_+ = 0` だけで従う（`Ising2D.S1_isHermitian` / `S1_transpose` ほか）。
  ただし `S_2 = K_2^*∑σ^x_m` の表式自体は `V_is_positive_definite` Step 1 で
  `V_2` の 2 つの表式を突き合わせるのに使われているので、本文から削れるわけではない。
- `joint_eigenspace_decomposition` (4) の二項展開と二項定理は不要。
  「どちらの因子でも `2 tr(R_j X) = tr(X)`」の 1 段の帰納法で
  `2^m tr(Q_ε) = tr(I)` が出る（`Ising2D.Abstract.two_pow_smul_tau_projOn`）。
- `star_preserves_norm_and_limits` の (2)(3)（`‖A^*‖ = ‖A‖` と極限の共役転置）は
  `exp(S)` がエルミートであることを示すためだけに使われている。
