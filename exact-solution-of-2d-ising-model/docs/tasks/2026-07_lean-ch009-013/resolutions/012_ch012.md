## 指摘 1（記録 §1）実数解析から外部に頼る事実は「(R1)(R2) の 2 つだけ」ではない

**指摘の要約**: 章冒頭の注記（「実数解析へ移行するのはこの章のこの箇所だけである」）は、
外部から持ち込む事実を Heine–Cantor の一様連続性定理と連続関数の Riemann 可積分性の
2 つだけだと宣言している。しかし同じ章の「γ は ℝ 上で連続」の証明は、余弦関数の連続性・
非負実数上の平方根の連続性・正の実数上の対数関数の連続性という、この 2 つに含まれない
実数解析の事実を使っている。列挙が不足している（証明の構成が誤っているわけではない）。

**決着**: 本文を修正した。

**一次情報（修正前の本文が実際に (R1)(R2) 外の事実を使っていること）**:
`freeenergy_002_claim_gamma_is_continuous` の proof Step 1 は
「`cos` は `ℝ` 上連続で周期 `2π` をもつので」と書き、Step 2 は
「`y ↦ y^2-1` は連続で `[1,∞)` 上非負、非負実数の平方根は連続、`y+√(y^2-1) ≥ 1 > 0` 上で
`log` は連続なので」と書いている。いずれも有限個の複素数・行列の代数計算では代用できない。

**変更前**（`freeenergy_000_remark_escape_to_real_analysis`）:

> そこで外部から持ち込む事実は次の 2 つだけであり、この表式を得るまでの他の箇所では使わない。
> (R1) Heine–Cantor …／(R2) 連続関数の Riemann 可積分性 …

**変更後**: 宣言の範囲を「積分について」に限定し、初等関数の連続性を (R0) として明示的に
数える段落と箇条書きを (R1)(R2) の列挙の直後に追加した。

> そこで**積分について**外部から持ち込む事実は次の 2 つだけであり、この表式を得るまでの
> 他の箇所では使わない。
> （(R1)(R2) の列挙。ここは変更なし）
> **積分とは別に、被積分関数の連続性を示すところでもう 1 種類の外部事実を使う。**
> 「γ は ℝ 上で連続」の証明は、`γ = arccosh ∘ γ_1` を初等関数の合成として書いて
> 連続性を導くので、次を認める必要がある。
> - (R0) **初等関数の連続性**：`cos : ℝ→ℝ` は連続、`√· : ℝ_{≥0}→ℝ` は連続、
>   `log : ℝ_{>0}→ℝ` は連続であり、連続関数の四則（分母が 0 にならない範囲）と合成は連続である。
>
> (R0) は Riemann 積分とは独立の事実であり、(R1)(R2) には含まれない。これも有限の代数計算では
> 代用できないので、外部事実として明示的に数える。この章で持ち込む実数解析の事実は
> (R0)(R1)(R2) の 3 種類でちょうど尽きている。

あわせて、読者が「どこから来た事実か」を辿れるように、「γ は ℝ 上で連続」の proof の
Step 1・Step 2 から (R0) への参照を書き足した（`cos` の連続性・平方根と対数の連続性の
それぞれに「注記の (R0)」を明記）。章末の「章 E では (R3)〜(R6) を追加で持ち込む」という
段落も「この章の (R0)(R1)(R2) とは独立に管理する」に直した。

**番号の付け方について（判断の根拠）**: 追加分に (R3) を使わなかったのは、
`content/020_critical_point.ts` の注記（臨界点と比熱の章で追加する実数解析の事実）が
(R3)〜(R6) を既に使っているためである。担当外のファイルなので衝突を避けて (R0) とした。
なお 020 章の注記には「（012 章の注記は）外部から持ち込む事実が (R1)(R2) の 2 つだけで
あることを述べた」という要約文が残っており、今回の (R0) 追加を反映していない。
020 章は担当外なので編集していない。**020 章を担当する側で、この要約文を
「積分について (R1)(R2)、被積分関数の連続性について (R0)」に合わせて直す必要がある。**

## 指摘 2（記録 §2）集合上の和から添字つきの和への移行が正当化されていない

**指摘の要約**: 「Onsager の自由エネルギーの表式」の主張は、運動量の値の**集合**
`Θ^{(δ)}_M = { 2π(μ-δ)/M | μ = 1,…,M }` の上での和で `Λ^{(δ)}_M` を定義しているのに、
証明は断りなく μ = 1,…,M についての**添字つきの和**へ移っている。両者が一致するには
μ ↦ 2π(μ-δ)/M が単射（値に重複がない）ことが要る。主張自体は正しいが、その一行が本文に無い。

**決着**: 本文を修正した（証明に単射性の議論を挿入）。集合による定義そのものは変えていない。

**定義を添字つきの和に変えなかった理由（一次情報）**: `content/017_even_sector_eigenvalues.ts`
の `evenEigen_011_theorem_max_eigenvalue_of_V_plus_simple` の proof は、この定理の定義を
**集合の形のまま引用**している。

> 「(1) `onsager_free_energy_expression` の δ = 1/2 の場合の定義は
> `Θ_M^{(1/2)} = { 2π(μ-1/2)/M | μ = 1,…,M }`, `Λ^{(1/2)}_M = (2 sinh 2K_2)^{M/2}
> exp((1/2) Σ_{θ ∈ Θ_M^{(1/2)}} γ(θ))` である。」

さらに 017 章はその直後で「この M 個の値は互いに相異なる」ことを自前で証明して
`Σ_{θ∈Θ} γ(θ) = Σ_{μ=1}^{M} γ(θ̃_μ)` を導いている。定義を添字つきの和に差し替えると、
017 章のこの引用と単射性の議論が本文と食い違う。017 章は担当外で編集できないため、
**定義は集合のまま維持し、012 章の証明に欠けていた単射性の一行を足す**方を採った。
これで 012 章・017 章の両方が同じ定義を指し、どちらも単射性を明示的に使う形になる。

**変更前**（`freeenergy_005_theorem_onsager_expression` の proof）: `log Λ^{(δ)}_M` を
集合上の和で書いた式の直後に、いきなり

> `M > 0` で割ると
> `(1/M) log Λ^{(δ)}_M = (1/2) log(2 sinh 2K_2) + (1/2)·(1/M) Σ_{μ=1}^{M} γ(2π(μ-δ)/M)`

と添字つきの和へ移っていた。

**変更後**: その間に次を挿入した。

> ここで集合 `Θ_M^{(δ)}` 上の和を添字 μ についての和に書き換える。写像 μ ↦ 2π(μ-δ)/M は
> {1,…,M} 上**単射**である：実際 μ ≠ ν なら 2π(μ-δ)/M − 2π(ν-δ)/M = 2π(μ-ν)/M ≠ 0
> （2π/M > 0 かつ μ-ν ≠ 0）。よって `Θ_M^{(δ)}` はちょうど M 個の元をもち、
> `Σ_{θ∈Θ_M^{(δ)}} γ(θ) = Σ_{μ=1}^{M} γ(2π(μ-δ)/M)`
> が成り立つ（重複がないので、集合についての和と添字についての和が同じ実数になる）。

## 指摘 3（記録 §3）「等間隔点の平均は積分に収束する」の周期性の仮定と δ < 1 が過剰

**指摘の要約**: 実数解析への移行点である定理（等間隔点での値の平均が積分に収束する）は、
被積分関数 g に「連続かつ周期 2π」を仮定し、証明末尾に「周期性は δ = 0 のとき代表点が
区間の端点 2π になることを許すために使っている」と注記している。しかし証明が実際に使うのは
「代表点が閉小区間に属する」ことだけで、g(2π) と g(0) を比べる必要はどこにも生じない。
同様に代表点をずらす量 δ の範囲も、右端を開いて δ ∈ [0,1) とする必要はなく、
δ ∈ [0,1]（δ = 1 は各小区間の左端点を代表点に取る場合）で成り立つ。

**決着**: 本文を修正した（周期性の仮定を削除、δ の範囲を閉区間に拡張、末尾の注記を差し替え）。

**証明が周期性を使っていないことの確認（本文の一次情報）**: この定理の proof は
Step 0 で `[0,2π]` の M 等分 `I_μ = [2π(μ-1)/M, 2πμ/M]` と区間加法性、Step 1 で
`t^{(M)}_μ ∈ I_μ`、Step 2 で「t ∈ I_μ と t^{(M)}_μ はいずれも `[0,2π]` に属し距離が 2π/M 以下
なので、ω の定義より |g(t) − g(t^{(M)}_μ)| ≤ ω(2π/M)」、Step 3 で総和、Step 4 で (R1) を
`[0,2π]` 上の g に適用する、という構成である。連続度 ω の定義域も `s,t ∈ [0,2π]` に限られている。
δ ∈ [0,1] なら t^{(M)}_1 = 2π(1-δ)/M ≥ 0、t^{(M)}_M = 2π(M-δ)/M ≤ 2π なので代表点はすべて
`[0,2π]` に入り、Step 1〜4 のどの段も `[0,2π]` の外の g の値を参照しない。

**変更（statement）**:

- 変更前: 「`g : ℝ → ℝ` を連続かつ周期 2π の関数とし、δ ∈ [0,1) を固定する。」
- 変更後: 「`g : ℝ → ℝ` を連続関数とし、δ ∈ [0,1] を固定する（**周期性は仮定しない**）。」

**変更（proof Step 1）**:

- 変更前: 「δ ∈ [0,1) より 0 < 1-δ ≤ 1 なので `2π(μ-1)/M < 2π(μ-δ)/M ≤ 2πμ/M`」
- 変更後: 「δ ∈ [0,1] より 0 ≤ 1-δ ≤ 1 なので、2π/M > 0 を掛けて 2π(μ-1)/M を足すと
  `2π(μ-1)/M ≤ 2π(μ-δ)/M ≤ 2πμ/M`」（結論の `t^{(M)}_μ ∈ I_μ` は変更前と同じ）

**変更（proof 末尾の注記）**:

- 変更前: 「（周期性は本証明では δ = 0 のとき `t^{(M)}_M = 2π` が区間 `[0,2π]` の端点として
  現れることを許すために使っている。`g(2π) = g(0)` なので、どちらの端点を代表点に取っても
  値は同じである。）」
- 変更後: 「（証明で g について使ったのは、有界閉区間 `[0,2π]` 上の連続性だけである。
  δ = 0 のとき代表点 `t^{(M)}_M = 2π` は区間 `I_M` の右端、δ = 1 のとき `t^{(M)}_1 = 0` は
  `I_1` の左端であり、どちらも `[0,2π]` に属するので Step 2 の評価がそのまま通る。
  `g(2π)` と `g(0)` を比べる必要はどこにも生じない。）」

**参照側が壊れないことの確認**:

- 同じ章の「Onsager の自由エネルギーの表式」の proof は「γ は ℝ 上連続かつ周期 2π なので
  適用でき」と書いていた。仮定が弱まった（周期性が不要になった）ので、この一行を
  「γ は ℝ 上連続であり、δ ∈ [0,1) ⊂ [0,1] なので適用でき」に直した。定理の δ の範囲が
  広がった側なので、δ ∈ [0,1) を固定するこの定理の主張はそのまま通る。
- 同じ章の「γ は ℝ 上で連続」の statement にあった「これが（移行点の定理）を適用するために
  実際に使う条件である」は不正確になるので、「適用するために使うのは**連続性だけ**である。
  周期 2π をもつことは γ の性質として併せて述べておく（積分区間を `[0,2π]` に取れば十分で
  あることの根拠にはなるが、（移行点の定理）の仮定には入っていない）」に直した。
  周期性は結論として残してある（指摘記録の推奨どおり）。
- 他章からの参照は 3 箇所あり、いずれも仮定を再掲していないので影響しない。
  `content/018_even_sector_closing.ts` の 2 箇所（章の道具立ての説明と、
  `c(M)` の極限を出す最後の等号で「この定理を経由する」と述べる箇所。適用は δ = 1/2）と、
  `content/020_critical_point.ts` の 1 箇所（(R1)(R2) の要約）である。
  `gamma_is_continuous` を参照しているのは 012 章の中だけである（他章に参照はない）。
- 定義・命題の適用に使う δ の値は 0 と 1/2 だけで、どちらも新しい範囲 [0,1] に入る。
- ラベル・ブロック id は増減していないので、生成ファイル（`labels.generated.ts` /
  `document.generated.ts`）の再生成は不要。

## 指摘 4（記録 §4）`lean/README.md` の「mathlib に `Real.arccosh` が無い」は現状では誤り

**指摘の要約**: 機械的証明側の README にある「mathlib に無いことが分かっているもの」の記述が
現状と合っていない。固定している mathlib には双曲線余弦の逆関数（綴りは `arccosh` ではなく
`arcosh`）の定義と、その値が正しいこと・非負であること・`[1,∞)` 上連続であることが揃っており、
自前定義は不要だった。README の該当行を直す必要がある。

**決着**: **本文（`structured-latex/content/`）の修正対象ではない。** 指摘対象は
`lean/README.md` であり、本作業では `lean/` 配下の編集が禁止されているため手を付けていない。
`lean/README.md` を担当する側で直す必要がある（記録 §4 に必要な一次情報がそろっている）。

**本文側に波及がないことの確認**: 012 章の本文は `arccosh` を「`cosh|_{[0,∞)}` の逆写像として
`[1,∞)` 上で定義された実数値関数」として自前に導入し、その明示式
`arccosh(y) = log(y + √(y^2-1))` を「γ は ℝ 上で連続」の Step 2 で自前に証明している。
機械的証明側が mathlib の既存定義を使うか自前定義を使うかは、本文の記述の正しさに影響しない。
本文の綴り `\mathrm{arccosh}` は数学の慣用表記であり、mathlib の識別子の綴り `arcosh` に
合わせる必要はない（本文は Lean の識別子を参照していない）。

## 指摘 5（記録 §5）mathlib に無かったものの探索記録

**指摘の要約**: 等分割のリーマン和が積分に収束するという主張は mathlib に見つからず
（単調関数の和と積分の比較の補題は目的が異なる）、本リポジトリで証明する必要があった、
という探索の記録。あわせて、本文が (R1)(R2) として挙げた外部事実はいずれも mathlib に
存在し、新たな公理を持ち込む必要がなかったことが記録されている。

**決着**: **本文の修正対象ではない。** これは機械的証明側の探索結果の記録であり、
本文への指摘（誤り・欠落・過剰）を含まない。

**本文側に波及がないことの確認**: この記録は「本文が (R1)(R2) として挙げた外部事実が
mathlib の既存定理に 1 対 1 で対応する」ことを示しており、本文の (R1)(R2) の列挙が
（積分に関する限り）過不足ないことの裏づけになっている。ただし記録 §1 で指摘された
初等関数の連続性はこの表に載っていない。指摘 1 の修正で本文に (R0) として追加した。

（なお記録 §6「形式化していない部分（章 011 への依存）」は、機械的証明の側で章 011 の
