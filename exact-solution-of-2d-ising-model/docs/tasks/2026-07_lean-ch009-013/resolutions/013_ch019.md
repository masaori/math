## (b-1) 絶対値ベクトルの二次形式の評価に「W の成分がすべて正」は要らず、非負で足りる

```

```

## (b-3) 「偶セクターの単位ベクトルが存在すること」に、不動点をもたないことは要らない

**指摘の要約**: 本章の定理 `c_minus_le_c_plus` の Step 1 は、偶セクター側の値の集合 `𝓡_+` が空でないことを
「符号反転置換行列 ε が単位ベクトル `(e_1 + e_{π(1)})/√2` を固定する」ことから出している。
しかしこのベクトルは `π(1) = 1` の場合でも（`e_1` の 2 倍として）非零で ε 不変なので、
不動点の有無に関係なく `𝓡_+ ≠ ∅` が言える。

**決着: 修正した（`1/√2` という定数を自身のノルムでの正規化に置き換え、不動点を使わない形にした）。**

**変更前**:

```
ref("epsilon_is_sign_flip_permutation"), " (4) の ", math(`x_0`), " により ", math(`\mathcal{R}_-\neq\emptyset`),
" であり、", math(`\varepsilon`), " が単位ベクトル ", math(`\tfrac{1}{\sqrt2}(e_1 + e_{\pi(1)})`), " を固定する（",
ref("epsilon_is_sign_flip_permutation"), " (1)(2) から ", math(`\varepsilon(e_1+e_{\pi(1)}) = e_{\pi(1)}+e_1`),
"）ことから ", math(`\mathcal{R}_+\neq\emptyset`), " である。"
```

この書き方は、係数 `1/√2` がノルム 1 を与えるために `e_1 ≠ e_{π(1)}`（すなわち `π(1) ≠ 1`）を暗黙に使っている。

**変更後**（`v` を正規化する形にして、対合性 `π∘π = id` だけで閉じるようにした）:

```
ref("epsilon_is_sign_flip_permutation"), " (4) の ", math(`x_0`), " により ", math(`\mathcal{R}_-\neq\emptyset`),
" である。", math(`\mathcal{R}_+`), " については ", math(`v := e_1 + e_{\pi(1)}`), " を取る。第 ", math(`1`),
" 成分が ", math(`1`), " 以上なので ", math(`v \neq 0`), " であり、", ref("epsilon_is_sign_flip_permutation"),
" (1) と ", math(`\pi(\pi(1)) = 1`), "（同 (2)）から ", math(`\varepsilon v = e_{\pi(1)} + e_1 = v`), " なので ",
math(`y_0 := v/\|v\|`), " は ", math(`\mathcal{F}^{(+)}\cap\mathbb{R}^{2^M}`), " の単位ベクトルであり、",
math(`\mathcal{R}_+\neq\emptyset`), " である。"
```

さらに、どちらの側で不動点が効くのかを明示する段落を続けて追加した。

```
"（", math(`\mathcal{R}_+\neq\emptyset`), " に使ったのは ", ref("epsilon_is_sign_flip_permutation"),
" (2) のうち ", math(`\pi\circ\pi = \mathrm{id}`), " の部分だけで、", math(`\pi(k) \neq k`),
"（不動点をもたないこと）は使っていない。", math(`\pi(1) = 1`), " であれば ", math(`v = 2e_1`),
" となるだけで、上の議論はそのまま通る。不動点をもたないことが本質的に効くのは ", math(`\mathcal{R}_-\neq\emptyset`),
" の側、すなわち同 (4) の ", math(`x_0 = \tfrac{1}{\sqrt2}(e_1 - e_{\pi(1)})`), " が非零であるところである。）"
```

**参照が壊れないことの確認**: `epsilon_is_sign_flip_permutation` の主張 (1)〜(4) は一切変更していない
（`π(k) ≠ k` を含む (2) はそのまま残る。この章の対象は `M ≥ 2` なので不動点をもたないこと自体は真である）。
変更したのは `c_minus_le_c_plus` の証明中で、その事実をどこで使うかの書き方だけである。

## (c) 章 011 の「セクターごとの上限を定める集合が空でないことに触れていない」という穴が、本章で埋まった
