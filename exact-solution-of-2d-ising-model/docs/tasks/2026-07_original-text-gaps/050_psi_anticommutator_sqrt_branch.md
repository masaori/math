## (1) どの条件が抜けていたか

### 事実確認: 本リポジトリの √ は単一値の関数である

`calculation_formulae_038_definition_sqrt_of_complex_number`（`labels`: `def_sqrt_cc`）が

```
√(·) : ℂ → ℂ
```

を、極形式の偏角を `arg^{[0,2π)}` に取ったうえで半分にする形で**関数として**定義している。
したがって「同じ複素数に 2 つの √ の値がありうる」という事態は本文の枠組みでは起こらない。
proof が使っている

```
√(γ₂(θ_μ)γ₂(−θ_μ)) · √(γ₂(θ_ν)γ₂(−θ_ν))
  = √(γ₂(θ_μ)γ₂(−θ_μ)) · √(γ₂(−θ_μ)γ₂(θ_μ))
  = (√(γ₂(θ_μ)γ₂(−θ_μ)))² = γ₂(θ_μ)γ₂(−θ_μ)
```

は、**2 つの根号の中身が複素数として等しいことさえ言えれば**、
`square_of_sqrt`（`(√z)² = z`）から正しく従う。分枝を追加で仮定する必要はない。

### 実際に抜けていた段

問題はその「中身が等しいこと」の根拠である。**修正前の** proof は

> δ^M\_{μ+ν,0} ≠ 0 のとき μ + ν ≡ 0 (mod M) **すなわち θ\_ν = −θ\_μ** である。

と書くが、**この「すなわち」は成り立たない。** μ + ν ≡ 0 (mod M) が意味するのは
ν = −μ + kM（k ∈ ℤ）であり、このとき

```
θ_ν = 2πν/M = −2πμ/M + 2πk = −θ_μ + 2πk
```

なので θ\_ν と −θ\_μ は **2π の整数倍だけずれる**。ℳ = {−M, …, −1, 1, …, M} の範囲でも
k ≠ 0 の場合が実際に起こる（下記の反例）。

γ₂(θ) = i e^{iθ} s₂\*(c₁cos θ − i sin θ − s₁c₂) は θ について 2π 周期なので
**結論 γ₂(θ\_ν) = γ₂(−θ\_μ) は正しい**が、それを言うには γ₂ の 2π 周期性が要る。
当時、本文にあった周期性の主張は `TV1_hatZ_hatY_041_claim_gamma2_periodicity`
（`labels`: `gamma2_theta_M_periodicity`）だけで、これは

```
γ₂(θ_M) = γ₂(θ_{−M}),   γ₂(−θ_M) = γ₂(−θ_{−M})
```

という **μ = ±M の場合に特化した主張**であり、一般の μ, ν には使えない。
b) の「γ₂(−θ\_ν) = γ₂(θ\_μ) より」も同じ理由で根拠が欠けている。

## (2) 正しくはどうあるべきか（当時書いた修正案。実際の修正もほぼ同内容）

### 追加すべき claim（新規ブロック）

> **γ₂ の 2π 周期性**（`labels` 案: `gamma2_two_pi_periodicity`）
>
> 任意の θ ∈ ℝ と k ∈ ℤ について
>
> ```
> γ₂(θ + 2πk) = γ₂(θ),    γ₁(θ + 2πk) = γ₁(θ)
> ```
>
> **証明**: γ₁, γ₂ は θ に cos θ, sin θ, e^{iθ} の形でしか依存せず、これらはいずれも
> 2π 周期である（`euler_formula_cos_sin` と cos, sin の 2π 周期性）。

> **系**（`labels` 案: `gamma2_thetaMu_of_dvd`）
>
> μ, ν ∈ ℤ が M | μ + ν を満たすとき
>
> ```
> γ₂(θ_ν) = γ₂(−θ_μ),   γ₂(−θ_ν) = γ₂(θ_μ),
> したがって γ₂(θ_ν)γ₂(−θ_ν) = γ₂(θ_μ)γ₂(−θ_μ)
> ```
>
> **証明**: M | μ + ν より ν = −μ + kM（k ∈ ℤ）と書ける。θ\_ν = −θ\_μ + 2πk なので
> 上の周期性から従う。

### `anticommutator_of_psi` の proof の書き換え案

a) の当該段落を次のように直す。

> δ^M\_{μ+ν,0} ≠ 0 のとき μ + ν ≡ 0 (mod M) である。このとき θ\_ν = −θ\_μ **とは限らない**
> （2π の整数倍だけずれうる）が、上記の系より γ₂(θ\_ν) = γ₂(−θ\_μ)、γ₂(−θ\_ν) = γ₂(θ\_μ)
> であり、とくに 2 つの根号の中身は複素数として等しい:
> γ₂(θ\_ν)γ₂(−θ\_ν) = γ₂(θ\_μ)γ₂(−θ\_μ)。よって `def_sqrt_cc` の √ が関数であることと
> `square_of_sqrt` より（以下現行どおり）。

b) の「γ₂(−θ\_ν) = γ₂(θ\_μ) より」にも同じ系への参照を付ける。

### statement 側に足すべきこと

statement の等式部分はそのままでよいが、**√ が `def_sqrt_cc` の単一値関数であること**を
`def_fermi` か本ブロックのどこかで一言明記しておくと、
「分枝を選ぶ余地がある」という誤読を防げる（次節の Lean の反例を参照）。

## (3) 反例と検算の根拠

### 「θ\_ν = −θ\_μ」が偽である具体例

M = 4, μ = 1, ν = 3（いずれも ℳ = {−4, −3, −2, −1, 1, 2, 3, 4} の元、μ + ν = 4 ≡ 0 mod 4）:

```
θ_μ = 2π·1/4 = 1.5707963267948966   (= π/2)
θ_ν = 2π·3/4 = 4.71238898038469     (= 3π/2)
−θ_μ         = −1.5707963267948966
θ_ν − (−θ_μ) = 6.283185307179586    (= 2π ≠ 0)
```

すなわち θ\_ν ≠ −θ\_μ。一方で γ₂ の値は一致する（K₁ = 0.4, K₂ = 0.7 で計算）:

```
γ₂(θ_ν)  = −1.0031110056562873 + 0.5251269293427332i
γ₂(−θ_μ) = −1.003111005656287  + 0.5251269293427329i
|差| = 4.0e-16
γ₂(θ_ν)γ₂(−θ_ν) = −1.2819899815896958
γ₂(θ_μ)γ₂(−θ_μ) = −1.2819899815896951
```

**結論そのものは正しく、飛んでいるのは根拠だけ**である、ということがこの数値で確認できる。
再現コード（Python 3、標準ライブラリのみ）:

```python
import cmath, math
K1, K2 = 0.4, 0.7
c1, s1 = math.cosh(2*K1), math.sinh(2*K1)
c2 = math.cosh(2*K2)
K2s = -0.5*math.log(math.tanh(K2)); s2s = math.sinh(2*K2s)
g2 = lambda th: 1j*cmath.exp(1j*th)*s2s*(c1*math.cos(th) - 1j*math.sin(th) - s1*c2)
M, mu, nu = 4, 1, 3
tm, tn = 2*math.pi*mu/M, 2*math.pi*nu/M
print(tn - (-tm), abs(g2(tn) - g2(-tm)), g2(tn)*g2(-tn), g2(tm)*g2(-tm))
```

### Lean の裏づけ

Lean 側は **√ という関数を使わず**、`t² = γ₂(θ_μ)γ₂(−θ_μ)` を満たす `t` を引数に取る形で
形式化してある。この形では t は符号の分だけ決まらないので、μ と ν で同じ側を取ることを
仮定として持たなければならない。それが
`lean/Ising2D/Part008/Definition030_Fermi.lean` の仮定

```
hbr : (M : ℤ) ∣ (μ + ν) → tν = tμ
```

である。関係する定理:

- `Ising2D.t_sq_eq_of_dvd` — `M ∣ μ+ν ⇒ t_ν² = t_μ²`（**符号は決まらない**）
- `Ising2D.gamma2_neg_mul_gamma2_neg_of_dvd` — `M ∣ μ+ν ⇒ γ₂(−θ_μ)γ₂(−θ_ν) = γ₂(θ_μ)γ₂(−θ_μ)`
  （**本文で欠けている周期性の議論に対応する部分。Lean 側には存在する**）
- `Ising2D.gamma2_add_int_mul_two_pi` / `Ising2D.gamma2_thetaMu_of_dvd`
  （`Definition019_ThetaGamma.lean`）— 上記 (2) の「追加すべき claim」とその系にそのまま対応する
- `Ising2D.acomm_psiDag_psiDag` / `acomm_psiDag_psi` / `acomm_psi_psi` — `hbr` を仮定した本体

**逆分枝を取ると本当に偽になること**も定理として証明してある
（`lean/Ising2D/Part008/Claim032_AnticommutatorPsiAbstract.lean`）:

- `Ising2D.acomm_psiDag_psiDag_of_opposite_branch` — `t_ν = −t_μ` のとき
  `[ψ_μ†, ψ_ν†]₊ = I`（本来は 0）
- `Ising2D.acomm_psiDag_psi_of_opposite_branch` — 同じ状況で
  `[ψ_μ†, ψ_ν]₊ = 0`（本来は I）

**これは原文が誤っていることの証明ではない。** 原文の √ は `def_sqrt_cc` の単一値関数なので
逆分枝は起こらない。この 2 定理が示しているのは「√ を多価と読むと第 1 式・第 2 式が破れる」
という**誤読のコスト**であり、statement に「√ は `def_sqrt_cc` の関数」と明記すべき理由である。
