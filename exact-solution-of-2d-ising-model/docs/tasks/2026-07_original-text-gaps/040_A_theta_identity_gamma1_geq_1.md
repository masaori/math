## (1) どの条件が抜けていたか

A(θ) を γ₁, γ₂ で書くと

```
A(θ) = ( γ₁(θ)     γ₂(θ) )
       ( −γ₂(−θ)   γ₁(θ) )
```

なので、γ₂(θ\_μ) = 0 のとき（`relation_of_gamma_2` より γ₂(−θ\_μ) = 0 でもある）

```
A(θ_μ) = γ₁(θ_μ) · I
```

までは定義だけから出る。しかし **これだけでは A = I とは言えない。**
`det A(θ_μ) = 1` を併用しても得られるのは

```
γ₁(θ_μ)² + γ₂(θ_μ)γ₂(−θ_μ) = γ₁(θ_μ)² = 1  ⟹  γ₁(θ_μ) = ±1  ⟹  A(θ_μ) = ±I
```

までである。**符号を +1 に確定するには γ₁(θ\_μ) > 0 という独立な情報が要る。**

- **Step 3**: A(θ\_μ) = diag 形に代入して I。

したがって Step 2 の議論は循環していない。

## (3) 反例と検算の根拠

### 「A = ±I までしか出ない」ことの確認

γ₁ = −1, γ₂ = 0 という値の組は `det A = γ₁² + γ₂γ₂(−θ) = 1` を満たし、A = −I になる。
これは det の条件だけでは排除できない。排除するのは γ₁ の定義式の正値性
（K₁, K₂ ∈ ℝ\_{>0} のとき c₁c₂\* > s₁s₂\* ≥ s₁s₂\*cos θ）である。

### Lean の裏づけ
