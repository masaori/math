## (1) 何が誤りだったか

原文の同値の連鎖には

```
{ θ_μ = 0, ±π, ±2π, … ;  c₂s₁ = c₁cos θ_μ }
  ⟺ { μ = ±M ;  c₂s₁ = c₁cos θ_μ }
```

という段がある。ここで**第 1 式だけを取り出して「sin θ\_μ = 0 ⟺ μ = ±M」と読むと偽**である。

θ\_μ = 2πμ/M に対して

```
sin θ_μ = 0  ⟺  2πμ/M ∈ πℤ  ⟺  ∃k ∈ ℤ: 2μ = kM  ⟺  M | 2μ
```

であり、`ℳ = {−M, …, −1, 1, …, M}`（すなわち 1 ≤ |μ| ≤ M）の範囲で `M | 2μ` を満たすのは

- `|μ| = M`（常に）
- `|μ| = M/2`（**M が偶数のときのみ**）

の 2 通りである。したがって M が偶数なら `μ = ±M/2` も第 1 式を満たす。

## (2) 正しくはどうあるべきか（＝現在の本文がそうなっている）

現在の statement は、同値の連鎖の直後に次の段落を置いている。

> 上の同値はいずれも「連立条件全体としての同値」である。特に第 2 段から第 3 段への同値において、
> sin θ\_μ = 0 という条件だけでは μ = ±M は従わない。実際 M が偶数のときは μ = ±M/2 ∈ ℳ も
> θ\_μ = ±π、sin θ\_μ = 0 を満たす。この μ が排除されるのは、もう一方の条件
> c₂s₁ = c₁cos θ\_μ = −c₁ < 0 が c₁, s₁, c₂ > 0 と矛盾するからである（証明の Step 4 を参照）。

そして proof の Step 4（⇒ 向き）で

```
θ_μ = kπ ⟺ 2μ = kM ⟺ M | 2μ、1 ≤ |μ| ≤ M より 2 ≤ 2|μ| ≤ 2M、
この範囲の M の倍数は M と 2M のみ ⟹ |μ| = M/2（M 偶数）または |μ| = M
```

と場合分けし、`|μ| = M/2` のとき `cos θ_μ = −1` なので第 2 式が `c₂s₁ = −c₁` を要求し、
`c₂s₁ > 0`、`−c₁ < 0` と矛盾する、として排除している。**修正すべき点は残っていない。**

## (3) 反例と検算の根拠

### 反例（第 1 式単独に対する）

`M = 6`, `μ = 3` とすると `θ_μ = 2π·3/6 = π`、`sin θ_μ = 0` だが `μ ≠ ±M = ±6`。
`μ = 3 ∈ ℳ = {−6,…,−1,1,…,6}` なので範囲内の正真正銘の反例である。
数値でも `sin(2π·3/6) = 0.0`（`M = 6, μ = 6` も `sin = 0`）。

この μ が最終的に排除されるのは連立条件のもう一方による。`θ_3 = π` なので
`c₁cos θ_3 = −c₁ < 0` に対し `c₂s₁ = cosh(2K₂)·sinh(2K₁) > 0`（K₁, K₂ > 0）で矛盾する。
