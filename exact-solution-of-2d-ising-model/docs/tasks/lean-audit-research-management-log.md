# Lean の点検の直しの研究管理の記録

runbook（[lean-end-to-end-runbook.md](lean-end-to-end-runbook.md)）のゴールラインの四つの条件（分離・繋がり・未定義の記号・一対一）の残りを、
毎回同じ検査で数えた値と、状態台帳（[lean-end-to-end-state.md](lean-end-to-end-state.md)）の先頭の表の順序・割り方を変えた理由を残す。

数え方: `lean/` で `lake build` の後、
分離はリポジトリ直下から `bash scripts/lean-concrete-necsuf-separation/check.sh exact-solution-of-2d-ising-model/lean` の四つの件数の和、
繋がりは `bash scripts/connection-to-final-theorem/check.sh` の「最終定理の依存に入らない具体版の宣言」、
未定義の記号は `bash scripts/mathlib-symbols-undefined-in-text/check.sh` の「宣言と記号の組」、
一対一は `bash scripts/text-and-concrete-one-to-one/check.sh` の五つの食い違いの件数の和（一致する主張・定理の数は含めない）。
判断の基準は四つの和が前々回の記録から減っていることである。

## 判断

### 2026-11-22

- 和は基準から 90 増えた。この記録は初回なので、前々回の代わりに四つの検査が揃った時点（`c96455606`）の台帳の行数と比べた。
- 減らなかった理由: 基準からの連続実行の 13 単位は全て表の先頭の行「本文の各ブロックに対応する具体版の宣言を機械で読める形で書く」に充てられた。
  この行は欄 `lean` を書くことで、docstring の太字では見えなかった食い違いを数えられるようにする行である。
  一対一の内訳は、具体版だけが使う組が 517 から 275 へ 242 減り、具体版の無いブロックが 266 から 213 へ 53 減った一方、本文だけが引く組が 1,082 から 1,278 へ 196 増え、欄の無いブロックが 189 現れた（基準の時点では欄の無いブロックを数えていなかった）。
  分離・繋がり・未定義の記号の三つは、その間に手が付かず変わっていない。
- 未定義の記号の 24,189 行は 646 個の記号から成り、少数の記号に集中している（`Eq` 2,196・`Complex` 1,986・`Fin` 1,800・ℕ の 2 が 1,503・`Matrix` 1,169）。
  一つの記号を本文で宣言するか本文の定義との一致を確かめて許可の一覧に載せると、その記号の行が全ての宣言から一度に消える。
  一単位で消える行の数は、この種の行が最も大きい。
- 変えた順序と割り方: 行「本文に定義の無い記号を本文で定義か宣言し、Lean の対応先を許可の一覧に載せる」から、台帳の件数の多い記号のまとまりを五つの行に切り出した。
  - 表の先頭に「論理と等号の記号を本文で宣言し、許可の一覧に載せる」（`Eq`・`Ne`・`And` ほか、約 2,800 行）と、
    「ℂ とその演算を、本文の定義と mathlib の構成が一致することを確かめて許可の一覧に載せる」（`Complex`・`Complex.ofReal`・ℂ の積・`Complex.I` ほか、約 3,800 行）を置いた。
    どちらも本文に定義か宣言のブロック（`set_and_algebra_notation`・`definition_of_cc`・`def_imaginary_unit`・`inclusion_rr_to_cc`）が既にあり、依存が無い。
  - 欄 `lean` の行（残り 189 ブロック）は三番目に下げた。止めずに続ける行だが、和を減らす速さは上の二行より小さい。
  - その下に「行列とその演算」（約 2,400 行）、「ℝ の数・順序・差・商」（約 1,900 行）、「添字の集合と ℕ の数・演算」（約 5,200 行）を置いた。
    添字の集合の行は件数が最も多いが、本文の添字 `{1,…,n}` と Lean の `Fin n` の食い違いをどう書くかを先に決める必要があるので、最後に置いた。
- 許可の一覧に載せる条件（本文が定義し具体版が本文の定義どおりか、本文が外から持ち込んで使う性質を列挙したものだけ）は変えていない。
  mathlib の構成と本文の定義が等しくない記号（ℂ・ℝ の逆数と商、`Fin` の添字の始まり）は、切り出した行の備考で載せないものとして書いた。
