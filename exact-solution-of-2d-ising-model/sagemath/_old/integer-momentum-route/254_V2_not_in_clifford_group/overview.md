# SageMath Check: 254_V2_not_in_clifford_group

## 対象

**対象ラベル**: `V2_not_in_clifford_group` （structured-latex 側の安定識別子）

- ファイル: `structured-latex/content/008_TV1_hatZ_hatY_part1.ts`

- 範囲: V₂σ^z_1V₂^{-1} が Pauli 群の元にならないこと

V₂σ^z_1V₂^{-1} を Pauli 基底 σ^{a_1}⊗…⊗σ^{a_M} で展開し、**非零成分が 2 個以上ある**ことを示す。Clifford 群の元なら単一の Pauli 元に写るはずなので、これで反証になる。展開係数を実際に出力している。

許容誤差は既定の相対誤差 `1.0e-09`（成分の最大絶対値で正規化）。既定から変更していない。

## 備考

V₂ はユニタリではない（正定値エルミートの定数倍）ので、係数の平方和は 1 にならない。この値も参考として出力している。
