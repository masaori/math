## 計算の帰属と範囲

浮動小数点と `RR` への脱出はない。主張は `ℝ` について述べるが、証明は `ℝ` の四則演算と大小関係だけを使うので、
一般の等式は `QQ` 上の多項式環・有理関数体の不定元で、不等号の行は `QQ` の具体の値で確かめた。
不定元で成り立つ多項式・有理関数の等号は、実数を代入しても（分母が 0 でない限り）成り立つ。

両辺を同じ式から作らないため、`x^T P y` の値は Sage の `vector(x) * matrix(P) * vector(y)` と比べ、
`q(t)` は展開した式ではなく `w(t)` から定義どおりに計算した値と比べた。

## 確かめられない行と理由

(ii) の背理法は、`a = 0` かつ `b ≠ 0` となる半正定値の `P` が存在しないことを示す議論なので、
仮定を満たす具体の値では `b ≠ 0` の行に当てはまる例が無い。代わりに、等号の行を `b` を不定元とする有理関数で確かめ、
半正定値でない `P` で `q(t_0) = -1` が実際に起きることを確かめた。
