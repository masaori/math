# SageMath Check: 052_def_check_index_set

## 対象

**対象ラベル**: `def_check_index_set` （structured-latex 側の安定識別子）

- ファイル: `structured-latex/content/013_even_sector_modes.ts`
- 併せて検証:
  - `conjugate_index_of_check_Z_Y`（`θ~_{M+1-μ} = 2π - θ~_μ`、`Ž_{M+1-μ} = Ž_{1-μ}`）

### 何を確定させるための検証か

013〜017 章（章 C′）は当初、添字を `μ ∈ ℤ` 全体で量化していた。これは範囲が広すぎる。
008 章が `𝓜 = {−M,…,−1,1,…,M}` という名前付きの有限集合で量化しているのに倣い、
半整数運動量に必要な最小の有限集合

```
𝓜̌ := {1, 2, …, M}
```

を定義して、章 C′ のすべての主張をそこへ絞った。この検証はその絞り込みが正しいこと
——**必要十分であること**——を数値で固定する。

確定させるのは次の 3 点である。

1. **`𝓜̌` はこれ以上減らせない。** `θ~_μ`（`μ ∈ 𝓜̌`）は `(0, 2π)` 内の相異なる `M` 個であり、
   `𝓜̌` から 1 点でも除くと `M` 個を尽くせない（check_01 の最小性）。
2. **共役 `μ ↦ M+1−μ` について `𝓜̌` は閉じている**（`def_check_index_set` (2)）。
   自己共役点は `M` が奇数のときの `μ = (M+1)/2`（`θ~_μ = π`）だけである（同 (4)）。
3. **合同式が消える。** `μ, ν ∈ 𝓜̌` では `μ+ν ≡ 1 (mod M) ⟺ ν = M+1−μ` であり、
   反交換関係のデルタは `δ^M_{(μ+ν,1)}` ではなく通常のクロネッカーのデルタ
   `δ_{ν, M+1−μ}` で書ける（同 (5)）。

さらに、本文の書き換え（共役添字 `1−μ` → `M+1−μ`）が値を変えないことを直接確認する
（`conjugate_index_of_check_Z_Y` (3)。`Ž` の添字周期性 `def_half_integer_modes` (2) による）。

## 検証の枠組み

`sagemath/_shared/spin_ops.sage` の演算子構成に、本ディレクトリの `_prelude.sage` で
`θ~_μ = 2π(μ − 1/2)/M`、`Ž_μ`、`Y̌_μ`、`𝓜̌ = {1,…,M}` を加えた。

- **添字だけの検証**（check_01）は `M = 2,…,40` を**全探索**する。
  行列を作らないので広い範囲を尽くせる。
- **行列を使う検証**（check_02）は `M = 2,3,4,5`、`j` は `−2M,…,2M`。

## 備考

- `M = 2..40` の全探索で、自己共役点（`M+1−μ = μ` を満たす `μ ∈ 𝓜̌`）の総数が
  「`M` が奇数である `M` の個数」と一致することを確認した（`def_check_index_set` (4) の
  「`M` が奇数のときちょうど 1 つ、偶数のときは無い」に対応）。
- 008 章の `𝓜 = {−M,…,−1,1,…,M}` が `μ ↦ −μ` について閉じ、自己共役点が
  `μ = ±M, ±M/2` だったのと同じ構造である。半整数運動量では共役が `μ ↦ M+1−μ` になる。
- **`μ ∈ ℤ` で量化したまま残してよいのは 2 つの主張だけ**である：
  `def_half_integer_modes` (2)（`Ž_{μ+M} = Ž_μ`）と `periodicity_of_check_fermi` (2)
  （`γ_1, γ_2` の `θ~_{μ+kM}` での値）。前者は本ディレクトリの check_02 が使う橋渡しであり、
  後者は `γ_1, γ_2` が `θ ∈ ℝ` の関数であることによって意味をもつ。
