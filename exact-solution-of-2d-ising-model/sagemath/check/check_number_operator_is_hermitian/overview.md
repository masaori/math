## 計算の帰属と範囲

- **厳密**: すべて。(1) は `QQ(i)`、(2) は円分体 `QQ(ζ_{4M})`、(3)(4) は数体 `F := QQ(ζ_{4M}, √(2s_2), √t)` と `E_μ := F(r_μ)` の中の等号
  （`ψ̌` の作り方は `../def_check_number_operator/_prelude.sage` と、その読み込む `../T_V_plus_eq_T_check_Vprime_on_check_Z_Y/_prelude.sage`）。
  結びの鎖の実数の行（絶対値・平方根・`≥ 0`）は、値を `QQbar` へ移して `AA`（実代数的数）で判定する。浮動小数点は使わない。
- **複素共役**: 体の自己同型として持つ。`QQ(i)` は `i ↦ −i`、円分体は `ζ ↦ ζ^{−1}`、`F` は自己同型のうち埋め込み `emb`（`ζ ↦ exp(2πi/(4M))`、
  平方根は正）について `emb∘c = conj∘emb` を生成元で満たすただ一つのもの。`E_μ = F(R)` では `R^2 ∈ F` が動かないことを確かめて `R ↦ R` で延ばし、
  `R ↦ +r_μ` の埋め込みで `R` と `F` の生成元について本物の複素共役であることを確かめる。自己同型は和と積を保つので、生成元で一致すれば全ての元で一致する。
- **ℝ への脱出**: `K_1`・`K_2` の選び方、位相を 1 の冪根で表すこと、`r_μ = |γ_2(θ̃_μ)|` と `(√M_col)_ℂ`（どれも代数的数として厳密に持つ）、
  結びの鎖の `|w_k|`・`‖w‖`（`AA`）。
- 範囲外: (3)(4) の `M_col ≥ 4`（`ψ̌` を数体に作る費用が大きい。`check_number_operators_commute` の overview の「計算の帰属と範囲」と同じ理由）。
  (1) の `M_col ≥ 6`、(2) の `M_col ≥ 7`。

## 構成上かならず成り立つ比較

- 定義を代入するだけの行（`Z_j` の鎖の 1・5 行目、`Ž_μ` の鎖の 1・5 行目、`(σ_k^a)^*` の鎖の 1・5 行目、`conj(α_μ)` の主鎖の 1・2・12 行目、準備 (c) の 1 行目と `d_ν` の定義を戻す行、
  `(ψ̌_μ^†)^*` の鎖の 1・6 行目、`ň_μ` の鎖の 1・4 行目、`Q̌_ε` の鎖の 1・5 行目）は、同じ行列を両辺に置くので必ず成り立つ。写し間違いだけを検出する。
- 結びの鎖の 3 行目 `x^*(Q̌_ε^*Q̌_ε)x` と 4 行目（`def_conjugate_bilinear_value` の展開）は、`body_bilinear` がその式そのものなので構成上一致する。
- `conj(w_m)w_m` が複素共役で動かないことの比較は、`conj` が対合なら必ず成り立つ。`conj(w_m)w_m` が実数で正であることの中身は、値を `AA` へ移す行（実数でなければ移せない）にある。
- 中身の検査は、共役転置の積の順の反転・係数の共役・`(1)`〜`(3)` を当てる行・`(σ_k^a)^*` の鎖で単位行列と Pauli 行列の共役転置の主張を当てる 3・4 行目・可換性を当てる行・`α_μ` の符号の行にある。

## 否定コントロール

- 転置だけ（複素共役なし）では `σ^y`・`Y_j`・一般のクロネッカー積が崩れ、結合定数と `M_col` の組ごとにある `ň_μ` が崩れる。
- 同じサイトの可換でない因子では `(σ_1^xσ_1^z)^* ≠ (σ_1^x)^*(σ_1^z)^*`（積の順の反転が要る）、`σ_1^zσ_1^x ≠ σ_1^xσ_1^z`（相異なるサイトであることが要る）。
- `ν ≠ μ` のとき: `Ž_μ`・`Y̌_μ`・`ψ̌_μ^†` はエルミートでない、係数を共役しない和は `Ž_ν` でない、`conj(α_μ) ≠ α_ν`（符号が要る）。全ての `μ` で `r_ℂ/d_ν ≠ α_ν`（準備 (e) の符号が要る）。
- 可換でないエルミートな冪等行列の積 `P_1P_2` はエルミートでない（`Q̌_ε` の鎖の 4 行目に可換性が要る）。
  エルミートでない冪等行列 `P'` では `x^*P'x` が実数でない（`Q̌_ε^* = Q̌_ε` が要る）。
