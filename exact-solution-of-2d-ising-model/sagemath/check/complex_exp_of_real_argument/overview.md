## 計算の帰属と範囲

- **厳密**: 係数は `QQ`・`QQ(i)`、平方根は `AA`。準備・冪・項・部分和の鎖では ℂ を本文どおり実数の対で持つ
  （共通の準備 `sagemath/_shared/complex_as_real_pairs.sage`）。Sage の `QQ(i)` は、部分和の独立な経路の確認、1 行 1 列の複素行列の差の鎖、
  本文の複素数の exp の部分和 `S_N([x_C]_C)`（`body_complex_exp_ball`）で使った。後者が実数の対で作った `ι(S_N([x]_R)_11)` と一致することは厳密に確かめた。帰納法の各段は具体の `m`・`N` について一つずつ確かめた（一般の `m`・`N` は帰納法そのものが担う）。
- **`ℝ` への脱出（`RealBallField(512)`・`ComplexBallField(512)`）**: `exp(x)`・`exp(x_C)` は極限なので `QQ`・`QQ(i)` に収まらない。
  本文の exp（1 行 1 列の行列の部分和の成分）を、尾の評価 `2|x|^{N+1}/(N+1)!` を半径にしたボールで囲んだ（実数は `sagemath/_shared/one_by_one_matrix.sage` の
  `body_real_exp_ball`、複素数は検算の中の `body_complex_exp_ball`）。尾の評価は `N + 2 ≥ 2|x|` のとき比 `1/2` の等比級数との比較で成り立つ（本文には無く、検算の側で導いたもの）。
  Arb の exp は使わない。`→ 0` の上界には、512 ビットの丸めの分として `2^{-400}` を足した。

構成上かならず一致する比較:

- 二つの exp のボールは同じ部分和の値を中心に持つ（その値の一致は厳密に確かめた）。そのためボールの重なりは、二つの列が同じ列であることを数値で示すにとどまる。極限の一意性そのものは `matrix_norm_triangle_inequality` (4) が担う。
- 準備の三つの鎖のうち定義を展開するだけの行（`(a+b, 0+0)` と `(a+b, 0)` など）は、多項式環の中で評価した時点で同じ値になる。中身があるのは和・積の定義式を当てる行である。
- ノルムの鎖の 1〜3 行目は、同じ絶対値の関数に同じ成分を入れて作っている。中身があるのは `√(|w|^2) = |w|` の行である。
- 第一の収束の鎖の 3〜5 行目のボールは、同じボールの差 `E_N - exp x` から作っている。中身は準備の差の鎖と `abs_basic_properties` (6) が担い、ここでは重なることを見るだけである。

範囲外のもの:

- 選んだ以外の点。帰納法の、確かめた範囲を超える `m`・`N`。
