## 計算の帰属と範囲

- **厳密**: すべて。`QQ(i)`・円分体 `QQ(ζ_{4M})`・その上の多項式環・数体 E_μ の中の等号。浮動小数点は使わない。
- **ℝ への脱出**: 位相 exp(−i(j_R θ̃_μ)_ℂ) を 1 の冪根 ζ_{4M}^{−2(2μ−1)j} として持つこと（本文の exp との照合は `nesting_of_commutator_of_H_and_check_Z` の検算）、
  K_1 = 2 log y・K_2 = log x の選び方、r_μ = |γ_2(θ̃_μ)| と (√M_col)_ℂ を代数的数として持つこと（`def_check_number_operator` の検算の準備と同じ）。
- **作り方で自明な比較**（両辺を同じ Sage の式から作るので、本文の写し間違いだけを検出する）: (2) の鎖の先頭と末尾の等号（W̌_μ の定義の代入）、
  (3) の鎖の先頭と末尾の等号（def_check_fermi の代入。本文の ψ̌ の検算では、ψ̌ が第二の式に等しいことを別に確かめている）、
  (4) の ň_μ の鎖の先頭と末尾（def_check_number_operator の代入）、A_ν の鎖の先頭と末尾（A_ν の置き方）。
  Q̌_ϵ の鎖の先頭と末尾は、Sage の演算子で組んだ Q̌_ϵ と本文の定め方の Π_ν A_ν を比べるので自明な比較ではない。
- **否定コントロールの効き方**: (2) の対照は ε を I に替える（σ_1^z は Y_j の全部と反可換なので Y̌ の対照にならない）。(3) の対照の σ_1^z は Z_1 と可換なので Ž と反可換でなく、
