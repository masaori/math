`_lines.sage` の関数を二つの検算が呼ぶ。

- `check_generic_positive_definite_matrices.sage`: 証明が使う `W` の性質は「成分が実数で対称」「正定値（`moment_log_convexity` の前提）」
  「`c` が `R` の上限」だけなので、`P := A^⊤A`（`A` は列が一次独立な整数行列、`d = 1..4`）の有理行列 12 個と、`x = e_1` と逆立体射影で作った
  有理の単位ベクトル（`d = 1` では `x = (−1)`）で確かめる。`check_varrho_lines` は `P` を `W` として QQbar に置く。等号 18212 個、不等号 5371 個。
- `check_symmetrized_transfer_matrix.sage`: 本文の `W = (BV_2)B`（`def_symmetrized_transfer_matrix`）を `K_1 := 2 log y`、`K_2 := log x`
  （`x, y ∈ {2, 3}`、`M_col = 2, 3`）で作る。`W` は QQ の行列である。等号 27724 個、不等号 5176 個。

`c` は `rayleigh_bounds_operator_norm/_prelude.sage` の `rayleigh_sup_exact` で、特性多項式の最大の実根（AA）として作り、
`cI − P` が半正定値であること（上界）と固有ベクトルで到達すること（最小の上界）を確かめる。最大固有値と上限の一致は本文に無く、
証明も使わない。ここでは `c` の値を作る独立な経路として使う。

二乗の行は冪を `def_power_of_real_number` の定義どおり（`rpow`: `a^0 := 1`、`a^{m+1} := a^m a`）に組み、積の形とは `square_of_real_number_is_product` の行で行き来する。

## 計算の帰属と範囲

- **厳密**: 実数の側の行列の成分も `x` も QQ で（`ϱ` の行は QQbar と AA）、等号・不等号は QQ の厳密な比較である。`c`、`‖z‖`、`w`、`‖x‖ = 1` の確認は AA（実代数的数）の厳密な比較である。
  浮動小数点は使わない。
- ℝ への脱出は本文の `W` の `K_1, K_2` の選び方と、上限 `c` が代数的数として表せる場合に限って確かめていることである。
- 確かめられない行: 【上限への移行】の「`r` は `R` の上界でないので `t > r` となる単位ベクトル `x` がある」は存在の主張で、
  上限の定義（最小の上界）から従う。検算では `t` として `c` の固有ベクトルの値（`t = c > r`）を示すだけである。
  背理法の仮定 `c^n > T` は主張に反するので、本物の `T` では起こらない。仮の `T'` で鎖の算術だけを確かめる。

## 否定コントロール（3 件、`check_generic_…`）

## 証明の修正（2026-11-05）

- 「…」で書いた望遠鏡積と「単調非減少を `j−1` 回適用」を、`m_k ≥ m_1m_{k−1}`（`k` の帰納法）と `m_p ≥ m_1^p`（`p` の帰納法）の鎖にした。
  `m_0 = 1`・`m_1 = x^⊤Wx` を鎖で示し、`m_k` を `moment_log_convexity` の置き方で読むと書いた。
- 半正定値行列の二次形式をトレースで抑える八段の鎖は、実数の絶対値・有限和の三角不等式・平方根の積の法則（本文にラベルが無い）と
  `psd_cauchy_schwarz` の二回の適用を使っていた。`W^n` の半正定値性を `v_i := x_l(e_k)_i − x_k(e_l)_i` に当てた
  `2x_k(W^n)_klx_l ≤ x_l^2(W^n)_kk + x_k^2(W^n)_ll` を足し合わせる鎖に替えた（旧い鎖は誤りではない）。`v` は実数の組 `e_q` で定め、ℂ の δ を実数として読む同一視を避けた。
- 「`W^n` は正定値」の散文を、`z = 0` と `z ≠ 0` に分け、`w := ‖z‖^{-1}z` に `moment_log_convexity` の正値性を当てる鎖にした。
- 「`t ↦ t^n` は単調増加なので上限と可換」は `t^n` の連続性を暗に使っていた。【正の実数の冪の比較】を示し、背理法で `c^n ≤ T` を導いた。
- レビューの指摘で、`‖w‖`・`δ`・`m_n` の鎖の複数の操作をまとめた行を分け、定数の括り出しを `finite_sum_of_real_scalar_multiples` で引き、`‖z‖ ≠ 0` と `c^{n−1} > 0` の根拠を書いた。
- 主張は不変。計算の誤りは無かった。
