否定コントロール:
- −V^{(+)} は正定値でなく、トレースは負（厳密版とボール版）。
- V^{(+)} − (V^{(+)}_{11} + 1)E_{11} はエルミートだが正定値でなく、(1,1) 成分が負で r_1 > 0 の段が外れる。同じ行列と b^{(1)} ≠ 0 で x^*Wx ≤ 0 となり、1 行目の x^*Ax ∈ ℝ_{>0} の判定が外れる（厳密版。b^{(1)*}Wb^{(1)} = W_11 = −1 なので W_11 < 0 と中身は同じで、二次形式の判定が偽を返せることを示す）。
- トレースの符号の否定コントロール（−V^{(+)}）は tr(−V) = −tr(V) なので tr(V^{(+)}) > 0 が通れば必ず通る。判定の関数が常に真を返していないことだけを示す。
- b^{(k)} を零ベクトルにすると x^*V^{(+)}x = 0 で ℝ_{>0} に入らない（b^{(k)} ≠ 0 が要ること。厳密版）。

構成上かならず一致する比較（写し間違いの検出だけに効く）:
- 厳密版の Σ_k V^{(+)}_{kk} = Σ_k (r_k)_ℂ は、r_k を、V^{(+)}_{kk} に等しく虚部 0 と確かめた b^{(k)*}V^{(+)}b^{(k)} の実部として作るので必ず成り立つ（人手の「r_k の取り方を各項へ」の行に当たる。中身として効くのは r_k > 0 の段）。
- ボール版の Σ_k V^{(+)}_{kk} と Σ_k r_k の重なりも、r_k を V^{(+)}_{kk} の実部のボールとして作るので、丸めの順序が違うだけで必ず重なる。ボール版の r_1 > 0 は、k = 1 の r_k > 0 と同じ内容である（人手の「r_1 ∈ ℝ_{>0}」の行に当てている）。
- Σ_k (r_k)_ℂ = (Σ_k r_k)_ℂ は、r_k を AA の元として QQbar へ移すので QQbar の和で必ず成り立つ。
- ボール版の b^{(k)*}V^{(+)}b^{(k)} と V^{(+)}_{kk} の重なりは、b^{(k)} の成分が厳密な 0 と 1 なので必ず重なる（厳密版は `quadratic_form_value` の成分の和の式で比べる）。

## 計算の帰属と範囲

- `check_exact.sage`: K_1 := 2 log y、K_2 := log x（x, y ∈ {2, 3}）と選ぶ（`V_plus_is_positive_definite` の検算と同じ置き方。
  準備は `sagemath/check/V_plus_is_positive_definite/_prelude.sage` を読み込み、その先は共有の準備 `sagemath/_shared/transfer_matrix_factor_inverses.sage`）。
  (V_1^{(+)})^{1/2} = exp((log y)·iH_1^{(+)}) は iH_1^{(+)} の整数の固有値 λ の射影に y^λ を掛けて QQ で作ってから AA へ移し、V_2 は成分 x^n で AA で作り、
  V^{(+)} は AA、二次形式は QQbar で持つ。**ℝ への脱出は K_1・K_2 の選び方の一点だけ**で、以後の等号・不等号は全て厳密計算である。
- `check_balls.sage`: K_1 ∈ {1/4, 1/2}、K_2^* ∈ {1/3, 1/2}（有理数）。K_2 := artanh(u)（u := exp(−2K_2^*)）。exp は `def_exp` の部分和に
  尾の上界を半径として足した 256 ビットのボール（ℝ への脱出: exp の極限）。許容誤差は置かず、等号はボールの重なり、不等号はボール全体で判定する。
  エルミート性がちょうど成り立つことはボールでは言えないので厳密版が受け持つ。
- 範囲: M_col = 2, 3, 4。M_col = 1 は共有の準備の H_1^{(+)} が扱わないので範囲外（主張は M_col ∈ ℤ_{≥1} について述べている）。
