## 計算の帰属と範囲

- **厳密**: すべて。角度の鎖（π を不定元にした有理関数体と QQ）、イデアルの所属（ℚ(i) 上の多項式環）、具体値の γ_1・γ_2・|γ_2|^2（円分体 Q(ζ_{4M})）、P̌ の成分（F(r, √M) の有理式）、cos・sin の値の照合（QQbar）。浮動小数点・ボールは使っていない。
- **ℝ への脱出**: 本文の γ = arccosh(γ_1)（`def_arccosh` は実対数を使う）。検算は arccosh の値を計算せず、γ_1 の一致と定義域を厳密に確かめる。全実数上の cos・sin の 2π 周期性は本文で未整備の前提で、検算は θ が π の有理数倍の点だけで照合する。
- **作り方で自明な比較**（中身は括弧の中が担う）:
  - 円分体では exp(iqπ) を ζ の冪で持つので、角度が等しい（QQ の有理数として同じ）点の値は同じ元になる。具体値の (1)(2)(3) の鎖のうち、角度の等式を代入する行（例: γ(θ̃_{μ+kM}) = γ(θ̃_μ + 2πk)）と周期性の行はこのため自明である（角度の等式は `check_angle_chains.sage`、周期性の中身は Sage の記号の値の照合と、一般の点のイデアルの検算）。
  - 具体値の準備の二つ（cos(-x) = cos x、cos x + i sin x = exp(ix)）は、`Angle` が cos・sin を exp(±iθ) から euler の式で作るので恒等式になる（一般の点の `check_generic_chains.sage` が担う）。
  - 準備の i(-x) = -ix・-i(-x) = ix・cos x + i sin x の鎖の各行は、多項式環・有理関数体の中ではどれも同じ元になる。行ごとの比較は本文の書き写しの確認で、中身を担うのは否定の対照と、cos x + i sin x の左辺と第 1 行のイデアルの検査である。
