## 計算の帰属と範囲

- 結合定数は `Y = exp(2K_1)`・`Z = exp(2K_2)` を QQ_{>1} の有理数に取る。`c_1, s_1, c_2, c_2^*, s_2^*` はすべて QQ の元になる。
  ℝ への脱出は `K_i = (1/2) log Y` などの選び方だけで、検算は実対数を計算しない。
- 角度 θ~_μ = π(2μ − 1)/M_col は円分体 Q(ζ_{4M}) の中で `exp(iθ~_μ) = ζ_{4M}^{2(2μ−1)}` として持ち、cos・sin は `euler_formula_cos_sin` の式で作る。
  γ_2(−θ) は −θ での定義式に Euler の式を −θ で当てた cos(−θ)・sin(−θ) を入れて作り、def_A_theta の (2,1) 成分とは別に作った。
  |γ_2| を含む鎖の行は円分体 F に r を r^2 = N := γ_2 conj(γ_2) で添えた商環で、主張の λ_±・|γ_2| の値は AA（実代数的数）で計算する。
  Euler の式の cos・sin と Sage 組み込みの cos・sin の照合は、QQbar への変換が重いので M_col ≤ 4 に限った。浮動小数点は使っていない。
- 範囲: 結合定数 (Y, Z) ∈ {(2,3), (3,2), (4,3), (101/100,7)}（(2,3)・(3,2) は臨界点）、M_col = 2..8 の全 μ（140 組）。
  一般の点の鎖は `check_generic_chains.sage` が範囲によらず確かめる。

## 確かめられない行と理由

- u + iv = e_+ の鎖の第 2 行が引く `euler_formula_cos_sin` と u^2 + v^2 の鎖の第 3 行が引く `exp_of_negative_i_real_as_cos_minus_i_sin` は、全実数上の cos・sin（未整備）を前提にしている。検算は Euler の式を関係として置いた代数的な行と、具体の角度の値を確かめるにとどまる。
- e_+e_− の鎖の第 3・5 行が引く `scalar_exp_product`・`scalar_exp_zero` は exp の性質そのもの（各ブロックに検算がある）で、ここでは具体値の exp(iθ)exp(−iθ) = 1 だけを見る。
- 準備の「実数の和・差・積の像は像の和・差・積」は、対で持った ℂ で一般の実数の不定元について確かめた。
