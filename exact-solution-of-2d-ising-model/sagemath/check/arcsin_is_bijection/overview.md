# SageMath Check: arcsin_is_bijection

## 対象

**対象ラベル**: `arcsin_is_bijection` （structured-latex 側の安定識別子）

- ファイル: `structured-latex/content/000_calculation_formulae_10_19.ts`
- ブロック: `calc_formulae_014b_claim_arcsin_bijection`（arcsin の値域・狭義単調増加・全単射・連続）
- 範囲: 主張の値域・狭義単調増加・全単射の三項と、証明の「準備」「値域」「狭義単調増加」「全単射」の段落。連続の項は範囲外

## 証明の行との対応

証明は、`f(y) := l(AP)`（`def_arcsin` の第一の式）が狭義単調増加で像が `[0,π/2]` であることだけを
齋藤微積分 命題 2.1.5 に委ね、残りを場合分けで示す。弧の長さ `l(PQ)`（`def_arc_length`）は同じ文献に委ねられ、
円周率 `π` は本文で定義されていない。検算は arcsin の値を、弧の長さの定め方に沿った二つの折れ線で上下から挟んで確かめる。

## 計算の帰属と範囲

- **厳密（`AA`）**: 定義の点 `P`、点の並び、全射の証人 `y_k`（`ζ_{48}` は 1 の原始 48 乗根）は実代数的数 `AA` で作った。
  `AA` は可算で、平方根・四則・等号・大小がすべて厳密に決定できる。
- **`R` への脱出（`RB = RealBallField(256)`）**: 弧の長さ `l(AP)` は実数の上限で、`π` も実数なので `AA` に収まらない。
  この二つだけを `RealBallField` で扱った。`RealBallField` は値と誤差の上界の組を持ち運び、丸めの誤差も包含に入れる。
  比べるのは区間の端点（厳密な上界・下界）で、「`a ≤ b`」は `a` の上端が `b` の下端以下であることで確かめた。
  `l(AP)` は、`A` から `P` までの弧の上の 513 点を結ぶ内接折れ線（下界）と、隣り合う点の接線の交点を経る
  外接折れ線（上界）で挟んだ。Sage の標準の arcsin は使っていない（本文の定義と一致することを前提にしないため）。
  許容幅 `10^-5` は、512 辺での実測の幅（最大 `2.08·10^-6`）より大きく、隣り合う検算の値の間隔
  （最小でも `arcsin(1) - arcsin(1-10^-6) ≈ 1.4·10^-3`）より十分小さい値として選んだ。

範囲外のもの:

- 外部文献に委ねた事柄。`f` が狭義単調増加で像が `[0,π/2]` であること（命題 2.1.5）は具体の値で確かめたに留まる。
  弧の長さが内接折れ線の長さの上限であること・外接折れ線より長くないことは、挟み込みの前提として認めた。
- `π` が本文で定義されていないこと（`docs/tasks/goal-alignment-audit.md` の「`π`、弧長 `l(PQ)`」の項）。検算は `RB` の `π` を使う。
- 連続の項。有限個の値では確かめられない。証明の連続の段落は、値域・狭義単調増加・全単射の項だけから `δ` を作る論証で、
  その中の計算は最後の三行（`|arcsin(y) - θ_0| ≤ ε/2 < ε`）の大小比較だけである。
- `y = ±1` での等号 `arcsin(±1) = ±π/2`。区間演算では等号を決められず、区間が `±π/2` を含むことまでを確かめた。
- 検算で選んだ以外の `y`。
