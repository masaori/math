## 計算の帰属と範囲

- **厳密**: 行列の成分も `x` も QQ で、等号・不等号は全て QQ の厳密な比較である。`‖x‖ = 1` の確認だけ AA の平方根を使う。浮動小数点は使わない。
- 単位ベクトルを QQ で取るために、逆立体射影 `x := (2s_1, …, 2s_{d−1}, |s|^2 − 1)/(|s|^2 + 1)`（`s ∈ QQ^{d−1}`）を使う。
- ℝ への脱出は本文の `W` の `K_1, K_2` の選び方だけで、`W` が QQ の行列になる場合に限って確かめている。

## 否定コントロール（3 件、`check_generic_…`）

- 対称だが正定値でない `diag(1, −2)` と `x = (3/5, 4/5)` では `m_1 = −23/25 < 0`、`m_2^2 = 5329/625 > m_1m_3 = 2737/625`（半正定値性が効いている）。
- 対称でない `[[1,1],[0,1]]` では `x^⊤T^{a+b+1}x ≠ (T^bx)^⊤T(T^ax)` となる `(a, b)` がある（【二つの冪で挟んだ値】に【冪の実対称性】が効いている）。
- 半正定値だが正定値でない `diag(1, 1, 0)` と `x = e_3` では `Wx = 0`・`x^⊤Wx = 0`（【W^ax は零でない】と `m_1 > 0` に正定値性が効いている）。

## 構成上かならず一致する比較（写し間違いの検出だけに効く）

- 【二つの冪で挟んだ値】の 1〜6 段と 9〜10 段、【I と W の正値性】の I の鎖、背理法の鎖、【正値性】の 1 段目は、和の項を並べ替える・展開するだけなので QQ の計算規則で必ず一致する。

## 証明の修正（2026-11-05）

- 旧い鎖は `(W^bx)^⊤W(W^ax)` と `x^⊤W^{a+b+1}x` の等号を「冪の指数法則と `(W^b)^⊤ = W^b`」としていたが、行列の積の転置の主張は本文に無い。
  【二つの冪で挟んだ値】`x^⊤(W^b(BW^a))x = (W^bx)^⊤B(W^ax)` を `def_real_bilinear_value`・`mat_mult`・`W^b` の成分の対称性で示し、二つの不等式の鎖をこれで書いた。
  `P = I` の鎖はユークリッドノルムを経ずに `(u^(a))^⊤Iu^(a)` で閉じた。
- 「冪の指数法則」を `matrix_power_exponent_law` の行に、「`W` は実対称」を `power_of_real_symmetric_complex_matrix_is_real_symmetric` の【冪の実対称性】にした。
- 正値性の「`W` が可逆なので `W^ax ≠ 0`」は、可逆から核の自明性を導く主張が本文に無い。`W` の正定値性から `Wu ≠ 0`（`u ≠ 0`）を示し、`a` の帰納法で `W^ax ≠ 0` とした。
  `I` と `W` が `psd_cauchy_schwarz` の前提（`def_real_symmetric_matrix` の対称と半正定値）を満たすことを鎖で示した。
- レビューの指摘で、積の行列 `W^b(BW^a)` の成分が実数であることを `product_of_real_entry_matrices_has_real_entries` で示して実数として読むと書き、`u^(a+1)` の鎖に `W^{0+1}` の行を足し、`I_kl = I_lk`・`W_kl = W_lk` を示した。
- 主張文に `m_k ∈ ℝ` と `W^k` の読み方を書いた。不等式は不変。計算の誤りは無かった。
