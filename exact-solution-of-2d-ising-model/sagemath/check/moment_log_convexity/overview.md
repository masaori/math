`_lines.sage` の `check_proof_lines` と `check_varrho_lines` を二つの検算が呼ぶ（`check_varrho_lines` は行列ごとに 1 回）。

- `check_generic_positive_definite_matrices.sage`: 証明が使う `W` の性質は「成分が実数で対称」「正定値（実の `y ≠ 0` で `y^⊤Wy > 0`）」だけなので、
  `P := A^⊤A`（`A` は列が一次独立な整数行列、`n = 1..5`）の有理行列 20 個と、`x = e_1` と逆立体射影で作った有理の単位ベクトル 2 本（`n = 1` では `x = (−1)` の 1 本）の 56 組で確かめる。等号 113872 個、不等号 5792 個。
- `check_symmetrized_transfer_matrix.sage`: 本文の `W = (BV_2)B`（`def_symmetrized_transfer_matrix`）を `K_1 := 2 log y`、`K_2 := log x`
  （`x, y ∈ {2, 3}`、`M_col = 2, 3`）で作る。`W` は QQ の行列である。`x` は `e_1` と逆立体射影の有理の単位ベクトル。等号 43752 個、不等号 1296 個。

`W` の作り方、ノルム・`x^⊤Py`・行列とベクトルの積・冪・正定値性の判定（実対称な行列の特性多項式の係数の符号）の関数は、
`sagemath/check/rayleigh_bounds_operator_norm/_prelude.sage` を読み込んで使う。

## 計算の帰属と範囲

- **厳密**: `check_proof_lines` では行列の成分も `x` も QQ で、等号・不等号は全て QQ の厳密な比較である。`‖x‖ = 1` の確認だけ AA の平方根を使う。`check_varrho_lines` は `W` を QQbar、`W_ℝ = ϱ(W)` を AA で作り、厳密に比べる。浮動小数点は使わない。
- 単位ベクトルを QQ で取るために、逆立体射影 `x := (2s_1, …, 2s_{d−1}, |s|^2 − 1)/(|s|^2 + 1)`（`s ∈ QQ^{d−1}`）を使う。
- ℝ への脱出は本文の `W` の `K_1, K_2` の選び方だけで、`W` が QQ の行列になる場合に限って確かめている。

## 否定コントロール（3 件、`check_generic_…`）

- 対称だが正定値でない `diag(1, −2)` と `x = (3/5, 4/5)` では `m_1 = −23/25 < 0`、`m_2^2 = 5329/625 > m_1m_3 = 2737/625`（半正定値性が効いている）。
- 対称でない `[[1,1],[0,1]]` では `x^⊤T^{a+b+1}x ≠ (T^bx)^⊤T(T^ax)` となる `(a, b)` がある（【二つの冪で挟んだ値】に【冪の対称性】が効いている）。
- 半正定値だが正定値でない `diag(1, 1, 0)` と `x = e_3` では `Wx = 0`・`x^⊤Wx = 0`（【(W_ℝ)^ax は零でない】と `m_1 > 0` に正定値性が効いている）。

## 構成上かならず一致する比較（写し間違いの検出だけに効く）

- 【二つの冪で挟んだ値】の 1〜6 段と 9〜10 段、【I_ℝ と W_ℝ の正値性】の I_ℝ の鎖、`u^(0)` と `u^(a+1)` の成分の鎖、背理法の鎖、【正値性】の 1 段目は、和の項を並べ替える・展開するだけなので QQ の計算規則で必ず一致する。
  中身は、7〜8 段（`((W_ℝ)^b)_il = ((W_ℝ)^b)_li`。対称でない行列では外れる）と、組み込みの積との比較・左辺が `m_{a+b(+1)}` に等しいことの比較にある。
- 次の行も同じ式から作るので構成上一致する: `(W_ℝ)^{a+1}` の `ϱ` の鎖の `W^{a+1}`→`W^{a+0+1}` と `W^0`→`I` の行（`check_varrho_lines` の `pc[a+0+1]` は `pc[a+1]` と同じ要素、`pc[0]` は単位行列）、【正値性】の 2 段目（`m_{2a}` と `x^⊤(W_ℝ)^{a+a}x`）、不等式の鎖の 1→2 段目と後半の `(W_ℝ)^{a+a+1}`→`(W_ℝ)^{2a+1}`（`(W_ℝ)^{a+a}`→`(W_ℝ)^{2a}`）の行、`I_ℝ` の対称性の 3 段。
- 背理法の鎖は前の 3 段だけを確かめる。後の 2 段は `W_ℝu^(a) = 0` という仮定の下の行で、正定値の行列では作れないので検算しない。
- 【冪の分け方】の `Mat(d,ℂ)` の鎖の `W^{b+a}`・`W^{b+(1+a)}`・`W^{0+1}`・`W^0`・`I` の行は、冪を `def_exp` (1) の漸化式で作るので構成上一致する。
  `matrix_power_exponent_law` を当てる行（`W^bW^a`、`W^bW^{1+a}`、`W^b(W^1W^a)`）は別々に作った冪の積の比較なので中身がある。

## 証明の修正（2026-11-05）

- 旧い鎖は `(W^bx)^⊤W(W^ax)` と `x^⊤W^{a+b+1}x` の等号を「冪の指数法則と `(W^b)^⊤ = W^b`」としていたが、行列の積の転置の主張は本文に無い。
  【二つの冪で挟んだ値】`x^⊤(W^b(BW^a))x = (W^bx)^⊤B(W^ax)` を `def_real_bilinear_value`・`mat_mult`・`W^b` の成分の対称性で示し、二つの不等式の鎖をこれで書いた。
  `P = I` の鎖はユークリッドノルムを経ずに `(u^(a))^⊤Iu^(a)` で閉じた。
- 「冪の指数法則」を `matrix_power_exponent_law` の行に、「`W` は実対称」を `power_of_real_symmetric_complex_matrix_is_real_symmetric` の【冪の実対称性】にした。
- 正値性の「`W` が可逆なので `W^ax ≠ 0`」は、可逆から核の自明性を導く主張が本文に無い。`W` の正定値性から `Wu ≠ 0`（`u ≠ 0`）を示し、`a` の帰納法で `W^ax ≠ 0` とした。
  `I` と `W` が `psd_cauchy_schwarz` の前提（`def_real_symmetric_matrix` の対称と半正定値）を満たすことを鎖で示した。
- レビューの指摘で、積の行列 `W^b(BW^a)` の成分が実数であることを `product_of_real_entry_matrices_has_real_entries` で示して実数として読むと書き、`u^(a+1)` の鎖に `W^{0+1}` の行を足し、`I_kl = I_lk`・`W_kl = W_lk` を示した。
- 主張文に `m_k ∈ ℝ` と `W^k` の読み方を書いた。不等式は不変。計算の誤りは無かった。

## 証明の修正（2026-11-06）

- 主張と証明を `def_W_real` の `W_ℝ` で述べ直した（`m_k := x^⊤(W_ℝ)^kx`、冪は `K = ℝ` の `def_exp` (1)、単位行列は `I_ℝ`）。
  旧い版は `W` の冪の成分を「実数として読む」としていた。`ϱ` で運ぶ行を `check_varrho_lines` で、実数の側の行を `check_proof_lines` で確かめる。
- 旧い `u^(a+1)` の鎖の `(WW^a)x = W(W^ax)`（`mat_mult_associative`）は、実数の行列とベクトルの積の結合則の主張が本文に無いので、
  `(W_ℝ)^{a+1} = W_ℝ(W_ℝ)^a` の `ϱ` の鎖と成分の 8 段の鎖に替えた。値は不変。
