## 計算の帰属と範囲

- **厳密**: 整数 `ZZ` と多項式環 `ZZ[a, b, c]` だけで計算した。浮動小数点は使わない。
- 有限個の `(x, y)` で確かめたのは式変形の書き間違いの裏取りであり、証明ではない（すべての `x, y` についての主張は帰納法が与える）。
- `ι(x + 0)`・`ι((x + y) + 1)` のように ℕ の式を引数に取る行は、Sage が引数の ℕ の計算を先に済ませるので、ℕ の和の再帰の式の段は数の上では書き間違いと区別できない。その段の正しさは本文と Lean の `rfl`（ℕ の和の定義の式）が受け持つ。
