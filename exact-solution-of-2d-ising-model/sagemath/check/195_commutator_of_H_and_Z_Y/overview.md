## 備考

**(a)** 本文 `[H₁^{(±)}, hatZ_μ^{(∓)}] = 2e^{−iθ_μ}hatY_μ` は成り立たない。差はちょうど −4e^{−iθ_μ}Y_M で、成り立つ形は `2e^{−iθ_μ}hatY_μ − 4e^{−iθ_μ}Y_M`。由来は hatZ^{(−)}−hatZ^{(+)} = 2Z₁e^{−iθ_μ} と [H₁^{(±)}, Z₁] = ∓2Y_M。

**(b)** 本文 `[H₂, hatZ_μ^{(+)}] = −2hatY_μ + (1/M)Σ_j(−2e^{−i(2π/M)(−j+μ)}hatY_j)` は成り立たない。補正項の係数が **−2 ではなく +4** でなければ合わない。成り立つ形は `−2hatY_μ + (4/M)Σ_j e^{−i(2π/M)(μ−j)}hatY_j = −2hatY_μ + 4e^{−iθ_μ}Y₁`。由来は [H₂, Z₁] = −2Y₁ と Y₁ = (1/M)Σ_j hatY_j e^{i2πj/M}。

どちらも M = 2,3,4,5 の全 μ、両符号で機械精度（相対誤差 ~1e-15）で修正形が一致する。
