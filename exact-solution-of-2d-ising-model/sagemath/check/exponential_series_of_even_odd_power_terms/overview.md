## 計算の帰属と範囲

- 準備と中間目標「各項」「部分和」「差」は、ℝ を `QQ` 上の多項式環、ℂ を実数の対または `QQ(i)` 上の多項式環で持ち、浮動小数点を使わない。不定元での等号は、任意の実数 x・任意の複素数 c と A・B の成分を代入しても成り立つ。
- 実数の exp の値は `QQ` に収まらないので、「実数の評価」「ノルムの評価」の不等号と ε の鎖と主張だけを ℝ へ脱出して確かめる。exp は `_shared/hyperbolic_by_definition.sage` の `exp_ball`（本文の 1 行 1 列の行列の exp の部分和に、尾の評価 2|x|^{N+1}/(N+1)! を半径として足したボール。512 bit。Arb の exp は使わない）。S_N・α_N・β_N・E_N は `QQ`・`QQ(i)` で厳密に作り、絶対値とノルムを取るときだけボールへ移す。平方和は非負なので、平方根はボールの負の部分を落として取る（`sqrtpos`）。
- 不等号 l ≤ r の行は、l の上端が r の下端以下であるか、両辺のボールが重なることで確かめる。重なるだけで通った行はログに「等号の場合」と書いた。重なるだけで通るのは「実数の評価」の三角不等式の行だけで、二つの数の符号が逆で等号が成り立つ場合である（x の正負と N の偶奇により α か β の一方がそうなる。三つの点のどれでも起きる）。N ≥ 80 では差がボールの半径（10^{-150} 程度）を下回って不等号の行が確かめられないので、不等号の行は N ≤ 40 に限った。
- 全ての n・N への一般化と、極限の推論（全ての ε への一般化）は確かめられない。範囲は表の「結果」のとおり。

## 確かめられない行と理由

- 「ℂ の積の可換律・結合律」「ℂ の有限和の分配則」「実数の四則」だけで並べ替える行は、可換環の元として作るので前の行との一致は作り方から必ず通る。誤った因子・符号を書いた場合に落ちることを担保する記録として置いた。
- 「T_n の仮定」の行は仮定そのものなので、仮定の列を作った式と一致することしか確かめられない。
- 包含の略記だけを書き換える行（`c 0_C` と `c (0)_C`）は、両辺を同じ `iota`・同じ元で作るので一致は作り方から必ず通る。`0_C` が包含の像であることは `inclusion_rr_to_cc` の略記そのものである。
