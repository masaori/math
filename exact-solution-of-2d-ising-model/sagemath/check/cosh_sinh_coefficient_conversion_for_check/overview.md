## 計算の帰属と範囲

- 共通の準備は `_shared/half_integer_check_operators.sage`（`nesting_of_commutator_of_H_and_check_Z` と共有）と `_shared/complex_as_real_pairs.sage`。

  この表し方と本文の exp の値との照合（Euler の公式が本文で未整備であることを含む）は `nesting_of_commutator_of_H_and_check_Z` の `check_premises.sage` が行う。
  この主張の証明は位相を変形しないので、位相は鎖の中で掛けて運ぶだけである。
- `k1`・`k2` は円分体上の多項式環の不定元で、不定元での等号は全ての実数 `K_1, K_2^*` の像での等号を表す。浮動小数点は使わない。
- 帰納法の推論そのもの（全ての m・l への一般化）と、主張の全ての n・M_col への一般化は確かめられない。範囲は表の「結果」のとおり。

## 確かめられない行と理由

- 「帰納法の仮定」の行は、仮定の式で置き換える推論である。検算は仮定の式がその段で実際に成り立つことと、置き換えた後の値が前の行と一致することを確かめる。
- 次の行は、前の行と同じ値を同じ演算で作ることになるので、前の行との一致は作り方から必ず通る。検算はその行の式どおりに組んだ値を記録として置き、誤った指数・符号・因子を書いた場合に落ちることを担保する。
  - ℂ の積の可換律・結合律だけで並べ替える行（厳密な可換環の元として作る）
  - 「ℂ の積の単位元」の行（`1·x`）
  - `-i := (-1_C)i` の行（`-i` を `(-1)·i` として作る）
  - 「n = 2l+1」「n = 2l」の代入の行と、冪の約束で `i^{2l+1}` を `i^{2l}i` に開く行（冪は同じ右からの再帰で作る。`n` と `2l+1`・`2l` の等しさは別に確かめる）
- 中身を確かめているのは、「記法」の行（Sage の再帰との比較）、(★) の行、`nesting_of_commutator_of_H_and_check_Z` を代入する行、(†) の `2_C^{-1}2_C = 1_C` を使う行、(‡) と `i i = -1_C`・`(-1_C)(-1_C) = 1_C` を使う行と、主張そのものである。
