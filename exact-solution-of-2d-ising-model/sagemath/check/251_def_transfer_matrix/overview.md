# SageMath Check: 251_def_transfer_matrix

## 対象

**対象ラベル**: `def_transfer_matrix` （structured-latex 側の安定識別子）

| 02 | `check_02_V2_as_kronecker_power.sage` | V₂ が 2×2 転送行列 t のクロネッカー積 t^(⊠N) に一致すること、|𝔐| = 2^N、V₁ の対角成分が 1 次元 Ising 環のエネルギーから組み上がること | 60 | 4.736e-16 | **PASS** |

許容誤差は既定の相対誤差 `1.0e-09`（成分の最大絶対値で正規化）。既定から変更していない。

check 02 は check 01 とは別経路の構成である。check 01 は (V₂)_{μ,μ′} = exp(Σ_j J μ(j)μ′(j)) を成分ごとに再計算して照合しているのに対し、check 02 は t := ((e^J, e^{-J}), (e^{-J}, e^J)) の N 重クロネッカー積として V₂ を**構成レベルで**組み上げる。定義式の和 Σ_j が積 Π_j へ分解すること（サイトごとに独立であること）を、成分計算を経ずに確かめる経路になっている。添字の対応は「μ(j) = -1 → ビット 0、μ(j) = +1 → ビット 1、j が上位から下位へ」で、`_prelude.sage` の `transfer_matrices` が既定で使う順序に一致する。V₁ は隣接サイトを結ぶため同じ形には分解しないので、対角成分の直接照合にとどめている。

## 備考

別セッションが「V₁ の行内結合は J′、V₂ の行間結合は J」と訂正した後の定義に従って実装している。
