## 計算の帰属と範囲

- **厳密**: 多項式は `QQ` 係数。`y` の点と `cos(qπ)` の値は `AA`（実代数的数）。`cos(qπ)` は `e^{iqπ} = ζ_{2d}^m` の実部として作る。
- **`ℝ` への脱出（`RealBallField(512)`）**: 連続性と `γ > 0` の確かめだけ。log・cos の値が `QQ`・`AA` に収まらず、連続性は区間の上の振れ幅で
  しか見られないためである。log は有理数の端点を本文の exp のボール（Arb の exp は使わない）で確かめて挟んだ区間
  （`_shared/positive_coupling_and_real_log.sage` の `real_log_enclosure`）、√ は Arb の sqrt、cos は Arb の cos。
  `arccosh` の区間は、`y ↦ y + √(y^2-1)` と log の単調増加により端点の値で挟む。下端を 1 で切る根拠は、`γ_1` の区間では
  `gamma1_lower_bound_all_theta`、`arccosh` の連続性の確かめでは定義域を `[1,∞)` に制限していることである。
- **cos**: 本文の `def_cos` は `[-π/2, π/2]` でしか cos を定めておらず、全実数上の cos は本文に無い。主張はそれを前提として書いている。
  `AA` の値も Arb の cos も、その外では標準の cos の値であり、本文が未整備の拡張を先取りしている。
- 許容誤差は置かず、ボールの包含・大小で判定する。振れ幅は区間の端点を `QQ` にして `QQ` で比べる（`√δ` との比較は両辺を 2 乗する）。

## 確かめられない行と理由

- **連続性そのもの**（Step 1・Step 2・Step 3 の結論）は有限個の計算では決められない。検算が示すのは、選んだ点の周りの区間での
  振れ幅の上界が `δ` とともに 0 へ縮むことで、連続性の証明ではない。区間は連続な部品から組むので、縮むことは作り方からほぼ決まっており、
  この検査は主に写し間違い（定義域の端の扱い、式の取り違え）を捕まえる。連続性の根拠は本文の `remark_real_analysis_escape_point` の (R0)
  （外から持ち込む事実）である。
- 範囲外: 選んだ以外の結合定数・点・`δ`。`gamma1_lower_bound_all_theta`・`arccosh_properties` などの引かれる主張そのもの
  （それぞれの検算が持つ）。
- 2026-11-05 にこのブロックから参照用ノートへ移した「`γ` は周期 `2π` をもつ」は対象外である。
