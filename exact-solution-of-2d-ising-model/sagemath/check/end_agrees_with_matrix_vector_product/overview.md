- **厳密**: 係数は `QQ`・`QQ(i)`、不定元は `QQ(i)` 上の多項式環。浮動小数点は使わない。不定元で成り立つ多項式の等号は、不定元へ任意の複素数を代入しても成り立つ（代入は環準同型である）。
