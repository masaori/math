### 何を確定させるための検証か

011 章の `sector_decomposition_of_rayleigh_sup` (3) は
`c(M) = max(c_+(M), c_−(M))` までしか述べておらず、018 章の `onsager_exact_solution` は
この `max` の値を決めないまま `Λ^{(1/2)}_M ≤ c(M) ≤ 2Λ^{(1/2)}_M` という粗い挟み撃ちで
自由エネルギーを出している（係数 `2` は `(log 2)/M → 0` で消えるため表式には影響しない）。

019 章は、この `max` が**偶セクター側から来る**ことを確定させる。すなわち

> **`c_−(M) ≤ c_+(M)`、したがって `c(M) = c_+(M) = Λ^{(1/2)}_M`**

を本文の定理にする。本検証はその各段をラベル単位で確かめる。

証明の筋（本文と 1 対 1 に対応する）:

1. `ε = σ^x_1 ⋯ σ^x_M` は全スピン反転に対応する `0/1` の置換行列で、その置換 `π` は
   不動点をもたない対合。成分では `(εx)_k = x_{π(k)}`。
2. `x ∈ F^{(-)} ∩ R^{2^M}` なら `εx = −x`、すなわち `x_{π(k)} = −x_k`。したがって
   `u_k := |x_k|` は `(εu)_k = |x_{π(k)}| = |−x_k| = u_k`、すなわち **`εu = u`**（`u ∈ F^{(+)}`）。
   ノルムも `‖u‖ = ‖x‖` で変わらない。
3. `W` の成分はすべて正（011 章 `W_has_positive_entries`）なので、三角不等式から
   `u^T W u = Σ_{k,l}|x_k x_l W_{kl}| ≥ |Σ_{k,l} x_k x_l W_{kl}| = |x^T W x| ≥ x^T W x`。
4. よって `c_+(M) ≥ u^T W u ≥ x^T W x`。`x` について上限を取って `c_+(M) ≥ c_−(M)`。
5. `c(M) = max(c_+, c_−) = c_+(M)`。018 章 `c_plus_equals_Lambda_half_integer` と合わせて
   `c(M) = Λ^{(1/2)}_M`。

**`c_−(M)` の値そのものには立ち入らない。** 018 章が記録しているとおり
`c_−(M) = Λ^{(0)}_M` は一般には成り立たない（下記 check_04 (5) の高温側の対照出力）。
本章が示すのは不等号だけである。

## 検証の枠組み

`_prelude.sage` は `_shared/spin_ops.sage` だけを土台に自己完結させてある
（053 と同じ理由。別ディレクトリの prelude を `load` すると `__file__` の解決が環境依存になる）。

```
ε        := σ^x_1 ⋯ σ^x_M                      (def_transfer_matrix_symbols)
W        := V_1^{1/2} V_2 V_1^{1/2}            (def_symmetrized_transfer_matrix)
           V_1 = exp(K_1 Σ_{m=1}^{M} σ^z_m σ^z_{m+1}) は周期境界
F^{(±)}  := ε の固有値 ±1 の固有空間            (def_eigenspaces_of_epsilon)
c_±(M)   := sup{ x^T W x | x ∈ F^{(±)} ∩ R^{2^M}, ‖x‖ = 1 }
c(M)     := sup{ x^T W x | x ∈ R^{2^M}, ‖x‖ = 1 }
Λ^{(δ)}_M := (2 sinh 2K_2)^{M/2} exp( (1/2) Σ_{μ=1}^{M} γ(2π(μ−δ)/M) )
```

`c_±(M)` は `F^{(±)} ∩ R^{2^M}` の正規直交基底（`sector_basis`）へ `W` を制限した
実対称行列の最大固有値として求める（`W` は実対称なので Rayleigh 商の上限は最大固有値に一致する。
011 章の本文は上限としてしか扱っていないが、数値側では固有値で評価してよい）。

## 結論

019 章の 4 ブロックすべてが、`M = 2,3,4,5`・臨界点を含む 6 組の `(K_1, K_2)` で
数値的に成り立つことを確認した。とくに

- `x ∈ F^{(-)}` の成分ごとの絶対値 `u = |x|` が `F^{(+)}` に入ること（本文の要）
