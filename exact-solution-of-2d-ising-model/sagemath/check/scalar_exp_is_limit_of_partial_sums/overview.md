## 計算の帰属と範囲

- **厳密**: 本文の `K = R` は係数 `QQ`、`K = C` は係数 `QQ(i)`（ガウス有理数）で確かめた。Step 1・Step 2 は、これらの上の多項式環で `x` を不定元として確かめた。
  不定元で成り立つ多項式の等号は、`x` へ `K` の任意の元を代入しても成り立つ（代入は環準同型である）ので、各 `m`・`N` について一般の `x` で確かめたことになる。
- **構成上かならず一致する比較**: Step 1 の第五辺 `x^m x` と第六辺 `x^{m+1}` は、共通の準備の数の冪が `x^m x` で次を作るので必ず一致する。
  `x^{m+1}` の独立な確認は、Sage の冪 `x^(m+1)` との比較である。
- **`R` への脱出（`ComplexBallField(1024)`）**: Step 3 は極限で、`exp(x)` の値は `QQ` にも代数的数にも収まらない。この段だけを Arb のボール（値と誤差の上界の組。丸めの誤差も包含に入る）で扱った。
  部分和は各点で `QQ(i)` の中で厳密に計算し、最後にボールへ移した。比べた `exp(x)` は Arb の exp で、本文の定義（1 行 1 列の行列の exp の成分）とは独立な経路である。
  精度 1024 ビットは、`N = 120` での尾（最小 `10^{-201}` 程度）を丸めの誤差より大きく保つために選んだ。
  点は `x = 0, 1, -3, 7/2, -10`（`K = R`）と `x = i, 2-3i, -5+i/2`（`K = C`）。

範囲外のもの:

- 一般の `m`・`N`（帰納法と有限和の一般の場合）は人手証明が担う。
- Step 3 の論証（`exp_converges` (1b) を `n = 1` に適用すること）は収束の定理の適用であり、有限個の値では確かめられない。検算は具体の点で極限の値が合うことまでを確かめた。
