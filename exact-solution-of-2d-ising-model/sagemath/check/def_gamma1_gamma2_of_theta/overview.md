## 計算の帰属と範囲

- 一般の検算は `QQ(i)` 上の 12 変数の多項式環で行い、イデアルの所属はグレブナー基底で判定する（浮動小数点なし）。
- 具体値は `QQbar`・`AA`（代数的数）で厳密に判定する。ℝ への脱出は結合定数の選び方 `K_1 = (1/2) log Y`・`K_2^* = (1/2) log X`（`X, Y ∈ QQ_{>1}`）、
  `exp(2K_2) = (X+1)/(X−1)` と、θ = 2πk/n の三角関数・指数関数の値を Sage の記号式から代数的数へ変換することだけである。
  −θ での値も記号式から作るが、Sage の記号式は作った時点で偶奇性を当てはめる（`cos(-6*pi/7)` は `-cos(1/7*pi)` になる）。
  したがって具体値で三つの関係式が成り立つことの検査は独立な確認ではなく、行の等号が引いた関係式だけから従うことの本体は一般の不定元のイデアルの検査である。
- 範囲: `(Y, X) ∈ {(4, 3), (9, 7/3), (25/4, 2)}`、θ ∈ {0, 2π/3, π/2, 2π/5, 4π/5, π/3, 6π/7, 5π/4, 7π/6}。

## 確かめられない行と理由

- `cos(−θ) = cos θ`・`sin(−θ) = −sin θ` は主張 `cos_of_negated_real`・`sin_of_negated_real` を引く（鎖の検算は `sagemath/check/` のそれぞれのラベルのディレクトリ）。どちらも `euler_formula_cos_sin` を通して全実数上の cos・sin（本文で未整備）に依る。
  この検算はその当てはめを Sage の cos・sin で確かめるにとどまる。
- `def_A_theta` は θ ∈ ℝ について定め、(1,1)・(2,2) 成分を実数の式の像、(1,2)・(2,1) 成分を像の ℂ の式と読み、(2,1) 成分の先頭の `-i` を `(-1)i`、四つの因子の積を左から括る、と定義に書いている。検算はこの読みどおりに成分を作る。
