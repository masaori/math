## 計算の帰属と範囲

- **厳密**: 係数は `QQ(i)`、不定元は `QQ(i)` 上の多項式環、絶対値は `AA`。
- **`ℝ` への脱出（`ComplexBallField(512)`）**: `exp(D)` と `exp(d_k)` の値だけ。極限で定まり `QQ(i)` に収まらないためである。
  ボールの中心は本文の部分和、半径は尾の評価 `2c^{M+1}/(M+1)!`（`M` は中心の部分和の次数で既定は `max(150, ⌈8c⌉)`、`c` は `‖D‖` の有理数の上界 `Σ(|Re a|+|Im a|)`、`M + 2 ≥ 2c`）。
  各成分の誤差が `‖exp(D) - S_M‖` 以下であること、`‖D^m‖ ≤ ‖D‖^m`（`matrix_norm_submultiplicativity`）、比 1/2 の等比級数との比較による。
  この尾の評価は本文には無く、検算の側で導いた。許容誤差は置かず、ボールの重なりと 0 の包含で判定する。
- 範囲外: 選んだ以外の対角行列、`p > 9`・`N > 10` の冪と部分和の記号計算。
