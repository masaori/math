# SageMath Check: scalar_limit_is_unique

## 対象

**対象ラベル**: `scalar_limit_is_unique` （structured-latex 側の安定識別子）

- ファイル: `structured-latex/content/003_exp_linear_map.ts`
- ブロック: `exp_linear_map_claim_scalar_limit_is_unique`（数の列の極限は一意。`K = ℝ` または `ℂ` の列が `a` と `a'` の両方へ収束すれば `a = a'`）
- 範囲: 証明の四つの鎖（1 行 1 列の行列の差、1 行 1 列の行列のノルム、収束の鎖、最後の成分の鎖）と、主張の対照

## 計算の帰属と範囲

- **厳密**: 係数は `QQ`・`QQ(i)`、ノルムと絶対値は `AA`（実代数的数）。浮動小数点は使っていない。
- 範囲外: 選んだ以外の点と列、無限列の極限そのもの。
