## 備考

- **ℝ 脱出（指数評価と実対数）**: `V^{(+)}`・`V̌'`・`Q̌_ε` は行列の指数関数と、固有値が一般に無理数の作用素から作るので
  成分が超越数になる。`Λ̌_ε` と `Λ^{(1/2)}_M` は実数の指数と `arccosh`（実対数）の値である。いずれも厳密計算できないので、
  倍精度 `CDF`・`RDF` で計算した。
- (3) の 1 行目は、`max_eigenvalue_of_V_plus_simple` の証明（集合 `Θ^{(1/2)}_M` の元が `θ̃_μ` と一致し互いに相異なること）を
  経ずに、定義どおり集合として作った値と比べている。
- 否定コントロールの幅を `1e-7`（一致の判定幅の 10 倍）にしたのは、高温側（`K_1 = 0.05, K_2 = 0.1`）で
  `Λ^{(0)}_M` と `Λ^{(1/2)}_M` の相対差が `M = 5` で `7.5e-7` まで真に縮むためである。
- 臨界点上では `δ = 0` の `θ = 0` で `γ_1(0) = 1` となり、倍精度の丸めで `1` をわずかに下回る。`γ_1(θ) ≥ 1` は
  `gamma1_lower_bound_all_theta` が保証するので、`1 − 1e-12` より大きいことを確かめてから `1` で下から押さえて `arccosh` を取る。
- 共通定義（`SpinOps`・`psi_pair`・`V_plus`・`Vprime_check`・`n_check_all`・`Q_check`・`gamma_tilde`・`g1`・`th_tilde`）は
  `050_claim_even_sector_eigenvalues/_prelude.sage` を使う。
