## 計算の帰属と範囲

浮動小数点と `RR` / `CC` への脱出はない。

- **一般の点**: `x` を `QQ` 上の不定元とする多項式環 `QQ[x]`。不等式の行は、差が `x^2`（実数の平方は非負）や `1` に厳密に等しいことで確かめた。
  `s` は `x` の多項式でないので、`s` を含む行は一般の点では扱わない。
- **具体の点**: `x` を `AA`（実代数的数）に取った。`AA` は可算で、平方根・絶対値・四則・等号・大小がすべて厳密に決定できる。
  点は `0`・`±1`・有理数・大きさの離れた数（`10^6`、`-10^{-6}`）・無理数（`√2`、`-∛5`、`√3-2`）を含む。
  `s` は、定義域 `1+x^2 ≥ 0` を確かめてから `AA` の平方根で作り、値が `AA` に留まること（`AA` の平方根は負の数にも例外を出さず複素数を返すため）と、
  証明が非負平方根の定義から使う性質（`s ≥ 0`、`s^2 = 1+x^2`）を作った値について確かめた。

実数の絶対値は本文で未定義で（状態台帳に記録）、検算は `|q| = max(q,-q)` として扱った。
主張の `x` は `R` の元であり、`AA` に入らない点は検算の範囲外で、人手証明が担う。

次の行は等号が自動的に成り立つか、性質の確認に留まる:
`s^2 = 1+x^2` と `1+x^2 = s^2`（非負平方根の定義。作った `s` がこの性質を持つことを確かめる）、
`s^2 = s·s` と `|x|·|x| = |x|^2`（冪の定義）、`s/s = 1`（割り算が作った時点で `1` に簡約されるので、確かめているのは約分の前提 `s ≠ 0` だけ）。
背理法の鎖は仮定 `s < |x|` が具体の点で偽なので、その点では評価できない。仮定を満たす別の非負の対で鎖の推論を確かめ、
具体の点では仮定が成り立たないことと結論 `|x| ≤ s` を確かめるに留まる。
