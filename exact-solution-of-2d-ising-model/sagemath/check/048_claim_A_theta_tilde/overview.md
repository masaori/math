### 何を確定させるための検証か

章 C′（偶セクターの半整数運動量モード）の C′-12 にあたる。
008 章は整数運動量 `θ_μ = 2πμ/M` について同じ対角化を行っているが、そこでは
臨界点 `sinh 2K_1 sinh 2K_2 = 1` かつ `μ = ±M` で `γ_2(θ_μ) = 0` となり、
`A(θ_μ) = I` という例外処理が必要だった。

**この検証の主眼は、半整数運動量ではその例外が起こらないことを数値で固定することにある。**
`γ_2(θ~_μ) ≠ 0` が言えると、固有値の分離 `λ_+ > 1 > λ_- > 0`（同値: `γ(θ~_μ) > 0`）が
場合分けなしで従い、C′-15（最大固有値の一意性）で使える形になる。

## 検証の枠組み

`_prelude.sage` に、`_shared/defs.sage` の symbolic 版に対応する**数値版**（`RDF`/`CDF`）を置いた。

```
γ_1(θ) = c_1 c_2* − s_1 s_2* cos θ
γ_2(θ) = i e^{iθ} s_2* (c_1 cos θ − i sin θ − s_1 c_2)
A(θ)   = [[γ_1(θ), γ_2(θ)], [−γ_2(−θ), γ_1(θ)]]
θ~_μ   = 2π(μ − 1/2)/M      （半整数運動量）
θ_μ    = 2πμ/M              （整数運動量。対比用）
```

パラメータ:

- `M = 2, 3, 4, 5, 6, 7, 8`（全 `μ ∈ {1,…,M}`）
- `(K_1, K_2)` は 16 組。**厳密な臨界点**（`sinh 2K_1 sinh 2K_2 = 1` を満たす `K_2` を
  `K_2 = arcsinh(1/sinh 2K_1)/2` で構成）4 組、その**近傍**（相対 `±1e-9`, `±1e-4`, `±1e-6`）6 組、
  一般の点 6 組。

`sqrt` は本プロジェクト定義（偏角を `[0,2π)` で取り半分にする）を使う。この定義は**正の実軸で不連続**
なので、数学的には正の実数である `−γ_2(θ~)γ_2(−θ~) = |γ_2|²` が倍精度の丸めで虚部 `−0` を持つと
符号が反転する。`_prelude.sage` の `clean_real()` でその丸めを明示的に取り除いてから `sqrt` に渡している。

## 備考

- **半整数運動量で `γ_2 ≠ 0` になる理由**（本文 `gamma_2_theta_tilde_nonzero` の証明）:
  `γ_2(θ) = 0` は `sin θ = 0` かつ `c_1 cos θ = s_1 c_2` を要する。
  `sin θ~_μ = 0` は `2μ − 1 = kM` を意味し、**左辺が奇数なので `k` は奇数**、よって
  `cos θ~_μ = cos(kπ) = −1`。すると `s_1 c_2 = −c_1 < 0` が要求され、`c_1, s_1, c_2 > 0` に矛盾する。
  check_01 の (c) はこの「`sin θ~ = 0` なら必ず `cos θ~ = −1`」を全探索で確認している
  （整数運動量では `cos θ_μ = +1` の場合が残り、そこが臨界点で零点になる）。
- check_05 の対比表が示すとおり、**整数運動量では臨界点で `γ(2π) = 0`**（`γ_1(2π) = 1`）になる。
  半整数運動量側の `min γ(θ~_μ)` は同じ `K` でも `3.0e-1` 以上あり、固有値は常に分離している。
