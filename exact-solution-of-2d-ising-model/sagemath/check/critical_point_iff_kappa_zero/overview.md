## 計算の帰属と範囲

- **厳密**: 行の同値の一般の検算は `QQ` 上の 7 変数の多項式環で、両向きの倍元の差がイデアルに入ることをグレブナー基底で判定する。
  同値 f = 0 ⟺ g = 0 は、関係式の成り立つ点で f が g の倍元かつ g が f の倍元であれば成り立つ。主張は `QQ(t,u)` の有理関数体でも確かめた。
- **ℝ への脱出（`RealBallField(256)`）**: sinh・cosh の値が実数の exp の値（部分和の極限）で、K_2^* が実対数の値なので、具体値の確認だけに使う。
  K_1・K_2^* は `QQ` に取り、sinh 2K_1・cosh 2K_1・sinh 2K_2^* は本文の exp を囲むボール（`body_real_exp_ball`。部分和に尾の評価を半径として足す）から作る。
  K_2 := artanh(exp(−2K_2^*)) は `QQ` に無いので、K_2 と sinh 2K_2・cosh 2K_2 だけは Arb の関数を使い、K_2 > 0 と −(1/2) log tanh K_2 が K_2^* と重なること（`def_second_dual_coupling_constant`）を確かめた。
  許容誤差は置かない。等号はボールの重なりと差の半径が 2^{-100} 未満であること、「等号が成り立たない」はボールが 0 を含まないことで判定し、どちらにも決まらなければ失敗とする。
  臨界でない点で s_1s_2 ≠ 1 はボールが 0 を含まないことで確定し、差が 10^{-6} の点でも確定した。

## 確かめられない行と理由
