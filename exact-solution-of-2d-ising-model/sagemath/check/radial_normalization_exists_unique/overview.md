## 計算の帰属と範囲

二通りの帰属で確かめた。浮動小数点と `RR` / `CC` への脱出はない。

- **一般の点**: `x, y` を `QQ` 上の不定元とする有理関数体 `F = QQ(x,y)` の上に、二つの環を置いた。
  `V = F[rv,t]/(rv t - 1)` は `r`（`rv`）が可逆であること（`t` が `r^{-1}`）だけを持ち、
  `K = F[r]/(r^2-(x^2+y^2))` は正の平方根の定義のうち `r^2 = x^2+y^2` だけを持つ。`V` から `K` へは `rv ↦ r, t ↦ r^{-1}` で写す。
  四則・約分の行は `V`（または関係式の無い `F[rv,t]`）で、`r^2 = x^2+y^2` を使う行だけを `K` で確かめたので、
  どの行がどの関係式を使うかが検算に現れる。`K` では関係式が自動で簡約されるので、`K` の中だけで隣り合う行を比べることはしていない。
  一意性の側は `r', x_c', y_c'` を不定元とし、単位円の関係式 `(x_c')^2+(y_c')^2 = 1` で割った商環と、有理関数体 `QQ(r',X)` を使った。
  いずれも等号は厳密に決定できる。正負と大小は使わない。
- **具体の点**: 座標を `AA`（実代数的数）に取った。`AA` は可算で、平方根・四則・等号・大小がすべて厳密に決定できる。
  正の平方根の値、`r > 0`、`r' = r` のような大小と正負に依る行は、こちらでだけ確かめられる。
  前提 `x^2+y^2 ≠ 0`（存在の鎖の第四行の約分）もこちらで確かめた。
  点は座標軸上・負の座標・無理数の座標（`√2`、`∛(-3)`、`√5`）・大きさの離れた座標（`10^6` と `10^{-6}`）を含む。

主張の座標は `R` の元であり、`AA` に入らない点は検算の範囲外で、人手証明が担う。
一意性も、検算で作った組以外の組は範囲外である。

次の行は、名前を付けた値や条件を代入するだけの行なので、代入した値と行の右辺の式が一致することを確かめるに留まる:
`r x_c = r(x/r)` と `r y_c = r(y/r)`（`x_c, y_c` の定義）、存在の鎖の第一行（`x_c, y_c` の定義）、
一意性の鎖の第一行（条件 `r'x_c' = x, r'y_c' = y`）、`r'` の鎖の第二行（`r` の定義）、座標の鎖の第三行（`x_c, y_c` の定義）。

存在の鎖の第四行 `(x^2+y^2)/(x^2+y^2) = 1` は、`F` でも `AA` でも割り算が作った時点で `1` に簡約されるので、
等号そのものは自動的に成り立つ。この行で確かめているのは約分の前提 `x^2+y^2 ≠ 0`（具体の点）だけである。
ほかの行は、隣り合う行の値をそれぞれ別の式から組み、等号を比べている。
