# 構成案：複素行列環とクリフォード代数の同型

2026-10-31 の代表の依頼（Slack）による案である。複素行列版2次元イジング模型の論文
（`exact-solution-of-2d-ising-model/`）から、行列環とクリフォード代数の同型の証明だけを別の論文として切り出す。
同日の代表の指示により、**クリフォード代数と行列環の一般論として示し、具体的な全単射（逆写像を明示した同型）で証明する**。
**承認されるまで、本文・README・runbook・定期実行は作らない。**

## 抽象度：Jordan–Wigner 行列と Pauli 行列を主役にしない

Jordan–Wigner 行列 $`Z_m,Y_m`$ で準同型を作る証明は、数学として誤りではない。しかし一般論としては抽象度が合わない。

- **特定の二次空間についての主張にしかならない。** $`\mathbb{C}^{2M}`$ と $`q(v)=\sum_a v_a^2`$ と、その正規直交基底と、
  サイトの並び順を固定して初めて行列が書ける。Jordan–Wigner の弦 $`\sigma^x_1\cdots\sigma^x_{m-1}`$ は、この並び順に依存する。
- **同型の本体は、二次形式を $`W\times W^{*}\to\mathbb{C}`$ の対（ペアリング）に分けたところにある。**
  $`V=W\oplus W^{*}`$、$`q(w,f)=f(w)`$ と書くと、$`W`$ の元は生成作用素、$`W^{*}`$ の元は消滅作用素として働く。
  Jordan–Wigner 行列は、生成・消滅作用素を部分集合の基底で行列に書いたときの成分の符号
  $`(-1)^{\#\{t\in T: t<i\}}`$ を、Pauli 行列の積で書き直したものにすぎない。

したがって本文の主役は、生成・消滅作用素（Fock 表現）と、その逆写像を明示した同型とする。
Jordan–Wigner 行列と Pauli 行列は、複素行列版イジングの論文へつなぐ最後の系に置く。

係数は $`\mathbb{C}`$ に固定する（`docs/context/証明の書き方.md` の「抽象度を上げない（人手証明）」）。
一般の可換環で通ることは Lean の必要十分版で見る（生成・消滅作用素による同型は、2 の可逆性も $`i`$ も使わない見込みである）。

## クリフォード代数の定義と、行列環と同型になる範囲

**定義は ℂ 上で直接置く。実クリフォード代数から複素化する手順は使わない。**
クリフォード代数は、体 $`K`$ 上の有限次元線型空間 $`V`$ と二次形式 $`q:V\to K`$ の組ごとに、
テンソル代数 $`T(V)`$ を $`\iota(v)\iota(v)-q(v)1`$（$`v\in V`$）が生成する両側イデアルで割った商代数 $`\mathrm{Cl}(V,q)`$ として定まる。
$`K`$ は実数体である必要はない。この論文は $`K=\mathbb{C}`$ とし、$`V`$ は初めから $`\mathbb{C}`$-線型空間である。

複素化が現れるのは、実クリフォード代数 $`\mathrm{Cl}_{p,q}(\mathbb{R})`$ を分類する文脈である。
$`\mathrm{Cl}_{p,q}(\mathbb{R})\otimes_{\mathbb{R}}\mathbb{C}\cong\mathrm{Cl}(\mathbb{C}^{p+q},\sum_a v_a^2)`$ は定理であって、
複素クリフォード代数の定義ではない。$`\mathbb{C}`$ 上では $`-1`$ が平方根をもつので、符号数 $`(p,q)`$ の区別が消え、
同じ次元の非退化な二次形式はすべて等長写像で移り合う。この論文は実クリフォード代数を扱わない。

**一つの行列環と同型になるのは、$`\dim V`$ が偶数で $`q`$ が非退化のときに限る。**

| $`V`$ と $`q`$ | $`\mathrm{Cl}(V,q)`$ | 理由 |
|---|---|---|
| $`\dim V=2M`$、非退化 | $`\mathrm{Mat}(2^M,\mathbb{C})`$ | 主定理と、一般の非退化な二次空間への系 |
| $`\dim V=2M+1`$、非退化 | $`\mathrm{Mat}(2^M,\mathbb{C})\times\mathrm{Mat}(2^M,\mathbb{C})`$ | 奇数次元への系。次元 $`2^{2M+1}`$ が平方数でないので、一つの行列環とは同型にならない |
| 退化 | 行列環の直積にならない | 退化した方向の生成元が冪零で、0 でない冪零な両側イデアルを生む（本文では扱わない） |

## ゴールの主張

**主定理（分裂した二次空間）。** $`M\in\mathbb{Z}_{\ge 1}`$、$`W`$ を $`M`$ 次元の $`\mathbb{C}`$-線型空間、$`W^{*}`$ をその双対空間とし、
$`V:=W\oplus W^{*}`$ に二次形式 $`q(w,f):=f(w)`$ を置く。$`W`$ の基底 $`w_1,\dots,w_M`$ と双対基底 $`f_1,\dots,f_M`$ を一つ固定し、
$`\{1,\dots,M\}`$ の部分集合全体を $`\mathcal{P}_M`$ と書く。このとき、次の二つの写像は互いに逆な $`\mathbb{C}`$-代数の同型である。

```math
\Phi:\mathrm{Cl}(V,q)\to\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C}),\qquad
\Phi(\gamma(w_i))=c_i,\quad \Phi(\gamma(f_i))=c_i^{\mathsf T},
```

```math
\Psi:\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})\to\mathrm{Cl}(V,q),\qquad
\Psi(E_{S,T})=a^{\dagger}_S\,P\,a_T .
```

記号は次のとおりである。

- $`\gamma:V\to\mathrm{Cl}(V,q)`$ はテンソル代数への埋め込みと商代数への射影の合成。$`a^{\dagger}_i:=\gamma(w_i)`$、$`a_i:=\gamma(f_i)`$。
- $`c_i\in\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})`$ は生成作用素の行列：$`i\notin T`$ なら $`(c_i)_{T\cup\{i\},T}=(-1)^{\#\{t\in T:t<i\}}`$、他の成分は 0。
- $`E_{S,T}`$ は行列単位。$`a^{\dagger}_S:=a^{\dagger}_{s_1}\cdots a^{\dagger}_{s_k}`$（$`s_1<\dots<s_k`$）、$`a_T:=a_{t_l}\cdots a_{t_1}`$（$`t_1<\dots<t_l`$、逆順）。
- $`P:=a_1a^{\dagger}_1\,a_2a^{\dagger}_2\cdots a_Ma^{\dagger}_M\in\mathrm{Cl}(V,q)`$（真空への射影にあたる元）。

**系（一般の非退化な二次空間）。** $`2M`$ 次元の $`\mathbb{C}`$-線型空間上の非退化な二次形式は、
$`W\oplus W^{*}`$ と $`q(w,f)=f(w)`$ の形に、名前を付けた等長写像で移せる。したがってそのクリフォード代数も
$`\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})`$ と同型である（ここで $`\mathbb{C}`$ の平方根の存在を使う。$`\mathbb{R}`$ への脱出は無い）。

**系（奇数次元）。** $`V':=V\oplus\mathbb{C}u`$、$`q'(v+tu):=q(v)+t^2`$ とする。
$`\varepsilon:=\prod_{i=1}^{M}(a_ia^{\dagger}_i-a^{\dagger}_ia_i)`$ と置くと、$`z:=\varepsilon\,\gamma'(u)`$ は $`\mathrm{Cl}(V',q')`$ の中心に入り $`z^2=1`$ を満たす。
次の二つの写像は互いに逆な $`\mathbb{C}`$-代数の同型である（$`j:\mathrm{Cl}(V,q)\to\mathrm{Cl}(V',q')`$ は包含 $`V\to V'`$ が誘導する準同型）。

```math
\Phi':\mathrm{Cl}(V',q')\to\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})\times\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C}),\qquad
\Phi'(\gamma'(v))=(\Phi(\gamma(v)),\Phi(\gamma(v))),\quad \Phi'(\gamma'(u))=(\Phi(\varepsilon),-\Phi(\varepsilon)),
```

```math
\Psi'(X,Y):=j(\Psi(X))\,\tfrac12(1+z)+j(\Psi(Y))\,\tfrac12(1-z).
```

$`\Phi(\varepsilon)`$ は対角行列 $`\mathrm{diag}((-1)^{\#T})_{T\in\mathcal{P}_M}`$ である。2 で割るのはここだけである。

**系（複素行列版イジングの記号）。** $`(\mathbb{C}^{2M},\sum_a v_a^2)`$ の場合に、等長写像と添字の番号付け
$`\mathcal{P}_M\to\{1,\dots,2^M\}`$ を合成すると、$`e_m,e_{M+m}`$ の像が Jordan–Wigner 行列 $`Z_m,Y_m`$ になる。

## 証明の経路：逆写像を明示する

1. **$`\Phi`$ の存在と一意性。** 行列 $`c_i`$ と $`c_i^{\mathsf T}`$ が反交換関係
   $`c_ic_j^{\mathsf T}+c_j^{\mathsf T}c_i=\delta_{ij}I`$、$`c_ic_j+c_jc_i=0`$、$`c_i^{\mathsf T}c_j^{\mathsf T}+c_j^{\mathsf T}c_i^{\mathsf T}=0`$
   を満たすことを成分で計算し、クリフォード代数の普遍性で $`\Phi`$ を得る。
2. **クリフォード代数の中の三つの等式。** 反交換関係だけから次を示す。
   - $`P\,a_T\,a^{\dagger}_U\,P=\delta_{T,U}\,P`$
   - $`\sum_{S\in\mathcal{P}_M}a^{\dagger}_S\,P\,a_S=1`$
   - $`a_i\,P=0`$、$`P\,a^{\dagger}_i=0`$
3. **$`\Psi`$ が代数の準同型であること。** 行列単位の積の規則 $`E_{S,T}E_{U,R}=\delta_{T,U}E_{S,R}`$ と $`\sum_SE_{S,S}=I`$ が、
   2 の一つ目と二つ目の等式で保たれる。
4. **$`\Phi\circ\Psi=\mathrm{id}`$。** $`\Phi(a^{\dagger}_S P a_T)=E_{S,T}`$ を成分で計算する。
5. **$`\Psi\circ\Phi=\mathrm{id}`$。** $`\Psi\circ\Phi`$ は代数の準同型なので、生成元 $`\gamma(w_i)`$、$`\gamma(f_i)`$ で一致すれば全体で一致する。
   生成元での一致は、2 の二つ目の等式（$`1`$ の分解）を左から掛けて示す。

**単調な語が張ること、像の線型独立、次元の比較は、どれも使わない。** 系として、
$`a^{\dagger}_SPa_T`$ の $`4^M`$ 個が $`\mathrm{Cl}(V,q)`$ の基底になることが従う（$`\Psi`$ が行列単位を移すため）。

$`\mathbb{Z}/2`$ の次数付け（$`\mathrm{Cl}(V\oplus V')\cong\mathrm{Cl}(V)\mathbin{\hat\otimes}\mathrm{Cl}(V')`$ で次元を剥がす経路）も使わない。
次数付きテンソル積と、$`\mathrm{Mat}_a\otimes\mathrm{Mat}_b\cong\mathrm{Mat}_{ab}`$ などの同型を何段も要し、
そのそれぞれが暗黙の同一視の置き場になるためである。

## 章立て

並びは上から順である。

### 数学的道具立て

- **環。** 単位元をもつ環の公理、環の準同型。
- **$`\mathbb{C}`$-線型空間。** 公理、線型写像、双対空間と双対基底、直和。
- **$`\mathbb{C}`$-代数（多元環）。** 環の構造と線型空間の構造の組で、両立条件 $`\lambda(xy)=(\lambda x)y=x(\lambda y)`$ を満たすもの。
  代数の準同型は、環の準同型かつ線型写像であるもの。部分集合が代数を生成すること、
  生成元で一致する二つの準同型は等しいこと。
- **代数を環・線型空間として見るときの記号の規則。** 代数 $`A`$ から、その環 $`U_{\mathrm{ring}}(A)`$ と
  線型空間 $`U_{\mathrm{vec}}(A)`$ を取り出す写像に名前を付け、以後はこの写像を通してだけ行き来する。
  演算と単位元には $`+_A,\ \cdot_A,\ 1_A`$ のように属する代数を添字で書く。「$`A`$ を環とみなす」と書かない。
- **両側イデアル、生成されるイデアル、商代数。** 商代数は同値関係による商集合として作り、射影 $`\pi`$ に名前を付ける。
  商代数の普遍性（イデアル上で 0 になる準同型は、射影を通してただ一つに分解する）。
- **テンソル積。** $`k`$ 個のテンソル積 $`V^{\otimes k}`$ を、$`k`$ 重線型写像についての普遍性で定義し、その存在を構成で示す。
  二項のテンソル積を繰り返して作らないので、$`(V\otimes V)\otimes V`$ と $`V\otimes(V\otimes V)`$ の同一視が生じない。
- **テンソル代数。** $`T(V):=\bigoplus_{k\ge0}V^{\otimes k}`$ と、その積。積 $`V^{\otimes k}\times V^{\otimes l}\to V^{\otimes(k+l)}`$ は
  $`k+l`$ 重線型写像の普遍性で定め、結合法則は純テンソルで確かめる。埋め込み $`\iota:V\to T(V)`$ に名前を付け、
  $`V`$ を $`T(V)`$ の部分集合とみなさない。テンソル代数の普遍性（線型写像 $`V\to A`$ は、代数の準同型 $`T(V)\to A`$ にただ一つに延びる）。
- **二次形式。** 二次形式と付随する対称双線型形式、非退化性、等長写像。

### 複素行列環

- 行と列の添字を有限集合 $`S`$ の元にとる行列の代数 $`\mathrm{Mat}_S(\mathbb{C})`$ と、代数の公理の確認。
- 行列単位 $`E_{S,T}`$ と、その積の規則、単位行列の分解。
- 添字の番号付け $`\mathcal{P}_M\to\{1,\dots,2^M\}`$ を名前を付けた全単射として定義し、
  $`\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})`$ から $`\mathrm{Mat}(2^M,\mathbb{C})`$ への代数の同型を示す。

### クリフォード代数

- $`\mathrm{Cl}(V,q):=T(V)/I_q`$。$`I_q`$ は $`\iota(v)\iota(v)-q(v)1`$（$`v\in V`$）が生成する両側イデアル。$`\gamma:=\pi\circ\iota`$。
- クリフォード代数の普遍性（$`f(v)^2=q(v)1_A`$ を満たす線型写像は、代数の準同型にただ一つに延びる）。
- $`\gamma(V)`$ が $`\mathrm{Cl}(V,q)`$ を生成すること。
- 分裂した二次空間 $`W\oplus W^{*}`$ での反交換関係
  $`a_ia^{\dagger}_j+a^{\dagger}_ja_i=\delta_{ij}1`$、$`a_ia_j+a_ja_i=0`$、$`a^{\dagger}_ia^{\dagger}_j+a^{\dagger}_ja^{\dagger}_i=0`$（$`q`$ を偏極して示す）。

### 同型の証明

- 生成作用素の行列 $`c_i`$ と、その反交換関係。
- 証明の経路の 1 から 5 を、この順に一つずつブロックにする。最後のブロックに主定理を置く。
- 一般の非退化な二次空間への系（等長写像の構成）。
- 奇数次元への系（中心の元 $`z`$ による分解と、逆写像 $`\Psi'`$）。
- 複素行列版イジングの記号への系（Jordan–Wigner 行列が現れること）。

## 記述と検証の方針

- 記述は `docs/context/証明の書き方.md` に従う。特に「同一視をしない」を全章に適用し、
  二つの集合の元を行き来するときは必ず名前を付けた写像を通す。

  $`\mathbb{R}`$ への脱出は無い。

  $`\Phi(\Psi(E_{S,T}))=E_{S,T}`$ を厳密計算で確かめる（2026-10-31 に $`M=3`$ で浮動小数点の予備計算は通った）。

  必要十分版は同じ手順のまま、係数の環に要る性質だけを仮定する。

## 採らなかった経路

  （この構成案の最初の版）。$`(\mathbb{C}^{2M},\sum_a v_a^2)`$ と基底の並び順を固定した主張にしかならず、
  一般論の抽象度に合わないため採らない。逆写像も明示されない。
