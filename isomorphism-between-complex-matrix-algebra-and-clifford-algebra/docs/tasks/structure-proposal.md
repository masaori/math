# 構成案：複素行列環とクリフォード代数の同型

2026-10-31 の代表の依頼（Slack）による案である。複素行列版2次元イジング模型の論文
（`exact-solution-of-2d-ising-model/`）から、行列環とクリフォード代数の同型の証明だけを別の論文として切り出す。
**承認されるまで、本文・README・runbook・定期実行は作らない。**

## ゴールの主張

$`M\in\mathbb{Z}_{\ge 1}`$ を固定する。$`V_M:=\mathbb{C}^{2M}`$ に標準基底 $`e_1,\dots,e_{2M}`$ と二次形式
$`q_M(v):=\sum_{a=1}^{2M}v_a^2`$ を置き、クリフォード代数を $`\mathrm{Cl}(V_M,q_M)`$、その生成元を
$`\gamma_M:=\pi_M\circ\iota_M:V_M\to\mathrm{Cl}(V_M,q_M)`$（$`\iota_M`$ は $`V_M`$ からテンソル代数への埋め込み、
$`\pi_M`$ は商代数への射影）と書く。

```math
\exists!\ \Phi_M:\mathrm{Cl}(V_M,q_M)\to\mathrm{Mat}_{\{0,1\}^M}(\mathbb{C})\ \text{（$\mathbb{C}$-代数の準同型）},\quad
\Phi_M(\gamma_M(e_m))=Z_m,\quad \Phi_M(\gamma_M(e_{M+m}))=Y_m\quad(1\le m\le M),
```

かつ $`\Phi_M`$ は全単射である。$`Z_m:=\sigma^x_1\cdots\sigma^x_{m-1}\sigma^z_m`$、$`Y_m:=\sigma^x_1\cdots\sigma^x_{m-1}\sigma^y_m`$
は複素行列版イジングの論文と同じ Jordan–Wigner 行列である。
系として、単調な語 $`\gamma_M(e_{a_1})\cdots\gamma_M(e_{a_r})`$（$`a_1<\dots<a_r`$）の $`2^{2M}`$ 個が
$`\mathrm{Cl}(V_M,q_M)`$ の基底になる。

## 証明の経路：$`\mathbb{Z}/2`$ の次数付けを使わない

以前の証明は、クリフォード代数が $`\mathbb{Z}/2`$-次数付き代数であることを使っていた。
典型的には $`\mathrm{Cl}(V\oplus W)\cong\mathrm{Cl}(V)\mathbin{\hat\otimes}\mathrm{Cl}(W)`$（次数付きテンソル積）で次元を一つずつ剥がす。
この経路は、次数付きテンソル積という新しい構造と、$`\mathrm{Mat}_a\otimes\mathrm{Mat}_b\cong\mathrm{Mat}_{ab}`$ などの
同型を何段も要し、そのそれぞれが暗黙の同一視の置き場になる。

**本案は、Jordan–Wigner 行列で直接に準同型を作り、行列の側の計算だけで全単射を示す。**

1. **準同型の存在と一意性。** 線型写像 $`f_M:V_M\to\mathrm{Mat}`$ を $`e_m\mapsto Z_m`$、$`e_{M+m}\mapsto Y_m`$ で定め、
   $`f_M(v)^2=q_M(v)I`$ を反交換関係から示す。クリフォード代数の普遍性で $`\Phi_M`$ が一つだけ得られる。
2. **単調な語がクリフォード代数を張ること。** 反交換関係による並べ替えで、任意の語が単調な語の線型結合に書ける
   （クリフォード代数の側の議論はここだけで、線型独立はここでは示さない）。
3. **単調な語の像が Pauli 行列の積に符号 $`\pm1,\pm i`$ を掛けたものであること。** 単調な語と
   $`\{I,\sigma^x,\sigma^y,\sigma^z\}^M`$ の間の全単射を、名前を付けた写像として定義する。
4. **Pauli 行列の積の $`4^M`$ 個が行列環の基底であること。** 線型独立はトレースの直交性
   $`\mathrm{tr}(P\,Q^{*})=2^M\delta_{P,Q}`$ で、張ることは行列単位を各サイトの $`2\times2`$ の行列単位の積に分けて示す。
5. **全単射。** 単射は「2 で書いた線型結合の像が 0 なら、4 の線型独立で係数が全部 0」から、
   全射は「像が 4 の基底を全部含む」から従う。**次元の一般論（階数・退化次数の定理）を使わない。**

次数付けの経路は、捨てずに参照用ノートへ移し、採らなかった理由を書く。

## 章立て

並びは上から順である。

### 数学的道具立て

- **環。** 単位元をもつ環の公理、環の準同型。
- **$`\mathbb{C}`$-線型空間。** 公理、線型写像、線型結合、線型独立、張ること。
- **$`\mathbb{C}`$-代数（多元環）。** 環の構造と線型空間の構造の組で、両立条件 $`\lambda(xy)=(\lambda x)y=x(\lambda y)`$ を満たすもの。
  代数の準同型は、環の準同型かつ線型写像であるもの。
- **代数を環・線型空間として見るときの記号の規則。** 代数 $`A`$ から、その環 $`U_{\mathrm{ring}}(A)`$ と
  線型空間 $`U_{\mathrm{vec}}(A)`$ を取り出す写像に名前を付け、以後はこの写像を通してだけ行き来する。
  演算と単位元には $`+_A,\ \cdot_A,\ 1_A`$ のように属する代数を添字で書く。「$`A`$ を環とみなす」と書かない。
- **両側イデアル、生成されるイデアル、商代数。** 商代数は同値関係による商集合として作り、射影 $`\pi`$ に名前を付ける。
  商代数の普遍性（イデアル上で 0 になる準同型は、射影を通してただ一つに分解する）。
- **テンソル積。** 基底 $`e_1,\dots,e_n`$ をもつ線型空間の $`k`$ 個のテンソル積を、長さ $`k`$ の語
  $`(a_1,\dots,a_k)\in\{1,\dots,n\}^k`$ を基底とする線型空間として**構成する**。
  多重線型写像の普遍性はこの構成についての定理として示す。
  $`(V\otimes V)\otimes V`$ と $`V\otimes(V\otimes V)`$ の同一視が起きないよう、積は語の連結で定める（連結は結合的なので、括弧の付け替えの同型が要らない）。
- **テンソル代数。** すべての長さの語を基底とし、語の連結を積とする代数 $`T(V)`$。
  埋め込み $`\iota:V\to T(V)`$ に名前を付け、$`V`$ を $`T(V)`$ の部分集合とみなさない。
  テンソル代数の普遍性（線型写像 $`V\to A`$ は、代数の準同型 $`T(V)\to A`$ にただ一つに延びる）。

### 複素行列環

- 行と列の添字を有限集合 $`S`$ の元にとる行列の代数 $`\mathrm{Mat}_S(\mathbb{C})`$ と、代数の公理の確認。
- $`S=\{0,1\}^M`$ をとり、Pauli 行列と、サイトごとの Pauli 行列の積を成分の積の式で直接定義する
  （クロネッカー積と、その結合性の同一視を経由しない）。
- Jordan–Wigner 行列 $`Z_m,Y_m`$ と、その反交換関係。
- 添字の番号付け $`\{0,1\}^M\to\{1,\dots,2^M\}`$ を名前を付けた全単射として定義し、
  $`\mathrm{Mat}_{\{0,1\}^M}(\mathbb{C})`$ から $`\mathrm{Mat}(2^M,\mathbb{C})`$ への代数の同型を示す
  （複素行列版イジングの論文の記号とつなぐため）。

### クリフォード代数

- $`\mathrm{Cl}(V_M,q_M):=T(V_M)/I_{q_M}`$。$`I_{q_M}`$ は $`\iota(v)\iota(v)-q_M(v)1`$（$`v\in V_M`$）が生成する両側イデアル。
- 同じイデアルが、有限個の $`\iota(e_a)\iota(e_b)+\iota(e_b)\iota(e_a)-2\delta_{ab}1`$ で生成されること（両包含で示す。2 で割る操作は要らない）。
- クリフォード代数の普遍性（$`f(v)^2=q(v)1_A`$ を満たす線型写像は、代数の準同型にただ一つに延びる）。
- 単調な語が $`\mathrm{Cl}(V_M,q_M)`$ を張ること。

### 同型の証明

- 証明の経路の 1 から 5 を、この順に一つずつブロックにする。
- 最後のブロックにゴールの主張と、単調な語が基底になるという系を置く。

## 記述と検証の方針

- 記述は `docs/context/証明の書き方.md` に従う。特に「同一視をしない」を全章に適用し、
  二つの集合の元を行き来するときは必ず名前を付けた写像を通す。
- 数の住処：係数はすべて $`\mathbb{C}`$ の元として書く。実際に現れる係数は $`\mathbb{Z}[i]`$ に収まり、
  $`\mathbb{R}`$ への脱出は無い。何が本質的に要るか（$`i`$ の存在、2 の可逆性が不要なこと）は Lean の必要十分版で見る。
- SageMath：$`M=1,2,3`$ で、反交換関係、単調な語の像、トレースの直交性、行列単位の展開を厳密計算（`QQbar`）で確かめる。
- Lean：具体版は人手証明と1対1に対応させ、mathlib の `CliffordAlgebra` の一般論へ委ねない。
  必要十分版は同じ手順のまま、係数の環に要る性質だけを仮定する。
