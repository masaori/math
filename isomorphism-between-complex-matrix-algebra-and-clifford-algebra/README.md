## ゴール

**ℂ 上の偶数次元の非退化な二次空間のクリフォード代数が、複素行列環と同型であることを、逆写像を明示した全単射として示す。**

- 主定理は、分裂した二次空間 $`V=W\oplus W^{*}`$、$`q(w,f)=f(w)`$ について述べる。
  同型 $`\Phi:\mathrm{Cl}(V,q)\to\mathrm{Mat}_{\mathcal{P}_M}(\mathbb{C})`$ を生成・消滅作用素の行列で作り、
  逆写像 $`\Psi(E_{S,T})=a^{\dagger}_SPa_T`$ を式で与え、$`\Phi\circ\Psi`$ と $`\Psi\circ\Phi`$ が恒等写像であることを示す。
- 系として、一般の偶数次元の非退化な二次空間、奇数次元（行列環二つの直積）、
  複素行列版イジングの論文の Jordan–Wigner 行列への接続を置く。
- 単調な語が張ること、像の線型独立、次元の比較、$`\mathbb{Z}/2`$ の次数付けは使わない。

## 記述の規約（この論文の核）

この論文を別に立てた理由は、**世の中の証明が暗黙の同一視を多く含み、読めない**ことにある。したがって次を全章に適用する。

- **同一視をしない。** 「$`A`$ の元を $`B`$ の元とみなす」と書かない。行き来には名前を付けた写像を通す
  （例: $`\iota:V\to T(V)`$、$`\pi:T(V)\to\mathrm{Cl}(V,q)`$、$`\gamma:=\pi\circ\iota`$、包含が誘導する $`j`$）。
- **演算と単位元には、属する構造を添字で書く**（$`+_A,\ \cdot_A,\ 1_A`$）。代数から環・線型空間を取り出すときは、
  取り出す写像に名前を付け、その写像を通してだけ行き来する。
- **テンソル積を二項の繰り返しで作らない。** $`V^{\otimes k}`$ は $`k`$ 重線型写像の普遍性で定義し、
  括弧の付け替えの同型が要らない形にする。
- **係数は ℂ に固定する。** 一般の可換環へ持ち上げない（`docs/context/証明の書き方.md` の「抽象度を上げない（人手証明）」）。
  何が本質的かは Lean の必要十分版で見る。極限・完備性は使わないので、ℝ への脱出は無い。
- 式変形・根拠・1 ブロック 1 主張は `docs/context/証明の書き方.md` に従う。

- SageMath: 行列の計算は $`M=1,2,3`$ で厳密計算して確かめる。検証は `sagemath/check/<対象名>/overview.md` に対象ラベルを書く。

  mathlib の `CliffordAlgebra` の一般論へ委ねない。
