# SageMath 検算: 因果集合の一次文献との照合

## 対象

**対象ラベル**: `claim_event_order_locally_finite`

- 検証範囲: 反射的到達可能関係の部分順序性、一次文献の区間の有限性、一次文献の区間と前章の区間の集合としての一致
- 全数範囲: $|V|\leq2$、$0\leq\tau\leq2$ の隣接時刻間の全ての関係

## チェック一覧

| ファイル | 検証内容 | ステータス | 結果 |
| --- | --- | --- | --- |
| `check_partial_order.sage` | 反射的到達可能関係が反射的・反対称的・推移的である | PASS | 283 関係で成立 |
| `check_local_finiteness.sage` | 一次文献の各区間がイベント集合の部分集合であり有限である | PASS | 283 関係の 9,521 区間で成立 |
| `check_interval_equality.sage` | 一次文献の区間と前章の区間が集合として一致する | PASS | 283 関係の 9,521 区間で一致 |

## 限界と帰属

- 全数検査は上記の有限範囲に限られ、一般の有限舞台・任意の $\tau\in\mathbb{N}$ に対する証明ではない。一般の場合の根拠は構造化記述の人手証明である。
- 検査対象を CA から得る関係より広い「隣接時刻間の任意の有限関係」とした。人手証明がこの章で使うのは、既証明の部分順序性とイベント集合・区間の有限性だけである。
- 一次文献の区間と前章の区間は、同じ所属条件を別々の手続きで評価して集合の等号を検査する。
- 全て有限集合、有限関係、非負整数の等号・大小比較として厳密に検査する。浮動小数点と $\mathbb{R}/\mathbb{C}$ 脱出はない。
