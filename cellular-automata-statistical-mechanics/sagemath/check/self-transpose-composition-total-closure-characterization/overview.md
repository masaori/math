# SageMath 検算: 自己転置な近傍割り当て全体の合成閉性の特徴づけ

## 対象

**対象ラベル**: `claim_all_self_transpose_assignments_composition_closed_iff_subsingleton`

- 併せて検証するラベル:
  `def_all_self_transpose_assignments_composition_closed`、
  `claim_self_transpose_iff_symmetric_membership`、
  `claim_self_transpose_composition_iff_commute`、
  `def_composed_neighborhood`
- 本文の二つの向き（相異なる二元を持つ舞台での非閉性、舞台元数が一以下のときの閉性）と、
  特徴づけそのものの有限決定を別々の検算に分け、最終式だけの一致で済ませない。

## 検証範囲

- 証人の自己転置性と非閉性の検算は `|V| = 2, 3, 4, 5` の全ての相異なる順序対 `(a, b)` 40 組を尽くす。
  所属条件の検査は 754 件である。
- `Closed_st(V)` の全走査による判定は `|V| = 0, 1, 2, 3` である。自己転置な割り当てはそれぞれ
  1、2、8、64 個で、その順序対を全て走った。`|V| = 4` は順序対が 1,048,576 組になるため走査せず、
  列挙の一致と個数 1,024 だけを検査した。
- `|V| >= 6` の証人検査と `|V| >= 4` の全走査は行っていない。したがってこれらは有限範囲の全数検査で
  あって、任意の有限舞台に対する一般証明ではない。一般の場合の根拠は構造化記述である。

## 走査で分かったこと（本文の記述との差）

- 合成が自己転置になる（＝可換な）自己転置割り当ての順序対の個数は、`|V| = 0, 1, 2, 3` で
  それぞれ 1、4、42、1,204 である。`|V| <= 1` では順序対の全てが可換で、`|V| >= 2` では真に少ない。
  本文の特徴づけと一致する。
- 本文の記述に修正を要する差は見つからなかった。

## 限界と帰属

- 有限集合、有限部分集合、有限写像表、`ZZ` の等号だけを使う。浮動小数点と `R/C` 脱出はない。
- 有限決定は判定の手続き（合成の各セルで高々 `|V|` 項の合併、自己転置性の判定で `|V|` 個の値の比較）
  まで検査したものであり、計算コストモデルそのものは検査していない。
