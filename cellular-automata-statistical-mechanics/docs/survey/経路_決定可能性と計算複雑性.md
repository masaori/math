# 経路: 決定可能性と計算複雑性

**一言**: CA の側には「何が決定可能で何が不能か」の精密な地図が既にある。
統計力学の側にはそれがない。**この地図をそのまま統計力学の量に翻訳すれば、
`docs/context/` の決定可能性の梯子に物理的な目盛りが入る。**

## 統計力学への翻訳（本プロジェクトの狙い）

CA の時空図は $\{0,1\}$ 重みの格子模型の配位である（[全体像_接続経路の地図](全体像_接続経路の地図.md) 「CA の時空図 ＝ 1 次元高い格子模型の配位」節）。
したがって上表は次のように読み替わる。

| CA 側の問題 | 統計力学側の対応 | 帰属 |
|---|---|---|
| SFT の非空性（domino problem） | **分配関数が $Z>0$ か** | **決定不能**（2 次元） |
| 位相的エントロピー | **自由エネルギー密度** | 決定不能（一般） |
| 位相的エントロピー（線形 CA） | 同上 | **$\Lambda$ 値・決定可能** |
| 可逆性 | ユニタリ性・detailed balance | 決定可能（1 次元） |
| 加法的保存量 | 保存カレント | 決定可能 |
| YB 写像／双ユニタリ性 | **可積分性・可解性** | **決定可能（有限検査）** |

### 際立つ 2 点

**(i) 「分配関数が非零か」が決定不能。**
Berger の結果は、$\{0,1\}$ 重みの 2 次元格子模型について
「$Z>0$ か $Z=0$ か」が決定不能であることを意味する。
これは統計力学の最も素朴な量が、可算・有限データから出発しても計算不能になり得ることを示す。
**`docs/context/` の梯子でいえば、$\mathbb{R}$ 脱出とは別種の壁**である
（非可算性ではなく計算不能性による壁）。この区別は本リポジトリの台帳にまだ載っていない。

**(ii) 「可解性」が決定可能な述語になる。**
通常の可積分性は「スペクトルパラメータ $u\in\mathbb{C}$ の族が YBE を満たす」という
連続体上の条件だが、CA（有限集合上の写像）に落とすと
**有限個の等式の検査**になる（「可積分CA」の経路 「際立つ 2 点」節、「可解な決定論的CA」の経路 §3.1）。
「解ける模型かどうか」が有限記号操作で判定できる——
これは [`docs/research/有限記号操作で証明可能な分野.md`](../../../docs/research/有限記号操作で証明可能な分野.md) の
関心事に直接該当する。

## 複雑性（決定可能なものの中での階層）

| 量 | 複雑性 |
|---|---|
| $Z_N=\operatorname{Tr}T^N$ の値（$T$ 固定、$N$ 与えられる） | $O(\log N)$ 回の行列積（繰り返し二乗法） |
| 指定した $p$ の $v_p(Z_N)$ | $\bmod p^k$ 漸化で多項式時間、周期後 $O(1)$ |
| $\Phi_N\in\Lambda$ の**全座標**（＝$Z_N$ の完全素因数分解） | 超多項式（GNFS） |
| 傾き $M$（Newton 多角形） | 多項式時間、$N$ 非依存 |
| 初等 CA 256 個に対する各種有限検査 | 定数時間 |

（`R-Lambda-duality/README.md` §8.6 末尾の計算量の注意と同じ構図。
**決定可能性は素因数分解を経由しない**：素点ごとのアクセスは安い。）

## 「$\mathbb{R}$ 脱出」と「計算不能性」は別の壁

本プロジェクトで区別すべき 3 種類の壁：

| 壁 | 原因 | 例 |
|---|---|---|
| **「ℝ脱出の壁」: $\mathbb{R}$ 脱出** | 非可算集合・完備性 | 自由エネルギー $\log_{\mathbb{R}}\lambda_{\max}$、臨界指数 |
| **「計算不能性の壁」: 計算不能性** | 停止問題への帰着 | domino problem、一般 CA のエントロピー |
| **「計算量の壁」: 計算量** | 決定可能だが高コスト | $Z_N$ の完全素因数分解 |

- 「ℝ脱出の壁」は `docs/context/ℝ脱出の台帳と判定手順.md` の台帳が扱う。
- **「計算不能性の壁」は台帳にまだ無い。** 可算・有限データの中に閉じているのに計算不能、という壁は
  $\mathbb{R}$ 脱出とは独立で、CA 側に豊富な実例がある。
- 「計算量の壁」は決定可能性を損なわない（素点ごとのアクセスで回避できる）。

**提案**: `docs/context/ℝ脱出の台帳と判定手順.md` の脱出台帳に、「計算不能性の壁」の欄を追加する。
CA の表がそのまま統計力学の量の表になるので、実例には困らない（→ 種「二つの壁は独立」）。

## この経路の空白

1. **CA の決定可能性の表を統計力学の量の表として書き直した文献がない。**
   個々の対応（domino problem ↔ 敷き詰め）は知られているが、
   「自由エネルギー・分配関数・可解性」という物理の語彙での整理は無い。
2. **決定可能／不能の境界が、線形性（＝群環の可換性）で切れている**という観察が、
   統計力学側の「可解／非可解」の境界と対応するかは未検討。
3. **「ℝ脱出の壁」と 「計算不能性の壁」の関係が問われていない。** 「$\mathbb{R}$ 脱出のない量は決定可能か」は偽
   （一般 CA のエントロピーは $\Lambda$ 的な設定でも計算不能）。逆も偽。
   この 2 つの壁の独立性を明示的に述べた命題は見当たらない。
