## 調査の限界（正直な記載）

- 調査は **Web 検索による書誌・要旨レベル**である。[文献表.md](文献表.md) の「状態」列で
  要旨確認済／未読を区別してある。**原論文を精読した上での主張は、現時点では一つもない。**
- したがって「空白である」という記述は「見つからなかった」の意味であり、
  存在しないことの証明ではない。種を命題へ昇格させる前に、
  該当分野の一次文献にあたって重複を潰す必要がある。
- 特に精読が必要なもの: D'Amico–Manzini–Margara（線形 CA のエントロピー公式の正確な形）、
  Gross–Nesme–Vogts–Werner（指数の定義の正確な形と値域）、Rujàn（既に何が対応づけられているか）。
