# docs/survey — 既存研究の網羅調査

「2 値セルオートマトンの規則 ↔ 統計力学／場の量子論の代数構造」に関する既存研究を、
**互いにほとんど交流のない独立した接続経路**として整理したもの。

**探索は二相に分かれる。** 第一相は CA 側から出発して代数構造をカタログ化する（物理を見ない）。
第二相でそれを物理側と突き合わせる。物理起点で始めると確証バイアスで探索が狭くなるため。

まず [CAから出発する代数構造の探索.md](CAから出発する代数構造の探索.md)（**第一相の枠組み・中心文書**）、
次に [連続物理の可算な担い手.md](連続物理の可算な担い手.md)（第二相の台帳）を読む。
経路別の調査（下表の後半）は物理起点で行った最初の調査であり、**第二相の資産**である。

## 調査の限界（正直な記載）

- 調査は **Web 検索による書誌・要旨レベル**である。[文献表.md](文献表.md) の「状態」列で
  要旨確認済／未読を区別してある。**原論文を精読した上での主張は、現時点では一つもない。**
- したがって「空白である」という記述は「見つからなかった」の意味であり、
  存在しないことの証明ではない。種を命題へ昇格させる前に、
  該当分野の一次文献にあたって重複を潰す必要がある。
- 特に精読が必要なもの: D'Amico–Manzini–Margara（線形 CA のエントロピー公式の正確な形）、
  Gross–Nesme–Vogts–Werner（指数の定義の正確な形と値域）、Rujàn（既に何が対応づけられているか）。
