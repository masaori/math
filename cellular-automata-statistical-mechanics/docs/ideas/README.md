## 種に書くべき 4 項目（新しい種を追加するときの書式）

1. **主張の骨子** — 何を主張するのか。1 段落。
2. **なぜ可算側か** — 登場する量の帰属（$\mathbb{N}/\mathbb{Q}/\Lambda/\overline{\mathbb{Q}}/\mathbb{R}$）と、
   $\mathbb{R}$ 脱出があるならその型（E0–E4）。
3. **最初の検算** — 具体的に何を計算すれば真偽の手がかりが得られるか。コストの見積もり。
4. **潰れ方** — どう間違っていそうか。既存研究との重複可能性。反例が出たときに何が残るか。

**4 を書けない種は種として弱い。** 「潰れ方が書けない」＝「反証可能な形になっていない」。
