# 種 S1 — CA の $\Lambda$ 値不変量は三つの顔を持つ

**概念的な中心。** リポジトリの哲学（可算コア）が、物理側から独立に支持されていることを示す種。

## 1. 三つの量

一つの CA 規則 $F$ に対して、互いに独立な文脈で定義された 3 つの量がある。
**いずれも $\Lambda$（または $\Lambda\otimes\mathbb{Q}$）に値をとり、$\mathbb{R}$ 脱出を含まない。**

### (1) GNVW 指数（情報流のカイラリティ）

可逆 CA を QCA として実装したときの指数

$$
\operatorname{ind}(F)\in\mathbb{Q}_{>0},\qquad \log\operatorname{ind}(F)\in\Lambda .
$$

- 合成について乗法的 ⇒ $\log\operatorname{ind}$ は群準同型 $\{\text{1D QCA}\}\to\Lambda$。
- $\operatorname{ind}=1\iff$ 有限深さ回路。**1 次元では完全不変量**（安定同値の分類）。
- 局所次元 $d$ の一様鎖では $\operatorname{ind}$ の素因数は $d$ の素因数に限る。
  **2 値 CA なら $\operatorname{ind}\in 2^{\mathbb{Z}}$、すなわち $\log\operatorname{ind}\in\mathbb{Z}\ell_2$。**（要一次文献確認）
- シフト $\sigma$ について $\operatorname{ind}(\sigma)=2$、$\log\operatorname{ind}(\sigma)=\ell_2$。

### (2) 位相的エントロピー（線形 CA の場合）

$\mathbb{Z}_m$ 上の線形 CA について閉じた公式があり、値は $m$ の素因数にわたる $\log p$ の
非負整数結合、すなわち

$$
h(F)=\rho\Big(\sum_{p\mid m}c_p\,\ell_p\Big),\qquad c_p\in\mathbb{Z}_{\ge0}.
$$

（$\rho:\Lambda\to\mathbb{R}$ は実現写像。要一次文献確認 → [`survey/06`](../survey/06_経路F_代数力学_群環とMahler測度.md) §4）

- シフト $\sigma$ について $h(\sigma)=\log2=\rho(\ell_2)$。
- **一般の（非線形）CA では $h$ は計算不能**（Hurd–Kari–Culik）。

### (3) $\Phi_N$ の傾き

有限環 $\mathbb{Z}/L$ 上の分配関数 $Z_N=\operatorname{Tr}T^N$ に対し

$$
M(F)=\sum_p\mu_{\min}(p)\,\ell_p\in\Lambda\otimes\mathbb{Q},\qquad
\Phi_N=N\cdot M+R(N).
$$

- 可逆 CA では $M=0$（種 S6 命題 2）。
- Newton 多角形で計算、$\mathbb{R}$ 不使用。

## 2. 観察：シフトでは (1) と (2) が一致する

$$
\log\operatorname{ind}(\sigma)=\ell_2,\qquad h(\sigma)=\log 2=\rho(\ell_2).
$$

すなわち $h(\sigma)=\rho\big(\log\operatorname{ind}(\sigma)\big)$。恒等写像でも両辺 $0$ で一致する。

**問い**: 一般の可逆 CA $F$ について $h(F)-\rho(\log\operatorname{ind}(F))$ は何を測るか。

## 3. 予想される構造：符号つき量 vs 符号なし量

指数とエントロピーは、どちらも「情報の流れ」を測るが性質が正反対である：

| | GNVW 指数 $\operatorname{ind}$ | 位相的エントロピー $h$ |
|---|---|---|
| 符号 | **カイラル（向きつき）**。$\operatorname{ind}(F^{-1})=\operatorname{ind}(F)^{-1}$ | **非負**。$h\ge0$ |
| 値域 | $\mathbb{Q}_{>0}\cong\Lambda$ | $\mathbb{R}_{\ge0}$ |
| 合成 | 乗法的（完全に加法的な準同型） | 劣加法的のみ |
| 計算 | **決定可能** | **一般に計算不能** |
| 分類能力 | 1 次元 QCA の完全不変量 | 不変量だが不完全 |

> **仮説 S1**: $\Lambda$ 側に落ちるのは**符号つき（カイラル）な量**であり、
> $\mathbb{R}$ 側に残るのは**符号なし（総量）な量**である。
> $\rho(\log\operatorname{ind})$ が「正味の流れ」、$h$ が「総流量」に対応し、差は
> 左右両方向へ同時に広がる成分（$\operatorname{ind}$ には現れず $h$ には現れる部分）を測る。

**この構造は `R-Lambda-duality` の対比と同型である**:

| | $\Lambda$ 側 | $\mathbb{R}$ 側 |
|---|---|---|
| `R-Lambda-duality` | $M=\sum_p\min_i v_p(\lambda_i)\ell_p$（$\min$-$v_p$、符号つき付値） | $\log_{\mathbb{R}}\lambda_{\max}$（$\max$-$\|\cdot\|_\infty$、非負の大きさ） |
| 本種 | $\log\operatorname{ind}$（カイラル、決定可能） | $h$（非負、計算不能） |

**両者は「同一対象に対する二つの付値汎関数」という同じ形をしている。**
これが偶然か構造的かを決めるのが本種の目標。

## 4. $\Lambda\to\overline{\mathbb{Q}}\to\mathbb{R}$ の階段（既存の物理的実例）

経路 D の文献が、**この階段をすでに物理的に実現している**（[`survey/04`](../survey/04_経路D_量子CA_指数理論と作用素代数.md) §4）：

| 舞台 | 不変量 | 値域 | 帰属 |
|---|---|---|---|
| テンソル積 Hilbert 空間（可逆対称性） | GNVW 指数 | $\mathbb{Q}_{>0}$ | **$\Lambda$** |
| 融合圏スピン鎖（非可逆対称性） | 指数 | 量子次元の生成群（例 $\sqrt2$） | **$\overline{\mathbb{Q}}$** |
| 3 次元 Clifford QCA | Witt 群の元 | 有限群 | 有限 |
| 2+1 次元境界の位相秩序 | $c_-\bmod 8$ | 有限群 | 有限 |
| 連続極限（CFT） | 中心電荷 $c$ | $\mathbb{R}$（有理 CFT なら $\mathbb{Q}$） | $\mathbb{R}$ |

**「非可逆対称性を入れると $\Lambda$ から $\overline{\mathbb{Q}}$ へ上がる」**という明確な段差がある。
これは `docs/context/01` の決定可能性の梯子（$\Lambda\prec\overline{\mathbb{Q}}\prec\mathbb{R}$）の
**物理側からの独立な再発見**であり、リポジトリの哲学に対する外部からの支持である。

**未検討の問い**: 中心電荷 $c$ は連続極限で初めて $\mathbb{R}$ になるが、
その手前（格子上）ではすべて可算な不変量で書けている。
**$c$ を「$\Lambda$ 値・$\overline{\mathbb{Q}}$ 値の格子不変量の極限」として構成し直せるか。**
これは `docs/context/03` の課題 4.6 そのもの。

## 5. 最初の検算

```text
対象: シフト、恒等写像、Rule 90、Rule 150、Rule 54（第二種可逆化）、
      ブロック CA（YB 写像由来のもの）

各対象について 3 つの量を求め、表にする:
  (1) log ind(F) ∈ Λ        … 可逆 CA のみ。QCA としての実装を明示すること
  (2) h(F)                   … 線形なら閉じた公式、非線形は数値上界のみ
  (3) M(F) ∈ Λ⊗ℚ            … 有限 L の charpoly の Newton 多角形（種 S6 のコードを流用）

確認すべきこと:
  - シフトで (1) と (2) が ρ を通して一致するか（既に手計算で一致）
  - 有限深さ回路（ind=1）で h > 0 になる例があるか
    → あれば h ≠ ρ(log ind) が確定し、差が何かを問う段階へ進む
  - M(F) が (1)(2) と独立か（可逆 CA では M=0 なので独立性は強く示唆される）
```

## 6. 潰れ方（リスク）

| リスク | 内容 | 対処 |
|---|---|---|
| **既知** | GNVW 論文自体が指数とエントロピー輸送の関係を論じている可能性が高い | **GNVW 原論文の精読が必須**。ここが最大の重複リスク |
| 定義の噛み合わせ | 古典可逆 CA を QCA として実装する方法が一意でない | 実装（置換ユニタリ）を明示的に固定する。指数が実装に依らないことを確認 |
| 適用範囲の狭さ | 指数は可逆 CA にしか定義されず、Rule 90 のような非可逆 CA では比較できない | 非可逆側は $M$ と $\Phi_N$ で見る（種 S6）。3 量が全部揃うのは可逆 CA だけと割り切る |
| 三者無関係 | 3 つの量が単に無関係 | それも結論。「$\Lambda$ 値不変量は複数あり互いに独立」は台帳に載せる価値がある |
| 中心電荷の部分 | §4 末尾の問いは大きすぎて検算にならない | 長期課題として `docs/context/03` の課題表に置くに留める |
