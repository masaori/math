# マニフェスト — 有限・可算な構造から数学を作り直す

このプロジェクトは、量子力学・場の量子論・相対論の既存形式をセルオートマトンへ移植する試みではない。
**有限の局所規則から内在的に生じる数学的構造を先に同定し、その後で既存理論との対応を検査する。**

## 研究上の前提

1. **自然現象の実体は有限、または高々可算である。**
   個々の系は有限であり、無限対象を使う場合も、まず有限対象の族とその間の写像を正本とする。
2. **実数・複素数を含む非可算な構造は、説明能力の高い道具であって、自然現象そのものとは仮定しない。**
   それらは有限・可算な実体を記述する理想化された近似でありうる。
3. **既存理論の説明能力は、その基礎的な数学構造が自然の実体であることの証拠ではない。**
   初期の地動説が既存の天動説を予測精度で直ちに凌駕したわけではなかった、という歴史的比喩を忘れない。
4. **既存の数学的道具立てそのものが、自然の記述単位としては誤っている可能性を常に残す。**
   これは既存数学の定理がその公理系の内部で誤りだという意味ではない。ヒルベルト空間、作用素代数、
   多様体、実数体などを、自然の原始的な構成要素として採用する判断が誤りうる、という意味である。
5. **セルオートマトンも正解として先取りしない。**
   有限データで局所規則を書き切れるため、有力な探索舞台として採用する。必要な構造が出ないなら、その失敗も記録する。

## 方法

- **物理の名前から逆算しない。** 「粒子」「場」「時空」「エネルギー」などの意味を局所規則へ埋め込まず、
  有限集合、写像、関係、代数、順序、作用、圏、極限系として何が生じるかを調べる。
- **CA 側を先に分類する。** 有限舞台と有限規則から得られる不変量、部分構造、合成則、因果順序、
  表現、スペクトル的データを、既存物理との対応を見ずにカタログ化する。
- **対応は後から写像として書く。** 既存理論との一致を主張するときは、対象間の写像、保存される構造、
  失われる情報、成立条件を明示する。名称の類似だけを対応の根拠にしない。
- **「近似」を数学的主張にするときは定義する。** 対象、比較写像、誤差または収束概念を与えられない段階では、
  「非可算理論は理想化された近似である」は研究上の前提であって、証明済みの定理とは呼ばない。
- **有限・可算側で閉じる範囲を最大化する。** 非可算な対象へ移る箇所では、何を得るために移り、
  どの情報と決定可能性を失うかを記録する。
- **記号だけで母集合を判別できるようにする。** 構造化論文で角括弧の区間記法を使う場合は、
  自然数区間を $[a,b]_{\mathbb{N}}$ と書くなど、必ず母集合を添字で示す。実数区間と同形の
  無添字記法を、地の文による断りだけで別の意味へ流用しない。
- **反証を保存する。** 数値検証、形式検証、既存研究との照合で仮説が崩れた場合も、条件と反例を成果として残す。

## 成功条件

このプロジェクトの成功は、既存物理をそれらしく再現する図を作ることではない。次を満たすことで判定する。

- 有限の舞台・状態・局所規則から、物理的意味付けに依存しない数学的対象が定義されている。
- その主張が構造化テキスト、人手証明、厳密な数値検証、形式検証の対応した形で残っている。
- どの段階まで有限または可算で閉じ、どこで非可算な理想化へ移ったかが追跡できる。
- 既存理論との比較が、明示的な写像と保存・欠落する構造によって述べられている。
- 既存理論に対応物がない CA 内在構造を、失敗として捨てずに独立の候補として扱っている。

**目標は、既存の数学で自然を説明し直すことではなく、有限・可算な実体から必要な数学を作り直せるかを検証することである。**
