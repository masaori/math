## 対象表

`status` は `todo` / `構造化記述まで` / `SageMath まで` / `Lean 具体版まで` / `done` のいずれか。
数学的命題の `done` は四層が揃った場合だけ付ける。

| 対象 | 問うこと | status |
| --- | --- | --- |
| 本質的依存台の有限決定 | 局所真理値表のある近傍元を反転して出力が変わるかという有限検査が、その元への本質的依存と同値か | done |
| 冗長近傍からの独立性 | 局所規則を使わない元を近傍へ追加しても本質的依存台が変わらないか | done |
| 時間展開上の直接依存 | 有限舞台と有限時間区間から、イベントの有限集合と一段の依存関係を定義できるか | SageMath まで |
| 依存の推移閉包の反対称性 | 一段の依存で時間が増えることだけから、到達可能性が部分順序になるか | todo |
| 有限伝播境界 | 有限近傍から、有限時刻後の依存元が有限個に限られることを示せるか | todo |
| 依存順序から得る部分構造 | 順序凸部分集合、非比較関係、境界を CA 内在的な対象として定義し分類できるか | todo |
| 既存因果構造との比較 | 上で得た構造と causal set / net 的構造の間の写像、保存量、欠落情報は何か | todo |
