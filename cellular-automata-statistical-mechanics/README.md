# cellular-automata-statistical-mechanics

**2値セルオートマトンの規則と、統計力学／場の量子論の代数構造との対応を探す。**

> 可算コア／$\mathbb{R}$ 脱出という本リポジトリの立場の一次情報は
> [`docs/discussion/対数順序群上の統計力学/`](../docs/discussion/対数順序群上の統計力学/) と
> [`docs/discussion/可算性の効用/`](../docs/discussion/可算性の効用/)。

## ゴール設定

### 問い

セルオートマトン（CA）の**規則**——すなわち

- 舞台となる**グラフ形状**（$\mathbb{Z}$、$\mathbb{Z}^d$、Cayley グラフ、非従順グラフ、有限グラフ）
- **近傍**（どのセルを見るか。半径・形状）
- **状態集合**（本プロジェクトは 2 値 $\{0,1\}$ を基本とする）
- **時間発展の規則**（局所写像 $f$、同期/ブロック更新、可逆/非可逆、決定論/確率的）

——と、統計力学・場の量子論に現れる**作用素・代数構造**——すなわち

- 転送行列、$R$ 行列、Boltzmann 重み、保存量の代数、局所作用素代数、指数・不変量

——との間に、**体系的な対応関係のパターンがあるか**。あるならその辞書を書き下す。

### スタンス（可算コアと $\mathbb{R}$ 脱出）

- **理論のコアは可算側（$\mathbb{N}\subset\mathbb{Q}\subset\Lambda\subset\overline{\mathbb{Q}}$）で書く。**
  CA はこの方針にとって**理想的な題材**である：状態集合が有限、規則が有限記号、履歴の数え上げが
  $\mathbb{N}$ 値、分配関数が $\{0,1\}$ 成分行列のトレース。**格子模型のうち $\mathbb{R}$ を最初から
  必要としない部分だけを取り出した対象**とみなせる。
- $\mathbb{R}$ への脱出は「応用のための便宜」として扱い、$\mathbb{R}$ 脱出の箇所と理由を必ず明示する
  （[`docs/discussion/対数順序群上の統計力学/README.md`](../docs/discussion/対数順序群上の統計力学/README.md)）。
- 逆向きの作業も行う：物理側の道具（Hilbert 空間、作用素代数、中心電荷、経路積分）を
  **可算側で特徴づける**（[`docs/research/場の量子論の数学的定式化/10_可算性から見た場の量子論.md`](../docs/research/場の量子論の数学的定式化/10_可算性から見た場の量子論.md) の課題表を更新していく）。

### 何をもって成果とするか

現段階は**探索フェーズ**である。成果は次の 3 種類。

1. **辞書（対応表）** — CA の構成要素 ↔ 物理側の対象 ↔ 代数構造 ↔ 帰属（$\mathbb{N}/\mathbb{Q}/\Lambda/\overline{\mathbb{Q}}/\mathbb{R}$）。
   → [`docs/survey/全体像_接続経路の地図.md`](docs/survey/全体像_接続経路の地図.md) 「対応辞書（暫定版）」節
2. **アイディアの種** — 命題になる前の仮説。各種に「主張の骨子／なぜ $\Lambda$ 側か／最初の検算／潰れ方」を付ける。
   → [`docs/ideas/`](docs/ideas/)
3. **命題候補** — 種のうち検算を通ったものを、帰属と脱出点を明示した statement に昇格させる。

**件数ではなく、「既存研究と重複せず、可算側で厳密化でき、最初の一手が具体的に書ける」種の質で評価する。**

### やらないこと

- CA の計算万能性・複雑性クラス分類そのもの（Wolfram クラス、Rule 110 万能性）は、
  代数構造との対応に効く範囲でのみ触れる。
- 数値シミュレーションによる現象論的探索（パターン分類、機械学習）はしない。
- 物理的解釈の哲学的議論（'t Hooft 解釈の是非、Bell 不等式）には踏み込まない。
  **代数構造の対応という数学的側面だけを扱う。**
