# 有限グラフ上の Ising 分配多項式と Fisher 零点の依存関係

## ゴール

有限グラフの組合せ入力から整数係数分配多項式を構成し、その係数・評価・因子・代数的零点を
決定可能な有限データとして追跡する。

## 依存関係

```text
有限グラフとスピン配位
└── 破れ辺集合と多重度
    └── Ising 分配多項式
        ├── 係数・次数・最大カット
        ├── 正の有理評価と順序
        ├── 整除性と零点 -1
        └── 全辺二分割と相反性
            └── 代数的 Fisher 零点の逆数軌道・重複度・積
```

## 次に進める対象

既存 51 ラベルと 32 件の SageMath 検算をレビューし、未定義概念、参照不足、検算不足があれば
新規主張より先に修正する。欠陥がなければ、全辺二分割を仮定しない一般有限グラフで意味をもつ
Fisher 零点の有限算術データを、一 tick につき一つの定義・主張・定理だけ前進させる。
