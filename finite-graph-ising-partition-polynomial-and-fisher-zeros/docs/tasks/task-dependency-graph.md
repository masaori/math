# 有限グラフ上の Ising 分配多項式と Fisher 零点の依存関係

## ゴール

有限グラフの組合せ入力から整数係数分配多項式を構成し、その係数・評価・因子・代数的零点を
決定可能な有限データとして追跡する。

## 依存関係

```text
有限グラフとスピン配位
└── 破れ辺集合と多重度
    └── Ising 分配多項式
        ├── 係数・次数・最大カット
        │   └── 一般有限グラフの Fisher 零点積と両端係数比
        ├── 正の有理評価と順序
        ├── 整除性と零点 -1
        └── 全辺二分割と相反性
            └── 代数的 Fisher 零点の逆数軌道・重複度・積
```

## 次に進める対象

移設後の独立性レビューと、一般有限グラフの重複度込み Fisher 零点積を両端係数比で与える定理は完了した。
次は、その定数項が正であることから零が Fisher 零点として現れないことを一つの定理として進める。
以後も、全辺二分割を仮定しない一般有限グラフで意味をもつ Fisher 零点の有限算術データを、
一 tick につき一つの定義・主張・定理だけ前進させる。
