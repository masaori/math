## ゴール

**3 次元 Ising 模型の臨界点を、実数として置かず、有理数の二つの集合（切断）として定める。**
どちらの集合も「有限のデータについての有理数の不等式が成り立つこと」で定義し、
その所属を有限の計算で判定できる形にする。

到達したい形は次である。

1. **低温側**：有限箱の数え上げから、箱の大きさに依らない一様な有理数の不等式を導く証拠の族を定め、
   その族が捉える有理数の集合を確定する。
2. **高温側**：整係数多項式の比についての有理数の不等式 1 本で書ける証拠の族を定め、
   その族が上向きに閉じることを可算側の議論で示す。
3. **未解決問題**：両側が $\mathbb{Q}\cap(0,1)$ の高々 1 元を除く全体を覆うか。
   覆えて初めて「切断が定まった」と言える。**現状は覆えていない。**

## 立場（このプロジェクトの根幹。姉妹プロジェクトより強い）

**明示的に宣言した脱出箇所以外では、$\mathbb{R}/\mathbb{C}$ を正当化されたものとして使わない。
そこに属する数のようなものを、定義・命題・証明の論理に一切登場させない。**

**許される非可算への脱出は、有限格子の量の列について箱の大きさを大きくする極限だけである。**

| | 道具 | 扱い |
| --- | --- | --- |
| ○ | 有限集合の数え上げ、有限和・有限積 | 土台。$\mathbb{N}$ |
| ○ | 整係数多項式環 $\mathbb{Z}[x]$、有理関数体 $\mathbb{Q}(x)$、有理数の不等式 | 土台 |
| ○ | 素因数分解と対数順序群 $\Lambda$、代数的数 $\overline{\mathbb{Q}}$ | 可算な拡大 |
| △ | 箱の大きさの極限 | **唯一の許される脱出。** 宣言して 1 回だけ取る |
| ✗ | 上限・下限（完備性）、積分、微分、無限和・級数 | 箱の大きさの極限ではない |
| ✗ | 指数関数・実対数、$x=e^{-2\beta J}$ の代入、逆温度の記号 | 同上 |
| ✗ | 乱流（random current）表現 | 重みに指数と無限和を含む |
| ✗ | 相・臨界温度・自発磁化などの無限体積の語を主張に使うこと | 極限を取る主張を別に立てるまで使わない |

$\mathbb{R}$ 側の定理は**辞書**として別に書く。動機づけと比較のために書き、
本文の命題の前提にも根拠にもしない。**$\mathbb{R}$ 側の定理から含意を借りない。**

## 記述の規則

- **正本は構造化テキスト**（`structured-latex/content/`）。Typst では書かない。
- **一ステップ一定理**。式変形を省略せず、根拠を行末に $(\because\ \dots)$ で書く。
  本文で示した定義・主張の適用には `\blkref{<ラベル>}` でラベル参照を付ける。
- **記号の濫用を排除する。** 1 記号 1 意味。多項式とその値を区別する。
  同一視を「みなす」で済ませず、写像に名前を付ける。
- **住処 `habitat` を宣言する**（型と実行時検査で強制される）。
  非可算を宣言したら `realEscape` が必須。可算なら書けない。
- **未証明を未証明と書く。** 証明が書けていない主張は `todo` を残し、
  それに依存する主張には依存していることを明記する。
- 規則の正本は [docs/context/証明の書き方.md](../docs/context/証明の書き方.md) である。

## 構成と検証コマンド

```text
critical-point-cut-of-3d-ising/
├── README.md                  # このファイル（ゴールと立場）
├── MEMORY.md                  # 引き継ぎメモ
├── structured-latex/          # 証明の正本（構造化テキスト）
├── sagemath/                  # 厳密計算による裏取り
├── docs/tasks/                # 自動ループの手順書と状態台帳
├── scripts/                   # 自動ループの起動スクリプト
└── logs/                      # 実行ログ（git 管理外）
```

```sh
(cd structured-latex && npm run gen)      # ラベル・集約モジュールの再生成
(cd structured-latex && npm run check)    # 生成物の鮮度 → 型検査 → 実行時検証 → ノート非混入
(cd structured-latex && npm run build:pdf) # PDF を作る（tectonic が必要）
node sagemath/tools/verify-check-linkage.ts # 検証 ↔ 証明の対応
```

初回のみ `(cd structured-latex && pnpm install)`（Node 22.18 以降）。
