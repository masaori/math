`done` は runbook の「セクション完了の条件」を満たしたときだけ書く。

| --- | --- | --- |
| 極小分離集合の指数上界 | 極小分離集合が連結であることを示し、辿る対応で個数を $C^n$ で抑える。定数 $C$ を具体的な自然数として決める（`claim_minimal_separating_growth` の `todo` を消す） | todo |
| Peierls の反転写像 | 極小分離集合の内側を反転する写像が単射であり、破れ数をちょうど $\#F$ 減らすことを示して `claim_peierls_bound` を証明する | todo |
| 低温側の証拠の数値的な裏取り | 小さい箱で $R_L(q)$ と分離集合の数え上げを厳密に計算し、本文の不等式が成り立つことを確かめる（SageMath。`ZZ`/`QQ` のみ） | todo |
| 高温側の証拠の定義 | 有限集合 $S$ 上の $\Phi_S\in\mathbb{Q}(x)$ を、分子・分母が $\mathbb{Z}[x]$ に属する形で定義し、検査が有理数の不等式 1 本になることを示す | todo |
| 高温側の証拠の単調性 | $\Phi_S$ が $x$ について非増加であることを $\mathbb{Z}[x]$ の係数の議論で示す（$\mathbb{R}$ 側の相関不等式に頼らない） | todo |
| 高温側の有理点の集合が上向きに閉じること | 上の単調性から、高温側の集合が上向きに閉じることを示す | todo |
| 両側が重ならないこと | 低温側と高温側の証拠が同じ有理数に同時に付かないことを示す（付いたら本文の不等式が矛盾する） | todo |
| 覆うことの現状の記録 | どの有理数にどちらの証拠も付かないかを、具体的な有理数の範囲として記録する。未解決問題の輪郭を数値で示す | todo |
